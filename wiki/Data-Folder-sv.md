# Datamapp

[← Home](Home-sv)

Allt finns i mappen `data` bredvid programmet (`C:\E-LAYER-ANALYZER\data`, `~/E-LAYER-ANALYZER/data`). Ingenting i AppData.

| Fil / mapp | Innehåll |
|---|---|
| `ela.ini` | Inställningar för E-LAYER ANALYZER (station, sessioner, vyer) |
| `config.ini` | Inställningar för YA-MS, språk och färgschema |
| `call3.txt`, `call3_nuovi.txt` | Databas anropssignal → lokator och lokatorer inlärda från spots |
| `spot/` | Insamlade spots, en CSV per dag |
| `log/` | Hämtad LoTW-rapport |
| `swpc/` | Data från NOAA (oval, Kp, solvind) |
| `mappa/` | Kustlinjer och gränser från Natural Earth |
| `igrf14.csv` | Koefficienter för magnetfältsmodellen IGRF-14 |
| `lingue/` | Översättningar |
| `ela_documento_tecnico*`, `ela_manuale*`, `ela_relazione*` (.txt/.docx), `ela_fonti*.txt` | Sammanfattning av beräkningsvalen, användarhandbok, teknisk rapport och källor på alla språk |
