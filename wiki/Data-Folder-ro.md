# Dosarul de date

[← Home](Home-ro)

Totul se află în dosarul `data` de lângă program (`C:\E-LAYER-ANALYZER\data`, `~/E-LAYER-ANALYZER/data`). Nimic în AppData.

| Fișier / dosar | Conținut |
|---|---|
| `ela.ini` | Setările E-LAYER ANALYZER (stație, sesiuni, vederi) |
| `config.ini` | Setările YA-MS, limba și schema de culori |
| `call3.txt`, `call3_nuovi.txt` | Baza de date indicativ → locator și locatoarele învățate din spoturi |
| `spot/` | Spoturi colectate, un CSV pe zi |
| `log/` | Raportul LoTW descărcat |
| `swpc/` | Date NOAA (oval, Kp, vânt solar) |
| `mappa/` | Linii de coastă și granițe Natural Earth |
| `igrf14.csv` | Coeficienții modelului magnetic IGRF-14 |
| `lingue/` | Traduceri |
| `ela_documento_tecnico*`, `ela_manuale*`, `ela_relazione*` (.txt/.docx), `ela_fonti*.txt` | Sinteza alegerilor de calcul, manualul de utilizare, raportul tehnic și sursele în fiecare limbă |
