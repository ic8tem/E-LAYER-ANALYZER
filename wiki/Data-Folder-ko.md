# 데이터 폴더

[← Home](Home-ko)

모든 것은 프로그램 옆의 `data` 폴더(`C:\E-LAYER-ANALYZER\data`, `~/E-LAYER-ANALYZER/data`)에 있습니다. AppData에는 아무것도 없습니다.

| 파일 / 폴더 | 내용 |
|---|---|
| `ela.ini` | E-LAYER ANALYZER 설정(국, 세션, 보기) |
| `config.ini` | YA-MS 설정, 언어, 색 구성 |
| `call3.txt`, `call3_nuovi.txt` | 호출부호 → 로케이터 데이터베이스와 스폿에서 학습한 로케이터 |
| `spot/` | 수집된 스폿, 하루 하나의 CSV |
| `log/` | 다운로드한 LoTW 리포트 |
| `swpc/` | NOAA 데이터(오벌, Kp, 태양풍) |
| `mappa/` | Natural Earth 해안선과 국경 |
| `igrf14.csv` | IGRF-14 자기장 모델 계수 |
| `lingue/` | 번역 |
| `ela_documento_tecnico*`, `ela_manuale*`, `ela_relazione*` (.txt/.docx), `ela_fonti*.txt` | 언어별 계산 선택 요약, 사용 설명서, 기술 보고서, 출처 |
