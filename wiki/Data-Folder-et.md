# Andmekaust

[← Home](Home-et)

Kõik asub programmi kõrval olevas kaustas `data` (`C:\E-LAYER-ANALYZER\data`, `~/E-LAYER-ANALYZER/data`). AppData kausta ei kasutata.

| Fail / kaust | Sisu |
|---|---|
| `ela.ini` | E-LAYER ANALYZERi seaded (jaam, seansid, vaated) |
| `config.ini` | YA-MS-i seaded, keel ja värviskeem |
| `call3.txt`, `call3_nuovi.txt` | Andmebaas kutsung → lokaator ja spotidest õpitud lokaatorid |
| `spot/` | Kogutud spotid, üks CSV päevas |
| `log/` | Allalaaditud LoTW aruanne |
| `swpc/` | NOAA andmed (ovaal, Kp, päikesetuul) |
| `mappa/` | Natural Earthi rannajooned ja piirid |
| `igrf14.csv` | Magnetmudeli IGRF-14 koefitsiendid |
| `lingue/` | Tõlked |
| `ela_documento_tecnico*`, `ela_manuale*`, `ela_relazione*` (.txt/.docx), `ela_fonti*.txt` | Arvutusvalikute kokkuvõte, kasutusjuhend, tehniline aruanne ja allikad kõigis keeltes |
