# Тека даних

[← Home](Home-uk)

Усе міститься в теці `data` поруч із програмою (`C:\E-LAYER-ANALYZER\data`, `~/E-LAYER-ANALYZER/data`). Нічого в AppData.

| Файл / тека | Вміст |
|---|---|
| `ela.ini` | Налаштування E-LAYER ANALYZER (станція, сесії, вигляди) |
| `config.ini` | Налаштування YA-MS, мова і колірна схема |
| `call3.txt`, `call3_nuovi.txt` | База «позивний → локатор» і локатори, отримані зі спотів |
| `spot/` | Зібрані споти, один CSV на добу |
| `log/` | Завантажений звіт LoTW |
| `swpc/` | Дані NOAA (овал, Kp, сонячний вітер) |
| `mappa/` | Берегові лінії та кордони Natural Earth |
| `igrf14.csv` | Коефіцієнти магнітної моделі IGRF-14 |
| `lingue/` | Переклади |
| `ela_documento_tecnico*`, `ela_manuale*`, `ela_relazione*` (.txt/.docx), `ela_fonti*.txt` | Зведення розрахункових рішень, посібник користувача, технічний звіт і джерела всіма мовами |
