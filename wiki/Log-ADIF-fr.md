# LOG ADIF

[← Home](Home-fr)

![LOG ADIF](https://raw.githubusercontent.com/ic8tem/E-LAYER-ANALYZER/ci-screenshots/6_log_adif.png)

- **Ouvrir un fichier ADIF...** (plusieurs fichiers possibles) ou **Télécharger depuis LoTW...** (nom d'utilisateur et mot de passe ; le mot de passe n'est jamais enregistré).
- Un onglet pour chaque bande **à partir de 28 MHz**, chacune séparément, **sans agrégation** ; à côté : carrés contactés / confirmés.
- Couleurs : **orange** = contacté, **bleu** = confirmé par QSL, **vert** = confirmé via LoTW.
- Filtre sur le **mode de propagation** du log (PROP_MODE : ES, FAI, AUR/AUE, MS, TR, EME, F2).
- Clic sur un carré : liste des QSO avec date, heure, mode et confirmation, distance et azimut.
- **Effacer la mémoire** : retire les fichiers ouverts et le rapport LoTW.
