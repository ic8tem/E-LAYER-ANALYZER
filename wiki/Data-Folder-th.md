# โฟลเดอร์ข้อมูล

[← Home](Home-th)

ทุกอย่างอยู่ในโฟลเดอร์ `data` ข้างโปรแกรม (`C:\E-LAYER-ANALYZER\data`, `~/E-LAYER-ANALYZER/data`) ไม่มีสิ่งใดใน AppData

| ไฟล์ / โฟลเดอร์ | เนื้อหา |
|---|---|
| `ela.ini` | การตั้งค่าของ E-LAYER ANALYZER (สถานี เซสชัน มุมมอง) |
| `config.ini` | การตั้งค่าของ YA-MS ภาษา และชุดสี |
| `call3.txt`, `call3_nuovi.txt` | ฐานข้อมูลสัญญาณเรียกขาน → locator และ locator ที่เรียนรู้จากสปอต |
| `spot/` | สปอตที่เก็บได้ วันละหนึ่งไฟล์ CSV |
| `log/` | รายงาน LoTW ที่ดาวน์โหลดมา |
| `swpc/` | ข้อมูล NOAA (วงรี Kp ลมสุริยะ) |
| `mappa/` | แนวชายฝั่งและพรมแดนจาก Natural Earth |
| `igrf14.csv` | สัมประสิทธิ์ของแบบจำลองสนามแม่เหล็ก IGRF-14 |
| `lingue/` | คำแปล |
| `ela_documento_tecnico*`, `ela_manuale*`, `ela_relazione*` (.txt/.docx), `ela_fonti*.txt` | สรุปทางเลือกในการคำนวณ คู่มือผู้ใช้ รายงานทางเทคนิค และแหล่งอ้างอิงในทุกภาษา |
