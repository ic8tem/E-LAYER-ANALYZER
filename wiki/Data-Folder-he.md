# תיקיית הנתונים

[← Home](Home-he)

הכול נמצא בתיקיית `data` שליד התוכנה (`C:\E-LAYER-ANALYZER\data`, ‏`~/E-LAYER-ANALYZER/data`). שום דבר ב-AppData.

| קובץ / תיקייה | תוכן |
|---|---|
| `ela.ini` | הגדרות E-LAYER ANALYZER (תחנה, חיבורים, תצוגות) |
| `config.ini` | הגדרות YA-MS, שפה וערכת צבעים |
| `call3.txt`, `call3_nuovi.txt` | מסד נתונים אות קריאה → לוקייטור, ולוקייטורים שנלמדו מספוטים |
| `spot/` | ספוטים שנאספו, CSV אחד ליום |
| `log/` | דוח LoTW שהורד |
| `swpc/` | נתוני NOAA (אליפסה, Kp, רוח השמש) |
| `mappa/` | קווי חוף וגבולות של Natural Earth |
| `igrf14.csv` | המקדמים של המודל המגנטי IGRF-14 |
| `lingue/` | תרגומים |
| `ela_documento_tecnico*`, `ela_manuale*`, `ela_relazione*` (.txt/.docx), `ela_fonti*.txt` | סיכום בחירות החישוב, מדריך למשתמש, דוח טכני ומקורות בכל השפות |
