# 首次啟動

[← Home](Home-zh-TW)

1. 在頂部輸入**呼號**、**網格座標**（6 個字元，例如 JN70CN）和以公尺為單位的**高度**，然後按**套用**。
2. 在右上角選擇**語言**和**配色方案**（視窗會立即重建）。
3. 前往 **DATA COLLECTION > Telnet 連線**：檢查三個連線的主機、連接埠和指令，然後按**連線**。勾選**啟動時連線**後，它們會自動開啟。
4. 幾分鐘後，spot 就會出現在 **SPORADIC-E**、**F.A.I.** 和 **AURORA** 中。

## 地圖

- 滑鼠**滾輪**：以游標為中心放大。
- 按住左鍵**拖曳**：移動地圖。
- 右上角：游標下方位置的座標和網格座標。
- **歐洲** / **世界**按鈕：初始視圖。
- 每個含地圖的頁面都以 65 % 給地圖、35 % 給資料；分隔線可以拖曳。
