# Φάκελος δεδομένων

[← Αρχική](Home-el)

Όλα βρίσκονται στον φάκελο `data` δίπλα στο πρόγραμμα (`C:\E-LAYER-ANALYZER\data`, `~/E-LAYER-ANALYZER/data`). Τίποτα στο AppData.

| Αρχείο / φάκελος | Περιεχόμενο |
|---|---|
| `ela.ini` | Ρυθμίσεις του E-LAYER ANALYZER (σταθμός, συνεδρίες, προβολές) |
| `config.ini` | Ρυθμίσεις του YA-MS, γλώσσα και χρωματικό σχήμα |
| `call3.txt`, `call3_nuovi.txt` | Βάση δεδομένων διακριτικό κλήσης → locator και locator που μαθεύτηκαν από τα spot |
| `spot/` | Συλλεγμένα spot, ένα CSV ανά ημέρα |
| `log/` | Αναφορά LoTW που ελήφθη |
| `swpc/` | Δεδομένα NOAA (ωοειδές, Kp, ηλιακός άνεμος) |
| `mappa/` | Ακτογραμμές και σύνορα Natural Earth |
| `igrf14.csv` | Συντελεστές του μαγνητικού μοντέλου IGRF-14 |
| `lingue/` | Μεταφράσεις |
| `ela_documento_tecnico*`, `ela_manuale*`, `ela_relazione*` (.txt/.docx), `ela_fonti*.txt` | Σύνοψη των επιλογών υπολογισμού, εγχειρίδιο χρήσης, τεχνική έκθεση και πηγές σε κάθε γλώσσα |
