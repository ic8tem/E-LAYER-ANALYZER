# Folder data

[← Home](Home-id)

Semuanya ada di folder `data` di samping program (`C:\E-LAYER-ANALYZER\data`, `~/E-LAYER-ANALYZER/data`). Tidak ada apa pun di AppData.

| File / folder | Isi |
|---|---|
| `ela.ini` | Pengaturan E-LAYER ANALYZER (stasiun, sesi, tampilan) |
| `config.ini` | Pengaturan YA-MS, bahasa dan skema warna |
| `call3.txt`, `call3_nuovi.txt` | Basis data callsign → locator dan locator yang dipelajari dari spot |
| `spot/` | Spot terkumpul, satu CSV per hari |
| `log/` | Laporan LoTW yang diunduh |
| `swpc/` | Data NOAA (oval, Kp, angin surya) |
| `mappa/` | Garis pantai dan perbatasan Natural Earth |
| `igrf14.csv` | Koefisien model magnetik IGRF-14 |
| `lingue/` | Terjemahan |
| `ela_documento_tecnico*`, `ela_manuale*`, `ela_relazione*` (.txt/.docx), `ela_fonti*.txt` | Ringkasan pilihan perhitungan, panduan penggunaan, laporan teknis dan sumber dalam setiap bahasa |
