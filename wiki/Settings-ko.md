# 설정

[← Home](Home-ko)

버전 0.4.18부터 **설정** 탭에는 프로그램의 일반 옵션과 탭 사이의 스폿 분류가 모여 있습니다. 하위 탭이 두 개 있습니다.

## 일반

| 항목 | 설정 내용 |
|---|---|
| 국 | 호출부호, 로케이터, 고도로, 상단 표시줄과 같습니다; **적용**으로 모든 탭에 확정합니다. |
| 모양 | 언어, 색 구성, **프로그램 전체의 글꼴 크기**(85-140 %, YA-MS와 같음). 언어와 색을 바꾸면 창이 다시 만들어집니다: 설정과 스폿은 유지됩니다. |
| 지도와 예보 데이터 | 대륙으로, 탭 표시줄의 메뉴와 같습니다. |
| 시각 | NTP 상태와 서버 시각과 PC 시계의 차이. |
| 업데이트 | 시작할 때와 6시간마다의 GitHub 확인, 자동·무음 업데이트, **지금 확인** 버튼. 자동 업데이트는 시스템 패키지(.deb, .rpm, Arch, Slackware)에는 적용되지 않습니다. |
| 데이터 | `data` 폴더를 여는 버튼. Bureau of Meteorology의 API 키는 계속 DATA COLLECTION › 전파 데이터에 있습니다. |

## 스폿 분류

왼쪽 표에는 프로그램이 각 스폿을 어디로 보낼지 정하는 규칙이 **적용되는 순서대로** 나열됩니다: 처음 해당하는 규칙이 탭을 정합니다. 표시되는 값은 필터에 설정한 값입니다.

| # | 스폿이... | 보내는 곳 |
|---|---|---|
| 1 | 로컬 필터 범위 밖에 있음 (27990 kHz 미만 또는 145 MHz 초과; 430-440 MHz는 오로라만) | 버림 |
| 2 | AUE, AU-E 또는 AURORAL E를 포함함 | AURORA (오로라 E) |
| 3 | 오로라 단어를 포함함 (기본값 AU, AUR) | AURORA |
| 4 | F.A.I. 단어를 포함함 (기본값 FAI; 밴드 6, 4, 2 m: F.A.I.는 432 MHz에 이르지 않음) | F.A.I. |
| 5 | 유성 산란 모드 또는 `<MS>`가 있음 | METEOR SCATTER |
| 6 | 밴드플랜의 MS 구간에 있음 (50 MHz에서는 배타적이지 않음; 50·70 MHz의 FT8과 FT4는 제외) | METEOR SCATTER |
| 7 | 50 MHz의 FT8 또는 FT4이며 4분 이내에 중간점이 150 km 이내인 다른 스폿이 없음 | 유성 산란 (스포라딕 E 아님) |
| 8 | 144 MHz의 Q65 또는 JT65임 (`<ES>`가 있으면 제외) | EME: 버림 |
| 9 | 다른 전파 표기를 포함함 | 스포라딕 E 아님 |
| 10 | 적도 횡단임 | 스포라딕 E 아님 (TEP) |
| 11-15 | 28, 40, 50, 70 또는 144 MHz에서 거리 규칙에 맞음 | SPORADIC-E |
| 16 | 어떤 규칙에도 해당하지 않음 (대류권, 432 MHz, HF...) | 탭 없음 (수집된 스폿에 남음) |

오른쪽에는 **로컬 필터**와 각 모드의 필터가 다섯 개의 하위 탭에 있습니다: 유성 산란(YA-MS의 필터는 METEOR SCATTER 탭에서 설정), 스포라딕 E, F.A.I., 오로라, 그리고 **필터 테스트**로, 클러스터 줄을 붙여 넣으면 어떻게 분류되는지 볼 수 있습니다. **저자 규칙으로 복원** 버튼을 누르면 기본값으로 돌아갑니다.
