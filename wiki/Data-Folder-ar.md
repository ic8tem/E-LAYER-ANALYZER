# مجلد البيانات

[← Home](Home-ar)

كل شيء موجود في مجلد `data` بجانب البرنامج (`C:\E-LAYER-ANALYZER\data`، `~/E-LAYER-ANALYZER/data`). لا شيء في AppData.

| الملف / المجلد | المحتوى |
|---|---|
| `ela.ini` | إعدادات E-LAYER ANALYZER (المحطة، الجلسات، المناظر) |
| `config.ini` | إعدادات YA-MS، واللغة ونظام الألوان |
| `call3.txt`، `call3_nuovi.txt` | قاعدة بيانات رمز النداء → محدد الموقع، ومحددات الموقع المستفادة من البلاغات |
| `spot/` | البلاغات المجمَّعة، ملف CSV واحد لكل يوم |
| `log/` | تقرير LoTW المنزَّل |
| `swpc/` | بيانات NOAA (الحلقة الشفقية، Kp، الرياح الشمسية) |
| `mappa/` | السواحل والحدود من Natural Earth |
| `igrf14.csv` | معاملات النموذج المغناطيسي IGRF-14 |
| `lingue/` | الترجمات |
| `ela_documento_tecnico*`، `ela_manuale*`، `ela_relazione*` (.txt/.docx)، `ela_fonti*.txt` | ملخص خيارات الحساب، ودليل الاستخدام، والتقرير التقني، والمصادر بكل اللغات |
