# 開始使用

[← 首頁](Home-zh-tw)

1. 在上方輸入**呼號**、**網格座標**（6 碼，例如 JN70CN）與**高度**（公尺），然後按**套用**。
2. 在右上方選擇**語言**與**配色方案**（視窗會立即重建）。
3. 前往 **DATA COLLECTION > Telnet 連線階段**：檢查三個連線階段的主機、連接埠與指令，然後按**連線**。勾選**啟動時連線**後，它們會自動開啟。
4. 幾分鐘後，spot 就會出現在 **SPORADIC-E**、**F.A.I.** 與 **AURORA** 中。

## 地圖

- 滑鼠**滾輪**：以游標為中心放大。
- 按住左鍵**拖曳**：移動地圖。
- 右上方：游標所在點的座標與網格座標。
- **歐洲** / **全球** 按鈕：起始檢視。
- 每個有地圖的頁面都以 65 % 顯示地圖、35 % 顯示資料；分隔線可以拖曳。
