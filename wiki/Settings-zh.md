# 设置

[← Home](Home-zh)

从 0.4.18 版起，**设置** 选项卡汇集了程序的常规选项以及 spot 在各选项卡之间的分流。它有两个子选项卡。

## 常规

| 部分 | 设置内容 |
|---|---|
| 台站 | 呼号、网格坐标和高度，与顶部栏相同；**应用** 将其确认到所有选项卡。 |
| 外观 | 语言、配色（YAEC 和 YA-MS 的方案，以及从 0.5.0 版起 IP-TRX-CTRL 的六种主题：浅色、夜间、黑色、蓝色、紫色、绿色）以及**整个程序的字体大小**（85-140 %，与 YA-MS 相同）。更改语言和配色会重建窗口：设置和 spot 都会保留。 |
| 地图和预报数据 | 大洲，与选项卡栏中的菜单相同。 |
| 时间 | NTP 状态以及服务器时间与电脑时钟之差。 |
| 更新 | 启动时及每 6 小时在 GitHub 上检查、自动静默更新、**立即检查** 按钮。自动更新不适用于系统软件包（.deb、.rpm、Arch、Slackware）。 |
| 数据 | 打开 `data` 文件夹的按钮。Bureau of Meteorology 的 API 密钥仍在 DATA COLLECTION › 传播数据 中。 |

## spot 分流

左侧的表格**按应用顺序**列出程序决定每条 spot 去向的规则：第一条符合的规则决定选项卡。显示的数值是在过滤中设置的数值。

| # | 如果 spot... | 送往 |
|---|---|---|
| 1 | 超出本地过滤的范围（低于 27990 kHz 或高于 145 MHz；430-440 MHz 只限极光） | 已丢弃 |
| 2 | 含有 AUE、AU-E 或 AURORAL E | AURORA（极光 E） |
| 3 | 含有极光的词（默认 AU、AUR） | AURORA |
| 4 | 含有 F.A.I. 的词（默认 FAI；频段 6、4 和 2 m：F.A.I. 到不了 432 MHz） | F.A.I. |
| 5 | 使用流星散射模式或带有 `<MS>` | METEOR SCATTER |
| 6 | 落在频段规划的 MS 窗口内（在 50 MHz 不具排他性；50 和 70 MHz 的 FT8 和 FT4 除外） | METEOR SCATTER |
| 7 | 是 50 MHz 的 FT8 或 FT4，4 分钟内没有中点在 150 km 以内的其他 spot | 流星散射（非偶发 E 层） |
| 8 | 是 144 MHz 的 Q65 或 JT65（有 `<ES>` 时除外） | EME：已丢弃 |
| 9 | 含有其他传播方式的标注 | 非偶发 E 层 |
| 10 | 属于跨赤道传播 | 非偶发 E 层（TEP） |
| 11-15 | 在 28、40、50、70 或 144 MHz 且符合距离规则 | SPORADIC-E |
| 16 | 不符合任何规则（对流层、432 MHz、HF...） | 无选项卡（留在“已收集的 spot”中） |

右侧是**本地过滤**和各模式的过滤，分为五个子选项卡：流星散射（YA-MS 的过滤在 METEOR SCATTER 选项卡中设置）、偶发 E 层、F.A.I.、极光和**过滤器测试**，在其中粘贴一行集群数据即可看到它如何分类。**恢复作者规则** 按钮可恢复默认值。
