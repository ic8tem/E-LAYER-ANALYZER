# 出典と文書

[← Home](Home-ja)

- **出典** タブには、[1]-[66] の番号付きですべての出典が並んでいます。
- **計算上の選択の概要** タブ (旧 *技術文書*) は各計算を式とともに説明し、ラベル **出典** (出典から取った手順)、**検証** (プログラムまたは実例での確認)、**選択** (実際のバンドで確認すべきプログラム上の選択) を付けています。
- **ユーザーマニュアル** タブは、プログラムの詳細なユーザーマニュアルで、タブごとに説明しています。
- **技術報告書** タブは、プログラムの実現に至った選択を説明しています: アーキテクチャ、物理モデル、データの認識、検証、限界と今後の開発。
- 3 つの文書は同じ書式で、すべての言語に翻訳され、Word にエクスポートできます。

主な式:

- 層上の地点への仰角: `e = atan2((r+H)·cos x − (r+h), (r+H)·sin x)`、x = d / r、屈折 k = 4/3;
- セカント則: `MUF = foEs · sec φ`;
- F.A.I./オーロラの反射条件: `c(A) + c(B) = 0`、c = 視線と IGRF-14 の磁力線に垂直な面とのなす角。
