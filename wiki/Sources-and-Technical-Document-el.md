# Πηγές και έγγραφα

[← Αρχική](Home-el)

- Η καρτέλα **ΠΗΓΕΣ** παραθέτει όλες τις πηγές, αριθμημένες [1]-[63].
- Η καρτέλα **ΣΥΝΟΨΗ ΤΩΝ ΕΠΙΛΟΓΩΝ ΥΠΟΛΟΓΙΣΜΟΥ** (πρώην *Τεχνικό έγγραφο*) εξηγεί κάθε υπολογισμό με τους τύπους του και τις ετικέτες **ΠΗΓΗ** (βήμα που προέρχεται από μια πηγή), **ΕΛΕΓΧΟΣ** (επαληθευμένο στο πρόγραμμα ή σε πραγματική περίπτωση) και **ΕΠΙΛΟΓΗ** (επιλογή του προγράμματος, που πρέπει να επιβεβαιωθεί στον αέρα).
- Η καρτέλα **ΕΓΧΕΙΡΙΔΙΟ ΧΡΗΣΗΣ** είναι το αναλυτικό εγχειρίδιο χρήσης του προγράμματος, καρτέλα προς καρτέλα.
- Η καρτέλα **ΤΕΧΝΙΚΗ ΕΚΘΕΣΗ** εκθέτει τις επιλογές που οδήγησαν στη δημιουργία του προγράμματος: αρχιτεκτονική, φυσικά μοντέλα, αναγνώριση δεδομένων, επαληθεύσεις, όρια και μελλοντικές εξελίξεις.
- Τα τρία έγγραφα έχουν την ίδια μορφοποίηση, είναι μεταφρασμένα σε κάθε γλώσσα και μπορούν να εξαχθούν σε Word.

Κύριοι τύποι:

- ανύψωση προς ένα σημείο του στρώματος: `e = atan2((r+H)·cos x − (r+h), (r+H)·sin x)`, με x = d / r και διάθλαση k = 4/3·
- νόμος της τέμνουσας: `MUF = foEs · sec φ`·
- συνθήκη ανάκλασης F.A.I./σέλαος: `c(A) + c(B) = 0`, όπου c = γωνία μεταξύ της ευθείας οπτικής επαφής και του επιπέδου που είναι κάθετο στο πεδίο IGRF-14.
