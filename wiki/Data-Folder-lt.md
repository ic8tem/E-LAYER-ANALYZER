# Duomenų aplankas

[← Home](Home-lt)

Viskas yra aplanke `data` šalia programos (`C:\E-LAYER-ANALYZER\data`, `~/E-LAYER-ANALYZER/data`). AppData nenaudojamas.

| Failas / aplankas | Turinys |
|---|---|
| `ela.ini` | E-LAYER ANALYZER nustatymai (stotis, seansai, vaizdai) |
| `config.ini` | YA-MS nustatymai, kalba ir spalvų schema |
| `call3.txt`, `call3_nuovi.txt` | Duomenų bazė šaukinys → lokatorius ir iš spotų išmokti lokatoriai |
| `spot/` | Surinkti spotai, po vieną CSV per dieną |
| `log/` | Atsisiųsta LoTW ataskaita |
| `swpc/` | NOAA duomenys (ovalas, Kp, Saulės vėjas) |
| `mappa/` | Natural Earth pakrantės ir sienos |
| `igrf14.csv` | Magnetinio modelio IGRF-14 koeficientai |
| `lingue/` | Vertimai |
| `ela_documento_tecnico*`, `ela_manuale*`, `ela_relazione*` (.txt/.docx), `ela_fonti*.txt` | Skaičiavimo sprendimų santrauka, naudotojo vadovas, techninė ataskaita ir šaltiniai visomis kalbomis |
