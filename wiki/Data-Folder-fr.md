# Dossier des données

[← Home](Home-fr)

Tout se trouve dans le dossier `data` à côté du programme (`C:\E-LAYER-ANALYZER\data`, `~/E-LAYER-ANALYZER/data`). Rien dans AppData.

| Fichier / dossier | Contenu |
|---|---|
| `ela.ini` | Réglages d'E-LAYER ANALYZER (station, sessions, vues) |
| `config.ini` | Réglages de YA-MS, langue et schéma de couleurs |
| `call3.txt`, `call3_nuovi.txt` | Base indicatif → locator et locators appris dans les spots |
| `spot/` | Spots collectés, un CSV par jour |
| `log/` | Rapport LoTW téléchargé |
| `swpc/` | Données de la NOAA (ovale, Kp, vent solaire) |
| `mappa/` | Côtes et frontières Natural Earth |
| `igrf14.csv` | Coefficients du modèle magnétique IGRF-14 |
| `lingue/` | Traductions |
| `ela_documento_tecnico*`, `ela_manuale*`, `ela_relazione*` (.txt/.docx), `ela_fonti*.txt` | Synthèse des choix de calcul, manuel d'utilisation, rapport technique et sources dans toutes les langues |
