# LOG ADIF

[← Home](Home-tl)

![LOG ADIF](https://raw.githubusercontent.com/ic8tem/E-LAYER-ANALYZER/ci-screenshots/6_log_adif.png)

- **Buksan ang ADIF file...** (puwede ang ilang file) o **I-download mula sa LoTW...** (username at password; hindi kailanman sine-save ang password).
- Isang tab para sa bawat banda **mula 28 MHz pataas**, bawat isa ay hiwalay, **nang walang pagsasama-sama**; sa tabi nito: mga grid square na nakontak / kumpirmado.
- Mga kulay: **kahel** = nakontak, **asul** = kumpirmado sa QSL, **berde** = kumpirmado via LoTW.
- Filter ayon sa **mode ng propagasyon** ng log (PROP_MODE: ES, FAI, AUR/AUE, MS, TR, EME, F2).
- I-click ang isang grid square: listahan ng mga QSO na may petsa, oras, mode at kumpirmasyon, distansiya at azimuth.
- **Burahin ang memorya**: inaalis ang mga binuksang file at ang ulat ng LoTW.
