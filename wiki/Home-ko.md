**E-LAYER ANALYZER**는 전리층 **E층**이 관여하는 모든 VHF 전파 모드를 분석하는 아마추어 무선사용 무료 프로그램입니다: **스포라딕 E**(대륙 간 멀티홉 포함), **F.A.I.**(자기력선 정렬 불규칙 구조), **유성 산란**(YA-MS 프로그램 내장), **전파 오로라**. **Windows(64비트와 32비트), Linux, Raspberry Pi, Mac**에서 **28개 언어**로 동작하며, 자기 폴더 밖에는 아무것도 기록하지 않습니다.

## 탭 구성

| 탭 | 기능 |
|---|---|
| [SPORADIC-E](Sporadic-E-ko) | 지도 위의 Es 스폿, 두 국의 첫 홉, Maidenhead 그리드의 Es 구름, 내 국의 MUF |
| [BENCHMARK Es](Benchmark-Es-ko) | ADIF 로그 전체(다른 국의 로그도 가능)에 대한 시험대: 날짜별·시간별 QSO, 섹터별 스킵, 추정 foEs, 멀티홉 검증, 구름 이동 |
| [BENCHMARK 50 MHz](Benchmark-50-ko) | 하나 또는 두 개의 ADIF 로그로 보는 50 MHz 멀티홉 스포라딕 E: 메르카토르 지도, 날짜와 시간대, 선택적 foEs, WWL이 표시된 확대 경로, 150 km 이내의 QSO |
| [F.A.I.](FAI-ko) | 국 쌍에 대한 스캐터 포인트의 Scatter trail, 그리고 한 점을 검증하는 등반사 궤적 |
| [METEOR SCATTER](Meteor-Scatter-ko) | YA-MS 프로그램 전체(유성우 효율, 레이더, 예보) |
| [AURORA](Aurora-ko) | 오로라 오벌, NOAA Kp와 태양풍, 오로라 Scatter trail과 등반사, 추천 빔 지향 |
| [DATA COLLECTION](Data-Collection-ko) | 세 개의 텔넷 세션(DX cluster, RBN, PSKReporter를 전달하는 DM4X), 수집된 스폿, CALL3 데이터베이스 |
| [LOG ADIF](Log-ADIF-ko) | 내 ADIF 또는 LoTW에서 읽은 28 MHz 이상 밴드별 교신·확인 그리드 |
| [출처, 계산 선택 요약, 사용 설명서, 기술 보고서](Sources-and-Technical-Document-ko) | 출처, 공식과 계산 선택, 상세 사용 설명서, 기술 보고서: Word로 내보내기 가능 |
