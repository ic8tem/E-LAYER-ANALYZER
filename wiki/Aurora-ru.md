![AURORA](https://raw.githubusercontent.com/ic8tem/E-LAYER-ANALYZER/ci-screenshots/aurora/aurora_scia_IO70VJ_JO59BC.png)

- **Авроральный овал** NOAA OVATION Prime (с плавной заливкой), **Kp** за последние 3 дня, **солнечный ветер** (Bz, скорость, плотность); обновляются каждые 5 минут и сохраняются в `data/swpc`.
- Те же виды, что и в F.A.I.: **Scatter trail** для пары станций и **Изоотражение** для проверки точки, с начальной высотой 110 km.
- **Рекомендуемое направление для обеих станций**: на линии перпендикулярности каждой станции (точки её цвета) — точка с наибольшей вероятностью по овалу. Практическое правило (G3WPO): начинать примерно с 45°, между севером и востоком.
- Пример IO70VJ - JO59BC: точка рассеяния JP01AK у Шетландских островов, отклонение 0,97°, QTF 11° и 299°.
- **Споты авроры на карте**: споты с **<AU>** или **<AUR>** в тексте относятся к авроре (правило автора). С флажком *Споты <AU>/<AUR> на карте с расчётом* вкладка показывает споты за последние 2 часа (не более 30): для каждой пары спотер–DX рассчитывается Scatter trail и показывается наиболее вероятная scatter point (оранжевый круг), а в результатах — QTF и угол места обеих станций.
- Помимо наиболее вероятной точки рассеяния, в результатах указывается **интервал QTF** обеих станций вдоль всего Scatter trail (отклонение ≤ 1,5°).
- **Окно Lange-Hesse**: точка рассеяния предпочтительно выбирается в 370-1100 km от каждой станции — в окне, которое Lange-Hesse рассчитал для 54° геомагнитной широты. Начиная с версии 0.4.5 окно смещается по наклонению IGRF-14 каждой станции: ближе для станций южнее, дальше для станций севернее (например, Капри около 260-990 km, Осло 470-1200 km). В результатах показано окно обеих станций.

## BENCHMARK AURORA

Вкладка AURORA имеет две подвкладки: **REAL-TIME** (описанный выше расчёт) и **BENCHMARK AURORA**, испытательный стенд модели на **298 реальных QSO через аврору** с временем и локатором: опубликованные журналы EI5FK (IO51RT, Ирландия, 2003-2005, 144 и 432 MHz) и карта журнала PA0O (JO33HG, Нидерланды).

![BENCHMARK AURORA](https://raw.githubusercontent.com/ic8tem/E-LAYER-ANALYZER/ci-screenshots/4k_benchmark_aurora.png)

- Для каждого QSO программа рассчитывает точку рассеяния той же моделью (IGRF-14, высота 110 km, рефракция 4/3, допуск 3°).
- Цвета: **зелёный** = точка рассеяния внутри окна Lange-Hesse обеих станций; **жёлтый** = объяснено, но вне этого окна; **оранжевый** = QSO длиннее 2000 km; **красный** = точки рассеяния нет, QSO моделью не объясняется.
- Сводка даёт проценты, также с фиксированным окном 370-1100 km для сравнения, и для каждого журнала интервал и медиану рассчитанного QTF. Щелчок по строке рисует трассу и оба направления антенн.
- Результат (версия 0.4.4): **объяснены 296 из 298 QSO (99%)**, 243 (82%) внутри окна 370-1100 km; медиана QTF EI5FK от 25° до 41°, то есть северо-восток, рекомендованный G3WPO. В журналах направление антенн не указано: проверяется геометрия, а не QTF. С подвижным окном (версия 0.4.5) результат тот же, 243 QSO (82%), что и с фиксированным окном: станции испытательного стенда (Ирландия, Великобритания, Нидерланды, Германия) имеют наклонение 66-70°, близкое к опорной точке Lange-Hesse (окно EI5FK 350-1080 km); разница касается станций южнее или севернее, для которых на испытательном стенде нет QSO.
