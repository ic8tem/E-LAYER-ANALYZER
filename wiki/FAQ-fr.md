# Questions fréquentes

[← Home](Home-fr)

**La carte est vide.** Au premier démarrage, une connexion réseau est nécessaire pour télécharger les côtes (Natural Earth) ; ensuite, elles restent dans `data/mappa`.

**Aucun spot n'arrive.** Dans DATA COLLECTION, vérifiez que l'indicatif est saisi (en haut ou dans le champ Login) et que la session est connectée ; sur ON0DXK, activez la VHF avec `set/filter dxbm/pass 6`.

**Fenêtre « Calcul impossible ».** Pour le modèle, aucun point ne satisfait la condition de réflexion tout en étant vu par les deux stations, ou bien le point choisi est sous l'horizon. Essayez une autre altitude ou activez la réfraction.

**De l'E sporadique sur 432 MHz ?** Cela ne s'applique pas : voir [SPORADIC-E](Sporadic-E-fr).

**Sur Mac, le programme ne s'ouvre pas.** Utilisez **Installa E-LAYER-ANALYZER.command** (clic droit > Ouvrir) : il lève le blocage « téléchargé depuis Internet ».
