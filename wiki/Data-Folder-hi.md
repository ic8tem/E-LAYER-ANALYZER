# डेटा फ़ोल्डर

[← Home](Home-hi)

सब कुछ प्रोग्राम के बगल के `data` फ़ोल्डर में है (`C:\E-LAYER-ANALYZER\data`, `~/E-LAYER-ANALYZER/data`)। AppData में कुछ नहीं।

| फ़ाइल / फ़ोल्डर | सामग्री |
|---|---|
| `ela.ini` | E-LAYER ANALYZER की सेटिंग्स (स्टेशन, सत्र, दृश्य) |
| `config.ini` | YA-MS की सेटिंग्स, भाषा और रंग योजना |
| `call3.txt`, `call3_nuovi.txt` | कॉलसाइन → लोकेटर डेटाबेस और स्पॉट से सीखे गए लोकेटर |
| `spot/` | एकत्रित स्पॉट, हर दिन एक CSV |
| `log/` | डाउनलोड की गई LoTW रिपोर्ट |
| `swpc/` | NOAA डेटा (अंडाकार, Kp, सौर पवन) |
| `mappa/` | Natural Earth तटरेखाएँ और सीमाएँ |
| `igrf14.csv` | IGRF-14 चुंबकीय मॉडल के गुणांक |
| `lingue/` | अनुवाद |
| `ela_documento_tecnico*`, `ela_manuale*`, `ela_relazione*` (.txt/.docx), `ela_fonti*.txt` | हर भाषा में गणना के विकल्पों का सारांश, उपयोगकर्ता पुस्तिका, तकनीकी रिपोर्ट और स्रोत |
