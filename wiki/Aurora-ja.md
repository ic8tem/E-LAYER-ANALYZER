- NOAA OVATION Prime の **オーロラオーバル** (グラデーション表示)、過去 3 日間の **Kp**、**太陽風** (Bz、速度、密度)。5 分ごとに更新し、`data/swpc` に保存します。
- F.A.I. と同じ表示: 2 局間の **Scatter trail** と、地点を検証する **等反射線**。既定の高度は 110 km です。
- **両局の推奨方向**: 各局の直交線 (その局の色の点線) 上で、オーバル確率が最も高い地点。目安 (G3WPO): 北と東の間、約 45° から始めます。
- 例 IO70VJ - JO59BC: 散乱点はシェトランド諸島沖の JP01AK、ずれ 0.97°、QTF 11° と 299°。
- **地図上のオーロラ・スポット**：テキストに **<AU>** または **<AUR>** を含むスポットはオーロラ（作者のルール）。「<AU>/<AUR> スポットを計算付きで地図に表示」にチェックを入れると、直近 2 時間（最大 30 件）のスポットを描画し、スポッター–DX の各ペアについて Scatter trail を計算して、最も可能性の高い scatter point（オレンジの円）と両局の QTF・仰角を結果に表示します。
- 最も可能性の高い散乱点に加えて、結果には Scatter trail 全体に沿った両局の **QTF の範囲** (ずれ ≤ 1.5°) が示されます。
- **Lange-Hesse の範囲**: 散乱点は各局から 370-1100 km の範囲が優先されます。これは Lange-Hesse が地磁気緯度 54° で求めた範囲です。バージョン 0.4.5 から、範囲は各局の IGRF-14 伏角に応じて移動します: 南の局ほど近く、北の局ほど遠くなります (例: カプリ約 260-990 km、オスロ 470-1200 km)。結果には両局の範囲が示されます。

## BENCHMARK AURORA

AURORA タブには 2 つのサブタブがあります: **REAL-TIME** (上で説明した計算) と **BENCHMARK AURORA** です。後者は、時刻とロケーターのある **298 の実際のオーロラ QSO** でモデルを検証する試験台です: EI5FK の公開ログ (IO51RT、アイルランド、2003-2005 年、144 MHz と 432 MHz) と PA0O のログの地図 (JO33HG、オランダ)。

![BENCHMARK AURORA](https://raw.githubusercontent.com/ic8tem/E-LAYER-ANALYZER/ci-screenshots/4k_benchmark_aurora.png)

- プログラムは各 QSO の散乱点を同じモデル (IGRF-14、高度 110 km、4/3 屈折、許容差 3°) で計算します。
- 色: **緑** = 散乱点が両局の Lange-Hesse の範囲内; **黄** = 説明できるがこの範囲の外; **オレンジ** = 2000 km を超える QSO; **赤** = 散乱点がなく、モデルで説明できない QSO。
- 概要には割合 (比較用に固定範囲 370-1100 km での割合も) と、ログごとの計算 QTF の範囲と中央値が示されます。行をクリックするとパスと 2 つのアンテナ方向が描かれます。
- 結果 (バージョン 0.4.4): **298 の QSO のうち 296 を説明 (99%)**、243 (82%) が 370-1100 km の範囲内; EI5FK の QTF の中央値は 25° から 41° で、G3WPO が勧める北東にあたります。ログにはアンテナ方向が記載されていないため、検証は QTF ではなく幾何で行います。 移動する範囲 (バージョン 0.4.5) でも結果は固定範囲と同じく 243 QSO (82%) です: 試験台の局 (アイルランド、イギリス、オランダ、ドイツ) の伏角は 66-70° で、Lange-Hesse の基準点に近いためです (EI5FK の範囲は 350-1080 km)。違いが出るのはより南またはより北の局で、試験台にはそれらの QSO がありません。
