# 資料資料夾

[← Home](Home-zh-TW)

所有內容都在程式旁的 `data` 資料夾中（`C:\E-LAYER-ANALYZER\data`、`~/E-LAYER-ANALYZER/data`）。AppData 中沒有任何東西。

| 檔案 / 資料夾 | 內容 |
|---|---|
| `ela.ini` | E-LAYER ANALYZER 的設定（電台、連線、視圖） |
| `config.ini` | YA-MS 的設定、語言和配色方案 |
| `call3.txt`、`call3_nuovi.txt` | 呼號 → 網格座標資料庫，以及從 spot 中學到的網格座標 |
| `spot/` | 已收集的 spot，每天一個 CSV |
| `log/` | 下載的 LoTW 報告 |
| `swpc/` | NOAA 資料（極光橢圓、Kp、太陽風） |
| `mappa/` | Natural Earth 的海岸線和國界 |
| `igrf14.csv` | IGRF-14 地磁模型的係數 |
| `lingue/` | 翻譯檔 |
| `ela_documento_tecnico*`、`ela_manuale*`、`ela_relazione*`（.txt/.docx）、`ela_fonti*.txt` | 各種語言的計算選擇摘要、使用手冊、技術報告和來源 |
