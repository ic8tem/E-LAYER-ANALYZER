# Folder ng datos

[← Home](Home-tl)

Nasa folder na `data` katabi ng programa ang lahat (`C:\E-LAYER-ANALYZER\data`, `~/E-LAYER-ANALYZER/data`). Walang anuman sa AppData.

| File / folder | Nilalaman |
|---|---|
| `ela.ini` | Mga setting ng E-LAYER ANALYZER (istasyon, mga session, mga tanaw) |
| `config.ini` | Mga setting ng YA-MS, wika at scheme ng kulay |
| `call3.txt`, `call3_nuovi.txt` | Database na callsign → locator at mga locator na natutunan mula sa mga spot |
| `spot/` | Mga nakolektang spot, isang CSV bawat araw |
| `log/` | Na-download na ulat ng LoTW |
| `swpc/` | Datos ng NOAA (oval, Kp, solar wind) |
| `mappa/` | Mga baybayin at hangganan ng Natural Earth |
| `igrf14.csv` | Mga coefficient ng magnetic model na IGRF-14 |
| `lingue/` | Mga salin |
| `ela_documento_tecnico*`, `ela_manuale*`, `ela_relazione*` (.txt/.docx), `ela_fonti*.txt` | Buod ng mga pagpili sa kalkulasyon, manwal ng paggamit, teknikal na ulat at mga sanggunian sa bawat wika |
