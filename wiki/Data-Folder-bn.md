# ডেটা ফোল্ডার

[← Home](Home-bn)

সবকিছু প্রোগ্রামের পাশের `data` ফোল্ডারে (`C:\E-LAYER-ANALYZER\data`, `~/E-LAYER-ANALYZER/data`)। AppData-তে কিছুই নয়।

| ফাইল / ফোল্ডার | বিষয়বস্তু |
|---|---|
| `ela.ini` | E-LAYER ANALYZER-এর সেটিংস (স্টেশন, সেশন, দৃশ্য) |
| `config.ini` | YA-MS-এর সেটিংস, ভাষা ও রঙের থিম |
| `call3.txt`, `call3_nuovi.txt` | কলসাইন → লোকেটর ডেটাবেস এবং স্পট থেকে শেখা লোকেটর |
| `spot/` | সংগৃহীত স্পট, প্রতিদিন একটি CSV |
| `log/` | ডাউনলোড করা LoTW রিপোর্ট |
| `swpc/` | NOAA-র তথ্য (ওভাল, Kp, সৌর বায়ু) |
| `mappa/` | Natural Earth-এর উপকূলরেখা ও সীমানা |
| `igrf14.csv` | IGRF-14 চৌম্বক মডেলের সহগ |
| `lingue/` | অনুবাদ |
| `ela_documento_tecnico*`, `ela_manuale*`, `ela_relazione*` (.txt/.docx), `ela_fonti*.txt` | প্রতিটি ভাষায় হিসাবের নির্বাচনসমূহের সারসংক্ষেপ, ব্যবহার নির্দেশিকা, প্রযুক্তিগত প্রতিবেদন ও উৎস |
