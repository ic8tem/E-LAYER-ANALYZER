# LOG ADIF

[← Home](Home-it)

![LOG ADIF](https://raw.githubusercontent.com/ic8tem/E-LAYER-ANALYZER/ci-screenshots/6_log_adif.png)

- **Apri file ADIF...** (anche più file) oppure **Scarica da LoTW...** (nome utente e password; la password non viene mai salvata).
- Una linguetta per ogni banda **dai 28 MHz in su**, ognuna per conto suo, **senza aggregazioni**; accanto: quadrati lavorati / confermati.
- Colori: **arancione** = lavorato, **blu** = confermato con QSL, **verde** = confermato via LoTW.
- Filtro sul **modo di propagazione** del log (PROP_MODE: ES, FAI, AUR/AUE, MS, TR, EME, F2).
- Clic su un quadrato: elenco dei QSO con data, ora, modo e conferma, distanza e azimut.
- **Cancella memoria**: toglie i file aperti e il report LoTW.
