# Data folder

[← Home](Home)

Everything is in the `data` folder next to the program (`C:\E-LAYER-ANALYZER\data`, `~/E-LAYER-ANALYZER/data`). Nothing in AppData.

| File / folder | Contents |
|---|---|
| `ela.ini` | E-LAYER ANALYZER settings (station, sessions, views) |
| `config.ini` | YA-MS settings, language and colour scheme |
| `call3.txt`, `call3_nuovi.txt` | Callsign → locator database and locators learned from spots |
| `spot/` | Collected spots, one CSV per day |
| `log/` | Downloaded LoTW report |
| `swpc/` | NOAA data (oval, Kp, solar wind) |
| `mappa/` | Natural Earth coastlines and borders |
| `igrf14.csv` | Coefficients of the IGRF-14 magnetic model |
| `lingue/` | Translations |
| `ela_documento_tecnico*.txt/.docx`, `ela_fonti*.txt` | Technical document and sources in every language |
