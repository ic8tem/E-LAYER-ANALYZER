# Složka dat

[← Domů](Home-cs)

Vše je ve složce `data` vedle programu (`C:\E-LAYER-ANALYZER\data`, `~/E-LAYER-ANALYZER/data`). Nic v AppData.

| Soubor / složka | Obsah |
|---|---|
| `ela.ini` | Nastavení E-LAYER ANALYZER (stanice, relace, zobrazení) |
| `config.ini` | Nastavení YA-MS, jazyk a barevné schéma |
| `call3.txt`, `call3_nuovi.txt` | Databáze značka → lokátor a lokátory získané ze spotů |
| `spot/` | Shromážděné spoty, jeden CSV na den |
| `log/` | Stažený výpis z LoTW |
| `swpc/` | Data NOAA (ovál, Kp, sluneční vítr) |
| `mappa/` | Pobřeží a hranice Natural Earth |
| `igrf14.csv` | Koeficienty magnetického modelu IGRF-14 |
| `lingue/` | Překlady |
| `ela_documento_tecnico*`, `ela_manuale*`, `ela_relazione*` (.txt/.docx), `ela_fonti*.txt` | Shrnutí voleb výpočtu, uživatelská příručka, technická zpráva a zdroje ve všech jazycích |
