# Datová složka

[← Home](Home-cs)

Vše je ve složce `data` vedle programu (`C:\E-LAYER-ANALYZER\data`, `~/E-LAYER-ANALYZER/data`). Nic v AppData.

| Soubor / složka | Obsah |
|---|---|
| `ela.ini` | Nastavení E-LAYER ANALYZER (stanice, relace, pohledy) |
| `config.ini` | Nastavení YA-MS, jazyk a barevné schéma |
| `call3.txt`, `call3_nuovi.txt` | Databáze značka → lokátor a lokátory naučené ze spotů |
| `spot/` | Sebrané spoty, jeden CSV soubor na den |
| `log/` | Stažený report z LoTW |
| `swpc/` | Data NOAA (ovál, Kp, sluneční vítr) |
| `mappa/` | Pobřeží a hranice z Natural Earth |
| `igrf14.csv` | Koeficienty magnetického modelu IGRF-14 |
| `lingue/` | Překlady |
| `ela_documento_tecnico*`, `ela_manuale*`, `ela_relazione*` (.txt/.docx), `ela_fonti*.txt` | Shrnutí výpočetních voleb, uživatelský manuál, technická zpráva a zdroje ve všech jazycích |
