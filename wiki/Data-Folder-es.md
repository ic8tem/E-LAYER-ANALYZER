# Carpeta de datos

[← Home](Home-es)

Todo está en la carpeta `data` junto al programa (`C:\E-LAYER-ANALYZER\data`, `~/E-LAYER-ANALYZER/data`). Nada en AppData.

| Archivo / carpeta | Contenido |
|---|---|
| `ela.ini` | Ajustes de E-LAYER ANALYZER (estación, sesiones, vistas) |
| `config.ini` | Ajustes de YA-MS, idioma y esquema de colores |
| `call3.txt`, `call3_nuovi.txt` | Base de datos indicativo → locator y locators aprendidos de los spots |
| `spot/` | Spots recogidos, un CSV por día |
| `log/` | Informe de LoTW descargado |
| `swpc/` | Datos de NOAA (óvalo, Kp, viento solar) |
| `mappa/` | Costas y fronteras de Natural Earth |
| `igrf14.csv` | Coeficientes del modelo magnético IGRF-14 |
| `lingue/` | Traducciones |
| `ela_documento_tecnico*`, `ela_manuale*`, `ela_relazione*` (.txt/.docx), `ela_fonti*.txt` | Síntesis de las opciones de cálculo, manual de uso, informe técnico y fuentes en todos los idiomas |
