# LOG ADIF

[← Home](Home)

![LOG ADIF](https://raw.githubusercontent.com/ic8tem/E-LAYER-ANALYZER/ci-screenshots/6_log_adif.png)

- **Open ADIF file...** (several files allowed) or **Download from LoTW...** (username and password; the password is never saved).
- One tab for each band **from 28 MHz up**, each one on its own, **with no aggregation**; next to it: squares worked / confirmed.
- Colours: **orange** = worked, **blue** = confirmed by QSL, **green** = confirmed via LoTW.
- Filter on the log's **propagation mode** (PROP_MODE: ES, FAI, AUR/AUE, MS, TR, EME, F2).
- Click a square: list of QSOs with date, time, mode and confirmation, distance and azimuth.
- **Clear memory**: removes the opened files and the LoTW report.
