# 数据文件夹

[← Home](Home-zh)

所有内容都在程序旁的 `data` 文件夹中（`C:\E-LAYER-ANALYZER\data`、`~/E-LAYER-ANALYZER/data`）。AppData 中没有任何内容。

| 文件 / 文件夹 | 内容 |
|---|---|
| `ela.ini` | E-LAYER ANALYZER 的设置（台站、会话、视图） |
| `config.ini` | YA-MS 的设置、语言和配色方案 |
| `call3.txt`、`call3_nuovi.txt` | 呼号 → 网格坐标数据库，以及从 spot 中获取的网格坐标 |
| `spot/` | 已收集的 spot，每天一个 CSV |
| `log/` | 已下载的 LoTW 报告 |
| `swpc/` | NOAA 数据（极光椭圆、Kp、太阳风） |
| `mappa/` | Natural Earth 海岸线和国界 |
| `igrf14.csv` | IGRF-14 地磁模型的系数 |
| `lingue/` | 翻译文件 |
| `ela_documento_tecnico*`、`ela_manuale*`、`ela_relazione*`（.txt/.docx）、`ela_fonti*.txt` | 各语言版本的计算选择摘要、使用手册、技术报告和来源 |
