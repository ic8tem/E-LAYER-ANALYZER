# Folder danych

[← Strona główna](Home-pl)

Wszystko znajduje się w folderze `data` obok programu (`C:\E-LAYER-ANALYZER\data`, `~/E-LAYER-ANALYZER/data`). Nic w AppData.

| Plik / folder | Zawartość |
|---|---|
| `ela.ini` | Ustawienia E-LAYER ANALYZER (stacja, sesje, widoki) |
| `config.ini` | Ustawienia YA-MS, język i schemat kolorów |
| `call3.txt`, `call3_nuovi.txt` | Archiwum znak wywoławczy → lokator i lokatory poznane ze spotów |
| `spot/` | Zebrane spoty, jeden CSV na dzień |
| `log/` | Pobrany raport LoTW |
| `swpc/` | Dane NOAA (owal, Kp, wiatr słoneczny) |
| `mappa/` | Linie brzegowe i granice Natural Earth |
| `igrf14.csv` | Współczynniki modelu magnetycznego IGRF-14 |
| `lingue/` | Tłumaczenia |
| `ela_documento_tecnico*`, `ela_manuale*`, `ela_relazione*` (.txt/.docx), `ela_fonti*.txt` | Podsumowanie wyborów obliczeniowych, instrukcja obsługi, raport techniczny i źródła w każdym języku |
