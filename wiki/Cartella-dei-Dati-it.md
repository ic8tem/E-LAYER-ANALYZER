# Cartella dei dati

[← Home](Home-it)

Tutto sta nella cartella `data` accanto al programma (`C:\E-LAYER-ANALYZER\data`, `~/E-LAYER-ANALYZER/data`). Niente in AppData.

| File / cartella | Contenuto |
|---|---|
| `ela.ini` | Impostazioni di E-LAYER ANALYZER (stazione, sessioni, viste) |
| `config.ini` | Impostazioni di YA-MS, lingua e schema di colori |
| `call3.txt`, `call3_nuovi.txt` | Archivio nominativo → locator e locator imparati dagli spot |
| `spot/` | Spot raccolti, un CSV al giorno |
| `log/` | Report LoTW scaricato |
| `swpc/` | Dati NOAA (ovale, Kp, vento solare) |
| `mappa/` | Coste e confini Natural Earth |
| `igrf14.csv` | Coefficienti del modello magnetico IGRF-14 |
| `lingue/` | Traduzioni |
| `ela_documento_tecnico*`, `ela_manuale*`, `ela_relazione*` (.txt/.docx), `ela_fonti*.txt` | Sintesi delle scelte di calcolo, manuale d'uso, relazione tecnica e fonti in ogni lingua |
