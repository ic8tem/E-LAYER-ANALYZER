# Datagids

[← Home](Home-af)

Alles is in die `data`-gids langs die program (`C:\E-LAYER-ANALYZER\data`, `~/E-LAYER-ANALYZER/data`). Niks in AppData nie.

| Lêer / gids | Inhoud |
|---|---|
| `ela.ini` | Instellings van E-LAYER ANALYZER (stasie, sessies, aansigte) |
| `config.ini` | YA-MS-instellings, taal en kleurskema |
| `call3.txt`, `call3_nuovi.txt` | Roepnaam → lokator-databasis en lokators wat uit spots geleer is |
| `spot/` | Versamelde spots, een CSV per dag |
| `log/` | Afgelaaide LoTW-verslag |
| `swpc/` | NOAA-data (ovaal, Kp, sonwind) |
| `mappa/` | Natural Earth-kuslyne en -grense |
| `igrf14.csv` | Koëffisiënte van die IGRF-14-magnetiese model |
| `lingue/` | Vertalings |
| `ela_documento_tecnico*`, `ela_manuale*`, `ela_relazione*` (.txt/.docx), `ela_fonti*.txt` | Opsomming van die berekeningskeuses, gebruikershandleiding, tegniese verslag en bronne in elke taal |
