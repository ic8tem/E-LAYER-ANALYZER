# Datamappe

[← Home](Home-nb)

Alt ligger i mappen `data` ved siden av programmet (`C:\E-LAYER-ANALYZER\data`, `~/E-LAYER-ANALYZER/data`). Ingenting i AppData.

| Fil / mappe | Innhold |
|---|---|
| `ela.ini` | Innstillinger for E-LAYER ANALYZER (stasjon, økter, visninger) |
| `config.ini` | Innstillinger for YA-MS, språk og fargeskjema |
| `call3.txt`, `call3_nuovi.txt` | Database kallesignal → lokator og lokatorer lært fra spot |
| `spot/` | Innsamlede spot, én CSV per dag |
| `log/` | Nedlastet LoTW-rapport |
| `swpc/` | NOAA-data (oval, Kp, solvind) |
| `mappa/` | Kystlinjer og grenser fra Natural Earth |
| `igrf14.csv` | Koeffisientene for den magnetiske modellen IGRF-14 |
| `lingue/` | Oversettelser |
| `ela_documento_tecnico*`, `ela_manuale*`, `ela_relazione*` (.txt/.docx), `ela_fonti*.txt` | Sammendrag av beregningsvalgene, brukerhåndbok, teknisk rapport og kilder på alle språk |
