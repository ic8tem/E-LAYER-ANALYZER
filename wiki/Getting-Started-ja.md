# 初回起動

[← Home](Home-ja)

1. 上部に **コールサイン**、**ロケーター** (6 桁、例: JN70CN)、**標高** (m) を入力し、**適用** を押します。
2. 右上で **言語** と **配色** を選びます (ウィンドウはすぐに再構築されます)。
3. **DATA COLLECTION > Telnet セッション** で 3 つのセッションのホスト、ポート、コマンドを確認し、**接続** を押します。**起動時に接続** をオンにすると自動で接続します。
4. 数分後、**SPORADIC-E**、**F.A.I.**、**AURORA** にスポットが表示されます。

## 地図

- マウスの **ホイール**: カーソル位置を中心に拡大・縮小。
- 左ボタンで **ドラッグ**: 地図を移動。
- 右上: カーソル位置の座標とロケーター。
- **ヨーロッパ** / **世界** ボタン: 初期表示。
- 地図のある各ページは 65 % を地図、35 % をデータに割り当てます。仕切りはドラッグで動かせます。
