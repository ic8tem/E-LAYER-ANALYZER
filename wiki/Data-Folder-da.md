# Datamappe

[← Home](Home-da)

Alt ligger i mappen `data` ved siden af programmet (`C:\E-LAYER-ANALYZER\data`, `~/E-LAYER-ANALYZER/data`). Intet i AppData.

| Fil / mappe | Indhold |
|---|---|
| `ela.ini` | Indstillinger for E-LAYER ANALYZER (station, sessioner, visninger) |
| `config.ini` | Indstillinger for YA-MS, sprog og farveskema |
| `call3.txt`, `call3_nuovi.txt` | Database kaldesignal → lokator og lokatorer lært fra spots |
| `spot/` | Indsamlede spots, én CSV pr. dag |
| `log/` | Hentet LoTW-rapport |
| `swpc/` | NOAA-data (oval, Kp, solvind) |
| `mappa/` | Kystlinjer og grænser fra Natural Earth |
| `igrf14.csv` | Koefficienterne for den magnetiske model IGRF-14 |
| `lingue/` | Oversættelser |
| `ela_documento_tecnico*`, `ela_manuale*`, `ela_relazione*` (.txt/.docx), `ela_fonti*.txt` | Resumé af beregningsvalgene, brugervejledning, teknisk rapport og kilder på alle sprog |
