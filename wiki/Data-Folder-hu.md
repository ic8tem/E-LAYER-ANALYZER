# Adatmappa

[← Kezdőlap](Home-hu)

Minden a program melletti `data` mappában van (`C:\E-LAYER-ANALYZER\data`, `~/E-LAYER-ANALYZER/data`). Semmi sincs az AppData-ban.

| Fájl / mappa | Tartalom |
|---|---|
| `ela.ini` | Az E-LAYER ANALYZER beállításai (állomás, kapcsolatok, nézetek) |
| `config.ini` | A YA-MS beállításai, nyelv és színséma |
| `call3.txt`, `call3_nuovi.txt` | Hívójel → lokátor adatbázis és a spotokból tanult lokátorok |
| `spot/` | Gyűjtött spotok, naponta egy CSV |
| `log/` | Letöltött LoTW-jelentés |
| `swpc/` | NOAA-adatok (ovális, Kp, napszél) |
| `mappa/` | Natural Earth partvonalak és határok |
| `igrf14.csv` | Az IGRF-14 mágneses modell együtthatói |
| `lingue/` | Fordítások |
| `ela_documento_tecnico*`, `ela_manuale*`, `ela_relazione*` (.txt/.docx), `ela_fonti*.txt` | A számítási választások összefoglalója, felhasználói kézikönyv, műszaki jelentés és források minden nyelven |
