# METEOR SCATTER

[← หน้าหลัก](Home-th)

แท็บนี้มี **YA-MS 1.8.9** ฉบับสมบูรณ์ ซึ่งเป็นโปรแกรม meteor scatter ของ IC8TEM: ทรงกลมท้องฟ้าพร้อมจุดกระจาย (radiant), ฟลักซ์จากเรดาร์ SKiYMET (Collm, Sodankylä), การคำนวณประสิทธิภาพของฝนดาวตก, การพยากรณ์เชิงทดลอง, เรขาคณิตและการสูญเสียตามเส้นทาง, GRAVES, แผนที่ช่องกริด, **ฝนดาวตกสด** (ZHR ที่วัดโดย Global Meteor Network และจุดกระจายจากเรดาร์ CMOR), **แผนที่แหล่งข้อมูล** (ตำแหน่งของ Collm, Sodankylä, GRAVES และ CMOR เทียบกับสถานี) และเอกสาร **คำอธิบายการคำนวณประสิทธิภาพ** พร้อมสูตร

YA-MS 1.5.0 เพิ่มแท็บ **การเก็บข้อมูล** (สปอต meteor scatter ที่กรองด้วย MSK144, FSK441, FSK41, PSK2K, JTMS, JT6M, `<MS>`) ภายใน E-LAYER ANALYZER แท็บนี้ไม่เปิดเซสชัน telnet ของตนเอง: แต่รับบรรทัดจากเซสชันของ DATA COLLECTION จึงไม่มีการเข้าสู่ระบบซ้ำด้วยสัญญาณเรียกขานเดียวกัน

YA-MS 1.6.0 จัดแท็บใหม่เป็น **ข้อมูลสดและตามเวลาจริง** (ทราฟฟิก meteor scatter สดพร้อมกลุ่มเมฆของแต่ละการติดต่อ, ฟลักซ์เรดาร์, GRAVES, การเก็บข้อมูล) และ **การคำนวณการพยากรณ์** (การพยากรณ์, เรขาคณิต, การคำนวณประสิทธิภาพ, การพยากรณ์เชิงทดลอง)

YA-MS 1.7.0 และ 1.8.0 เพิ่มการเปรียบเทียบจุดกระจาย (radiant) กับแคตตาล็อก IAU MDC, จำนวนนับรายวันของ Global Meteor Network แยกตามฝนดาวตก, ดัชนี k ที่ได้จากดัชนีประชากร, รัศมีเริ่มต้นของรอยดาวตกตาม Stober และคณะ (2021), ระยะเวลาของ ping ระหว่างย่านความถี่ (λ² เป็นค่าเริ่มต้น หรือค่าที่วัดโดย NN4SA ใน HamSCI MSQP) และการเปรียบเทียบกับการตรวจจับของ BRAMS ที่ Sonneberg (เพอร์เซอิดส์ 2026) การอัปเดตอัตโนมัติของ YA-MS ถูกปิดไว้ภายใน E-LAYER ANALYZER ซึ่งอัปเดตตัวเองจาก Release บน GitHub

YA-MS 1.8.1 ถือว่าลำคลื่นของสายอากาศเป็นแบบรูปแนวตั้ง (ช่อง «แบบรูปสายอากาศ» เปิดไว้เป็นค่าเริ่มต้น): จุดสะท้อนถ่วงน้ำหนักด้วยอัตราขยายแนวตั้งของสายอากาศทั้งสอง และประสิทธิภาพไม่หายไปอีกบนเส้นทางยาว เพิ่มคำเตือน «ไม่มีโซนร่วม» เน้นช่องของมุม β (ทางเลือกที่มีผลมากที่สุด) ใช้วันที่คำนวณเพียงวันเดียว มี «คู่มือการใช้งาน» และการเปรียบเทียบกับสปอตจริง 181 767 รายการที่ 50 MHz จาก HamSCI Meteor Scatter QSO Party เดือนสิงหาคม 2025: ชั่วโมงและด้านของเส้นทางเชื่อถือได้ ส่วนเปอร์เซ็นต์เป็นเพียงค่าบ่งชี้

- YA-MS ใช้ภาษาและชุดสีที่เลือกไว้ที่ด้านบนของ E-LAYER ANALYZER
- การตั้งค่าของ YA-MS เก็บไว้ใน `data/config.ini`
- YA-MS ทุกเวอร์ชันใหม่นำเข้ามาด้วยสคริปต์ `tools/sync_yams.py`
