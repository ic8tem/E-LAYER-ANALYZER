# METEOR SCATTER

[← Home](Home-th)

แท็บนี้มี **YA-MS 1.6.0** ฉบับสมบูรณ์ ซึ่งเป็นโปรแกรม meteor scatter ของ IC8TEM: ทรงกลมท้องฟ้าพร้อมจุดกระจาย (radiant) ฟลักซ์จากเรดาร์ SKiYMET (Collm, Sodankylä) การคำนวณประสิทธิภาพของฝนดาวตก การนำการพยากรณ์ไปใช้แบบทดลอง เรขาคณิตและการลดทอน GRAVES แผนที่ช่องกริด **ฝนดาวตกแบบสด** (ZHR ที่วัดโดย Global Meteor Network และจุดกระจายจากเรดาร์ CMOR) **แผนที่แหล่งข้อมูล** (Collm, Sodankylä, GRAVES และ CMOR เทียบกับสถานี) และเอกสาร **ประสิทธิภาพ - คำอธิบาย** พร้อมสูตร

YA-MS 1.5.0 เพิ่มแท็บ **การเก็บข้อมูล** (สปอต meteor scatter ที่กรองตาม MSK144, FSK441, FSK41, PSK2K, JTMS, JT6M, `<MS>`) ภายใน E-LAYER ANALYZER แท็บนี้จะไม่เปิดเซสชัน telnet ของตัวเอง แต่รับบรรทัดจากเซสชันของ DATA COLLECTION จึงไม่มีการล็อกอินซ้ำด้วยสัญญาณเรียกขานเดียวกัน

YA-MS 1.6.0 จัดแท็บใหม่เป็น **สดและข้อมูลเรียลไทม์** (การติดต่อ meteor scatter แบบสดพร้อมเมฆของแต่ละการติดต่อ ฟลักซ์จากเรดาร์ GRAVES การเก็บข้อมูล) และ **การคำนวณพยากรณ์** (การพยากรณ์ เรขาคณิต การคำนวณประสิทธิภาพ การนำการพยากรณ์ไปใช้)

- YA-MS ใช้ภาษาและชุดสีที่เลือกไว้ที่ด้านบนของ E-LAYER ANALYZER
- การตั้งค่าของ YA-MS เก็บอยู่ใน `data/config.ini`
- YA-MS แต่ละเวอร์ชันใหม่จะถูกนำเข้าด้วยสคริปต์ `tools/sync_yams.py`

ดูรายละเอียดได้ที่ [คลังโค้ดของ YA-MS](https://github.com/ic8tem/YA-MS)
