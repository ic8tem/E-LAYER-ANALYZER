# LOG ADIF

[← Home](Home-pt-BR)

![LOG ADIF](https://raw.githubusercontent.com/ic8tem/E-LAYER-ANALYZER/ci-screenshots/6_log_adif.png)

- **Abrir arquivo ADIF...** (vários arquivos permitidos) ou **Baixar do LoTW...** (usuário e senha; a senha nunca é salva).
- Uma aba para cada banda **a partir de 28 MHz**, cada uma separada, **sem agregação**; ao lado: quadrados trabalhados / confirmados.
- Cores: **laranja** = trabalhado, **azul** = confirmado por QSL, **verde** = confirmado via LoTW.
- Filtro pelo **modo de propagação** do log (PROP_MODE: ES, FAI, AUR/AUE, MS, TR, EME, F2).
- Clique num quadrado: lista dos QSOs com data, hora, modo e confirmação, distância e azimute.
- **Limpar memória**: remove os arquivos abertos e o relatório do LoTW.
