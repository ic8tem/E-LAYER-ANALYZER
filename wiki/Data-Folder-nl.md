# Gegevensmap

[← Home](Home-nl)

Alles staat in de map `data` naast het programma (`C:\E-LAYER-ANALYZER\data`, `~/E-LAYER-ANALYZER/data`). Niets in AppData.

| Bestand / map | Inhoud |
|---|---|
| `ela.ini` | Instellingen van E-LAYER ANALYZER (station, sessies, weergaven) |
| `config.ini` | Instellingen van YA-MS, taal en kleurenschema |
| `call3.txt`, `call3_nuovi.txt` | Database roepnaam → locator en uit spots geleerde locators |
| `spot/` | Verzamelde spots, één CSV-bestand per dag |
| `log/` | Gedownload LoTW-rapport |
| `swpc/` | NOAA-gegevens (ovaal, Kp, zonnewind) |
| `mappa/` | Kustlijnen en grenzen van Natural Earth |
| `igrf14.csv` | Coëfficiënten van het magnetische model IGRF-14 |
| `lingue/` | Vertalingen |
| `ela_documento_tecnico*`, `ela_manuale*`, `ela_relazione*` (.txt/.docx), `ela_fonti*.txt` | Samenvatting van de rekenkeuzes, handleiding, technisch verslag en bronnen in elke taal |
