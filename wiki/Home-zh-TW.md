# E-LAYER ANALYZER

*作者：Costantino IC8TEM* — **English** · [Italiano](Home-it) · [Deutsch](Home-de) · [Nederlands](Home-nl) · [Français](Home-fr) · [Español](Home-es) · [Português](Home-pt) · [Dansk](Home-da) · [Norsk](Home-nb) · [Svenska](Home-sv) · [Íslenska](Home-is) · [Eesti](Home-et) · [Lietuvių](Home-lt) · [Latviešu](Home-lv) · [Русский](Home-ru) · [Українська](Home-uk) · [Türkçe](Home-tr) · [Afrikaans](Home-af) · [العربية](Home-ar) · [עברית](Home-he) · [اردو](Home-ur) · [हिन्दी](Home-hi) · [বাংলা](Home-bn) · [Bahasa Indonesia](Home-id) · [Tagalog](Home-tl) · [日本語](Home-ja) · [한국어](Home-ko) · [中文](Home-zh)

**E-LAYER ANALYZER** 是一套供業餘無線電愛好者使用的免費程式，用於分析所有與電離層 **E 層**有關的 VHF 傳播方式：**偶發 E 層**（包括洲際多跳）、**F.A.I.**（場向不規則體）、**流星散射**（內建 YA-MS 程式）以及**無線電極光**。它可在 **Windows（64 位元和 32 位元）、Linux、Raspberry Pi 和 Mac** 上執行，提供 **28 種語言**，而且不會在自己的資料夾之外寫入任何東西。

## 各個分頁

| 分頁 | 功能 |
|---|---|
| [SPORADIC-E](Sporadic-E-zh-TW) | 地圖上的 Es spot、兩個電台的第一跳、Maidenhead 方格上的 Es 雲、本台的 MUF |
| [BENCHMARK Es](Benchmark-Es-zh-TW) | 針對整份 ADIF 日誌（也可以是其他電台的）的測試平台：每日和每小時的 QSO、依扇區統計的跳越距離（skip）、估算的 foEs、多跳檢驗、雲的漂移 |
| [BENCHMARK 50 MHz](Benchmark-50-zh-TW) | 根據一份或兩份 ADIF 日誌分析 50 MHz 的多跳偶發 E 層：麥卡托地圖、日期和時段、可選的 foEs、附 WWL 的放大路徑、150 km 範圍內的 QSO |
| [F.A.I.](FAI-zh-TW) | 一對電台散射點的 Scatter trail，以及用來檢驗某一點的等反射線 |
| [METEOR SCATTER](Meteor-Scatter-zh-TW) | 完整的 YA-MS 程式（流星雨效率、雷達、預報） |
| [AURORA](Aurora-zh-TW) | 極光橢圓、NOAA Kp 和太陽風、極光 Scatter trail 與等反射線、建議的天線指向 |
| [DATA COLLECTION](Data-Collection-zh-TW) | 三個 telnet 連線（DX cluster、RBN、附 PSKReporter 的 DM4X）、已收集的 spot、CALL3 資料庫 |
| [LOG ADIF](Log-ADIF-zh-TW) | 從 28 MHz 起逐頻段顯示已通聯和已確認的方格，資料來自您的 ADIF 或 LoTW |
| [來源、計算選擇摘要、使用手冊、技術報告](Sources-and-Technical-Document-zh-TW) | 來源、公式與計算選擇、詳細的使用手冊、技術報告：皆可匯出為 Word |
