# ڈیٹا فولڈر

[← Home](Home-ur)

سب کچھ پروگرام کے ساتھ والے `data` فولڈر میں ہے (`C:\E-LAYER-ANALYZER\data`، `~/E-LAYER-ANALYZER/data`)۔ AppData میں کچھ نہیں۔

| فائل / فولڈر | مواد |
|---|---|
| `ela.ini` | E-LAYER ANALYZER کی ترتیبات (اسٹیشن، سیشن، مناظر) |
| `config.ini` | YA-MS کی ترتیبات، زبان اور رنگ سکیم |
| `call3.txt`، `call3_nuovi.txt` | کال سائن → لوکیٹر ڈیٹا بیس اور اسپاٹس سے سیکھے گئے لوکیٹر |
| `spot/` | جمع شدہ اسپاٹ، ہر دن کی ایک CSV |
| `log/` | ڈاؤن لوڈ شدہ LoTW رپورٹ |
| `swpc/` | NOAA ڈیٹا (بیضوی حلقہ، Kp، شمسی ہوا) |
| `mappa/` | Natural Earth کی ساحلی لکیریں اور سرحدیں |
| `igrf14.csv` | IGRF-14 مقناطیسی ماڈل کے عددی سر |
| `lingue/` | ترجمے |
| `ela_documento_tecnico*`، `ela_manuale*`، `ela_relazione*` (.txt/.docx)، `ela_fonti*.txt` | ہر زبان میں حسابی انتخاب کا خلاصہ، استعمال کی ہدایات، تکنیکی رپورٹ اور ذرائع |
