# Gagnamappa

[← Home](Home-is)

Allt er í möppunni `data` við hlið forritsins (`C:\E-LAYER-ANALYZER\data`, `~/E-LAYER-ANALYZER/data`). Ekkert í AppData.

| Skrá / mappa | Innihald |
|---|---|
| `ela.ini` | Stillingar E-LAYER ANALYZER (stöð, lotur, sýnir) |
| `config.ini` | Stillingar YA-MS, tungumál og litaþema |
| `call3.txt`, `call3_nuovi.txt` | Gagnagrunnur kallmerki → locator og locatorar lærðir af spotum |
| `spot/` | Söfnuð spot, ein CSV-skrá á dag |
| `log/` | Sótt LoTW-skýrsla |
| `swpc/` | Gögn frá NOAA (sporbaugur, Kp, sólvindur) |
| `mappa/` | Strandlínur og landamæri frá Natural Earth |
| `igrf14.csv` | Stuðlar segulsviðslíkansins IGRF-14 |
| `lingue/` | Þýðingar |
| `ela_documento_tecnico*`, `ela_manuale*`, `ela_relazione*` (.txt/.docx), `ela_fonti*.txt` | Yfirlit yfir val útreikninga, notendahandbók, tækniskýrsla og heimildir á öllum tungumálum |
