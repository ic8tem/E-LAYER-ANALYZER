# Папка данных

[← Home](Home-ru)

Всё хранится в папке `data` рядом с программой (`C:\E-LAYER-ANALYZER\data`, `~/E-LAYER-ANALYZER/data`). Ничего в AppData.

| Файл / папка | Содержимое |
|---|---|
| `ela.ini` | Настройки E-LAYER ANALYZER (станция, сессии, виды) |
| `config.ini` | Настройки YA-MS, язык и цветовая схема |
| `call3.txt`, `call3_nuovi.txt` | База позывной → локатор и локаторы, полученные из спотов |
| `spot/` | Собранные споты, один CSV в день |
| `log/` | Загруженный отчёт LoTW |
| `swpc/` | Данные NOAA (овал, Kp, солнечный ветер) |
| `mappa/` | Береговые линии и границы Natural Earth |
| `igrf14.csv` | Коэффициенты магнитной модели IGRF-14 |
| `lingue/` | Переводы |
| `ela_documento_tecnico*.txt/.docx`, `ela_fonti*.txt` | Технический документ и источники на всех языках |
