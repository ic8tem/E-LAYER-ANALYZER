# Datu mape

[← Home](Home-lv)

Viss atrodas mapē `data` blakus programmai (`C:\E-LAYER-ANALYZER\data`, `~/E-LAYER-ANALYZER/data`). Nekā AppData mapē.

| Fails / mape | Saturs |
|---|---|
| `ela.ini` | E-LAYER ANALYZER iestatījumi (stacija, sesijas, skati) |
| `config.ini` | YA-MS iestatījumi, valoda un krāsu shēma |
| `call3.txt`, `call3_nuovi.txt` | Izsaukuma signāls → lokators arhīvs un no spotiem iegūtie lokatori |
| `spot/` | Savāktie spoti, viens CSV dienā |
| `log/` | Lejupielādētā LoTW atskaite |
| `swpc/` | NOAA dati (ovāls, Kp, Saules vējš) |
| `mappa/` | Natural Earth krasta līnijas un robežas |
| `igrf14.csv` | IGRF-14 magnētiskā modeļa koeficienti |
| `lingue/` | Tulkojumi |
| `ela_documento_tecnico*`, `ela_manuale*`, `ela_relazione*` (.txt/.docx), `ela_fonti*.txt` | Aprēķinu izvēļu kopsavilkums, lietošanas rokasgrāmata, tehniskais ziņojums un avoti visās valodās |
