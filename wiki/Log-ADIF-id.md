# LOG ADIF

[← Home](Home-id)

![LOG ADIF](https://raw.githubusercontent.com/ic8tem/E-LAYER-ANALYZER/ci-screenshots/6_log_adif.png)

- **Buka file ADIF...** (boleh beberapa file) atau **Unduh dari LoTW...** (nama pengguna dan kata sandi; kata sandi tidak pernah disimpan).
- Satu tab untuk setiap band **mulai 28 MHz ke atas**, masing-masing berdiri sendiri, **tanpa penggabungan**; di sampingnya: kotak yang dikerjakan / terkonfirmasi.
- Warna: **oranye** = dikerjakan, **biru** = terkonfirmasi dengan QSL, **hijau** = terkonfirmasi via LoTW.
- Filter menurut **mode propagasi** di log (PROP_MODE: ES, FAI, AUR/AUE, MS, TR, EME, F2).
- Klik sebuah kotak: daftar QSO dengan tanggal, jam, mode dan konfirmasi, jarak dan azimut.
- **Hapus memori**: menghapus file yang dibuka dan laporan LoTW.
