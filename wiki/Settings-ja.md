# 設定

[← Home](Home-ja)

バージョン 0.4.18 から、**設定** タブには、プログラムの一般的なオプションと、タブ間のスポットの振り分けがまとめられています。2 つのサブタブがあります。

## 一般

| セクション | 設定内容 |
|---|---|
| 局 | コールサイン、ロケーター、高さ。上部のバーと同じもので、**適用** ですべてのタブに確定します。 |
| 外観 | 言語、配色 (YAEC と YA-MS の配色と、バージョン 0.5.0 からは IP-TRX-CTRL の 6 つのテーマ: ライト、夜間、ブラック、ブルー、パープル、グリーン)、**プログラム全体のフォントサイズ** (85-140 %、YA-MS と同様)。言語と配色を変えるとウィンドウが再構築されます: 設定とスポットは残ります。 |
| 地図と予測データ | 大陸。タブバーのメニューと同じです。 |
| 時刻 | NTP の状態と、サーバーの時刻と PC の時計の差。 |
| 更新 | 起動時と 30 分ごとの GitHub での確認、自動・無言の更新、**今すぐ確認** ボタン。自動更新はシステムパッケージ (.deb、.rpm、Arch、Slackware) には適用されません。 |
| データ | `data` フォルダーを開くボタン。Bureau of Meteorology の API キーは引き続き DATA COLLECTION › 伝搬データ にあります。 |

## スポットの振り分け

左側の表には、プログラムが各スポットの行き先を決めるルールが **適用される順序で** 一覧表示されます: 最初に当てはまったルールがタブを決めます。表示される値はフィルターで設定した値です。

| # | スポットが... | 振り分け先 |
|---|---|---|
| 1 | ローカルフィルターの範囲外 (27990 kHz 未満または 145 MHz 超; 430-440 MHz はオーロラのみ) | 破棄 |
| 2 | AUE、AU-E または AURORAL E を含む | AURORA (オーロラ E) |
| 3 | オーロラの語を含む (初期値 AU、AUR) | AURORA |
| 4 | F.A.I. の語を含む (初期値 FAI; バンドは 6、4、2 m: F.A.I. は 432 MHz には届かない) | F.A.I. |
| 5 | メテオスキャッターのモードまたは `<MS>` がある | METEOR SCATTER |
| 6 | バンドプランの MS ウィンドウに入る (50 MHz では排他的でない; 50・70 MHz の FT8 と FT4 は除く) | METEOR SCATTER |
| 7 | 50 MHz の FT8 または FT4 で、4 分以内に中間点が 150 km 以内の別のスポットがない | メテオスキャッター (スポラディックE ではない) |
| 8 | 144 MHz の Q65 または JT65 (`<ES>` がある場合を除く) | EME: 破棄 |
| 9 | 他の伝搬の記述を含む | スポラディックE ではない |
| 10 | 赤道横断伝搬である | スポラディックE ではない (TEP) |
| 11-15 | 28、40、50、70、144 MHz で距離のルールに合う | SPORADIC-E |
| 16 | どのルールにも当てはまらない (対流圏、432 MHz、HF...) | タブなし (収集スポットに残る) |

右側には **ローカルフィルター** と各モードのフィルターが 5 つのサブタブにあります: メテオスキャッター (YA-MS のフィルターは METEOR SCATTER タブで設定します)、スポラディックE、F.A.I.、オーロラ、そして **フィルターのテスト** です。フィルターのテストではクラスターの行を貼り付けると、それがどう分類されるかがわかります。**作者のルールに戻す** ボタンで初期値に戻ります。
