# การตั้งค่า

[← Home](Home-th)

ตั้งแต่เวอร์ชัน 0.4.18 แท็บ **การตั้งค่า** รวบรวมตัวเลือกทั่วไปของโปรแกรมและการคัดแยกสปอตไปยังแท็บต่าง ๆ มีแท็บย่อยสองแท็บ

## ทั่วไป

| ส่วน | สิ่งที่ตั้งค่า |
|---|---|
| สถานี | สัญญาณเรียกขาน โลเคเตอร์ และความสูง เหมือนในแถบด้านบน; **นำไปใช้** ยืนยันค่าเหล่านี้สำหรับทุกแท็บ |
| รูปลักษณ์ | ภาษา ชุดสี (ชุดสีของ YAEC และ YA-MS และตั้งแต่เวอร์ชัน 0.5.0 ธีมทั้งหกของ IP-TRX-CTRL: สว่าง, กลางคืน, ดำ, น้ำเงิน, ม่วง, เขียว) และ**ขนาดแบบอักษรของทั้งโปรแกรม** (85-140 % เหมือนใน YA-MS) ภาษาและชุดสีจะสร้างหน้าต่างใหม่: การตั้งค่าและสปอตยังคงอยู่ |
| แผนที่และข้อมูลพยากรณ์ | ทวีป เมนูเดียวกับในแถบแท็บ |
| เวลา | สถานะ NTP และความต่างระหว่างเวลาของเซิร์ฟเวอร์กับนาฬิกาของ PC |
| การอัปเดต | การตรวจบน GitHub เมื่อเริ่มโปรแกรมและทุก 30 นาที การอัปเดตอัตโนมัติแบบเงียบ ปุ่ม **ตรวจเดี๋ยวนี้** การอัปเดตอัตโนมัติไม่ใช้กับแพ็กเกจของระบบ (.deb, .rpm, Arch, Slackware) |
| ข้อมูล | ปุ่มที่เปิดโฟลเดอร์ `data` คีย์ API ของ Bureau of Meteorology ยังคงอยู่ใน DATA COLLECTION › ข้อมูลการแพร่กระจาย |

## การคัดแยกสปอต

ทางซ้าย ตารางแสดงกฎที่โปรแกรมใช้ตัดสินว่าแต่ละสปอตจะไปที่ใด **ตามลำดับที่ใช้**: กฎแรกที่เข้าเงื่อนไขจะตัดสินแท็บ ค่าที่แสดงคือค่าที่ตั้งไว้ในตัวกรอง

| # | ถ้าสปอต... | ไปที่ |
|---|---|---|
| 1 | อยู่นอกตัวกรองในเครื่อง (ต่ำกว่า 27990 kHz หรือสูงกว่า 145 MHz; 430-440 MHz เฉพาะออโรรา) | ทิ้ง |
| 2 | มี AUE, AU-E หรือ AURORAL E | AURORA (ออโรรา-E) |
| 3 | มีคำของออโรรา (ค่าเริ่มต้น AU, AUR) | AURORA |
| 4 | มีคำของ F.A.I. (ค่าเริ่มต้น FAI; ย่าน 6, 4 และ 2 m: F.A.I. ไปไม่ถึง 432 MHz) | F.A.I. |
| 5 | มีโหมด meteor scatter หรือ `<MS>` | METEOR SCATTER |
| 6 | อยู่ในหน้าต่าง MS ของแผนความถี่ (บน 50 MHz ไม่เด็ดขาด; ยกเว้น FT8 และ FT4 บน 50 และ 70 MHz) | METEOR SCATTER |
| 7 | เป็น FT8 หรือ FT4 บน 50 MHz ที่ไม่มีสปอตอื่นภายใน 4 นาทีที่มีจุดกึ่งกลางภายใน 150 km | meteor scatter (ไม่ใช่ Sporadic-E) |
| 8 | เป็น Q65 หรือ JT65 บน 144 MHz (เว้นแต่มี `<ES>`) | EME: ทิ้ง |
| 9 | มีแท็กของการแพร่กระจายแบบอื่น | ไม่ใช่ Sporadic-E |
| 10 | เป็นแบบข้ามเส้นศูนย์สูตร | ไม่ใช่ Sporadic-E (TEP) |
| 11-15 | อยู่บน 28, 40, 50, 70 หรือ 144 MHz ภายในกฎระยะทาง | SPORADIC-E |
| 16 | ไม่เข้ากฎใดเลย (tropo, 432 MHz, HF...) | ไม่มีแท็บ (คงอยู่ใน สปอตที่เก็บรวบรวม) |

ทางขวาคือ **ตัวกรองในเครื่อง** และตัวกรองของแต่ละโหมด ในแท็บย่อยห้าแท็บ: Meteor scatter (ตัวกรองของ YA-MS ตั้งค่าในแท็บ METEOR SCATTER), Sporadic-E, F.A.I., ออโรรา และ **ทดสอบตัวกรอง** ซึ่งให้วางบรรทัดของคลัสเตอร์แล้วดูว่าถูกจัดประเภทอย่างไร ปุ่ม **คืนค่ากฎของผู้เขียน** จะนำค่าเริ่มต้นกลับมา
