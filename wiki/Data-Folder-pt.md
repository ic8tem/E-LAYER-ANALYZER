# Pasta de dados

[← Home](Home-pt)

Tudo está na pasta `data` ao lado do programa (`C:\E-LAYER-ANALYZER\data`, `~/E-LAYER-ANALYZER/data`). Nada em AppData.

| Ficheiro / pasta | Conteúdo |
|---|---|
| `ela.ini` | Definições do E-LAYER ANALYZER (estação, sessões, vistas) |
| `config.ini` | Definições do YA-MS, idioma e esquema de cores |
| `call3.txt`, `call3_nuovi.txt` | Base de dados indicativo → locator e locators aprendidos dos spots |
| `spot/` | Spots recolhidos, um CSV por dia |
| `log/` | Relatório do LoTW descarregado |
| `swpc/` | Dados da NOAA (oval, Kp, vento solar) |
| `mappa/` | Costas e fronteiras do Natural Earth |
| `igrf14.csv` | Coeficientes do modelo magnético IGRF-14 |
| `lingue/` | Traduções |
| `ela_documento_tecnico*`, `ela_manuale*`, `ela_relazione*` (.txt/.docx), `ela_fonti*.txt` | Síntese das escolhas de cálculo, manual de utilização, relatório técnico e fontes em todos os idiomas |
