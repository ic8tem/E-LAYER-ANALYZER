# LOG ADIF

[← Home](Home-pt-br)

![LOG ADIF](https://raw.githubusercontent.com/ic8tem/E-LAYER-ANALYZER/ci-screenshots/6_log_adif.png)

- **Abrir arquivo ADIF...** (são permitidos vários arquivos) ou **Baixar do LoTW...** (nome de usuário e senha; a senha nunca é salva).
- Uma aba para cada banda **a partir de 28 MHz**, cada uma por si, **sem agregação**; ao lado: quadrados trabalhados / confirmados.
- Cores: **laranja** = trabalhado, **azul** = confirmado por QSL, **verde** = confirmado via LoTW.
- Filtro pelo **modo de propagação** do log (PROP_MODE: ES, FAI, AUR/AUE, MS, TR, EME, F2).
- Clique em um quadrado: lista dos QSO com data, hora, modo e confirmação, distância e azimute.
- **Limpar memória**: retira os arquivos abertos e o relatório do LoTW.
