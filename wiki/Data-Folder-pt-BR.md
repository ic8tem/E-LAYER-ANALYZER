# Pasta de dados

[← Home](Home-pt-BR)

Tudo fica na pasta `data` ao lado do programa (`C:\E-LAYER-ANALYZER\data`, `~/E-LAYER-ANALYZER/data`). Nada em AppData.

| Arquivo / pasta | Conteúdo |
|---|---|
| `ela.ini` | Configurações do E-LAYER ANALYZER (estação, sessões, vistas) |
| `config.ini` | Configurações do YA-MS, idioma e esquema de cores |
| `call3.txt`, `call3_nuovi.txt` | Banco de dados indicativo → locator e locators aprendidos dos spots |
| `spot/` | Spots coletados, um CSV por dia |
| `log/` | Relatório do LoTW baixado |
| `swpc/` | Dados da NOAA (oval, Kp, vento solar) |
| `mappa/` | Litorais e fronteiras Natural Earth |
| `igrf14.csv` | Coeficientes do modelo magnético IGRF-14 |
| `lingue/` | Traduções |
| `ela_documento_tecnico*`, `ela_manuale*`, `ela_relazione*` (.txt/.docx), `ela_fonti*.txt` | Resumo das escolhas de cálculo, manual do usuário, relatório técnico e fontes em todos os idiomas |
