# LOG ADIF

[← Home](Home-ru)

![LOG ADIF](https://raw.githubusercontent.com/ic8tem/E-LAYER-ANALYZER/ci-screenshots/6_log_adif.png)

- **Открыть файл ADIF...** (можно несколько файлов) или **Загрузить из LoTW...** (имя пользователя и пароль; пароль никогда не сохраняется).
- Отдельная вкладка для каждого диапазона **от 28 MHz и выше**, каждый сам по себе, **без объединения**; рядом: сработанные / подтверждённые квадраты.
- Цвета: **оранжевый** = сработан, **синий** = подтверждён QSL, **зелёный** = подтверждён через LoTW.
- Фильтр по **виду распространения** из лога (PROP_MODE: ES, FAI, AUR/AUE, MS, TR, EME, F2).
- Щелчок по квадрату: список QSO с датой, временем, видом излучения и подтверждением, расстоянием и азимутом.
- **Очистить память**: убирает открытые файлы и отчёт LoTW.
