# 設定

[← Home](Home-zh-tw)

自 0.4.18 版起，**設定** 頁籤集中了程式的一般選項，以及 spot 在各頁籤之間的分派。它有兩個子頁籤。

## 一般

| 區段 | 設定內容 |
|---|---|
| 電台 | 呼號、網格座標與高度，與上方工具列相同；**套用** 會將其確認到所有頁籤。 |
| 外觀 | 語言、配色（YAEC 與 YA-MS 的方案，以及自 0.5.0 版起 IP-TRX-CTRL 的六種主題：淺色、夜間、黑色、藍色、紫色、綠色）以及**整個程式的字型大小**（85-140 %，與 YA-MS 相同）。變更語言與配色會重建視窗：設定與 spot 都會保留。 |
| 地圖與預報資料 | 洲，與頁籤列中的選單相同。 |
| 時間 | NTP 狀態，以及伺服器時間與電腦時鐘的差。 |
| 更新 | 啟動時及每 30 分鐘在 GitHub 上檢查、自動靜默更新、**立即檢查** 按鈕。自動更新不適用於系統套件（.deb、.rpm、Arch、Slackware）。 |
| 資料 | 開啟 `data` 資料夾的按鈕。Bureau of Meteorology 的 API 金鑰仍在 DATA COLLECTION › 傳播資料 中。 |

## spot 分派

左側的表格**依套用順序**列出程式決定每一筆 spot 去向的規則：第一條符合的規則決定頁籤。顯示的數值是在篩選器中設定的數值。

| # | 如果 spot... | 送往 |
|---|---|---|
| 1 | 在本機篩選的範圍外（低於 27990 kHz 或高於 145 MHz；430-440 MHz 僅限極光） | 已捨棄 |
| 2 | 含有 AUE、AU-E 或 AURORAL E | AURORA（極光 E） |
| 3 | 含有極光的字詞（預設 AU、AUR） | AURORA |
| 4 | 含有 F.A.I. 的字詞（預設 FAI；頻段 6、4 與 2 m：F.A.I. 到不了 432 MHz） | F.A.I. |
| 5 | 使用流星散射模式或帶有 `<MS>` | METEOR SCATTER |
| 6 | 落在頻段計畫的 MS 頻率窗內（在 50 MHz 不具排他性；50 與 70 MHz 的 FT8 與 FT4 除外） | METEOR SCATTER |
| 7 | 是 50 MHz 的 FT8 或 FT4，4 分鐘內沒有中點在 150 km 以內的其他 spot | 流星散射（非散塊 E 層） |
| 8 | 是 144 MHz 的 Q65 或 JT65（有 `<ES>` 時除外） | EME：已捨棄 |
| 9 | 含有其他傳播方式的標記 | 非散塊 E 層 |
| 10 | 屬於跨赤道傳播 | 非散塊 E 層（TEP） |
| 11-15 | 在 28、40、50、70 或 144 MHz 且符合距離規則 | SPORADIC-E |
| 16 | 不符合任何規則（對流層、432 MHz、HF...） | 無頁籤（留在 已收集的 spot 中） |

右側是 **本機篩選** 與各模式的篩選器，分為五個子頁籤：流星散射（YA-MS 的篩選器在 METEOR SCATTER 頁籤中設定）、散塊 E 層、F.A.I.、極光，以及 **篩選器測試**，在其中貼上一行 Cluster 內容即可看到它如何分類。**恢復作者規則** 按鈕會恢復預設值。
