# LOG ADIF

[← 首頁](Home-zh-tw)

![LOG ADIF](https://raw.githubusercontent.com/ic8tem/E-LAYER-ANALYZER/ci-screenshots/6_log_adif.png)

- **開啟 ADIF 檔案...**（可開啟多個檔案）或 **從 LoTW 下載...**（使用者名稱與密碼；密碼永遠不會儲存）。
- **28 MHz 以上**的每個頻段各有一個頁籤，各自獨立、**不合併**；旁邊列出已通聯 / 已確認的網格數。
- 顏色：**橘色** = 已通聯，**藍色** = 以 QSL 確認，**綠色** = 經由 LoTW 確認。
- 可依日誌的**傳播模式**篩選（PROP_MODE：ES、FAI、AUR/AUE、MS、TR、EME、F2）。
- 點選網格：列出通聯清單，含日期、時間、模式與確認狀態、距離與方位角。
- **清除記憶**：移除已開啟的檔案與 LoTW 報告。
