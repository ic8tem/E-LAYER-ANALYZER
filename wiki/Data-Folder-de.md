# Datenordner

[← Home](Home-de)

Alles liegt im Ordner `data` neben dem Programm (`C:\E-LAYER-ANALYZER\data`, `~/E-LAYER-ANALYZER/data`). Nichts in AppData.

| Datei / Ordner | Inhalt |
|---|---|
| `ela.ini` | Einstellungen von E-LAYER ANALYZER (Station, Sitzungen, Ansichten) |
| `config.ini` | Einstellungen von YA-MS, Sprache und Farbschema |
| `call3.txt`, `call3_nuovi.txt` | Datenbank Rufzeichen → Locator und aus Spots gelernte Locator |
| `spot/` | Gesammelte Spots, eine CSV-Datei pro Tag |
| `log/` | Geladener LoTW-Report |
| `swpc/` | NOAA-Daten (Oval, Kp, Sonnenwind) |
| `mappa/` | Küstenlinien und Grenzen von Natural Earth |
| `igrf14.csv` | Koeffizienten des Magnetfeldmodells IGRF-14 |
| `lingue/` | Übersetzungen |
| `ela_documento_tecnico*`, `ela_manuale*`, `ela_relazione*` (.txt/.docx), `ela_fonti*.txt` | Zusammenfassung der Berechnungsentscheidungen, Bedienungsanleitung, Technischer Bericht und Quellen in jeder Sprache |
