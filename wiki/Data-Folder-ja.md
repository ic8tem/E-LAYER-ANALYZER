# データフォルダー

[← Home](Home-ja)

すべてはプログラムの隣にある `data` フォルダーに入っています (`C:\E-LAYER-ANALYZER\data`、`~/E-LAYER-ANALYZER/data`)。AppData には何もありません。

| ファイル / フォルダー | 内容 |
|---|---|
| `ela.ini` | E-LAYER ANALYZER の設定 (自局、セッション、表示) |
| `config.ini` | YA-MS の設定、言語、配色 |
| `call3.txt`, `call3_nuovi.txt` | コールサイン → ロケーターのアーカイブと、スポットから取得したロケーター |
| `spot/` | 収集スポット (1 日 1 つの CSV) |
| `log/` | ダウンロードした LoTW レポート |
| `swpc/` | NOAA データ (オーバル、Kp、太陽風) |
| `mappa/` | Natural Earth の海岸線と国境 |
| `igrf14.csv` | 地磁気モデル IGRF-14 の係数 |
| `lingue/` | 翻訳 |
| `ela_documento_tecnico*`, `ela_manuale*`, `ela_relazione*` (.txt/.docx), `ela_fonti*.txt` | 各言語の計算上の選択の概要、ユーザーマニュアル、技術報告書、出典 |
