TITLE|E-LAYER ANALYZER 使用手册
SUB|详细使用手册 - 作者 Costantino IC8TEM - 版本 0.5.0，2026 年 11 月。方括号中的数字指向“来源”选项卡；公式和计算选择见“计算选择摘要”选项卡。
H1|1. 开始之前
H2|1.1 程序的功能
P|E-LAYER ANALYZER 将研究经由电离层 E 层的 VHF 传播模式所需的工具集中在一个程序中：偶发 E 层（包括多跳和洲际传播）、F.A.I.（沿磁场排列的不规则体）、流星散射（集成 YA-MS 程序）以及无线电极光。程序处理实时 DX cluster 的 spot 和 ADIF 日志，并将每个结果显示在占窗口三分之二的地图上，数据和计算位于右侧三分之一。
H2|1.2 安装与数据文件夹
P|程序可在 Windows（64 位、32 位和 ARM64）、Linux（x86_64、ARM64、armv7l 和 Alpine）、Raspberry Pi（64 位和 32 位 Raspberry Pi OS、Slackware ARM64）和 Mac（Apple Silicon 和 Intel）上运行；FreeBSD amd64 有一个试验性软件包。可从 GitHub 仓库的 Releases 页面下载：Windows 有安装程序和 .zip 格式的便携版；Linux 有 .deb、.rpm、Arch 和 Slackware 软件包、AppImage 以及带安装脚本的 .tar.gz 压缩包；Mac 有 .dmg 镜像。没有适用于 Linux i686（32 位 PC）和 OpenBSD 的版本，因为这些系统没有 .NET。
LI|Windows：安装程序把程序装在 C:\E-LAYER-ANALYZER，data 文件夹就在旁边；便携版可解压到任意文件夹，用 E-LAYER-ANALYZER.exe 启动。使用 ARM 处理器（Snapdragon）的电脑有 -win-arm64- 文件。
LI|Linux 和 Raspberry Pi：使用 .deb 包（sudo apt install ./e-layer-analyzer_..._amd64.deb，或用于 64 位 Raspberry Pi OS 的 _arm64.deb 和用于 32 位的 _armhf.deb）时，程序从菜单启动，首次启动时会复制到 ~/E-LAYER-ANALYZER；使用 .tar.gz 压缩包（linux-x64、linux-arm64、linux-arm 或 linux-armv7l）时，解压后运行 ./E-LAYER-ANALYZER，或用 ./installa.sh 把它安装到 ~/E-LAYER-ANALYZER 并在菜单中添加图标。
LI|Slackware（x86_64 和 ARM64）：以 root 身份用 installpkg e-layer-analyzer-...-x86_64-1_ic8tem.txz（或 -aarch64-）安装软件包；程序从菜单或终端用 e-layer-analyzer 启动，首次启动时会复制到 ~/E-LAYER-ANALYZER，与 .deb 相同。
LI|Fedora 和 openSUSE：sudo dnf install ./e-layer-analyzer-....x86_64.rpm（或 zypper install；另有 .aarch64.rpm 和 .armv7hl.rpm）。Arch、Manjaro、EndeavourOS 和 Arch Linux ARM：sudo pacman -U e-layer-analyzer-...-x86_64.pkg.tar.zst（或 -aarch64）。使用这些软件包时，程序同样会在首次启动时复制到 ~/E-LAYER-ANALYZER。
LI|AppImage（x86_64 和 aarch64）：一个文件适用于几乎所有 Linux 发行版；设为可执行后启动。首次启动时会把程序复制到 ~/E-LAYER-ANALYZER，并从那里启动。
LI|Alpine Linux 及其他使用 musl 的 Linux：-alpine-x64- 或 -alpine-arm64-portatile.tar.gz 压缩包；需要 icu-libs 和 fontconfig 软件包（apk add icu-libs fontconfig）。
LI|FreeBSD amd64：试验性、未经验证的软件包（-freebsd-amd64-sperimentale.tar.gz）。需要社区版 .NET 8（pkg install dotnet），以及为 FreeBSD 编译的 SkiaSharp 和 HarfBuzzSharp 库，而 Avalonia 不提供这些库：没有它们程序无法启动。说明见 LEGGIMI-FREEBSD.txt 文件。
LI|Mac：打开 .dmg 文件（arm64 用于 Apple Silicon M1-M4，x64 用于 Intel），右键点击 «Installa E-LAYER-ANALYZER.command» 并选择“打开”；另外，-app.zip 文件只包含应用程序本身。
LI|程序的所有数据都存放在程序旁边的 data 文件夹中：设置（config.ini）、CALL3 数据库、磁场系数、日志、下载的 NOAA 数据、收集的 spot。不会向 AppData 或其他系统文件夹写入任何内容。
LI|要将程序移到另一台计算机，只需复制其文件夹；要恢复初始设置，只需删除 data/config.ini。
LI|程序在 data 文件夹中还保存：lingue（翻译）、spot（收集到的 spot）、spot_ms（YA-MS 的流星散射 spot）、swpc（NOAA 数据）、mappa（Natural Earth 的海岸线和国界，首次启动时从 GitHub 下载：第一次需要联网）和 aggiornamento（自动更新的安装包，可以删除）。
LI|LoTW 密码从不保存；只能记住用户名。
LI|更新：从 0.4.5 版起，程序会在启动时以及之后每 6 小时自动检查 GitHub 上是否有新版本。如果有，会通过一个窗口和顶部栏中的橙色 ▲ 字样提示：“立即更新”会下载适合本机的软件包（Windows 64 或 32 位、Linux、Raspberry Pi、Mac），关闭程序，替换文件并重新启动；“稍后”表示推迟，“跳过此版本”则不再提示该版本。设置、已收集的 spot 和 call3.txt 都会保留。可以用同一窗口中的复选框关闭此检查。
LI|从 0.4.12 版起，更新为自动且静默：GitHub 上有新版本时，程序会下载、安装并自动重新启动，不询问任何问题。缺失的文件也会在不询问的情况下重新下载。只有点击顶部的版本号，或在“设置”（常规）中关闭自动更新时，才会出现更新窗口。
LI|自动更新适用于 Windows 的安装程序和 zip、Mac 的应用、.tar.gz 压缩包和 AppImage。使用系统软件包（.deb、.rpm、Arch 和 Slackware）时，程序不会自行更新：它会提示新版本，需从 Release 页面下载新软件包，并像第一次一样安装。
LI|磁场模型也会自动更新：启动时以及每 30 天，程序会在不询问的情况下到 NOAA 网站查找新一代 IGRF，如果有，就下载到 data 文件夹并立即使用。
LI|缺失的文件：启动时，程序会检查随程序分发的所有文件（翻译、文档、表格）是否齐全。如有缺失，会弹出窗口列出这些文件，“从 GitHub 下载”按钮会从 GitHub 上发布的同一版本重新获取它们。
LI|更新过程中，窗口会显示下载和解压的进度。如果程序文件夹不可写，例如位于系统文件夹内，程序会提示并给出发布页面，可从那里下载安装包；如果某一步失败，会显示原因，按钮变为“Release 页面”。
H2|1.3 顶部栏
P|在左上方输入自己的呼号、网格坐标（4、6 或 8 位）和天线高度（米）；“应用”按钮确认这些数据，所有选项卡随之更新。右上方是 UTC 时间、配色选择（YAEC 的全部配色方案：“浅色”、“夜间”、“黑色”、八种柔和色和“流星余迹”）以及语言选择（36 种语言）。更改配色或语言时窗口会立即重建，不会丢失已收集的数据。
P|UTC 时间旁的 NTP:OK（绿色）或 NTP:FAILED（红色）表示时间是否准确：程序每 5 分钟向分布在世界各地的十台时间服务器中的两台查询，如果没有响应就换用其他服务器。提示框中列出所用的服务器和电脑时钟的偏差。
P|程序始终使用正确的时间：测得的偏差会应用到程序自己的时钟上。如果偏差超过一秒，在 Windows 上且具有管理员权限时，程序还会校正电脑时钟，并在提示框中说明（“电脑时钟已校正”）；在 Linux 和 Mac 上不改动系统时钟。
P|NTP 字样旁显示当前使用的版本（例如 v0.4.5，灰色）：点击一下即可立即检查 GitHub 上是否有更新的版本。有新版本发布时，该字样变为橙色，例如 ▲ 0.4.6，点击一下即可打开更新窗口。
P|选项卡栏右侧是大洲菜单（欧洲、北美洲、南美洲、非洲、亚洲、大洋洲）：它将墨卡托地图以及 F.A.I. 和极光地图移到所选大洲，并选择该大洲的预报数据（N0NBH 的 E-skip 仅发布欧洲和北美洲的数据）。
P|呼号、网格坐标、高度、语言、配色、大洲和更新也可在“设置”选项卡（第 10 章）中设置，那里还可以设置整个程序的字体大小。
H2|1.4 状态栏
P|底部的状态栏显示 CALL3 数据库中的呼号数量、内存中的 spot 数量以及所用的磁场模型（IGRF-14 及其纪元）。内存中的 spot 在每次关闭程序时清除：每次会话都从没有旧 spot 的状态开始。
H2|1.5 地图
P|所有地图的用法相同：鼠标滚轮放大或缩小，按住左键拖动可移动视图，左键单击则根据选项卡选择一个点、一个 spot 或一条路径。右上角显示光标下的坐标和 6 位网格坐标；在方位等距地图中还显示到中心的距离和方位角。Maidenhead 场区和方格的网格随缩放而加密。
LI|每张地图的左下角都有其所用颜色和符号的图例。首次绘制时，可能会有几秒钟显示“正在载入地图（Natural Earth）...”。
H1|2. 数据收集（DATA COLLECTION）
P|该选项卡有两个子选项卡：Spot，包含 telnet 会话、PSKReporter MQTT、WSJT-X UDP、已收集的 spot 和 CALL3 档案；以及“传播数据”（第 2.5 章）。spot 过滤位于“设置”选项卡（第 10 章）。
H2|2.1 三个 telnet 会话
P|DATA COLLECTION 选项卡最多可同时打开三个 telnet 连接：一个任选的 DX cluster（默认为带 VHF 过滤器的 ON0DXK）、Reverse Beacon Network（FT8 用端口 7001，CW 和 RTTY 用端口 7000），以及提供 PSKReporter spot 的 DM4X cluster（dm4x.ddns.net，端口 8500）。
LI|“主机”和“端口”：cluster 的地址。“登录”：用于登录的呼号（为空时使用顶部栏中的呼号）。“登录后命令”：登录后发送的命令，以分号分隔（例如频段过滤器）。
LI|“连接”和“断开”打开和关闭会话；“重新连接”在掉线后自动重新打开会话；“启动时连接”在程序启动时打开会话。
LI|控制台显示收到的行；在下方的输入框中可以输入要发送到 cluster 的命令（例如 sh/dx 20），并用“发送”按钮或 Enter 键确认。
H2|2.2 过滤在哪里
P|在 DATA COLLECTION 收到的每个 spot 在到达各传播方式的选项卡之前都要经过过滤：整个程序只有一个数据收集。从 0.4.18 版起，过滤和本地过滤位于“设置”选项卡的“spot 分流”子选项卡（第 10.2 章）。
H2|2.3 程序如何读取 spot
P|程序从每一行 "DX de" 中提取 spotter、频率、DX、注释、时间，以及（如果有的话）注释中以 JN70CN<ES>JO62QM 形式写出的网格坐标和传播模式（第一个网格坐标属于 spotter，第二个属于 DX；也接受使用 <>、> 和括号的写法）。
LI|缺失的网格坐标在 CALL3 数据库中查找；不精确的网格坐标（少于 6 位）在 CALL3 中有 6 位网格坐标时被其替换。
LI|文本中带有 <MS>、<AU>、<AUR>、<TR>、<AS> 或 <ACS> 的 spot 不用于偶发 E 层：它们用于流星散射、极光、对流层传播或飞机散射。
LI|与 YA-MS 相同，流星散射 spot 是指位于 MS 典型频率窗口（50190-50300、70100-70400、144290-144399 kHz）内且没有其他传播标注的 spot，以及使用 MSK144、FSK441、FSK41、PSK2K、JTMS、JT6M 模式或带有 <MS> 的 spot。50 和 70 MHz 的 FT8 和 FT4 例外：模式已知时由模式决定，因此 70.154 MHz 的 FT8 即使落在流星散射窗口内也归入偶发 E 层。
LI|带有 <AU> 或 <AUR> 的 spot 进入 AURORA 选项卡，带有 FAI 的 spot 进入 F.A.I. 选项卡。
H2|2.4 已收集的 spot 和 CALL3 数据库
P|“已收集的 spot”页面列出最新的 spot，可按频段和来源过滤；“打开 spot 文件夹”按钮打开 data/spot。CALL3 页面显示呼号 -> 网格坐标数据库（JTDX/WSJT 格式）：可以搜索呼号、重新载入数据库，或导入新的 CALL3.TXT 文件替换正在使用的文件（旧文件保留为备份）。
LI|已收集 spot 的列为：UTC、“来源”（cluster、RBN 或 PSKReporter）、MHz、“频段”、DX 及其网格坐标、Spotter 及其网格坐标、km、Prop（声明的或识别出的传播模式）和“注释”。“所有来源”菜单可把表格限定为一个会话。
LI|CALL3 页面显示正在使用的文件、其日期、文件头和已载入的呼号数量（使用随程序分发的数据库时超过一百万个）。
LI|从 0.4.16 版起，整个程序只有一个 CALL3 数据库，即 YA-MS 数据收集（METEOR SCATTER 选项卡）中的数据库，规则与 LIVETROPOVHF 相同：从 MMMonVHF 更新、手工条目、添加的文件、集群修正、学到的定位符以及每 6 小时一次的 G7VRD；修正写入 data/call3.txt，data/call3_nuovi.txt 中的定位符导入一次。WSJT-X、JTDX 和 MSHV 的报告也可通过 UDP 接收（来源 WSJT-X UDP，端口 2237，转发到 2238）。
LI|这些来自 YA-MS 的过滤条件（CW、最小距离、频率窗口、MS 模式、波段）只适用于 METEOR SCATTER 选项卡：它们决定哪些报告进入该选项卡的收集。其他选项卡接收全部报告并使用各自的过滤条件。
H2|2.5 传播数据
P|“传播数据”子选项卡汇集有助于判断某个频段能否打开的数据。数据最多每小时自动更新一次；“立即更新”按钮可立刻下载。
LI|N0NBH (hamqsl.com)：VHF 状况横幅和太阳数据（太阳通量、A 和 K 指数、X 射线、太阳风、Bz、极光和极光纬度），以及欧洲和北美洲的 E-skip（DXrobot 数据）。
LI|N0NBH 的 VHF 条件按 hamqsl.com 发布的原样显示：Band Closed（频段关闭）、50MHz ES、70MHz ES 和 144MHz ES（该频段出现偶发 E 层）、High MUF；极光方面为 High LAT AUR 和 Mid LAT AUR（高纬度或中纬度极光）。
LI|用于极光的 Bz：NOAA SWPC，由 L1 点的卫星（DSCOVR/ACE）每分钟测量的实时太阳风。持续的负 Bz 有利于极光。
LI|极光：Kyoto 的 Dst 指数（地磁暴），以及南半球使用的澳大利亚 Bureau of Meteorology 极光警报，后者需要在“BoM API 密钥”框中填写免费密钥。“AE 指数（Kyoto）”和“SuperDARN 对流”按钮在浏览器中打开这两个页面。
LI|Dst 的级别这样理解：高于 -30 nT 为平静，-30 至 -50 nT 为弱扰动，-50 至 -100 nT 为中等磁暴，-100 nT 及以下为强磁暴。有 BoM 密钥时，还会显示澳大利亚 K 指数和正在发布的极光监测警报。
LI|流星散射：Make More Miles on VHF 的当日流星活动图（RMOB 数据）；流星雨、效率和实时通联位于 METEOR SCATTER 选项卡。
P|这些数据的摘要显示在 SPORADIC-E 和 F.A.I. 地图（所选大洲的 E-skip）以及 AURORA 地图（N0NBH 的极光和 NOAA 的 Bz）的右上角。
H1|3. 偶发 E 层（SPORADIC-E）
P|SPORADIC-E 选项卡有三个子选项卡：REAL-TIME，即本章介绍的实时 spot；BENCHMARK Es（第 4 章）和 BENCHMARK 50 MHz（第 5 章）。
H2|3.1 地图
P|“地图”菜单用于选择投影。“方位等距”：以自己台站为中心的方位等距地图，带缩放滑块（距中心 300 至 20000 km，也可用鼠标滚轮调节）。“墨卡托”：世界地图，带“欧洲”和“世界”按钮。两种投影都会围绕台站绘制 IK3XTV 表 [3] 的距离圆：500 km（单跳最小）、1500-2000 km（最佳）、2400 km（单跳最大）、5000 km（双跳最大）和 6900 km（三跳最大）。
P|50 MHz 跳距长度表来自 Flavio Egano IK3XTV 的 «Propagazione sui 6 metri - Caratteristiche generali»（6 米波段传播——一般特性）[3]；Es 云层位于约 100 km 高度，这使单跳限制在 2000 km 左右 [29]。地图上的环带和跳数遵循以下距离：
TAB|跳;最小距离;最佳距离;最大距离
TAB|单跳;500-650 km;1500-2000 km;2200-2400 km
TAB|双跳;2800-3000 km;3200-4000 km;4400-5000 km
TAB|三跳;-;4800-6400 km;6900 km
P|在方位等距视图中，虚线圆环标注到中心的公里数；圆环间隔随缩放而变化，外边界表示所显示的最大距离。
H2|3.2 控制
LI|“频段”：10、8、6、4 和 2 m（不分析 432 MHz：偶发 E 层不适用 [22]-[24]）；8 m（40 MHz）默认关闭。spot 的时间窗口从 15 分钟到 12 小时。
LI|Es 高度（默认 110 km）和天线的最低仰角（默认 1°）；仰角考虑对流层折射（地球半径 4/3），因此单跳可达约 2440 km。
LI|“首跳（等长跳）”：显示两个台站的第一跳；“短首跳范围”：显示作者提出的短首跳假设（默认 1200 km）[4]。
LI|“Maidenhead 方格上的 Es 云”：按 spot 的最高频率为反射点所在的方格着色（29 MHz 以内为绿色，51 以内为黄色，71 以内为橙色，145 MHz 以内为红色）。如果云在最长跳（2400 km）上的可能 MUF 达到更高的频段，方格会以该频段的颜色闪烁。对 144 MHz 适用作者的规则：只有当云给出 450 至 500 km 的 50 MHz 跳距时（450 km，容差 50 km），方格才会以红色闪烁。
LI|144 MHz 朝向加那利群岛、马德拉和亚速尔群岛（作者的规则）：超过 2400 km 时，只有至少两个 spot 指向同一 Es 云，该 spot 才有效；绘制 Es 跳、云块以及到海岛的虚线对流层路径。在 50 和 70 MHz 不适用此规则。
H2|3.3 表格和详情
P|“Es spot”表列出有效 spot 及其距离、跳数和最低 foEs；“Es 云（方格）”表列出带有估算云的方格，以及这些云对自己台站可提供的 MUF（红色 144 MHz，橙色 70 MHz，黄色 50 MHz）。设置缩放后，表格只显示地图上可见的内容。
LI|“Es spot”表的列：UTC、MHz、DX、Spotter、km、“跳数”、foEs≥（估算的最低 foEs）和 Prop。“Es 云（方格）”表的列：“方格”、foEs≥、spot 数量、相对本台的方位和距离以及“本台 MUF”。
LI|地图上的颜色和符号：10 m 路径为绿色，8 m 为黄色，6 m 为浅蓝色，4 m 为紫色，2 m 为橙色；黄色小方块 = 单跳的中点；橙色小方块 = 报告者的第一跳，紫色小方块 = DX 的第一跳（等长跳）；橙色小圆 = 短的第一跳（IC8TEM 的假设）；绿色圆 = 本台单跳的覆盖范围。
LI|在表格或地图上单击一个 spot：该路径以黄色光晕高亮，必要时地图会将其移入视野，“详情”框显示跳数、反射点、foEs 和方位角。新的 spot 到达时，所选 spot 仍保持选中。
LI|单击地图上的空白处：该点被视为可能的 Es 云，并给出 28、50、70 和 144 MHz 所需的 foEs。
LI|Kp 超过 3 时，地图右上角会给出提示，但这只是一个提示：IK3XTV-IZ3ESV [51] 发现超过 90% 的开通发生在 Kp ≤ 3 时，但在作者的 50 MHz 日志中，Kp > 3 时偶发 E 层并未减少。
LI|超过 11000 km 的 50 MHz QSO 在详细信息中显示为 ALLERTA（警示），仅作为统计消息（EI7GL [56]：HZ1SK-K4MOG，11460 km）。
LI|“多跳前兆”子选项卡：对于远方区域（全世界共三十个），程序检查路径的跳点上（按等长跳，并始终同时考虑 1200 km 以内的首个短跳）是否有由其他台站 spot 看到的活跃 Es 云。警示（红色）：所有跳点都已覆盖；前兆（黄色）：只缺一个跳点，且位于没有观测者的区域。单击一行会绘制虚线路径、跳点（绿色：活跃的云；灰色：没有观测者；红色：没有云）以及证明这些云的 spot；详情中给出每一跳所需的 foEs。
LI|前兆的三十个区域为：日本、朝鲜半岛、中国东部、菲律宾、关岛和马里亚纳群岛、印度尼西亚、澳大利亚北部、澳大利亚东部、新西兰、印度、阿拉伯半岛、中亚、东西伯利亚、西欧、东欧、斯堪的纳维亚、西非、南部非洲、加勒比地区、中美洲、墨西哥、北美洲东部、北美洲中部、北美洲西部、加拿大北部、阿拉斯加、夏威夷、南美洲北部、巴西和南锥体；只检查远离本台的区域。表格的列为“级别”、“区域”、“频段”、“跳数”、“假设”（等长跳或短的第一跳）、km 和 Az°。
LI|以电光蓝绘制并标注 TEP 的 spot，是跨越磁赤道、但比纯粹的 TEP 更长或更不对称的路径（例如 ZS6 - OH、SM、LA）：偶发 E 层可能接上了 TEP。它们仍留在 Es spot 之中；Prop 列中显示 ES+TEP。
H2|3.4 作者的规则
LI|144 MHz：偶发 E 层从 900 km 以上开始；单个 spot 不绘制；如果 5 分钟内同一片云上出现第二个 spot，或附近有一个短跳的 50 MHz spot，则予以绘制。顶部的绿色行显示有多少 spot 正在等待确认。
LI|跨赤道传播：通往非洲大陆（含马达加斯加）和南美洲的路径，如果中点落在磁倾角 -15° 至 +15° 的带内，则该通联属于跨赤道传播而非偶发 E 层，除非 spot 声明了 <ES>。加那利群岛、马德拉群岛、佛得角和阿拉伯半岛不适用此规则。15° 的数值取自 Cracknell [66]，他将 TEP 区域置于距零倾角线约 5-15° 处（作者的选择）。
LI|50 MHz：450 km 以内不是偶发 E 层。FT8 和 FT4 spot 只有属于一片云时才算偶发 E 层，即 4 分钟内有另一条中点在 150 km 以内的 50 MHz spot；孤立的 FT8 或 FT4 spot 归入流星散射（作者的规则）。
LI|70 MHz：450 km 以内不是偶发 E 层（作者的规则；G0ISW [65] 观测到的最短偶发 E 层在 50 和 70 MHz 超过 400 km）。FT8 和 FT4 即使位于频段规划的流星散射窗口内也归入偶发 E 层。
LI|40 MHz（8 m）：最小距离用正割定律由 50 MHz 的 450 km 求出（约 330 km），并且只接受 E 层几何第一跳以内的距离（约 2440 km）。
LI|144 MHz：Q65 和 JT65 spot 属于 EME，不归入偶发 E 层，除非文本中有 <ES>。G0ISW [65] 只在 1400 km 以上观测到 144 MHz 的偶发 E 层：作者的规则从 900 km 起，但要求确认。

LI|表格的列：“每日 QSO”（“日期”、QSO、“频段”、“最大 km”、“多跳”）；“当日各小时”（“UTC 时间”、QSO、“km 最小 - 最大”、“多跳”、“频段”）：点击某个小时会显示该小时的 QSO，含 UTC、“呼号”、“网格坐标”、MHz、km、“跳数”和 foEs≥。点击某个 QSO 会在地图上将其突出显示，并显示对方电台的第一跳。摘要还会说明排除了多少个跨赤道 QSO。

H1|6. F.A.I.

H1|7. METEOR SCATTER
P|该选项卡包含完整的 YA-MS 程序及其各个选项卡（实况与实时数据：实时流星散射通信、雷达流量、GRAVES 雷达；预报计算：天球与计算、几何与路径损耗、效率计算、试验性预报；技术文档：流星雨、来源、来源地图、效率计算说明、使用手册、方格地图）和计算手册。语言和配色与顶部所选的相同。在 E-LAYER ANALYZER 中，YA-MS 的数据收集不显示：数据收集只有一个，即 DATA COLLECTION，它将数据行传给 YA-MS，流星散射 spot 的过滤在 DATA COLLECTION 的过滤列中设置。

H1|8. AURORA
P|AURORA 选项卡使用与 F.A.I. 相同的视图（默认高度 110 km，Lange-Hesse [12]），并结合 NOAA 的空间天气数据 [15]：OVATION 极光椭圆（在地图上以渐变显示）、最近三天的 Kp 指数和太阳风，这些数据每 5 分钟下载到 data/swpc，也可用“立即下载 NOAA”立即下载。程序为两个台站给出建议的天线指向。
LI|本选项卡特有的控件：“极光椭圆（NOAA OVATION）”复选框默认开启，在地图上以渐变显示椭圆，并在选择散射点时将其用作权重；“立即下载 NOAA”立即更新数据。“空间天气（NOAA SWPC）”方框显示最近 3 天每 3 小时的行星 Kp 图，以及椭圆的时间和最近一次下载的时间。Scatter trail 和等反射线视图的用法与 F.A.I. 相同（第 6 章），容差为 3°。
LI|如果勾选“在地图上显示 <AU>/<AUR> spot 并计算”复选框，在“设置”的过滤中所选时间段内（默认最近 2 小时，最多 30 个）的极光 spot 会连同计算出的散射点（橙色圆）绘制在地图上；结果中显示两个台站的 QTF 和仰角。
LI|Scatter trail 视图的结果中显示散射点出现极光的概率（Kp ≤ 2 时不太可能；其余按 NOAA 椭圆）、N 与 NE 之间的典型 QTF（南半球为 S-SE）及与直接路径的偏差，以及关于多普勒和模式的建议（CW/SSB 或宽子模式的 Q65：FT8 常常无法解码）。散射点优先在每个台站的 Lange-Hesse 窗口内搜索，垂直度在 ±3° 以内：地磁纬度 54° 处为 370-1100 km，根据 IGRF-14 倾角，越往南的台站窗口越近，越往北的越远（例如卡普里约 260-990 km，奥斯陆 470-1200 km）。结果中给出每个台站的窗口；如果建议的点在窗口之外，程序会给出提示。
LI|散射点出现极光的概率按以下顺序判定：Kp ≤ 2 时不太可能，除非有磁暴（Dst ≤ -50 nT）；在南半球，有 BoM 极光警报时可能性大；如果该点的椭圆不为零，Dst ≤ -100 nT 时可能性大，Dst ≤ -50 nT 时有可能；椭圆达到 10% 时可能性大；椭圆达到 3% 或 Kp ≥ 5 时有可能；否则不太可能。
LI|超过 2000 km 的极光 spot 标记为存疑：据 Newton [48]，极光可达南北方向约 1000 km、东西方向约 2000 km。极光 E（AUE、AU-E、AURORAL E）的 spot 以绿色绘制在直接路径上：这是极光起源的偶发 E 层，没有多普勒。
LI|结果中给出散射点的太阳时：大多数极光反射发生在当地午夜前后 4 小时之内（Reeve [52]）。在南半球，50 MHz 极光在东西向路径上可达约 2000 km（ANVDG [55]）；极光 E 在直接路径上信号较弱而稳定（SM2CEW-SM0FOB [54]）。
LI|除最可能的散射点外，结果还给出两个电台沿整个 Scatter trail 的 QTF 范围（偏差 ≤ 1.5°）：极光可能来自范围内的任何一点，而最可能的点偏向最短路径。

LI|地图上方是各频段的选项卡：28、50、70、144 和 432 MHz 始终显示，另加日志中出现的其他频段，每个选项卡都标出已通联和已确认的方格数。“传播”菜单可把方格限定为一种模式：ES、FAI、极光（AUR/AUE）、MS、TR、EME、F2 或没有 PROP_MODE 的 QSO。
LI|颜色：橙色 = 已通联未确认，蓝色 = 已用 QSL 确认，绿色 = 已通过 LoTW 确认。“本频段方格”表格列出“方格”、QSO、“状态”、“呼号”和 Prop；点击地图或表格中的方格，会在“所选方格”方框中显示其详情。
LI|“从 LoTW 下载...”会询问用户名、密码，如有需要还可只指定一个呼号；它会下载上传到 LoTW 的所有 QSO 及其确认详情。如果 LoTW 拒绝访问，程序会给出提示；“记住用户名”复选框只保存用户名，从不保存密码。
H1|10. 设置
P|“设置”选项卡汇集了程序的常规选项以及 spot 在各选项卡之间的分流。它有两个子选项卡：“常规”和“spot 分流”。
H2|10.1 常规
LI|台站：呼号、网格坐标和高度，与顶部一行相同；“应用”将其确认到所有选项卡。
LI|外观：语言、配色以及整个程序的字体大小，从 85 到 140 %，与 YA-MS 相同。更改语言和配色会重建窗口，不会丢失设置和 spot。
LI|地图和预报数据：大洲，与选项卡栏中的菜单相同。
LI|时间：NTP 检查的状态以及服务器时间与电脑时间之差。
LI|更新：启动时及每 6 小时在 GitHub 上检查，自动静默更新（不适用于系统软件包 .deb、.rpm、Arch 和 Slackware），以及“立即检查”按钮。
LI|数据：打开 data 文件夹的按钮。Bureau of Meteorology 的 API 密钥仍在 DATA COLLECTION 的“传播数据”中。
H2|10.2 spot 分流
P|左侧的表格按应用顺序列出程序决定每条 spot 去向的规则：第一条符合的规则决定选项卡。显示的数值是在过滤中设置的数值。右侧是本地过滤和各模式的过滤，分为五个子选项卡。
P|最上方是本地过滤的复选框，默认勾选：频率低于 27990.0 kHz 或高于 145 MHz 的 "DX de" 行被丢弃，既不在控制台中显示，也不保存；在 430 至 440 MHz 之间只放行极光 spot。这对 RBN 和 PSKReporter 尤其有用，因为它们会发送大量 HF spot。取消勾选则全部放行。下方有五个子选项卡。
LI|流星散射：YA-MS 的过滤（MS 典型频率窗口、其他传播方式的标签、MS 数字模式和 <MS>、频段、过滤测试和计数器）。在 E-LAYER ANALYZER 中，YA-MS 的过滤在 METEOR SCATTER 选项卡中设置，并且只对该选项卡有效。
LI|偶发 E 层：将 spot 排除在偶发 E 层之外的 < > 标签；28、40、50 和 70 MHz 规则（在 50 和 70 MHz，450 km 以内不算偶发 E 层；在 40 MHz，从约 330 km 到第一跳，约 2440 km；50 MHz 的 FT8 和 FT4 只有属于一片云时才算；28 MHz 的最小距离按 IK3XTV 由 50 MHz 的距离推出，约 170 km；频段规划不是排他性标准，因此位于流星散射窗口内的 spot 仍归入偶发 E 层，除非是数字模式 MS 或 <MS>）；144 MHz 规则（最小距离；几分钟内由同一片云上的第二个 spot 确认，或由附近一个短跳的 50 MHz spot 确认）以及跨赤道传播规则及其磁倾角带，该规则适用于非洲和南美洲（作者的规则），并在全球范围内适用于以近乎南北方向跨越磁赤道的 3000-8000 km 通联（Kennewell 和 Wilkinson [49]）。“恢复作者规则”按钮可恢复默认值。
LI|偶发 E 层规则的默认值，均可修改：50 和 70 MHz 最小距离 450 km；50 MHz 的 FT8 和 FT4 需 4 分钟内有另一条 spot 且中点在 150 km 以内；144 MHz 规则开启，最小距离 900 km，需在 5 分钟内由 300 km 以内同一云上的第二个 spot 确认，或由最近 15 分钟内短跳不超过 1200 km 的 50 MHz spot 确认；跨赤道规则开启，磁倾角带为 ±15°。
LI|F.A.I.：表示 F.A.I. spot 的词（默认 FAI：<FAI> 或 fai 均可，大写、小写或混合均可；这些 spot 不归入偶发 E 层）、频段（6、4 和 2 m：F.A.I. 到不了 432 MHz）以及地图上 spot 的时间段（默认 24 小时）。
LI|极光：极光 spot 的词（带或不带 < >，不区分大小写；默认 AU 和 AUR）、频段以及地图上 spot 的时间段（默认 2 小时）。
LI|过滤测试：输入或粘贴一行集群数据，程序显示各过滤如何对其分类（流星散射、极光、F.A.I.、跨赤道传播、偶发 E 层），并给出频段、网格坐标和距离。
H1|11. 文档
P|“来源”选项卡按选项卡列出程序引用的来源。“计算选择摘要”选项卡给出公式和计算选择，并在每一步注明来源；本“使用手册”说明如何使用程序；“技术报告”阐述指导程序实现的理由。这三份文档都可以导出为 Word。
LI|每个文档的顶部都有“导出为 Word (.docx)...”按钮（把副本保存到任意位置）和“在 Word 中打开”按钮（用 .docx 文件的默认程序打开）。文档使用顶部所选的语言。
H1|12. 实用建议
LI|首先在顶部输入呼号和网格坐标并按“应用”：所有距离、MUF 和仰角都以此为起点计算。
LI|使用 RBN 和 PSKReporter 时请保持本地过滤开启，以免内存被 HF spot 填满。
LI|分析过去的季节时，请用自己的日志运行两个 BENCHMARK；对于极光和 F.A.I.，务必用等反射线视图验证所给出的点。
LI|计算结果仅供参考：一个 spot 或一个 QSO 只说明该路径当时是开通的，并不能说明云的确切位置。
H1|13. 常见问题
LI|NTP:FAILED：没有任何时间服务器响应。通常是防火墙阻止了 UDP 123 端口；程序会继续使用电脑时钟，并每 5 分钟重试一次。
LI|telnet 会话无法连接或立即关闭：检查主机、端口和登录信息（许多 cluster 要求输入呼号），并确认没有用同一呼号打开的另一个会话，例如来自另一个程序。
LI|SPORADIC-E 中没有 spot：检查所选的频段和时间范围，确认本地过滤没有丢弃该频段（它放行 27990 kHz 至 145 MHz，在 430 至 440 MHz 之间只放行极光），在 144 MHz 还要确认 spot 已得到确认（第 3.4 章）。“过滤器测试”（“设置”，“spot 分流”）可显示 cluster 的一行是如何分类的。
LI|首次启动时地图为空：海岸线和国界在第一次时从 GitHub 下载；需要联网，之后保存在 data/mappa 中。
LI|LoTW 拒绝访问：在 LoTW 网站上检查用户名和密码；日志较大时，下载可能需要几分钟。
LI|自动更新无法启动或失败：检查网络，并确认程序文件夹可写；使用 .deb、.rpm、Arch 和 Slackware 软件包时，自动更新是有意不启动的。无论如何，都可以从发布页面手动把新版本安装在旧版本之上，不会丢失 data 文件夹。
