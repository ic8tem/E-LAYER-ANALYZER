TITLE|Brugervejledning til E-LAYER ANALYZER
SUB|Udførlig brugervejledning - af Costantino IC8TEM - version 0.5.0, november 2026. Tallene i firkantede parenteser henviser til fanen KILDER; formlerne og beregningsvalgene findes i fanen RESUMÉ AF BEREGNINGSVALGENE.
H1|1. Før du begynder
H2|1.1 Hvad programmet gør
P|E-LAYER ANALYZER samler i ét program værktøjerne til at studere de VHF-udbredelsesformer, der går via ionosfærens E-lag: sporadisk E, også multi-hop og interkontinental, F.A.I. (feltlinjeorienterede irregulariteter), meteor scatter, med det integrerede program YA-MS, og radionordlys. Programmet arbejder med spots fra DX-clustere i realtid og med ADIF-logge, og viser hvert resultat på et kort, der fylder to tredjedele af vinduet, med data og beregninger i den højre tredjedel.
H2|1.2 Installation og datamappe
P|Programmet kører på Windows (64 bit, 32 bit og ARM64), Linux (x86_64, ARM64, armv7l og Alpine), Raspberry Pi (Raspberry Pi OS 64 og 32 bit, Slackware ARM64) og Mac (Apple Silicon og Intel); til FreeBSD amd64 findes en eksperimentel pakke. Det hentes fra siden Releases i GitHub-depotet: til Windows findes et installationsprogram og en bærbar version i en .zip-fil; til Linux pakkerne .deb, .rpm, Arch og Slackware, AppImage og .tar.gz-arkiverne med installationsscript; til Mac et .dmg-billede. Der findes ingen versioner til Linux i686 (32 bit-pc'er) og OpenBSD, fordi .NET ikke findes til de systemer.
LI|Windows: installationsprogrammet lægger programmet i C:\E-LAYER-ANALYZER med mappen data ved siden af; den bærbare version pakkes ud i en vilkårlig mappe og startes med E-LAYER-ANALYZER.exe. Til pc'er med ARM-processor (Snapdragon) findes filerne -win-arm64-.
LI|Linux og Raspberry Pi: med .deb-pakken (sudo apt install ./e-layer-analyzer_..._amd64.deb, eller _arm64.deb til 64 bit Raspberry Pi OS og _armhf.deb til 32 bit) startes programmet fra menuen og kopierer sig ved første start til ~/E-LAYER-ANALYZER; med .tar.gz-arkivet (linux-x64, linux-arm64, linux-arm eller linux-armv7l) pakker du det ud og starter ./E-LAYER-ANALYZER, eller også installerer ./installa.sh det i ~/E-LAYER-ANALYZER med ikon i menuen.
LI|Slackware (x86_64 og ARM64): som root installeres pakken med installpkg e-layer-analyzer-...-x86_64-1_ic8tem.txz (eller -aarch64-); programmet startes med e-layer-analyzer fra menuen eller terminalen og kopierer sig ved første start til ~/E-LAYER-ANALYZER, som med .deb-pakken.
LI|Fedora og openSUSE: sudo dnf install ./e-layer-analyzer-....x86_64.rpm (eller zypper install; der findes også .aarch64.rpm og .armv7hl.rpm). Arch, Manjaro, EndeavourOS og Arch Linux ARM: sudo pacman -U e-layer-analyzer-...-x86_64.pkg.tar.zst (eller -aarch64). Også med disse pakker kopierer programmet sig ved første start til ~/E-LAYER-ANALYZER.
LI|AppImage (x86_64 og aarch64): én fil til næsten alle Linux-distributioner; gør den eksekverbar, og start den. Ved første start kopierer den programmet til ~/E-LAYER-ANALYZER og starter det derfra.
LI|Alpine Linux og andre Linux med musl: arkivet -alpine-x64- eller -alpine-arm64-portatile.tar.gz; pakkerne icu-libs og fontconfig skal være installeret (apk add icu-libs fontconfig).
LI|FreeBSD amd64: eksperimentel og ikke verificeret pakke (-freebsd-amd64-sperimentale.tar.gz). Den kræver fællesskabets .NET 8 (pkg install dotnet) og bibliotekerne SkiaSharp og HarfBuzzSharp kompileret til FreeBSD, som Avalonia ikke leverer: uden dem starter programmet ikke. Vejledningen står i filen LEGGIMI-FREEBSD.txt.
LI|Mac: åbn .dmg-filen (arm64 til Apple Silicon M1-M4, x64 til Intel), højreklik på »Installa E-LAYER-ANALYZER.command«, og vælg Åbn; alternativt indeholder filen -app.zip kun selve programmet.
LI|Alle programmets data ligger i mappen data ved siden af programmet: indstillinger (config.ini), CALL3-databasen, magnetfeltkoefficienter, logge, hentede NOAA-data og indsamlede spots. Intet skrives til AppData eller til andre systemmapper.
LI|For at flytte programmet til en anden computer er det nok at kopiere dets mappe; for at vende tilbage til standardindstillingerne er det nok at slette data/config.ini.
LI|I mappen data gemmer programmet også: lingue (oversættelserne), spot (de indsamlede spots), spot_ms (meteor scatter-spots fra YA-MS), swpc (data fra NOAA), mappa (kystlinjer og grænser fra Natural Earth, hentet fra GitHub ved første start: første gang kræves netforbindelse) og aggiornamento (pakkerne fra den automatiske opdatering, som kan slettes).
LI|Adgangskoden til LoTW gemmes aldrig; kun brugernavnet kan huskes.
LI|Opdateringer: fra version 0.4.5 kontrollerer programmet selv, ved opstart og derefter hver 6. time, om der er kommet en ny version på GitHub. Er der det, meddeler det dette med et vindue og med den orange tekst ▲ i linjen øverst: »Opdatér nu« henter den pakke, der passer til computeren (Windows 64 eller 32 bit, Linux, Raspberry Pi, Mac), lukker programmet, erstatter filerne og genstarter det; »Senere« udsætter, »Spring versionen over« foreslår den ikke længere. Indstillinger, indsamlede spots og call3.txt bevares. Kontrollen kan slås fra med afkrydsningsfeltet i samme vindue.
LI|Fra version 0.4.12 er opdateringer automatiske og lydløse: når der er en ny version på GitHub, henter programmet den, installerer den og genstarter af sig selv uden at spørge om noget. Manglende filer hentes også igen uden at spørge. Opdateringsvinduet vises kun med et klik på versionen øverst, eller hvis du slår den automatiske opdatering fra i INDSTILLINGER (Generelt).
LI|Den automatiske opdatering gælder for installationsprogrammet og zip-filen til Windows, Mac-appen, .tar.gz-arkiverne og AppImage. Med systempakkerne (.deb, .rpm, Arch og Slackware) opdaterer programmet sig ikke selv: det melder den nye version, som installeres ved at hente den nye pakke fra siden Releases og installere den som den første.
LI|Også magnetfeltmodellen opdaterer sig selv: ved opstart og hver 30. dag søger programmet uden at spørge efter den nye IGRF-generation på NOAA's websted, og hvis den findes, henter det den til mappen data og bruger den straks.
LI|Manglende filer: ved opstart kontrollerer programmet, at det har alle de filer, det blev distribueret med (oversættelser, dokumenter, tabeller). Mangler der nogen, viser et vindue en liste over dem, og knappen »Hent fra GitHub« henter dem igen fra den samme version udgivet på GitHub.
LI|Under opdateringen viser vinduet, hvordan download og udpakning skrider frem. Hvis der ikke kan skrives i programmets mappe, for eksempel i en systemmappe, siger programmet det og foreslår release-siden, hvorfra installationspakken kan hentes; hvis noget mislykkes, vises årsagen, og knappen skifter til »Release-side«.
H2|1.3 Linjen øverst
P|Øverst til venstre indtaster du dit kaldesignal, din lokator (4, 6 eller 8 tegn) og antennens højde i meter; knappen Anvend bekræfter dem, og alle faner opdateres. Øverst til højre findes UTC-tiden, valget af farvetema (alle temaerne fra YAEC: Lys, Nat, Sort, otte pasteller og Meteorspor) og valget af sprog (36 sprog). Når farvetema eller sprog ændres, genopbygges vinduet straks, uden at indsamlede data går tabt.
P|Ved siden af UTC-tiden angiver teksten NTP:OK (grøn) eller NTP:FAILED (rød), om tiden er synkroniseret: hvert 5. minut spørger programmet to tidsservere blandt ti spredt over hele verden og skifter til andre, hvis de ikke svarer. Værktøjstippet viser de anvendte servere og afvigelsen på pc'ens ur.
P|Programmet bruger altid den korrekte tid: den målte afvigelse anvendes på programmets eget ur. Hvis afvigelsen overstiger et sekund, retter programmet på Windows og med administratorrettigheder også pc'ens ur, og værktøjstippet siger det (»Pc'ens ur er blevet korrigeret«); på Linux og Mac røres systemuret ikke.
P|Ved siden af NTP-teksten står versionen i brug (for eksempel v0.4.5, i gråt): et klik kontrollerer straks, om der findes en nyere på GitHub. Når der kommer en ny version, bliver teksten orange, for eksempel ▲ 0.4.6, og et klik åbner opdateringsvinduet.
P|Til højre i fanelinjen findes kontinentmenuen (Europa, Nordamerika, Sydamerika, Afrika, Asien, Oceanien): den flytter Mercator-kortene og F.A.I.- og nordlyskortene til det valgte kontinent og vælger prognosedataene for det kontinent (E-skip fra N0NBH udgives kun for Europa og Nordamerika).
P|Kaldesignal, lokator, højde, sprog, farveskema, kontinent og opdateringer indstilles også i fanen INDSTILLINGER (kapitel 10), hvor der desuden er skriftstørrelsen for hele programmet.
H2|1.4 Statuslinjen
P|Nederst viser statuslinjen, hvor mange kaldesignaler CALL3-databasen indeholder, hvor mange spots der er i hukommelsen, og hvilken magnetisk model der er i brug (IGRF-14 med dens epoke). Spots i hukommelsen slettes, hver gang programmet lukkes: hver session starter forfra uden gamle spots.
H2|1.5 Kortene
P|Alle kort bruges på samme måde: musehjulet zoomer ind eller ud, træk med venstre knap flytter visningen, og venstreklik vælger et punkt, et spot eller en strækning afhængigt af fanen. Øverst til højre vises koordinaterne og 6-tegns lokatoren under markøren; på de azimutale kort også afstand og azimut fra centrum. Gitteret med Maidenhead-felter og -kvadrater bliver tættere, når der zoomes ind.
LI|Hvert kort har nederst til venstre en forklaring på de farver og symboler, det bruger. Første gang kortet tegnes, kan teksten »Indlæser kortet (Natural Earth)...« vises i nogle sekunder.
H1|2. Dataindsamling (DATA COLLECTION)
P|Fanen har to underfaner: Spots, med telnet-sessionerne, PSKReporter MQTT, WSJT-X UDP, de indsamlede spots og CALL3-databasen, og Udbredelsesdata (kapitel 2.5). Spotfiltrene ligger i fanen INDSTILLINGER (kapitel 10).
H2|2.1 De tre telnet-sessioner
P|Fanen DATA COLLECTION åbner op til tre samtidige telnet-forbindelser: et valgfrit DX-cluster (som standard ON0DXK med VHF-filtre), Reverse Beacon Network (port 7001 for FT8, 7000 for CW og RTTY) og DM4X's cluster med spots fra PSKReporter (dm4x.ddns.net, port 8500).
LI|Vært og Port: clusterets adresse. Login: kaldesignal til adgang (hvis feltet er tomt, bruges det fra linjen øverst). Kommandoer efter login: kommandoer, der sendes efter login, adskilt af semikolon (for eksempel båndfiltre).
LI|Forbind og Afbryd åbner og lukker sessionen; Genforbind åbner den automatisk igen efter et udfald; Forbind ved opstart åbner den, når programmet starter.
LI|Konsollen viser de modtagne linjer; i feltet nedenunder kan du skrive kommandoer, der skal sendes til clusteret (for eksempel sh/dx 20), og bekræfte dem med Send eller med Enter-tasten.
H2|2.2 Hvor filtrene er
P|Hvert spot, der modtages i DATA COLLECTION, går gennem filtrene, før det når fanerne for hver udbredelsesmåde: dataindsamlingen er én for hele programmet. Fra version 0.4.18 ligger filtrene og det lokale filter i fanen INDSTILLINGER, underfanen Fordeling af spots (kapitel 10.2).
H2|2.3 Hvordan programmet læser spots
P|Fra hver "DX de"-linje udtrækker programmet spotter, frekvens, DX, kommentar, tid og, når de findes, lokatorerne og udbredelsesformen skrevet i kommentaren på formen JN70CN<ES>JO62QM (den første lokator er spotterens, den anden DX-stationens; formerne med <>, > og parenteser accepteres også).
LI|Manglende lokatorer søges i CALL3-databasen; upræcise lokatorer (færre end 6 tegn) erstattes med 6-tegns lokatoren fra CALL3, når den findes.
LI|Spots med <MS>, <AU>, <AUR>, <TR>, <AS> eller <ACS> i teksten bruges ikke til sporadisk E: de hører til meteor scatter, nordlys, tropo eller aircraft scatter.
LI|Som i YA-MS regnes som meteor scatter-spots dem, der ligger i de typiske MS-frekvensvinduer (50190-50300, 70100-70400, 144290-144399 kHz) uden angivelse af anden udbredelse, samt dem med modulationerne MSK144, FSK441, FSK41, PSK2K, JTMS, JT6M eller med <MS>. Undtaget er FT8 og FT4 på 50 og 70 MHz: hvis moden er kendt, afgør moden, så FT8 på 70,154 MHz går til sporadisk E, selv om den ligger i meteor scatter-vinduet.
LI|Spots med <AU> eller <AUR> går til fanen AURORA, dem med FAI til fanen F.A.I.
H2|2.4 Indsamlede spots og CALL3-databasen
P|Siden Indsamlede spots viser de seneste spots med filter for bånd og kilde; knappen Åbn spotmappen åbner data/spot. Siden CALL3 viser databasen kaldesignal -> lokator (JTDX/WSJT-format): du kan søge efter et kaldesignal, genindlæse databasen eller importere en ny CALL3.TXT-fil, som erstatter den, der er i brug (den gamle bevares som sikkerhedskopi).
LI|Kolonnerne for de indsamlede spots er: UTC, Kilde (cluster, RBN eller PSKReporter), MHz, Bånd, DX med sin lokator, Spotter med sin lokator, km, Prop (den angivne eller genkendte udbredelsesmåde) og Kommentar. Menuen Alle kilder begrænser tabellen til én session.
LI|Siden CALL3 viser filen i brug, dens dato, overskriften og antallet af indlæste kaldesignaler (over en million med den medfølgende database).
LI|Fra version 0.4.16 er der én CALL3-database for hele programmet, den i YA-MS Dataindsamling (fanen METEOR SCATTER), med samme regler som LIVETROPOVHF: opdatering fra MMMonVHF, håndindtastninger, tilføjede filer, cluster-rettelser, lærte locatorer og G7VRD hver 6. time; rettelserne skrives ind i data/call3.txt og locatorerne i data/call3_nuovi.txt importeres én gang. Spots fra WSJT-X, JTDX og MSHV kommer også via UDP (kilde WSJT-X UDP, port 2237 videresendt til 2238).
LI|Disse filtre fra YA-MS (CW, minimumsafstand, frekvensvinduer, MS-modes, bånd) gælder kun fanen METEOR SCATTER: de afgør, hvilke spots der kommer ind i dens indsamling. De andre faner får alle spots og bruger deres egne filtre.
H2|2.5 Udbredelsesdata
P|Underfanen Udbredelsesdata samler de data, der hjælper med at forstå, om et bånd kan åbne. De opdateres af sig selv højst én gang i timen; knappen Opdater nu henter dem med det samme.
LI|N0NBH (hamqsl.com): banneret med VHF-forholdene og soldataene (solflux, A- og K-indeks, røntgenstråling, solvind, Bz, nordlys og nordlysbredde) med E-skip for Europa og Nordamerika (data fra DXrobot).
LI|VHF-forholdene fra N0NBH vises, som hamqsl.com offentliggør dem: Band Closed (båndet lukket), 50MHz ES, 70MHz ES og 144MHz ES (sporadisk E på det bånd), High MUF; for nordlys High LAT AUR og Mid LAT AUR (nordlys på høje eller mellemste breddegrader).
LI|Bz for nordlys: NOAA SWPC, solvind i realtid målt af satellitten i punktet L1 (DSCOVR/ACE), hvert minut. En negativ og vedvarende Bz begunstiger nordlys.
LI|Nordlys: Dst-indekset fra Kyoto (geomagnetiske storme) og, for den sydlige halvkugle, nordlysvarslerne fra det australske Bureau of Meteorology, som kræver en gratis nøgle, der skrives i feltet BoM API-nøgle. Knapperne AE-indeks (Kyoto) og SuperDARN-konvektion åbner de to sider i browseren.
LI|Dst-niveauet læses sådan: roligt over -30 nT, svag forstyrrelse mellem -30 og -50 nT, moderat storm mellem -50 og -100 nT, kraftig storm fra -100 nT og nedefter. Med nøglen fra BoM vises også det australske K-indeks og de igangværende nordlysvarsler.
LI|Meteor scatter: grafen over dagens meteoraktivitet (RMOB-data) fra Make More Miles on VHF; sværme, effektivitet og live trafik findes under fanen METEOR SCATTER.
P|Sammendraget af disse data vises øverst til højre på kortene SPORADIC-E og F.A.I. (E-skip for det valgte kontinent) og AURORA (nordlys fra N0NBH og Bz fra NOAA).
H1|3. Sporadisk E (SPORADIC-E)
P|Fanen SPORADIC-E har tre underfaner: REAL-TIME, spots i realtid som beskrevet i dette kapitel; BENCHMARK Es (kapitel 4) og BENCHMARK 50 MHz (kapitel 5).
H2|3.1 Kortet
P|Menuen Kort vælger projektionen. Azimutal: azimutalt ækvidistant kort centreret på egen station, med zoomskyderen (fra 300 til 20000 km fra centrum, også med musehjulet). Mercator: verdenskortet med knapperne Europa og Verden. I begge projektioner tegnes afstandscirklerne fra IK3XTV's tabel [3] omkring stationen: 500 km (mindst for ét hop), 1500-2000 km (optimalt), 2400 km (højst for ét hop), 5000 km (højst for dobbelthop) og 6900 km (højst for tredobbelt hop).
P|Tabellen over hoplængder på 50 MHz er Flavio Eganos (IK3XTV), «Propagazione sui 6 metri - Caratteristiche generali» (Udbredelse på 6 meter - Generelle egenskaber) [3]; Es-skyerne ligger i omkring 100 km højde, og det begrænser ét hop til omkring 2000 km [29]. Kortenes ringe og antallet af hop følger disse afstande:
TAB|Hop;Mindste afstand;Optimal afstand;Største afstand
TAB|Ét hop;500-650 km;1500-2000 km;2200-2400 km
TAB|Dobbelthop;2800-3000 km;3200-4000 km;4400-5000 km
TAB|Tredobbelt hop;-;4800-6400 km;6900 km
P|I de azimutale visninger angiver de stiplede ringe km fra centrum; afstanden mellem ringene ændres med zoomen, og yderkanten angiver den største viste afstand.
H2|3.2 Betjeningen
LI|Bånd: 10, 8, 6, 4 og 2 m (432 MHz analyseres ikke: sporadisk E gælder ikke dér [22]-[24]); 8 m (40 MHz) er slået fra som standard. Tidsvindue for spots fra 15 minutter til 12 timer.
LI|Es-højde (som standard 110 km) og antennernes mindste elevation (som standard 1°); elevationen tager højde for troposfærisk refraktion (jordradius 4/3), så det enkelte hop når omkring 2440 km.
LI|Første hop (lige lange hop): viser begge stationers første hop; Kort første hop inden for…: viser forfatterens hypotese om et kort første hop (som standard 1200 km) [4].
LI|Es-skyer på Maidenhead-felter: farver refleksionspunkternes felter efter spottenes højeste frekvens (grøn op til 29 MHz, gul op til 51, orange op til 71, rød op til 145 MHz). Hvis skyens sandsynlige MUF på det længste hop (2400 km) når et højere bånd, blinker feltet med det bånds farve. For 144 MHz gælder forfatterens regel: feltet blinker kun rødt, hvis skyen giver et hop på 50 MHz mellem 450 og 500 km (450 km med en tolerance på 50 km).
LI|144 MHz mod De Kanariske Øer, Madeira og Azorerne (forfatterens regel): over 2400 km gælder spottet kun, hvis mindst to spots peger på den samme Es-sky; Es-hoppet, skyen og den stiplede tropo-strækning frem til øen tegnes. På 50 og 70 MHz gælder reglen ikke.
H2|3.3 Tabeller og detaljer
P|Tabellen Es-spots viser de gyldige spots med afstand, antal hop og mindste foEs; tabellen Es-skyer (felter) viser felterne med estimerede skyer og den MUF, de ville give for egen station (rød 144 MHz, orange 70 MHz, gul 50 MHz). Når der er indstillet en zoom, viser tabellerne kun det, der er synligt på kortet.
LI|Kolonner i tabellen Es-spots: UTC, MHz, DX, Spotter, km, Hop, foEs≥ (estimeret mindste foEs) og Prop. Kolonner i tabellen Es-skyer: Felt, foEs≥, antal spots, azimut og afstand fra egen station og Min MUF.
LI|Farver og symboler på kortet: strækninger på 10 m grønne, på 8 m gule, på 6 m lyseblå, på 4 m violette og på 2 m orange; lille gul firkant = midtpunkt for ét hop; lille orange firkant = spotterens første hop og lille violet firkant = DX-stationens første hop (lige store hop); lille orange cirkel = kort første hop (IC8TEM's antagelse); grøn cirkel = rækkevidde for ét hop fra egen station.
LI|Klik på et spot i tabellen eller på kortet: strækningen lyser op med en gul glorie, kortet flytter den ind i synsfeltet om nødvendigt, og boksen Detaljer viser hop, refleksionspunkter, foEs og azimut. Spottet forbliver valgt, også når der kommer nye spots.
LI|Klik på et tomt punkt på kortet: punktet behandles som en mulig Es-sky, med den foEs, der kræves for 28, 50, 70 og 144 MHz.
LI|Når Kp er over 3, angiver kortet det øverst til højre som en ren advarsel: IK3XTV-IZ3ESV [51] finder over 90 % af åbningerne ved Kp ≤ 3, men i forfatterens 50 MHz-log falder sporadisk E ikke ved Kp > 3.
LI|En QSO på 50 MHz over 11000 km vises i detaljerne som ALARM, kun som statistisk notits (EI7GL [56]: HZ1SK-K4MOG, 11460 km).
LI|Underfanen Multi-hop-forløbere: for fjerne regioner (tredive i hele verden) kontrollerer programmet, om der på strækningens hoppunkter, med lige store hop og altid også med et kort første hop inden for 1200 km, er aktive Es-skyer set i andre stationers spots. ALARM (rød): alle punkter dækket; FORLØBER (gul): der mangler kun ét punkt, i et område uden observatører. Et klik på en række tegner den stiplede strækning, hoppunkterne (grøn: aktiv sky; grå: ingen observatør; rød: ingen sky) og de spots, der beviser skyerne; detaljerne angiver den foEs, der kræves for hvert hop.
LI|De tredive forløberregioner er: Japan, Korea, Østkina, Filippinerne, Guam og Marianerne, Indonesien, Det nordlige Australien, Det østlige Australien, New Zealand, Indien, Den Arabiske Halvø, Centralasien, Østsibirien, Vesteuropa, Østeuropa, Skandinavien, Vestafrika, Det sydlige Afrika, Caribien, Mellemamerika, Mexico, Det østlige Nordamerika, Det centrale Nordamerika, Det vestlige Nordamerika, Det nordlige Canada, Alaska, Hawaii, Det nordlige Sydamerika, Brasilien og Det sydlige Sydamerika; programmet kontrollerer dem, der ligger langt fra egen station. Tabellens kolonner er Niveau, Region, Bånd, Hop, Antagelse (lige store hop eller kort første hop), km og Az°.
LI|Spots med elektrisk blå med teksten TEP er strækninger, der krydser den magnetiske ækvator, men er længere eller mere asymmetriske end ren TEP (for eksempel ZS6 - OH, SM, LA): sporadisk E kan koble sig på TEP. De forbliver blandt Es-spottene; i kolonnen Prop vises ES+TEP.
H2|3.4 Forfatterens regler
LI|144 MHz: sporadisk E begynder over 900 km; et enkeltstående spot tegnes ikke; det tegnes, hvis der inden for 5 minutter kommer et andet spot på samme sky, eller hvis der i nærheden findes et 50 MHz-spot med kort hop. Den grønne linje øverst angiver, hvor mange spots der venter på bekræftelse.
LI|Transækvatorial: mod det afrikanske fastland (med Madagaskar) og Sydamerika er forbindelsen transækvatorial og ikke sporadisk E, hvis midtpunktet falder i bæltet med magnetisk inklination mellem -15° og +15°, medmindre spottet angiver <ES>. De Kanariske Øer, Madeira, Kap Verde og Den Arabiske Halvø er undtaget fra reglen. Værdien 15° er hentet fra Cracknell [66], der placerer TEP-zonerne ca. 5-15° fra linjen med inklination nul (forfatterens valg).
LI|50 MHz: inden for 450 km er det ikke sporadisk E. FT8- og FT4-spots er kun sporadisk E, hvis de hører til en sky, dvs. hvis der inden for 4 minutter er et andet spot på 50 MHz med midtpunktet inden for 150 km; et isoleret FT8- eller FT4-spot går til meteor scatter (forfatterens regel).

LI|40 MHz (8 m): minimumsafstanden udledes af 50 MHz' 450 km med sekansloven (ca. 330 km), og kun afstande inden for det første hop i E-lagets geometri gælder (ca. 2440 km).
LI|144 MHz: Q65- og JT65-spots er EME og kommer ikke med i sporadisk E, medmindre <ES> står i teksten. G0ISW [65] ser sporadisk E på 144 MHz først over 1400 km: forfatterens regel starter ved 900 km, men kræver en bekræftelse.
H1|4. BENCHMARK Es (underfane til SPORADIC-E)
H2|4.1 Indlæsning af en log
P|Underfanen BENCHMARK Es er en prøvebænk for sporadisk E på en hel ADIF-log, også fra en anden station. Indlæs ADIF åbner filen (programmet husker den og indlæser den igen ved opstart), Fjern ADIF fjerner den. LI|Sendepositionen er MY_GRIDSQUARE for hver QSO; modtagepositionerne er GRIDSQUARE (manglende lokatorer eller lokatorer med 4 tegn hentes fra CALL3).
LI|Man kan udelade QSO'er med en anden PROP_MODE og dem under 500 km (900 km på 144 MHz); transækvatoriale QSO'er udelades altid, undtagen ved PROP_MODE=ES. Den magnetiske ækvator er den fra QSO'ets år (historisk IGRF-14), som i BENCHMARK 50 MHz.
LI|På kortet markerer en sløret gul prik midten af hvert hop, hvor skyen af sporadisk E formodes at ligge (også midten af det korte første hop, hvis hypotesen er aktiv).
H2|4.2 Dage, tidspunkter og beregninger

Det azimutale kort, med skyderen for maksimal afstand, tegner skip pr. 10°-sektor (orange bue = nærmeste QSO, grøn sektor = opnåede afstande), skyerne på felterne og, for hele dagen, skyernes forskydning time for time (rød linje).

H1|6. F.A.I.
H2|6.1 De to visninger
P|Fanen F.A.I. undersøger scatter fra feltlinjeorienterede irregulariteter (hovedkilder [1], [2]). Visningen Scatter trail (par A-B) beregner for to stationer det geometriske sted for mulige scatterpunkter, farvet efter afvigelsen fra refleksionsbetingelsen, foreslår det mest sandsynlige scatterpunkt og tegner øverst til højre boksen med QTF og elevation for begge stationer (rød = A, grøn = B). Visningen Iso-refleksion (punkt) tegner for et valgt refleksionspunkt iso-refleksionslinjerne i stil med AuroReflex og K9SE's SE-PROP: farvede bælter i de mørke temaer, tykke linjer i de lyse.
H2|6.2 Betjeningen
LI|Station A og Station B: kaldesignal (søges i CALL3) og/eller lokator; tom A = egen station. Menuen Kontroller... indlæser testparrene (IC8FAX-F6DRO, IC8FAX-G4LOH, IC8FAX-FA1MXE, DL5MCG-SV1DH fra 1987 via Budapest); de to tilfælde med en dato (1990 og 1987) beregnes med IGRF-14-feltet fra det år, som står i kortets billedtekst, så længe stationerne er tilfældets; menuen Kendte scatterpunkter... vælger et dokumenteret scatterpunkt (Genève, Bruxelles, Budapest, JN92, JN41/42).
LI|Højde (som standard 110 km), mindste elevation og Refraktion (4/3 jordradius), slået til fra start.
LI|Menuen Visning vælger mellem Scatter trail (A-B-par) og Iso-refleksion (punkt). I visningen Iso-refleksion ligger niveaukurverne ved 0, ±1, ±2, ±4, ±8 og ±16 graders afvigelse; kurven 0 er det geometriske sted for de stationer, der modtager A via det valgte punkt.
LI|Venstreklik på kortet: refleksionspunkt, der skal kontrolleres (skifter til visningen Iso-refleksion); højreklik: station B's position.
LI|Kontrollér det anbefalede punkt: beregner sporet, tager det foreslåede scatterpunkt og viser dets iso-refleksionslinjer med vurderingen: TILFREDSSTILLENDE (inden for 1°), ACCEPTABEL (inden for 2,5°), IKKE TILFREDSSTILLENDE (derudover).
LI|Resultaterne af visningen Scatter trail angiver det mest sandsynlige scatterpunkt (6-tegns lokator, koordinater og afvigelse), for hver station QTF, elevation og afstand samt den magnetiske inklination i punktet; hvis sporet passerer tæt på et kendt scatterpunkt, siger de det. På kortet viser boksen øverst til højre QTF'erne: A med rødt, B med grønt.
LI|Udstyr (DL5MCG [6]): til F.A.I. på 144 MHz kræves mindst en lang yagi og 100 W (SV1DH er også blevet kørt med en 8-elementers og 50 W). Antennen rettes mod det scatterpunkt, programmet angiver, ikke mod modstationen.
P|Hvis beregningen ifølge modellen ikke er mulig, vises meddelelsen Beregning ikke mulig, og ingen andre resultater vises. Nederst viser tabellen F.A.I.-spots de spots, der er angivet som FAI; et klik på et spot indlæser dets stationspar.
LI|F.A.I.-spots på kortet og i tabellen er dem fra den periode, der er valgt i filtrene i INDSTILLINGER (som standard 24 timer); tabellen viser UTC, MHz, DX, Spotter, km og Kommentar.
H1|7. METEOR SCATTER
P|Fanen indeholder hele programmet YA-MS med dets faner (Live og realtidsdata: live meteor scatter-trafik, radarflux, GRAVES-radaren; Prognoseberegning: himmelhvælvingen og beregning, geometri og dæmpning, effektivitetsberegning, eksperimentel anvendelse af prognoserne; Tekniske dokumenter: sværme, kilder, kildekort, forklaring af effektivitetsberegningen, brugervejledning, feltkort) og dets beregningsvejledning. Sprog og farvetema er dem, der er valgt øverst. Inde i E-LAYER ANALYZER vises Dataindsamling i YA-MS ikke: der er kun én dataindsamling, den i DATA COLLECTION, som sender linjerne videre til YA-MS, og filteret for meteor scatter-spots indstilles i filterkolonnen i DATA COLLECTION.
P|YA-MS 1.8.1 behandler antenneloben som et lodret diagram (feltet «antennediagram», slået til som standard): refleksionspunkterne vægtes med begge antenners lodrette forstærkning, og effektiviteterne forsvinder ikke længere på lange strækninger. Nyt er advarslen «ingen fælles zone», det fremhævede felt for vinklen β (det valg, der vejer mest), én enkelt beregningsdato, «Brugervejledning» og sammenligningen med 181 767 virkelige spots på 50 MHz fra HamSCI Meteor Scatter QSO Party i august 2025: timerne og strækningens sider er pålidelige, procenterne er vejledende.
H1|8. AURORA
P|Fanen AURORA bruger de samme visninger som F.A.I. (standardhøjde 110 km, Lange-Hesse [12]) med rumvejrsdata fra NOAA [15]: nordlysovalen OVATION (skraveret på kortet), Kp-indekset for de seneste tre døgn og solvind, hentet hvert 5. minut til data/swpc eller straks med Hent NOAA nu. Programmet foreslår antenneretning for begge stationer.
LI|Fanens egne kontroller: afkrydsningsfeltet Nordlysoval (NOAA OVATION), slået til fra start, skraverer ovalen på kortet og bruger den som vægt ved valget af scatterpunkt; Hent NOAA nu opdaterer straks dataene. Boksen Rumvejr (NOAA SWPC) viser grafen over planetarisk Kp for de seneste 3 døgn, hver 3. time, samt tidspunktet for ovalen og for den seneste hentning. Visningerne Scatter trail og Iso-refleksion bruges som i F.A.I. (kapitel 6) med tolerancen 3°.
LI|Nordlysspots fra den periode, der er valgt i filtrene i INDSTILLINGER (fra start de seneste 2 timer, højst 30), tegnes på kortet med det beregnede scatterpunkt (orange cirkel), hvis afkrydsningsfeltet <AU>/<AUR>-spots på kortet med beregningen er slået til; i resultaterne vises QTF og elevation for de to stationer.
LI|I resultaterne af visningen Scatter trail vises sandsynligheden for nordlys i scatterpunktet (usandsynlig ved Kp ≤ 2; ellers efter NOAA-ovalen), den typiske QTF mellem N og NØ (S-SØ på den sydlige halvkugle) med afvigelsen fra den direkte vej samt råd om Doppler og modes (CW/SSB eller Q65 med brede undermodes: FT8 dekoder ofte ikke). Scatterpunktet søges helst inden for hver stations Lange-Hesse-vindue, med vinkelrethed inden for ±3°: 370-1100 km ved 54° geomagnetisk bredde, tættere på for stationer længere mod syd og længere væk for stationer længere mod nord, efter IGRF-14-inklinationen (for eksempel Capri ca. 260-990 km, Oslo 470-1200 km). Resultaterne angiver hver stations vindue; hvis det foreslåede punkt ligger udenfor, gør programmet opmærksom på det.
LI|Sandsynligheden for nordlys i scatterpunktet afgøres i denne rækkefølge: usandsynlig ved Kp ≤ 2, undtagen ved storm (Dst ≤ -50 nT); på den sydlige halvkugle sandsynlig ved et nordlysvarsel fra BoM; sandsynlig ved Dst ≤ -100 nT og mulig ved Dst ≤ -50 nT, hvis ovalen i punktet ikke er nul; sandsynlig med ovalen fra 10 %; mulig med ovalen fra 3 % eller ved Kp ≥ 5; ellers usandsynlig.
LI|Nordlys-spots over 2000 km markeres som tvivlsomme: ifølge Newton [48] når nordlys omkring 1000 km nord-syd og 2000 km øst-vest. Spots af nordlys-E (AUE, AU-E, AURORAL E) tegnes med grønt på den direkte vej: det er sporadisk E af auroral oprindelse, uden Doppler.
LI|Resultaterne viser soltiden i scatterpunktet: inden for 4 timer fra lokal midnat falder de fleste nordlysrefleksioner (Reeve [52]). På den sydlige halvkugle når nordlys på 50 MHz op til omkring 2000 km på øst-vest-strækninger (ANVDG [55]); nordlys-E giver svagere og mere stabile signaler på den direkte vej (SM2CEW-SM0FOB [54]).
LI|Ud over det mest sandsynlige scatterpunkt angiver resultaterne QTF-intervallet for de to stationer langs hele sporet (afvigelse ≤ 1,5°): nordlyset kan komme fra ethvert punkt i intervallet, og det mest sandsynlige punkt foretrækker den korteste strækning.

H2|10.2 Fordeling af spots
P|Til venstre viser en tabel de regler, programmet bruger til at afgøre, hvor hvert spot skal hen, i den rækkefølge de anvendes: den første, der passer, afgør fanen. De viste værdier er dem, der er indstillet i filtrene. Til højre ligger det lokale filter og filtrene for hver udbredelsesmåde i fem underfaner.
P|Øverst er afkrydsningsfeltet for det lokale filter, slået til fra start: "DX de"-linjer med frekvens under 27990,0 kHz eller over 145 MHz kasseres, vises ikke i konsollen og gemmes ikke; mellem 430 og 440 MHz slipper kun nordlysspots igennem. Det er især nyttigt med RBN og PSKReporter, der sender rigtig mange spots på HF. Slås feltet fra, slipper alt igennem. Nedenunder er der fem underfaner.
LI|Meteor scatter: filteret fra YA-MS (frekvensvinduer typiske for MS, mærker for anden udbredelse, digitale MS-modes og <MS>, bånd, test af filteret og tællere). Inde i E-LAYER ANALYZER indstilles YA-MS-filteret i fanen METEOR SCATTER og gælder kun for den fane.
LI|Sporadisk E: mærkerne mellem < >, der udelukker et spot fra sporadisk E; 28, 40, 50 og 70 MHz-reglerne (på 50 og 70 MHz er det inden for 450 km ikke sporadisk E; på 40 MHz fra ca. 330 km op til det første hop, ca. 2440 km; FT8 og FT4 på 50 MHz kun hvis de hører til en sky; på 28 MHz udledes minimumsafstanden af den for 50 MHz efter IK3XTV, ca. 170 km; båndplanen er ikke et eksklusivt kriterium, så et spot i meteor scatter-vinduet forbliver i sporadisk E, medmindre det har den digitale mode MS eller <MS>); 144 MHz-reglen (minimumsafstand; bekræftelse med et andet spot på samme sky inden for nogle minutter eller med et 50 MHz-spot med kort hop i nærheden) og den transækvatoriale regel med dens bånd for magnetisk inklination, som gælder for Afrika og Sydamerika (forfatterens regel) og, i hele verden, for forbindelser på 3000-8000 km, der krydser den magnetiske ækvator i næsten nord-syd-retning (Kennewell og Wilkinson [49]). Knappen Gendan forfatterens regler sætter startværdierne tilbage.
LI|Standardværdier for reglerne for sporadisk E, som alle kan ændres: minimumsafstand på 50 og 70 MHz 450 km; FT8 og FT4 på 50 MHz med et andet spot inden for 4 minutter og midtpunkt inden for 150 km; 144 MHz-reglen slået til, med minimumsafstand 900 km og bekræftelse inden for 5 minutter fra et andet spot på en sky inden for 300 km eller fra et spot på 50 MHz fra de seneste 15 minutter med kort hop op til 1200 km; den transækvatoriale regel slået til, med inklinationsbåndet ±15°.
LI|F.A.I.: de ord, der angiver et F.A.I.-spot (fra start FAI: <FAI> eller fai gælder, med store, små eller blandede bogstaver; disse spots kommer ikke med i sporadisk E), båndene (6, 4 og 2 m: F.A.I. når ikke op til 432 MHz) og perioden for spots på kortet (fra start 24 timer).
LI|Nordlys: ordene for nordlysspots, med eller uden < > og med store eller små bogstaver (fra start AU og AUR), båndene og perioden for spots på kortet (fra start 2 timer).
LI|Test af filtre: du skriver eller indsætter en cluster-linje, og programmet viser, hvordan filtrene klassificerer den (meteor scatter, nordlys, F.A.I., transækvatorial, sporadisk E), med bånd, lokator og afstand.

H1|12. Praktiske råd

H1|13. Hyppige problemer
LI|NTP:FAILED: ingen tidsserver har svaret. Normalt blokerer en firewall porten UDP 123; programmet fortsætter med pc'ens ur og prøver igen hvert 5. minut.
LI|Telnet-sessionen forbinder ikke eller lukker straks: kontrollér vært, port og login (mange clustere kræver kaldesignalet), og at der ikke allerede er en anden session åben med samme kaldesignal, for eksempel fra et andet program.
LI|Ingen spots i SPORADIC-E: kontrollér de valgte bånd og det valgte tidsvindue, at det lokale filter ikke frasorterer båndet (det lader 27990 kHz til 145 MHz passere, og mellem 430 og 440 MHz kun nordlys), og på 144 MHz at spottet har en bekræftelse (kapitel 3.4). Test af filtre (INDSTILLINGER, Fordeling af spots) viser, hvordan en cluster-linje klassificeres.
LI|Tomme kort ved første start: kystlinjer og grænser hentes fra GitHub første gang; det kræver netforbindelse, og bagefter ligger de i data/mappa.
LI|LoTW afviser adgangen: kontrollér brugernavn og adgangskode på LoTW's websted; med store logs kan hentningen tage nogle minutter.
LI|Den automatiske opdatering starter ikke eller mislykkes: kontrollér netforbindelsen, og at der kan skrives i programmets mappe; med pakkerne .deb, .rpm, Arch og Slackware starter den bevidst ikke. Under alle omstændigheder kan den nye version installeres manuelt fra release-siden oven på den gamle uden at miste mappen data.
