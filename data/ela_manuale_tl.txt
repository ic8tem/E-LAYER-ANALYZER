TITLE|Manwal ng paggamit ng E-LAYER ANALYZER
SUB|Detalyadong manwal ng paggamit - inihanda ni Costantino IC8TEM - bersiyon 0.4.3, Nobyembre 2026. Ang mga numero sa loob ng square bracket ay tumutukoy sa tab na MGA SANGGUNIAN; ang mga pormula at ang mga pagpili sa kalkulasyon ay nasa tab na BUOD NG MGA PAGPILI SA KALKULASYON.
H1|1. Bago magsimula
H2|1.1 Ano ang ginagawa ng programa
P|Pinagsasama ng E-LAYER ANALYZER sa iisang programa ang mga kasangkapan para pag-aralan ang mga mode ng propagasyon sa VHF na dumaraan sa E layer ng ionosphere: ang sporadic-E, kasama ang multi-hop at ang lampas sa kontinente, ang F.A.I. (mga iregularidad na nakahanay sa magnetic field), ang meteor scatter, kasama ang nakapaloob na programang YA-MS, at ang radio aurora. Gumagana ito sa mga spot ng mga DX cluster nang real time at sa mga ADIF log, at ipinapakita ang bawat resulta sa isang mapa na sumasakop sa dalawang-katlo ng window, kasama ang data at mga kalkulasyon sa kanang ikatlong bahagi.
H2|1.2 Pag-install at ang folder ng data
P|Gumagana ang programa sa Windows (64 at 32 bit), Linux, Raspberry Pi (ARM64) at Mac (Apple Silicon at Intel). Dina-download ito mula sa pahinang Releases ng GitHub repository: para sa Windows may installer at portable na bersiyon sa isang .zip file; para sa Linux at Raspberry Pi isang .tar.gz archive na may installation script; para sa Mac isang .dmg image.
LI|Lahat ng data ng programa ay nasa folder na data katabi ng programa: mga setting (config.ini), database ng CALL3, mga coefficient ng magnetic field, mga log, na-download na data ng NOAA, mga nakolektang spot. Walang isinusulat sa AppData o sa iba pang folder ng sistema.
LI|Para ilipat ang programa sa ibang computer, kopyahin lamang ang folder nito; para bumalik sa mga unang setting, burahin lamang ang data/config.ini.
LI|Hindi kailanman sine-save ang password ng LoTW; ang username lamang ang maaaring tandaan.
H2|1.3 Ang bar sa itaas
P|Sa kaliwang itaas inilalagay ang sariling callsign, ang locator (4, 6 o 8 character) at ang taas ng antenna sa metro; kinukumpirma ito ng button na Ilapat at nag-a-update ang lahat ng tab. Sa kanang itaas makikita ang oras sa UTC, ang pagpili ng color scheme (lahat ng scheme ng YAEC: Maliwanag, Gabi, Itim, walong pastel at Bakas ng meteor) at ang pagpili ng wika (28 wika). Kapag pinalitan ang color scheme o wika, agad na binubuo muli ang window nang hindi nawawala ang nakolektang data.
H2|1.4 Ang status bar
P|Sa ibaba, ipinapakita ng status bar kung ilang callsign ang nasa database ng CALL3, ilang spot ang nasa memorya at ang magnetic model na ginagamit (IGRF-14 kasama ang epoch nito). Binubura ang mga spot sa memorya tuwing isinasara ang programa: nagsisimula ang bawat sesyon nang walang lumang spot.
H2|1.5 Ang mga mapa
P|Pare-pareho ang paggamit ng lahat ng mapa: pinalalaki o pinaliliit ng scroll wheel ng mouse, inililipat ang tanaw sa pag-drag gamit ang kaliwang button, at pumipili ang left click ng punto, spot o landas depende sa tab. Sa kanang itaas lumilitaw ang mga coordinate at ang 6-character na locator sa ilalim ng cursor; sa mga azimuthal na mapa pati ang distansiya at azimuth mula sa gitna. Kumakapal ang grid ng mga Maidenhead field at grid square habang nag-zo-zoom.
H1|2. Pangongolekta ng data (DATA COLLECTION)
H2|2.1 Ang tatlong telnet na sesyon
P|Nagbubukas ang tab na DATA COLLECTION ng hanggang tatlong sabay-sabay na telnet na koneksiyon: isang DX cluster na pinili (default ang ON0DXK na may mga VHF filter), ang Reverse Beacon Network (port 7001 para sa FT8, 7000 para sa CW at RTTY) at ang cluster ng DM4X na may mga spot ng PSKReporter (dm4x.ddns.net, port 8500).
LI|Host at Port: address ng cluster. Login: callsign para sa pag-access (kung blangko, ginagamit ang nasa bar sa itaas). Mga command pagkatapos ng login: mga command na ipapadala pagkatapos ng login, hinihiwalay ng semicolon (halimbawa ang mga filter ng banda).
LI|Binubuksan at isinasara ng Kumonekta at Idiskonekta ang sesyon; kusa itong binubuksan muli ng Kumonekta muli pagkatapos maputol; binubuksan ito ng Kumonekta sa pagsisimula pagbukas ng programa.
LI|Ipinapakita ng console ang mga natanggap na linya; sa kahon sa ibaba nito maaaring isulat ang mga command na ipapadala sa cluster (halimbawa sh/dx 20) at kumpirmahin ang mga ito gamit ang Ipadala o ang Enter key.
H2|2.2 Ang hanay ng mga filter
P|Ang kanang hanay ng tab, 40% ng window, ay nagtitipon ng lahat ng filter ng mga spot: iisa lang ang pangongolekta ng data para sa buong programa, at bawat natanggap na spot ay dumaraan dito bago makarating sa mga tab ng bawat mode ng propagasyon. Nasa itaas ang checkbox ng lokal na filter, nakabukas bilang default: itinatapon ang mga linyang "DX de" na may frequency na mas mababa sa 27990.0 kHz o mas mataas sa 145 MHz, hindi lumalabas sa console at hindi iniimbak. Lalo itong kapaki-pakinabang sa RBN at PSKReporter, na nagpapadala ng napakaraming spot sa HF. Kapag pinatay ang checkbox, dumaraan ang lahat. Sa ilalim nito ay may limang sub-tab.
LI|Meteor scatter: ang filter ng YA-MS (mga frequency window na karaniwan sa MS, mga tag ng ibang propagasyon, mga digital mode ng MS at <MS>, mga banda, pagsubok ng filter at mga counter). Sa loob ng E-LAYER ANALYZER, hindi lumalabas ang sub-tab na Pangongolekta ng data ng YA-MS: dito itinatakda ang filter nito.
LI|Sporadic-E: ang mga tag sa pagitan ng < > na nag-aalis ng isang spot sa sporadic-E; ang mga patakaran sa 28 at 50 MHz (sa loob ng 450 km ay hindi sporadic-E; hindi eksklusibong batayan ang bandplan, kaya nananatili sa sporadic-E ang spot na nasa window ng meteor scatter maliban kung digital mode na MS o <MS>); ang patakaran sa 144 MHz (minimum na distansya; kumpirmasyon ng pangalawang spot sa parehong ulap sa loob ng ilang minuto, o ng maikling-hop na spot sa 50 MHz sa paligid) at ang patakarang trans-equatorial kasama ang sinturon nito ng magnetic inclination. Ibinabalik ng button na Ibalik ang mga patakaran ng may-akda ang mga default na halaga.
LI|F.A.I.: ang mga salitang nagpapahiwatig ng spot ng F.A.I. (default FAI: tinatanggap ang <FAI> o fai, sa malalaki, maliliit o halong titik; hindi pumapasok sa sporadic-E ang mga spot na ito), ang mga banda at ang panahon ng mga spot sa mapa (default 24 oras).
LI|Aurora: ang mga salita ng mga spot ng aurora, may < > man o wala at malaki man o maliit ang titik (default AU at AUR), ang mga banda at ang panahon ng mga spot sa mapa (default 2 oras).
LI|Pagsubok ng mga filter: isinusulat o idinidikit ang isang linya ng cluster at ipinapakita ng programa kung paano ito inuuri ng mga filter (meteor scatter, aurora, F.A.I., trans-equatorial, sporadic-E), kasama ang banda, locator at distansya.
H2|2.3 Paano binabasa ng programa ang mga spot
P|Mula sa bawat linyang "DX de" kinukuha ng programa ang spotter, frequency, DX, komento, oras at, kung mayroon, ang mga locator at ang mode ng propagasyon na nakasulat sa komento sa anyong JN70CN<ES>JO62QM (ang unang locator ay sa spotter, ang pangalawa ay sa DX; tinatanggap din ang mga anyong may <>, > at panaklong).
LI|Hinahanap sa database ng CALL3 ang mga nawawalang locator; ang mga hindi tiyak na locator (wala pang 6 na character) ay pinapalitan ng 6-character na locator mula sa CALL3, kung mayroon.
LI|Hindi ginagamit para sa sporadic-E ang mga spot na may <MS>, <AU>, <AUR>, <TR>, <AS> o <ACS> sa teksto: para ang mga ito sa meteor scatter, aurora, tropo o aircraft scatter.
LI|Gaya ng sa YA-MS, mga spot ng meteor scatter ang mga nasa karaniwang frequency window ng MS (50190-50300, 70100-70400, 144290-144399 kHz) na walang tanda ng ibang propagasyon, at ang mga may mode na MSK144, FSK441, FSK41, PSK2K, JTMS, JT6M o may <MS>.
LI|Napupunta sa tab na AURORA ang mga spot na may <AU> o <AUR>, at sa tab na F.A.I. ang mga may FAI.
H2|2.4 Mga nakolektang spot at ang database ng CALL3
P|Inililista ng pahinang Mga nakolektang spot ang pinakahuling mga spot na may filter ayon sa banda at sa pinagmulan; binubuksan ng button na Buksan ang folder ng mga spot ang data/spot. Ipinapakita ng pahinang CALL3 ang database ng callsign -> locator (format ng JTDX/WSJT): maaaring maghanap ng callsign, i-reload ang database o mag-import ng bagong CALL3.TXT file, na papalit sa kasalukuyang ginagamit (nananatili ang luma bilang backup).
H1|3. Sporadic-E (SPORADIC-E)
H2|3.1 Ang mapa
P|Pinipili ng menu na Mapa ang projection. Azimuthal: mapang azimuthal equidistant na nakasentro sa sariling istasyon, na may zoom slider (mula 300 hanggang 20000 km mula sa gitna, pati gamit ang scroll wheel ng mouse). Mercator: ang mapa ng mundo, na may mga button na Europa at Mundo. Sa parehong projection, iginuguhit sa paligid ng istasyon ang mga bilog ng distansiya ng talahanayan ni IK3XTV [3]: 500 km (pinakamababa ng iisang hop), 1500-2000 km (pinakamainam), 2400 km (pinakamataas ng iisang hop), 5000 km (pinakamataas ng dobleng hop) at 6900 km (pinakamataas ng triple hop).
P|Ang talahanayan ng haba ng mga hop sa 50 MHz ay kay Flavio Egano IK3XTV, «Propagazione sui 6 metri - Caratteristiche generali» (Propagasyon sa 6 metro - Mga pangkalahatang katangian) [3]; ang mga ulap na Es ay nasa taas na humigit-kumulang 100 km, at nililimitahan nito ang iisang hop sa mga 2000 km [29]. Sinusunod ng mga singsing sa mga mapa at ng bilang ng hop ang mga distansiyang ito:
TAB|Hop;Pinakamababang distansiya;Pinakamainam na distansiya;Pinakamataas na distansiya
TAB|Iisang hop;500-650 km;1500-2000 km;2200-2400 km
TAB|Dobleng hop;2800-3000 km;3200-4000 km;4400-5000 km
TAB|Triple hop;-;4800-6400 km;6900 km
P|Sa mga azimuthal na tanaw, ipinapakita ng mga putol-putol na bilog ang km mula sa gitna; nagbabago ang pagitan ng mga bilog ayon sa zoom at ipinapakita ng panlabas na gilid ang pinakamalayong distansiyang ipinapakita.
H2|3.2 Ang mga kontrol
LI|Mga banda: 10, 6, 4 at 2 m (hindi sinusuri ang 432 MHz: hindi umiiral ang sporadic-E [22]-[24]); window ng oras ng mga spot mula 15 minuto hanggang 12 oras.
LI|Taas ng Es (default 105 km) at pinakamababang elebasyon ng mga antenna.
LI|Unang hop (pantay na hop): ipinapakita ang unang hop ng parehong istasyon; Maikling unang hop sa loob ng…: ipinapakita ang hinuha ng may-akda tungkol sa maikling unang hop (default 1200 km) [4].
LI|Mga ulap ng Es sa mga Maidenhead grid square: kinukulayan ang mga grid square ng mga punto ng repleksiyon ayon sa tinatayang pinakamababang foEs.
H2|3.3 Mga talahanayan at detalye
P|Inililista ng talahanayang Mga spot ng Es ang mga balidong spot kasama ang distansiya, bilang ng hop at pinakamababang foEs; inililista ng talahanayang Mga ulap ng Es (grid square) ang mga grid square na may tinatayang ulap at ang MUF na ibibigay ng mga ito para sa sariling istasyon (pula 144 MHz, kahel 70 MHz, dilaw 50 MHz). Kapag may nakatakdang zoom, ipinapakita lamang ng mga talahanayan ang nakikita sa mapa.
LI|I-click ang isang spot sa talahanayan o sa mapa: nagliliwanag ang landas na may dilaw na sinag, inilalapit ito ng mapa sa tanaw kung kailangan at ipinapakita ng panel na Mga detalye ang mga hop, mga punto ng repleksiyon, foEs at azimuth. Nananatiling napili ang spot kahit dumating ang mga bagong spot.
LI|I-click ang isang bakanteng punto sa mapa: itinuturing ang punto bilang posibleng ulap ng Es, kasama ang foEs na kailangan para sa 28, 50, 70 at 144 MHz.
H2|3.4 Ang mga patakaran ng may-akda
LI|144 MHz: nagsisimula ang sporadic-E sa lampas 900 km; hindi iginuguhit ang iisang spot; iginuguhit ito kung sa loob ng 5 minuto ay dumating ang pangalawang spot sa parehong ulap o kung may maikling-hop na spot sa 50 MHz sa paligid. Sinasabi ng berdeng linya sa itaas kung ilang spot ang naghihintay ng kumpirmasyon.
LI|Trans-equatorial: patungo sa kontinental na Africa (kasama ang Madagascar) at South America, kung ang gitnang punto ay nasa sinturon ng magnetic inclination sa pagitan ng -20° at +20°, ang koneksiyon ay trans-equatorial at hindi sporadic-E, maliban kung idineklara ng spot ang <ES>. Hindi saklaw ng patakaran ang Canary Islands, Madeira, Cape Verde at ang Arabian Peninsula.
H1|4. BENCHMARK Es
H2|4.1 Pagkakarga ng log
P|Ang tab na BENCHMARK Es ay isang pagsubok ng sporadic-E sa isang buong ADIF log, maaari ring sa ibang istasyon. Binubuksan ng Ikarga ang ADIF ang file (tinatandaan ito ng programa at ikinakarga muli sa pagsisimula), inaalis ito ng Alisin ang ADIF. Nagmumungkahi ang Istasyon sa gitna ng pinakamadalas na callsign at locator sa log; maaaring palitan ang mga ito at kumpirmahin gamit ang Ilapat.
LI|Ang posisyon ng pagpapadala ay ang MY_GRIDSQUARE ng bawat QSO; ang mga posisyon ng pagtanggap ay ang mga GRIDSQUARE (kinukuha sa CALL3 ang mga nawawala o 4-character na locator).
LI|Maaaring hindi isama ang mga QSO na may ibang PROP_MODE at ang mga mas maikli sa 500 km (900 km sa 144 MHz); laging hindi isinasama ang mga trans-equatorial, maliban kung PROP_MODE=ES.
H2|4.2 Mga araw, oras at kalkulasyon
P|Inililista ng talahanayang QSO bawat araw ang mga araw kasama ang bilang ng QSO, mga banda, pinakamalayong distansiya at mga multi-hop; ang pag-click sa isang araw ay pumupuno sa talahanayang Mga oras ng araw, na may isang hilera para sa bawat oras sa UTC at ang hilerang Buong araw. Iginuguhit ng azimuthal na mapa, gamit ang slider ng pinakamalayong distansiya, ang skip ayon sa mga sektor na 10° (kahel na arko = pinakamalapit na QSO, berdeng sektor = mga naabot na distansiya), ang mga ulap sa mga grid square at, para sa buong araw, ang paggalaw ng mga ulap bawat oras (pulang linya).
P|Ipinapakita ng pahinang Mga mungkahing kalkulasyon ang skip ayon sa sektor, ang tinatayang foEs kasama ang inaasahang MUF sa 1000, 1500, 2000 at 2400 km, ang mga tinatayang ulap, ang pagsusuri ng multi-hop (pantay na hop laban sa maikling unang hop, inihahambing sa mga ulap na nakita sa iisang hop sa loob ng ±30 minuto) at ang paggalaw ng mga ulap oras-oras.
H1|5. BENCHMARK 50 MHz
H2|5.1 Isa o dalawang istasyon
P|Nakalaan ang tab na BENCHMARK 50 MHz sa multi-hop na sporadic-E sa 50 MHz. Sa hilerang Istasyon 1 ikinakarga at inaalis ang log ng sariling istasyon; sa hilerang Istasyon 2 ang log ng pangalawang istasyon, na ipinapakita o itinatago gamit ang checkbox na Istasyon 2. Mapusyaw na asul ang mga landas ng istasyon 1, at lila ang sa istasyon 2.
LI|Ipinapakita ang mga multi-hop na QSO sa 50 MHz, ibig sabihin ay lampas sa 3100 km (patakaran ng may-akda); sinusunod ng bilang ng hop ang talahanayan ni IK3XTV.
LI|Araw, mula… hanggang… UTC: ang araw (sa pagbukas, ang may pinakamaraming multi-hop na QSO) at ang oras, sa mga hakbang na 15 minuto.
LI|foEs (opsiyonal): kinukulayan ang mga landas ayon sa pinakamababang foEs at inilalagay ito sa talahanayan. Ang Taas ng Es at Maikling unang hop sa loob ng 1200 km ay gaya ng sa ibang mga tab.
H2|5.2 Ang mapang Mercator
P|Mercator ang mapa na may malayang gitna. Kapag inilapit ang mouse sa isang landas, lumalaki ang linya at mga icon at lumilitaw ang 6-character na WWL grid square ng kausap na istasyon. Sa left click sa landas na iyon, itinatanong ng isang popup kung ipapakita ang lahat ng QSO sa file, mula sa lahat ng araw, na may dulong posisyon sa loob ng 150 km: inaalisan ng Oo ang laman ng mapa at ipinapakita ang mga QSO na iyon sa loob ng kahel na bilog, iniiwan ng Hindi ang mapa kung ano ito. Ibinabalik ng button na Bumalik sa araw at oras ang naunang pagpili.
H1|6. F.A.I.
H2|6.1 Ang dalawang tanaw
P|Pinag-aaralan ng tab na F.A.I. ang scatter mula sa mga iregularidad na nakahanay sa magnetic field (pangunahing sanggunian [1], [2]). Kinakalkula ng tanaw na Scatter trail (pares A-B), para sa dalawang istasyon, ang kinalalagyan ng mga posibleng scatter point, na kinulayan ayon sa paglihis mula sa kondisyon ng repleksiyon, nagmumungkahi ng pinakamalamang na scatter point at iginuguhit sa kanang itaas ang panel ng mga QTF at elebasyon ng parehong istasyon (pula = A, berde = B). Iginuguhit ng tanaw na Iso-repleksiyon (punto), para sa napiling punto ng repleksiyon, ang mga linya ng iso-repleksiyon gaya ng AuroReflex at SE-PROP ni K9SE: may kulay na mga sinturon sa madidilim na scheme, makakapal na linya sa maliliwanag na scheme.
H2|6.2 Ang mga kontrol
LI|Istasyon A at Istasyon B: callsign (hinahanap sa CALL3) at/o locator; blangkong A = ang sariling istasyon. Ikinakarga ng menu na Mga pagsusuri… ang mga pares na pansubok (IC8FAX-F6DRO, IC8FAX-G4LOH, IC8FAX-FA1MXE); pumipili ang menu na Kilalang scatter point… ng isang dokumentadong scatter point (Geneva, Brussels, Budapest, JN92, JN41/42).
LI|Taas (default 110 km), pinakamababang elebasyon at Repraksiyon (4/3 radius ng Daigdig), nakabukas bilang default.
LI|Left click sa mapa: punto ng repleksiyon na susuriin (lilipat sa tanaw na Iso-repleksiyon); right click: posisyon ng istasyon B.
LI|Suriin ang inirerekomendang punto: kinakalkula ang bakas, kinukuha ang iminungkahing scatter point at ipinapakita ang mga linya nito ng iso-repleksiyon kasama ang hatol: KASIYA-SIYA (sa loob ng 1°), KATANGGAP-TANGGAP (sa loob ng 2.5°), HINDI KASIYA-SIYA (lampas dito).
P|Kung hindi posible ang kalkulasyon ayon sa modelo, lumilitaw ang mensaheng Hindi posible ang kalkulasyon at walang ibang resultang ipinapakita. Sa ibaba, inililista ng talahanayang Mga spot ng F.A.I. ang mga spot na idineklarang FAI; ikinakarga ng pag-click sa isang spot ang pares ng mga istasyon nito.
H1|7. METEOR SCATTER
P|Nilalaman ng tab ang buong programang YA-MS, kasama ang mga tab nito (Live at real-time na datos: live na trapikong meteor scatter, flux ng radar, radar GRAVES; Kalkulasyon ng pagtataya: kalangitan at kalkulasyon, heometriya at path loss, kalkulasyon ng episyensya, eksperimental na pagtataya; Mga teknikal na dokumento: mga shower, mga sanggunian, mapa ng mga sanggunian, episyensya - paliwanag, mapa ng grid square) at ang manwal nito ng mga kalkulasyon. Ang wika at color scheme ay ang mga pinili sa itaas. Sa loob ng E-LAYER ANALYZER, hindi lumalabas ang Pangongolekta ng data ng YA-MS: iisa lang ang pangongolekta, ang sa DATA COLLECTION, na nagpapasa ng mga linya sa YA-MS, at ang filter ng mga spot ng meteor scatter ay itinatakda sa hanay ng mga filter ng DATA COLLECTION.
H1|8. AURORA
P|Ginagamit ng tab na AURORA ang parehong mga tanaw ng F.A.I. (default na taas 105 km) kasama ang data ng space weather ng NOAA [15]: ang OVATION auroral oval (malabong kulay sa mapa), ang Kp index ng huling tatlong araw at ang solar wind, na dina-download tuwing 5 minuto sa data/swpc o kaagad gamit ang I-download ang NOAA ngayon. Nagmumungkahi ang programa ng direksiyon ng antenna para sa parehong istasyon.
LI|Iginuguhit sa mapa ang mga spot ng aurora sa panahong pinili sa mga filter ng DATA COLLECTION (default ang huling 2 oras, hanggang 30) kasama ang kinalkulang scatter point (kahel na bilog) kung nakabukas ang checkbox na Mga spot na <AU>/<AUR> sa mapa na may kalkulasyon; lumalabas sa mga resulta ang QTF at elebasyon ng dalawang istasyon.
H1|9. LOG ADIF
P|Ipinapakita ng tab na LOG ADIF ang mga grid square na nakontak at nakumpirma, bawat banda mula 28 MHz pataas, nang hindi pinagsasama ang mga banda. Nagdaragdag ang Buksan ang ADIF file… ng mga file ng log; dina-download ng I-download mula sa LoTW… ang ulat ng mga kumpirmasyon (maaaring tandaan ang username, hindi kailanman sine-save ang password); inaalis ng Burahin ang memorya ang mga file at ulat. Kahel ang mga grid square kung nakontak, iba ang kulay kung nakumpirma sa QSL o via LoTW; ang pag-click sa isang grid square ay nagpapakita ng mga callsign at ng mode ng propagasyon.
H1|10. Mga dokumento
P|Inililista ng tab na MGA SANGGUNIAN ang mga sangguniang binanggit ng programa, bawat tab. Inilalahad ng tab na BUOD NG MGA PAGPILI SA KALKULASYON ang mga pormula at mga pagpili sa kalkulasyon kasama ang mga sanggunian sa bawat hakbang; ipinapaliwanag ng MANWAL NG PAGGAMIT na ito kung paano gamitin ang programa; inilalahad ng TEKNIKAL NA ULAT ang mga dahilang gumabay sa pagbuo ng programa. Maaaring i-export sa Word ang tatlong dokumento.
H1|11. Mga praktikal na payo
LI|Una sa lahat, isulat ang callsign at locator sa itaas at pindutin ang Ilapat: doon nagmumula ang lahat ng distansiya, MUF at elebasyon.
LI|Sa RBN at PSKReporter, panatilihing nakabukas ang lokal na filter, para hindi mapuno ang memorya ng mga spot sa HF.
LI|Para suriin ang isang nakaraang season, gamitin ang dalawang BENCHMARK kasama ang sariling log; para sa aurora at F.A.I., laging suriin ang iminungkahing punto gamit ang tanaw na Iso-repleksiyon.
LI|Indikatibo lamang ang mga kalkulasyon: sinasabi ng isang spot o QSO na bukas ang landas, hindi kung saan eksaktong naroon ang ulap.
