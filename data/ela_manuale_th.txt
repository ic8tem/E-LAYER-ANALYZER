TITLE|คู่มือผู้ใช้ E-LAYER ANALYZER
SUB|คู่มือผู้ใช้ฉบับละเอียด - โดย Costantino IC8TEM - เวอร์ชัน 0.4.10, พฤศจิกายน 2026 ตัวเลขในวงเล็บเหลี่ยมอ้างถึงแท็บ แหล่งอ้างอิง; สูตรและทางเลือกในการคำนวณอยู่ในแท็บ สรุปทางเลือกในการคำนวณ
H1|1. ก่อนเริ่มต้น
H2|1.1 โปรแกรมทำอะไร
P|E-LAYER ANALYZER รวบรวมเครื่องมือสำหรับศึกษาโหมดการแพร่กระจาย VHF ที่ผ่านชั้น E ของไอโอโนสเฟียร์ไว้ในโปรแกรมเดียว: sporadic-E รวมถึงแบบหลายฮอปและข้ามทวีป, F.A.I. (ความไม่สม่ำเสมอที่เรียงตัวตามสนามแม่เหล็ก), meteor scatter ด้วยโปรแกรม YA-MS ที่รวมไว้ และออโรราทางวิทยุ ทำงานกับสปอตจาก DX cluster ตามเวลาจริงและกับล็อก ADIF และแสดงผลลัพธ์ทุกอย่างบนแผนที่ซึ่งกินพื้นที่สองในสามของหน้าต่าง โดยมีข้อมูลและการคำนวณอยู่ในหนึ่งในสามทางขวา
H2|1.2 การติดตั้งและโฟลเดอร์ข้อมูล
P|โปรแกรมทำงานบน Windows (64 และ 32 บิต), Linux x86_64, Raspberry Pi (Raspberry Pi OS 64 และ 32 บิต, Slackware ARM64), Linux armv7l และ Mac (Apple Silicon และ Intel) ดาวน์โหลดได้จากหน้า Releases ของคลังเก็บ (repository) บน GitHub: สำหรับ Windows มีตัวติดตั้งและเวอร์ชันพกพาในไฟล์ .zip; สำหรับ Linux และ Raspberry Pi มีแพ็กเกจ .deb แพ็กเกจ Slackware .txz สำหรับ ARM64 และไฟล์บีบอัด .tar.gz พร้อมสคริปต์ติดตั้ง; สำหรับ Mac มีอิมเมจ .dmg ไม่มีเวอร์ชันสำหรับ Linux i686 (PC 32 บิต) เพราะไม่มี .NET สำหรับระบบนั้น และไม่มีสำหรับ FreeBSD ซึ่งขาดไลบรารีกราฟิกของ Avalonia
LI|Windows: ตัวติดตั้งจะวางโปรแกรมไว้ใน C:\E-LAYER-ANALYZER โดยมีโฟลเดอร์ data อยู่ข้าง ๆ; เวอร์ชันพกพาให้แตกไฟล์ลงในโฟลเดอร์ใดก็ได้ แล้วเริ่มด้วย E-LAYER-ANALYZER.exe
LI|Linux และ Raspberry Pi: เมื่อใช้แพ็กเกจ .deb (sudo apt install ./e-layer-analyzer_..._amd64.deb หรือ _arm64.deb สำหรับ Raspberry Pi OS 64 บิต และ _armhf.deb สำหรับ 32 บิต) โปรแกรมจะเริ่มจากเมนู และเมื่อเริ่มครั้งแรกจะคัดลอกตัวเองไปที่ ~/E-LAYER-ANALYZER; เมื่อใช้ไฟล์ .tar.gz (linux-x64, linux-arm64, linux-arm หรือ linux-armv7l) ให้แตกไฟล์แล้วเริ่ม ./E-LAYER-ANALYZER หรือใช้ ./installa.sh เพื่อติดตั้งใน ~/E-LAYER-ANALYZER พร้อมไอคอนในเมนู
LI|Slackware ARM64: ในฐานะ root ให้ติดตั้งแพ็กเกจด้วย installpkg e-layer-analyzer-...-aarch64-1_ic8tem.txz; โปรแกรมเริ่มด้วย e-layer-analyzer จากเมนูหรือจากเทอร์มินัล และเมื่อเริ่มครั้งแรกจะคัดลอกตัวเองไปที่ ~/E-LAYER-ANALYZER เหมือนกับ .deb
LI|Mac: เปิดไฟล์ .dmg (arm64 สำหรับ Apple Silicon M1-M4, x64 สำหรับ Intel) แล้วคลิกขวาที่ «Installa E-LAYER-ANALYZER.command» และเลือก เปิด; อีกทางหนึ่ง ไฟล์ -app.zip มีเฉพาะแอปพลิเคชัน
LI|ข้อมูลทั้งหมดของโปรแกรมอยู่ในโฟลเดอร์ data ข้างโปรแกรม: การตั้งค่า (config.ini), คลังข้อมูล CALL3, สัมประสิทธิ์สนามแม่เหล็ก, ล็อก, ข้อมูล NOAA ที่ดาวน์โหลด, สปอตที่เก็บรวบรวม ไม่มีการเขียนสิ่งใดลงใน AppData หรือโฟลเดอร์ระบบอื่น
LI|หากต้องการย้ายโปรแกรมไปยังคอมพิวเตอร์เครื่องอื่น เพียงคัดลอกโฟลเดอร์ของโปรแกรม; หากต้องการกลับไปใช้การตั้งค่าเริ่มต้น เพียงลบ data/config.ini
LI|ในโฟลเดอร์ data โปรแกรมยังเก็บโฟลเดอร์เหล่านี้: lingue (คำแปล), spot (สปอตที่เก็บรวบรวม), spot_ms (สปอต meteor scatter ของ YA-MS), swpc (ข้อมูลของ NOAA), mappa (แนวชายฝั่งและเส้นพรมแดนของ Natural Earth ซึ่งดาวน์โหลดจาก GitHub เมื่อเริ่มครั้งแรก: ครั้งแรกต้องใช้เครือข่าย) และ aggiornamento (แพ็กเกจของการอัปเดตอัตโนมัติ ซึ่งลบได้)
LI|รหัสผ่าน LoTW จะไม่ถูกบันทึกเลย; จำได้เฉพาะชื่อผู้ใช้
LI|การอัปเดต: ตั้งแต่เวอร์ชัน 0.4.5 โปรแกรมจะตรวจเองเมื่อเริ่มทำงานและทุก 6 ชั่วโมงหลังจากนั้นว่ามีเวอร์ชันใหม่บน GitHub หรือไม่ ถ้ามี จะแจ้งด้วยหน้าต่างและข้อความสีส้ม ▲ ในแถบด้านบน: "อัปเดตเลย" จะดาวน์โหลดแพ็กเกจที่เหมาะกับคอมพิวเตอร์ (Windows 64 หรือ 32 บิต, Linux, Raspberry Pi, Mac) ปิดโปรแกรม แทนที่ไฟล์ แล้วเปิดโปรแกรมใหม่; "ภายหลัง" จะเลื่อนออกไป, "ข้ามเวอร์ชันนี้" จะไม่เสนอเวอร์ชันนั้นอีก การตั้งค่า สปอตที่เก็บรวบรวม และ call3.txt จะยังคงอยู่ ปิดการตรวจได้ด้วยช่องทำเครื่องหมายในหน้าต่างเดียวกัน
LI|ไฟล์ที่ขาดหาย: เมื่อเริ่มทำงาน โปรแกรมจะตรวจว่ามีไฟล์ครบทุกไฟล์ที่แจกจ่ายมาด้วย (คำแปล เอกสาร ตาราง) ถ้าขาดไฟล์ใด หน้าต่างจะแสดงรายการไฟล์เหล่านั้น และปุ่ม "ดาวน์โหลดจาก GitHub" จะดึงไฟล์กลับมาจากเวอร์ชันเดียวกันที่เผยแพร่บน GitHub
LI|ระหว่างการอัปเดต หน้าต่างจะแสดงความคืบหน้าของการดาวน์โหลดและการแตกไฟล์ หากโฟลเดอร์ของโปรแกรมเขียนไม่ได้ เช่น อยู่ในโฟลเดอร์ของระบบ โปรแกรมจะแจ้งและเสนอหน้า release ซึ่งใช้ดาวน์โหลดแพ็กเกจติดตั้งได้; หากมีบางอย่างไม่สำเร็จ จะแสดงสาเหตุและปุ่มจะเปลี่ยนเป็น หน้า Release
H2|1.3 แถบด้านบน
P|ที่มุมซ้ายบนให้เขียนสัญญาณเรียกขานของตน โลเคเตอร์ (4, 6 หรือ 8 ตัวอักษร) และความสูงของสายอากาศเป็นเมตร; ปุ่ม นำไปใช้ จะยืนยันค่าเหล่านี้และทุกแท็บจะปรับปรุง ที่มุมขวาบนมีเวลา UTC การเลือกชุดสี (ทุกชุดสีของ YAEC: สว่าง, กลางคืน, ดำ, พาสเทลแปดแบบ และ รอยทางดาวตก) และการเลือกภาษา (36 ภาษา) เมื่อเปลี่ยนชุดสีหรือภาษา หน้าต่างจะสร้างใหม่ทันทีโดยไม่สูญเสียข้อมูลที่เก็บรวบรวมไว้
P|ข้างเวลา UTC ข้อความ NTP:OK (เขียว) หรือ NTP:FAILED (แดง) บอกว่าเวลาตรงกันหรือไม่: ทุก 5 นาที โปรแกรมสอบถามเซิร์ฟเวอร์เวลาสองแห่งจากสิบแห่งทั่วโลก และเปลี่ยนไปใช้แห่งอื่นหากไม่ตอบ ข้อความแนะนำ (tooltip) แสดงเซิร์ฟเวอร์ที่ใช้และส่วนต่างของนาฬิกา PC
P|โปรแกรมใช้เวลาที่ถูกต้องเสมอ: ค่าคลาดเคลื่อนที่วัดได้จะนำไปใช้กับนาฬิกาของโปรแกรม หากคลาดเคลื่อนเกินหนึ่งวินาที บน Windows และเมื่อมีสิทธิ์ผู้ดูแลระบบ โปรแกรมจะแก้ไขนาฬิกาของ PC ด้วย และกล่องข้อความจะแจ้งว่า แก้ไขนาฬิกาของ PC แล้ว; บน Linux และ Mac จะไม่แตะนาฬิกาของระบบ
P|ข้างข้อความ NTP มีเวอร์ชันที่ใช้อยู่ (เช่น v0.4.5 สีเทา): คลิกหนึ่งครั้งเพื่อตรวจทันทีว่ามีเวอร์ชันใหม่กว่าบน GitHub หรือไม่ เมื่อมีเวอร์ชันใหม่ ข้อความจะเปลี่ยนเป็นสีส้ม เช่น ▲ 0.4.6 และคลิกหนึ่งครั้งจะเปิดหน้าต่างการอัปเดต
P|ทางขวาของแถบแท็บมีเมนูทวีป (ยุโรป, อเมริกาเหนือ, อเมริกาใต้, แอฟริกา, เอเชีย, โอเชียเนีย): ย้ายแผนที่ Mercator และแผนที่ของ F.A.I. และออโรราไปยังทวีปที่เลือก และเลือกข้อมูลพยากรณ์ของทวีปนั้น (E-skip ของ N0NBH เผยแพร่เฉพาะยุโรปและอเมริกาเหนือ)
H2|1.4 แถบสถานะ
P|ด้านล่าง แถบสถานะแสดงจำนวนสัญญาณเรียกขานในคลังข้อมูล CALL3 จำนวนสปอตในหน่วยความจำ และแบบจำลองสนามแม่เหล็กที่ใช้ (IGRF-14 พร้อม epoch ของมัน) สปอตในหน่วยความจำจะถูกลบทุกครั้งที่ปิดโปรแกรม: แต่ละเซสชันเริ่มต้นใหม่โดยไม่มีสปอตเก่า
H2|1.5 แผนที่
P|แผนที่ทุกแผนที่ใช้งานแบบเดียวกัน: ล้อเมาส์ซูมเข้าหรือออก ลากด้วยปุ่มซ้ายเพื่อเลื่อนมุมมอง คลิกซ้ายเพื่อเลือกจุด สปอต หรือเส้นทาง ตามแต่ละแท็บ ที่มุมขวาบนจะแสดงพิกัดและโลเคเตอร์ 6 ตัวอักษรใต้เคอร์เซอร์; ในแผนที่อะซิมุทัลจะแสดงระยะทางและอะซิมุทจากศูนย์กลางด้วย เส้นตารางของฟิลด์และช่องกริด Maidenhead จะถี่ขึ้นเมื่อซูม
LI|แผนที่ทุกแผนที่มีคำอธิบายสีและสัญลักษณ์ที่ใช้อยู่ที่มุมซ้ายล่าง เมื่อวาดครั้งแรก อาจมีข้อความ กำลังโหลดแผนที่ (Natural Earth)... ปรากฏอยู่สองสามวินาที
H1|2. การเก็บข้อมูล (DATA COLLECTION)
P|แท็บนี้มีแท็บย่อยสองแท็บ: สปอต ซึ่งมีเซสชัน telnet สปอตที่เก็บรวบรวม คลังข้อมูล CALL3 และคอลัมน์ตัวกรอง และ ข้อมูลการแพร่กระจาย (บทที่ 2.5)
H2|2.1 เซสชัน telnet สามเซสชัน
P|แท็บ DATA COLLECTION เปิดการเชื่อมต่อ telnet ได้พร้อมกันสูงสุดสามการเชื่อมต่อ: DX cluster ที่เลือกเอง (ค่าเริ่มต้น ON0DXK พร้อมตัวกรอง VHF), Reverse Beacon Network (พอร์ต 7001 สำหรับ FT8, 7000 สำหรับ CW และ RTTY) และคลัสเตอร์ของ DM4X ที่มีสปอตจาก PSKReporter (dm4x.ddns.net, พอร์ต 8500)
LI|โฮสต์และพอร์ต: ที่อยู่ของคลัสเตอร์ ชื่อเข้าสู่ระบบ: สัญญาณเรียกขานสำหรับเข้าใช้ (หากว่างจะใช้สัญญาณเรียกขานในแถบด้านบน) คำสั่งหลังเข้าสู่ระบบ: คำสั่งที่จะส่งหลังเข้าใช้ คั่นด้วยเครื่องหมายอัฒภาค (เช่น ตัวกรองย่านความถี่)
LI|เชื่อมต่อ และ ตัดการเชื่อมต่อ เปิดและปิดเซสชัน; เชื่อมต่อใหม่ จะเปิดเซสชันใหม่เองหลังสายหลุด; เชื่อมต่อเมื่อเริ่มโปรแกรม จะเปิดเซสชันเมื่อเริ่มโปรแกรม
LI|คอนโซลแสดงบรรทัดที่ได้รับ; ในช่องด้านล่างสามารถเขียนคำสั่งที่จะส่งไปยังคลัสเตอร์ (เช่น sh/dx 20) แล้วยืนยันด้วย ส่ง หรือปุ่ม Enter
H2|2.2 คอลัมน์ตัวกรอง
P|คอลัมน์ขวาของแท็บ ซึ่งกว้าง 40% ของหน้าต่าง รวบรวมตัวกรองสปอตทั้งหมด: การเก็บข้อมูลมีเพียงชุดเดียวสำหรับทั้งโปรแกรม และทุกสปอตที่ได้รับจะผ่านที่นี่ก่อนไปถึงแท็บของแต่ละโหมดการแพร่กระจาย ด้านบนสุดมีช่องทำเครื่องหมายของตัวกรองในเครื่อง ซึ่งเปิดไว้เป็นค่าเริ่มต้น: บรรทัด "DX de" ที่มีความถี่ต่ำกว่า 27990.0 kHz หรือสูงกว่า 145 MHz จะถูกทิ้ง ไม่ปรากฏในคอนโซลและไม่ถูกเก็บ มีประโยชน์โดยเฉพาะกับ RBN และ PSKReporter ซึ่งส่งสปอต HF จำนวนมาก หากปิดช่องนี้ทุกอย่างจะผ่าน ด้านล่างมีแท็บย่อยห้าแท็บ
LI|Meteor scatter: ตัวกรองของ YA-MS (หน้าต่างความถี่ทั่วไปของ MS, ข้อความของการแพร่กระจายแบบอื่น, โหมดดิจิทัล MS และ <MS>, ย่านความถี่, การทดสอบตัวกรอง และตัวนับ) ภายใน E-LAYER ANALYZER แท็บย่อย การเก็บข้อมูล ของ YA-MS จะไม่ปรากฏ: ตัวกรองของมันตั้งค่าที่นี่
LI|Sporadic-E: ข้อความภายใน < > ที่ทำให้สปอตไม่ถูกนับเป็น sporadic-E; กฎ 28 และ 50 MHz (บน 50 MHz ภายใน 450 km ไม่ใช่ sporadic-E; บน 28 MHz ระยะทางต่ำสุดได้มาจากค่าของ 50 MHz ตาม IK3XTV ประมาณ 170 km; แผนความถี่ไม่ใช่เกณฑ์เด็ดขาด ดังนั้นสปอตในหน้าต่าง meteor scatter ยังคงอยู่ใน sporadic-E เว้นแต่มีโหมดดิจิทัล MS หรือ <MS>); กฎ 144 MHz (ระยะทางต่ำสุด; ยืนยันด้วยสปอตที่สองบนเมฆเดียวกันภายในไม่กี่นาที หรือด้วยสปอตฮอปสั้นบน 50 MHz ในบริเวณใกล้เคียง) และกฎข้ามเส้นศูนย์สูตรพร้อมแถบมุมเอียงแม่เหล็ก ซึ่งใช้กับแอฟริกาและอเมริกาใต้ (กฎของผู้เขียน) และทั่วโลกสำหรับการติดต่อ 3000-8000 km ที่ข้ามเส้นศูนย์สูตรแม่เหล็กในทิศทางเกือบเหนือ-ใต้ (Kennewell และ Wilkinson [49]) ปุ่ม คืนค่ากฎของผู้เขียน จะนำค่าเริ่มต้นกลับมา
LI|ค่าเริ่มต้นของกฎ sporadic-E ซึ่งแก้ไขได้ทั้งหมด: ระยะทางต่ำสุดบน 50 MHz 450 km; กฎของ 144 MHz เปิดอยู่ โดยมีระยะทางต่ำสุด 900 km และต้องยืนยันภายใน 5 นาทีด้วยสปอตที่สองบนเมฆเดียวกันภายใน 300 km หรือด้วยสปอต 50 MHz ใน 15 นาทีล่าสุดที่มีฮอปสั้นถึง 1200 km; กฎข้ามเส้นศูนย์สูตรเปิดอยู่ โดยมีแถบมุมเอียงแม่เหล็ก ±20°
LI|F.A.I.: คำที่บ่งบอกสปอต F.A.I. (ค่าเริ่มต้น FAI: ใช้ได้ทั้ง <FAI> หรือ fai เป็นตัวพิมพ์ใหญ่ เล็ก หรือผสม; สปอตเหล่านี้ไม่เข้าสู่ sporadic-E) ย่านความถี่ และช่วงเวลาของสปอตบนแผนที่ (ค่าเริ่มต้น 24 ชั่วโมง)
LI|ออโรรา: คำของสปอตออโรรา จะมีหรือไม่มี < > และเป็นตัวพิมพ์ใหญ่หรือเล็ก (ค่าเริ่มต้น AU และ AUR) ย่านความถี่ และช่วงเวลาของสปอตบนแผนที่ (ค่าเริ่มต้น 2 ชั่วโมง)
LI|ทดสอบตัวกรอง: เขียนหรือวางบรรทัดของคลัสเตอร์ แล้วโปรแกรมจะแสดงว่าตัวกรองจัดประเภทอย่างไร (meteor scatter, ออโรรา, F.A.I., ข้ามเส้นศูนย์สูตร, sporadic-E) พร้อมย่าน โลเคเตอร์ และระยะทาง
H2|2.3 โปรแกรมอ่านสปอตอย่างไร
P|จากทุกบรรทัด "DX de" โปรแกรมดึงผู้สปอต ความถี่ DX หมายเหตุ เวลา และเมื่อมี โลเคเตอร์และโหมดการแพร่กระจายที่เขียนในหมายเหตุในรูปแบบ JN70CN<ES>JO62QM (โลเคเตอร์แรกเป็นของผู้สปอต ที่สองเป็นของ DX; รูปแบบที่ใช้ <>, > และวงเล็บก็ยอมรับด้วย)
LI|โลเคเตอร์ที่ขาดหายจะค้นหาในคลังข้อมูล CALL3; โลเคเตอร์ที่ไม่ละเอียด (น้อยกว่า 6 ตัวอักษร) จะถูกแทนที่ด้วยโลเคเตอร์ 6 ตัวอักษรของ CALL3 เมื่อมี
LI|สปอตที่มี <MS>, <AU>, <AUR>, <TR>, <AS> หรือ <ACS> ในข้อความจะไม่ใช้สำหรับ sporadic-E: ใช้สำหรับ meteor scatter, ออโรรา, tropo หรือ aircraft scatter
LI|เช่นเดียวกับใน YA-MS สปอต meteor scatter คือสปอตในหน้าต่างความถี่ทั่วไปของ MS (50190-50300, 70100-70400, 144290-144399 kHz) ที่ไม่มีข้อความของการแพร่กระจายแบบอื่น และสปอตที่มีโหมด MSK144, FSK441, FSK41, PSK2K, JTMS, JT6M หรือ <MS>
LI|สปอตที่มี <AU> หรือ <AUR> ไปที่แท็บ AURORA สปอตที่มี FAI ไปที่แท็บ F.A.I.
H2|2.4 สปอตที่เก็บรวบรวมและคลังข้อมูล CALL3
P|หน้า สปอตที่เก็บรวบรวม แสดงรายการสปอตล่าสุดพร้อมตัวกรองตามย่านและตามแหล่งข้อมูล; ปุ่ม เปิดโฟลเดอร์สปอต จะเปิด data/spot หน้า CALL3 แสดงคลังข้อมูล สัญญาณเรียกขาน -> โลเคเตอร์ (รูปแบบ JTDX/WSJT): สามารถค้นหาสัญญาณเรียกขาน โหลดคลังข้อมูลใหม่ หรือนำเข้าไฟล์ CALL3.TXT ใหม่ซึ่งจะแทนที่ไฟล์ที่ใช้อยู่ (ไฟล์เก่าเก็บไว้เป็นสำเนาสำรอง)
LI|คอลัมน์ของสปอตที่เก็บรวบรวมได้แก่: UTC, แหล่งข้อมูล (cluster, RBN หรือ PSKReporter), MHz, ย่านความถี่, DX พร้อมโลเคเตอร์, Spotter พร้อมโลเคเตอร์, km, Prop (โหมดการแพร่กระจายที่ระบุหรือที่จดจำได้) และ หมายเหตุ เมนู ทุกแหล่งข้อมูล ใช้จำกัดตารางให้เหลือเพียงเซสชันเดียว
LI|หน้า CALL3 แสดงไฟล์ที่ใช้อยู่ วันที่ของไฟล์ ส่วนหัว และจำนวนสัญญาณเรียกขานที่โหลด (มากกว่าหนึ่งล้านกับฐานข้อมูลที่แจกจ่ายมา)
H2|2.5 ข้อมูลการแพร่กระจาย
P|แท็บย่อย ข้อมูลการแพร่กระจาย รวบรวมข้อมูลที่ช่วยให้เข้าใจว่าย่านความถี่อาจเปิดหรือไม่ ข้อมูลปรับปรุงเองไม่เกินชั่วโมงละครั้ง; ปุ่ม ปรับปรุงเดี๋ยวนี้ จะดาวน์โหลดทันที
LI|N0NBH (hamqsl.com): แบนเนอร์สภาพ VHF และข้อมูลดวงอาทิตย์ (ฟลักซ์สุริยะ, ดัชนี A และ K, รังสีเอกซ์, ลมสุริยะ, Bz, ออโรราและละติจูดออโรรา) พร้อม E-skip ของยุโรปและอเมริกาเหนือ (ข้อมูล DXrobot)
LI|สภาพ VHF ของ N0NBH แสดงตามที่ hamqsl.com เผยแพร่: Band Closed (ย่านปิด), 50MHz ES, 70MHz ES และ 144MHz ES (sporadic-E บนย่านนั้น), High MUF; สำหรับออโรรา High LAT AUR และ Mid LAT AUR (ออโรราที่ละติจูดสูงหรือละติจูดกลาง)
LI|Bz สำหรับออโรรา: NOAA SWPC ลมสุริยะตามเวลาจริงที่วัดโดยดาวเทียมที่จุด L1 (DSCOVR/ACE) ทุกนาที Bz ที่เป็นลบและคงอยู่นานเอื้อต่อการเกิดออโรรา
LI|ออโรรา: ดัชนี Dst ของ Kyoto (พายุแม่เหล็กโลก) และสำหรับซีกโลกใต้ การเตือนออโรราของ Bureau of Meteorology ของออสเตรเลีย ซึ่งต้องใช้คีย์ฟรีที่ต้องเขียนในช่อง คีย์ API ของ BoM ปุ่ม ดัชนี AE (Kyoto) และ การพาความร้อน SuperDARN จะเปิดสองหน้านี้ในเบราว์เซอร์
LI|ระดับของ Dst อ่านได้ดังนี้: สงบเมื่อสูงกว่า -30 nT, ถูกรบกวนเล็กน้อยระหว่าง -30 ถึง -50 nT, พายุปานกลางระหว่าง -50 ถึง -100 nT, พายุรุนแรงตั้งแต่ -100 nT ลงไป เมื่อมีคีย์ของ BoM จะแสดงดัชนี K ของออสเตรเลียและการเตือนเฝ้าระวังออโรราที่มีอยู่ด้วย
LI|Meteor scatter: กราฟกิจกรรมดาวตกประจำวัน (ข้อมูล RMOB) ของ Make More Miles on VHF; ฝนดาวตก ประสิทธิภาพ และทราฟฟิกสด อยู่ในแท็บ METEOR SCATTER
P|สรุปของข้อมูลเหล่านี้จะปรากฏที่มุมขวาบนของแผนที่ SPORADIC-E และ F.A.I. (E-skip ของทวีปที่เลือก) และของ AURORA (ออโรราของ N0NBH และ Bz ของ NOAA)
H1|3. Sporadic-E (SPORADIC-E)
P|แท็บ SPORADIC-E มีแท็บย่อยสามแท็บ: REAL-TIME คือสปอตสดที่อธิบายในบทนี้; BENCHMARK Es (บทที่ 4) และ BENCHMARK 50 MHz (บทที่ 5)
H2|3.1 แผนที่
P|เมนู แผนที่ ใช้เลือกเส้นโครงแผนที่ อะซิมุทัล: แผนที่อะซิมุทัลระยะเท่าที่มีสถานีของตนเป็นศูนย์กลาง พร้อมแถบเลื่อนซูม (จาก 300 ถึง 20000 km จากศูนย์กลาง ใช้ล้อเมาส์ได้) Mercator: แผนที่โลก พร้อมปุ่ม ยุโรป และ โลก ในทั้งสองเส้นโครงจะวาดวงกลมระยะทางตามตารางของ IK3XTV [3] รอบสถานี: 500 km (ต่ำสุดของฮอปเดียว), 1500-2000 km (เหมาะสม), 2400 km (สูงสุดของฮอปเดียว), 5000 km (สูงสุดของสองฮอป) และ 6900 km (สูงสุดของสามฮอป)
P|ตารางความยาวฮอปบน 50 MHz เป็นของ Flavio Egano IK3XTV, «Propagazione sui 6 metri - Caratteristiche generali» [3]; เมฆ Es อยู่ที่ความสูงประมาณ 100 km และสิ่งนี้จำกัดฮอปเดียวไว้ราว 2000 km [29] วงแหวนบนแผนที่และจำนวนฮอปเป็นไปตามระยะทางเหล่านี้:
TAB|ฮอป;ระยะทางต่ำสุด;ระยะทางเหมาะสม;ระยะทางสูงสุด
TAB|ฮอปเดียว;500-650 km;1500-2000 km;2200-2400 km
TAB|สองฮอป;2800-3000 km;3200-4000 km;4400-5000 km
TAB|สามฮอป;-;4800-6400 km;6900 km
P|ในมุมมองอะซิมุทัล วงแหวนเส้นประแสดง km จากศูนย์กลาง; ระยะห่างของวงแหวนเปลี่ยนตามการซูม และขอบด้านนอกแสดงระยะทางสูงสุดที่แสดง
H2|3.2 การควบคุม
LI|ย่านความถี่: 10, 6, 4 และ 2 m (ไม่วิเคราะห์ 432 MHz: sporadic-E ใช้ไม่ได้ [22]-[24]); ช่วงเวลาของสปอตตั้งแต่ 15 นาทีถึง 12 ชั่วโมง
LI|ความสูง Es (ค่าเริ่มต้น 110 km) และมุมเงยต่ำสุดของสายอากาศ (ค่าเริ่มต้น 1°); มุมเงยคิดรวมการหักเหในชั้นโทรโพสเฟียร์ (รัศมีโลก 4/3) ฮอปเดียวจึงไปถึงประมาณ 2440 km
LI|ฮอปแรก (ฮอปเท่ากัน): แสดงฮอปแรกของทั้งสองสถานี; ฮอปแรกแบบสั้นภายใน…: แสดงสมมติฐานของผู้เขียนเรื่องฮอปแรกแบบสั้น (ค่าเริ่มต้น 1200 km) [4]
LI|เมฆ Es บนช่องกริด Maidenhead: ระบายสีช่องกริดของจุดสะท้อนตามความถี่สูงสุดของสปอต (เขียวถึง 29 MHz, เหลืองถึง 51, ส้มถึง 71, แดงถึง 145 MHz) หาก MUF ที่น่าจะเป็นของเมฆบนฮอปที่ยาวที่สุด (2400 km) ไปถึงย่านที่สูงกว่า ช่องกริดจะกะพริบด้วยสีของย่านนั้น
LI|144 MHz ไปยังหมู่เกาะคานารี มาเดรา และอะซอร์ส (กฎของผู้เขียน): เกิน 2400 km สปอตจะนับได้ก็ต่อเมื่อมีสปอตอย่างน้อยสองรายการบ่งชี้เมฆ Es เดียวกัน; จะวาดฮอป Es เมฆ และเส้นทาง tropo เป็นเส้นประไปจนถึงเกาะ บน 50 และ 70 MHz ไม่ใช้กฎนี้
H2|3.3 ตารางและรายละเอียด
P|ตาราง สปอต Es แสดงรายการสปอตที่ใช้ได้พร้อมระยะทาง จำนวนฮอป และ foEs ต่ำสุด; ตาราง เมฆ Es (ช่องกริด) แสดงรายการช่องกริดที่มีเมฆโดยประมาณและ MUF ที่จะได้สำหรับสถานีของตน (แดง 144 MHz, ส้ม 70 MHz, เหลือง 50 MHz) เมื่อตั้งการซูมไว้ ตารางจะแสดงเฉพาะสิ่งที่เห็นบนแผนที่
LI|คอลัมน์ของตาราง สปอต Es: UTC, MHz, DX, Spotter, km, ฮอป, foEs≥ (foEs ต่ำสุดที่ประมาณได้) และ Prop คอลัมน์ของตาราง เมฆ Es (ช่องกริด): ช่องกริด, foEs≥, จำนวนสปอต, ทิศและระยะทางจากสถานีของตนเอง และ MUF ของฉัน
LI|สีและสัญลักษณ์บนแผนที่: เส้นทางบน 10 m สีเขียว, 6 m สีฟ้า, 4 m สีม่วง และ 2 m สีส้ม; สี่เหลี่ยมเล็กสีเหลือง = จุดกึ่งกลางของฮอปเดียว; สี่เหลี่ยมเล็กสีส้ม = ฮอปแรกของผู้สปอต และสี่เหลี่ยมเล็กสีม่วง = ฮอปแรกของ DX (ฮอปเท่ากัน); วงกลมเล็กสีส้ม = ฮอปแรกแบบสั้น (สมมติฐานของ IC8TEM); วงกลมสีเขียว = ระยะของฮอปเดียวจากสถานีของตนเอง
LI|คลิกสปอตในตารางหรือบนแผนที่: เส้นทางจะสว่างขึ้นด้วยรัศมีสีเหลือง แผนที่จะเลื่อนให้เห็นหากจำเป็น และกรอบ รายละเอียด จะแสดงฮอป จุดสะท้อน foEs และอะซิมุท สปอตยังคงถูกเลือกอยู่แม้มีสปอตใหม่เข้ามา
LI|คลิกจุดว่างบนแผนที่: จุดนั้นจะถือเป็นเมฆ Es ที่เป็นไปได้ พร้อม foEs ที่ต้องการสำหรับ 28, 50, 70 และ 144 MHz
LI|เมื่อ Kp เกิน 3 แผนที่จะแจ้งไว้ที่มุมขวาบน เป็นเพียงการแจ้งเตือน: IK3XTV-IZ3ESV [51] พบว่าการเปิดของย่านกว่า 90% เกิดเมื่อ Kp ≤ 3 แต่ในล็อก 50 MHz ของผู้เขียน sporadic-E ไม่ลดลงเมื่อ Kp > 3
LI|QSO บน 50 MHz ที่เกิน 11000 km จะปรากฏในรายละเอียดเป็น การแจ้งเตือน เพื่อเป็นข่าวสารทางสถิติเท่านั้น (EI7GL [56]: HZ1SK-K4MOG, 11460 km)
LI|แท็บย่อย สัญญาณบ่งชี้ล่วงหน้าของหลายฮอป: สำหรับภูมิภาคที่อยู่ไกล (สามสิบแห่งทั่วโลก) โปรแกรมตรวจสอบว่าบนจุดฮอปของเส้นทาง ทั้งแบบฮอปเท่ากัน และเสมอด้วยฮอปแรกแบบสั้นภายใน 1200 km มีเมฆ Es ที่ใช้งานอยู่ซึ่งเห็นได้จากสปอตของสถานีอื่นหรือไม่ การแจ้งเตือน (แดง): ทุกจุดครอบคลุม; สัญญาณบ่งชี้ล่วงหน้า (เหลือง): ขาดเพียงจุดเดียว ในบริเวณที่ไม่มีผู้สังเกต การคลิกแถวจะวาดเส้นทางเป็นเส้นประ จุดฮอป (เขียว: เมฆที่ใช้งานอยู่; เทา: ไม่มีผู้สังเกต; แดง: ไม่มีเมฆ) และสปอตที่พิสูจน์ว่ามีเมฆ; รายละเอียดแสดง foEs ที่ต้องการสำหรับแต่ละฮอป
LI|ภูมิภาคทั้งสามสิบของสัญญาณบ่งชี้ล่วงหน้า ได้แก่: ญี่ปุ่น, เกาหลี, จีนตะวันออก, ฟิลิปปินส์, กวมและหมู่เกาะมาเรียนา, อินโดนีเซีย, ออสเตรเลียตอนเหนือ, ออสเตรเลียตะวันออก, นิวซีแลนด์, อินเดีย, คาบสมุทรอาหรับ, เอเชียกลาง, ไซบีเรียตะวันออก, ยุโรปตะวันตก, ยุโรปตะวันออก, สแกนดิเนเวีย, แอฟริกาตะวันตก, แอฟริกาตอนใต้, แคริบเบียน, อเมริกากลาง, เม็กซิโก, อเมริกาเหนือตะวันออก, อเมริกาเหนือตอนกลาง, อเมริกาเหนือตะวันตก, แคนาดาตอนเหนือ, อะแลสกา, ฮาวาย, อเมริกาใต้ตอนเหนือ, บราซิล และ กรวยใต้ (Southern Cone); จะตรวจเฉพาะภูมิภาคที่อยู่ไกลจากสถานีของตนเอง คอลัมน์ของตารางคือ ระดับ, ภูมิภาค, ย่านความถี่, ฮอป, สมมติฐาน (ฮอปเท่ากันหรือฮอปแรกแบบสั้น), km และ Az°
LI|สปอตสีฟ้าไฟฟ้าที่มีป้าย TEP คือเส้นทางที่ข้ามเส้นศูนย์สูตรแม่เหล็กแต่ยาวกว่าหรือไม่สมมาตรมากกว่า TEP แท้ (เช่น ZS6 - OH, SM, LA): sporadic-E อาจเชื่อมต่อเข้ากับ TEP ยังคงอยู่ในกลุ่มสปอต Es; ในคอลัมน์ Prop จะแสดง ES+TEP
H2|3.4 กฎของผู้เขียน
LI|144 MHz: sporadic-E เริ่มที่มากกว่า 900 km; สปอตเดี่ยวจะไม่ถูกวาด; จะวาดเมื่อภายใน 5 นาทีมีสปอตที่สองบนเมฆเดียวกันมาถึง หรือเมื่อในบริเวณใกล้เคียงมีสปอตฮอปสั้นบน 50 MHz แถวสีเขียวด้านบนบอกจำนวนสปอตที่รอการยืนยัน
LI|ข้ามเส้นศูนย์สูตร: สำหรับทิศไปแอฟริกาภาคพื้นทวีป (รวมมาดากัสการ์) และอเมริกาใต้ หากจุดกึ่งกลางตกในแถบมุมเอียงแม่เหล็กระหว่าง -20° ถึง +20° การติดต่อนั้นเป็นแบบข้ามเส้นศูนย์สูตรและไม่ใช่ sporadic-E เว้นแต่สปอตจะระบุ <ES> หมู่เกาะคานารี มาเดรา เคปเวิร์ด และคาบสมุทรอาหรับ อยู่นอกกฎนี้
H1|4. BENCHMARK Es (แท็บย่อยของ SPORADIC-E)
H2|4.1 การโหลดล็อก
P|แท็บย่อย BENCHMARK Es เป็นแท่นทดสอบ sporadic-E บนล็อก ADIF ทั้งไฟล์ แม้เป็นของสถานีอื่น โหลด ADIF จะเปิดไฟล์ (โปรแกรมจะจำไว้และโหลดใหม่เมื่อเริ่มทำงาน) นำ ADIF ออก จะนำไฟล์ออก สถานีที่ศูนย์กลาง จะเสนอสัญญาณเรียกขานและโลเคเตอร์ที่พบบ่อยที่สุดในล็อก; สามารถเปลี่ยนแล้วยืนยันด้วย นำไปใช้
LI|ตำแหน่งที่ส่งคือ MY_GRIDSQUARE ของแต่ละ QSO; ตำแหน่งที่รับคือ GRIDSQUARE (โลเคเตอร์ที่ขาดหายหรือมี 4 ตัวอักษรจะนำมาจาก CALL3)
LI|สามารถไม่รวม QSO ที่มี PROP_MODE อื่นและที่ต่ำกว่า 500 km (900 km บน 144 MHz); QSO ข้ามเส้นศูนย์สูตรจะไม่รวมเสมอ เว้นแต่ PROP_MODE=ES
LI|บนแผนที่ จุดสีเหลืองจางทำเครื่องหมายศูนย์กลางของแต่ละฮอป ซึ่งสันนิษฐานว่าเป็นที่อยู่ของเมฆ sporadic-E (รวมถึงศูนย์กลางของฮอปแรกแบบสั้น หากเปิดใช้สมมติฐานนั้น)
H2|4.2 วัน เวลา และการคำนวณ
P|ตาราง QSO ต่อวัน แสดงรายการวันพร้อมจำนวน QSO ย่านความถี่ ระยะทางสูงสุด และหลายฮอป; การคลิกที่วันจะเติมตาราง ชั่วโมงของวัน โดยมีหนึ่งแถวต่อแต่ละชั่วโมง UTC และแถว ทั้งวัน แผนที่อะซิมุทัลพร้อมแถบเลื่อนระยะทางสูงสุด จะวาดเขตข้ามตามเซกเตอร์ 10° (ส่วนโค้งสีส้ม = QSO ที่ใกล้ที่สุด, เซกเตอร์สีเขียว = ระยะทางที่ไปถึง) เมฆบนช่องกริด และสำหรับทั้งวัน การเคลื่อนที่รายชั่วโมงของเมฆ (เส้นสีแดง)
P|หน้า การคำนวณที่เสนอ แสดงเขตข้ามตามเซกเตอร์ foEs โดยประมาณพร้อม MUF ที่คาดไว้ที่ 1000, 1500, 2000 และ 2400 km เมฆโดยประมาณ การตรวจสอบหลายฮอป (ฮอปเท่ากันเทียบกับฮอปแรกแบบสั้น เปรียบเทียบกับเมฆที่เห็นในฮอปเดียวภายใน ±30 นาที) และการเคลื่อนที่ของเมฆในแต่ละชั่วโมง
LI|คอลัมน์ของตาราง: QSO ต่อวัน (วัน, QSO, ย่านความถี่, km สูงสุด, หลายฮอป); ชั่วโมงของวัน (เวลา UTC, QSO, km ต่ำสุด - สูงสุด, หลายฮอป, ย่านความถี่): การคลิกที่ชั่วโมงจะแสดง QSO ของชั่วโมงนั้น พร้อม UTC, สัญญาณเรียกขาน, โลเคเตอร์, MHz, km, ฮอป และ foEs≥ การคลิกที่ QSO จะเน้น QSO นั้นบนแผนที่พร้อมฮอปแรกของสถานีคู่ติดต่อ สรุปยังบอกด้วยว่าตัด QSO ข้ามเส้นศูนย์สูตรออกไปกี่รายการ
H1|5. BENCHMARK 50 MHz (แท็บย่อยของ SPORADIC-E)
H2|5.1 หนึ่งหรือสองสถานี
P|แท็บย่อย BENCHMARK 50 MHz ใช้สำหรับ sporadic-E หลายฮอปบน 50 MHz ในแถว สถานี 1 ใช้โหลดและนำล็อกของสถานีตนเองออก; ในแถว สถานี 2 ใช้สำหรับล็อกของสถานีที่สอง ซึ่งแสดงหรือซ่อนได้ด้วยช่อง สถานี 2 เส้นทางของสถานี 1 เป็นสีฟ้า ของสถานี 2 เป็นสีม่วง
LI|แสดง QSO หลายฮอปบน 50 MHz คือที่เกิน 3100 km (กฎของผู้เขียน); จำนวนฮอปเป็นไปตามตาราง IK3XTV
LI|วัน, จาก… ถึง… UTC: วันที่ (เมื่อเปิดจะเป็นวันที่มี QSO หลายฮอปมากที่สุด) และช่วงเวลา ทีละ 15 นาที
LI|foEs (ไม่บังคับ): ระบายสีเส้นทางตาม foEs ต่ำสุดและแสดงไว้ในตาราง ความสูง Es และ ฮอปแรกแบบสั้นภายใน 1200 km ทำงานเหมือนในแท็บอื่น
LI|จุดสีเหลืองจางทำเครื่องหมายศูนย์กลางของแต่ละฮอป ซึ่งสันนิษฐานว่าเป็นที่อยู่ของเมฆ sporadic-E; บนเส้นทางที่อยู่ใต้เมาส์จุดนี้จะใหญ่ขึ้น
LI|ตารางแสดง QSO ที่แสดงอยู่พร้อม St. (สถานี 1 หรือ 2), วัน, UTC, สัญญาณเรียกขาน, WWL, km, ฮอป และ foEs≥ เมื่อเปิด foEs จุดฮอปจะแสดง foEs ต่ำสุด; โลเคเตอร์ 4 ตัวอักษรที่ไม่มีใน CALL3 จะถูกแจ้งไว้ข้าง WWL
H2|5.2 แผนที่ Mercator
P|แผนที่เป็นแบบ Mercator ที่กำหนดศูนย์กลางได้อิสระ เมื่อเลื่อนเมาส์เข้าใกล้เส้นทาง เส้นและไอคอนจะขยายใหญ่ขึ้นและปรากฏช่องกริด WWL 6 ตัวอักษรของสถานีคู่ติดต่อ เมื่อคลิกซ้ายบนเส้นทางนั้น หน้าต่างป๊อปอัปจะถามว่าจะแสดง QSO ทั้งหมดในไฟล์ จากทุกวัน ที่มีตำแหน่งปลายทางภายใน 150 km หรือไม่: ใช่ จะล้างแผนที่และแสดง QSO เหล่านั้นภายในวงกลมสีส้ม, ไม่ จะคงแผนที่ไว้ตามเดิม ปุ่ม กลับไปที่วันและเวลา จะกลับไปยังการเลือกก่อนหน้า
H1|6. F.A.I.
H2|6.1 มุมมองสองแบบ
P|แท็บ F.A.I. ศึกษาการกระเจิงจากความไม่สม่ำเสมอที่เรียงตัวตามสนามแม่เหล็ก (แหล่งอ้างอิงหลัก [1], [2]) มุมมอง Scatter trail (คู่ A-B) คำนวณโลคัสของจุดกระเจิงที่เป็นไปได้สำหรับสองสถานี ระบายสีตามค่าเบี่ยงเบนจากเงื่อนไขการสะท้อน เสนอจุดกระเจิงที่น่าจะเป็นที่สุด และวาดกรอบ QTF และมุมเงยของทั้งสองสถานีที่มุมขวาบน (แดง = A, เขียว = B) มุมมองไอโซเฟล็กชัน (จุด) วาดเส้นไอโซเฟล็กชันสำหรับจุดสะท้อนที่เลือก เช่นเดียวกับ AuroReflex และ SE-PROP ของ K9SE: เป็นแถบสีในชุดสีมืด และเส้นหนาในชุดสีสว่าง
H2|6.2 การควบคุม
LI|สถานี A และ สถานี B: สัญญาณเรียกขาน (ค้นหาใน CALL3) และ/หรือ โลเคเตอร์; A ว่าง = สถานีของตนเอง เมนู ตรวจสอบ… โหลดคู่ทดสอบ (IC8FAX-F6DRO, IC8FAX-G4LOH, IC8FAX-FA1MXE, DL5MCG-SV1DH ปี 1987 ผ่านบูดาเปสต์); เมนู จุดกระเจิงที่ทราบ… เลือกจุดกระเจิงที่มีการบันทึกไว้ (เจนีวา, บรัสเซลส์, บูดาเปสต์, JN92, JN41/42)
LI|ความสูง (ค่าเริ่มต้น 110 km), มุมเงยต่ำสุด และ การหักเห (รัศมีโลก 4/3) ซึ่งเปิดไว้เป็นค่าเริ่มต้น
LI|เมนูของมุมมองใช้เลือกระหว่าง Scatter trail (คู่ A-B) และ ไอโซเฟล็กชัน (จุด) ในมุมมอง ไอโซเฟล็กชัน เส้นชั้นอยู่ที่ค่าเบี่ยงเบน 0, ±1, ±2, ±4, ±8 และ ±16 องศา; เส้น 0 คือตำแหน่งของสถานีที่รับ A ผ่านจุดที่เลือกได้
LI|คลิกซ้ายบนแผนที่: จุดสะท้อนที่จะตรวจสอบ (เปลี่ยนไปที่มุมมองไอโซเฟล็กชัน); คลิกขวา: ตำแหน่งของสถานี B
LI|ตรวจสอบจุดที่แนะนำ: คำนวณ Scatter trail นำจุดกระเจิงที่เสนอมาแสดงเส้นไอโซเฟล็กชันพร้อมผลการประเมิน: น่าพอใจ (ภายใน 1°), ยอมรับได้ (ภายใน 2.5°), ไม่น่าพอใจ (เกินกว่านั้น)
LI|ผลลัพธ์ของมุมมอง Scatter trail แสดงจุดกระเจิงที่น่าจะเป็นที่สุด (โลเคเตอร์ 6 ตัวอักษร พิกัด และค่าเบี่ยงเบน) QTF มุมเงย และระยะทางของแต่ละสถานี และมุมเอียงแม่เหล็กที่จุดนั้น; หาก Scatter trail ผ่านใกล้จุดกระเจิงที่ทราบ ผลลัพธ์จะแจ้งไว้ บนแผนที่ กรอบที่มุมขวาบนแสดง QTF: A สีแดง, B สีเขียว
LI|อุปกรณ์ (DL5MCG [6]): สำหรับ F.A.I. บน 144 MHz ต้องมีอย่างน้อยยากิแบบยาวและ 100 W (SV1DH ยังเคยติดต่อได้ด้วย 8 อีลิเมนต์และ 50 W) หันสายอากาศไปที่จุดกระเจิงที่โปรแกรมแสดง ไม่ใช่ไปที่สถานีคู่ติดต่อ
P|หากตามแบบจำลองไม่สามารถคำนวณได้ จะปรากฏข้อความ ไม่สามารถคำนวณได้ และไม่แสดงผลลัพธ์อื่นใด ด้านล่าง ตาราง สปอต F.A.I. แสดงรายการสปอตที่ระบุว่าเป็น FAI; การคลิกสปอตจะโหลดคู่สถานีของสปอตนั้น
LI|สปอต F.A.I. บนแผนที่และในตารางคือสปอตในช่วงเวลาที่เลือกไว้ในคอลัมน์ตัวกรองของ DATA COLLECTION (ค่าเริ่มต้น 24 ชั่วโมง); ตารางแสดง UTC, MHz, DX, Spotter, km และ หมายเหตุ
H1|7. METEOR SCATTER
P|แท็บนี้มีโปรแกรม YA-MS ฉบับสมบูรณ์ พร้อมแท็บของมัน (ข้อมูลสดและตามเวลาจริง: ทราฟฟิก meteor scatter สด, ฟลักซ์เรดาร์, เรดาร์ GRAVES; การคำนวณการพยากรณ์: โดมท้องฟ้าและการคำนวณ, เรขาคณิตและการสูญเสียตามเส้นทาง, การคำนวณประสิทธิภาพ, การพยากรณ์เชิงทดลอง; เอกสารทางเทคนิค: ฝนดาวตก, แหล่งอ้างอิง, แผนที่แหล่งข้อมูล, คำอธิบายการคำนวณประสิทธิภาพ, คู่มือการใช้งาน, แผนที่ช่องกริด) และคู่มือการคำนวณของมัน ภาษาและชุดสีเป็นไปตามที่เลือกไว้ด้านบน ภายใน E-LAYER ANALYZER การเก็บข้อมูลของ YA-MS จะไม่ปรากฏ: การเก็บข้อมูลมีเพียงชุดเดียว คือของ DATA COLLECTION ซึ่งส่งบรรทัดต่อให้ YA-MS และตัวกรองสปอต meteor scatter ตั้งค่าในคอลัมน์ตัวกรองของ DATA COLLECTION
P|YA-MS 1.8.1 ถือว่าลำคลื่นของสายอากาศเป็นแบบรูปแนวตั้ง (ช่อง «แบบรูปสายอากาศ» เปิดไว้เป็นค่าเริ่มต้น): จุดสะท้อนถ่วงน้ำหนักด้วยอัตราขยายแนวตั้งของสายอากาศทั้งสอง และประสิทธิภาพไม่หายไปอีกบนเส้นทางยาว เพิ่มคำเตือน «ไม่มีโซนร่วม» เน้นช่องของมุม β (ทางเลือกที่มีผลมากที่สุด) ใช้วันที่คำนวณเพียงวันเดียว มี «คู่มือการใช้งาน» และการเปรียบเทียบกับสปอตจริง 181 767 รายการที่ 50 MHz จาก HamSCI Meteor Scatter QSO Party เดือนสิงหาคม 2025: ชั่วโมงและด้านของเส้นทางเชื่อถือได้ ส่วนเปอร์เซ็นต์เป็นเพียงค่าบ่งชี้
H1|8. AURORA
P|แท็บ AURORA ใช้มุมมองเดียวกับ F.A.I. (ความสูงเริ่มต้น 110 km, Lange-Hesse [12]) ร่วมกับข้อมูลสภาพอวกาศของ NOAA [15]: วงรีออโรรา OVATION (แรเงาบนแผนที่) ดัชนี Kp ของสามวันล่าสุด และลมสุริยะ ซึ่งดาวน์โหลดทุก 5 นาทีไปยัง data/swpc หรือทันทีด้วย ดาวน์โหลด NOAA เดี๋ยวนี้ โปรแกรมแนะนำทิศการหันสายอากาศสำหรับทั้งสองสถานี
LI|คำสั่งเฉพาะของแท็บ: ช่องทำเครื่องหมาย วงรีออโรรา (NOAA OVATION) ซึ่งเปิดไว้เป็นค่าเริ่มต้น จะแสดงวงรีแบบไล่สีบนแผนที่และใช้เป็นน้ำหนักในการเลือกจุดกระเจิง; ดาวน์โหลด NOAA เดี๋ยวนี้ อัปเดตข้อมูลทันที กรอบ สภาพอวกาศ (NOAA SWPC) แสดงกราฟ Kp ระดับดาวเคราะห์ของ 3 วันล่าสุด ทุก 3 ชั่วโมง และเวลาของวงรีและของการดาวน์โหลดครั้งล่าสุด มุมมอง Scatter trail และ ไอโซเฟล็กชัน ใช้เหมือนใน F.A.I. (บทที่ 6) โดยมีค่าเผื่อ 3°
LI|สปอตออโรราในช่วงเวลาที่เลือกในตัวกรองของ DATA COLLECTION (ค่าเริ่มต้น 2 ชั่วโมงล่าสุด ไม่เกิน 30 รายการ) จะถูกวาดบนแผนที่พร้อมจุดกระเจิงที่คำนวณได้ (วงกลมสีส้ม) หากเปิดช่อง สปอต <AU>/<AUR> บนแผนที่พร้อมการคำนวณ; ในผลลัพธ์จะแสดง QTF และมุมเงยของสองสถานี
LI|ในผลลัพธ์ของมุมมอง Scatter trail จะแสดงความน่าจะเป็นของออโรราที่จุดกระเจิง (ไม่น่าเป็นไปได้เมื่อ Kp ≤ 2; นอกนั้นตามวงรี NOAA) QTF ทั่วไประหว่าง N และ NE (S-SE ในซีกโลกใต้) พร้อมส่วนต่างจากเส้นทางตรง และคำแนะนำเรื่อง Doppler และโหมด (CW/SSB หรือ Q65 กับโหมดย่อยแบบกว้าง: FT8 มักถอดรหัสไม่ได้) จุดกระเจิงจะค้นหาโดยเลือกภายในช่วง Lange-Hesse ของแต่ละสถานีก่อน โดยมีความตั้งฉากภายใน ±3°: 370-1100 km ที่ละติจูดแม่เหล็กโลก 54° ใกล้ขึ้นสำหรับสถานีที่อยู่ทางใต้กว่า และไกลขึ้นสำหรับสถานีที่อยู่ทางเหนือกว่า ตามมุมเอียง IGRF-14 (เช่น คาปรี ประมาณ 260-990 km, ออสโล 470-1200 km) ผลลัพธ์แสดงช่วงของแต่ละสถานี; หากจุดที่เสนออยู่นอกช่วง โปรแกรมจะแจ้งไว้
LI|ความน่าจะเป็นของออโรราที่จุดกระเจิงตัดสินตามลำดับนี้: ไม่น่าเป็นไปได้เมื่อ Kp ≤ 2 เว้นแต่มีพายุ (Dst ≤ -50 nT); ในซีกโลกใต้ น่าจะเป็นไปได้เมื่อมีการเตือนออโรราของ BoM; น่าจะเป็นไปได้เมื่อ Dst ≤ -100 nT และเป็นไปได้เมื่อ Dst ≤ -50 nT หากวงรีที่จุดนั้นไม่เป็นศูนย์; น่าจะเป็นไปได้เมื่อวงรีตั้งแต่ 10%; เป็นไปได้เมื่อวงรีตั้งแต่ 3% หรือเมื่อ Kp ≥ 5; นอกนั้นไม่น่าเป็นไปได้
LI|สปอตออโรราที่เกิน 2000 km จะถูกแจ้งว่าน่าสงสัย: ตาม Newton [48] ออโรราไปถึงราว 1000 km ในแนวเหนือ-ใต้ และ 2000 km ในแนวตะวันออก-ตะวันตก สปอต aurora-E (AUE, AU-E, AURORAL E) จะวาดเป็นสีเขียวบนเส้นทางตรง: เป็น sporadic E ที่มีต้นกำเนิดจากออโรรา ไม่มี Doppler
LI|ผลลัพธ์แสดงเวลาสุริยะที่จุดกระเจิง: การสะท้อนจากออโรราส่วนใหญ่เกิดภายใน 4 ชั่วโมงรอบเที่ยงคืนท้องถิ่น (Reeve [52]) ในซีกโลกใต้ ออโรราบน 50 MHz ไปได้ถึงประมาณ 2000 km บนเส้นทางตะวันออก-ตะวันตก (ANVDG [55]); aurora-E ให้สัญญาณที่อ่อนกว่าและนิ่งกว่าบนเส้นทางตรง (SM2CEW-SM0FOB [54])
LI|นอกเหนือจากจุดกระเจิงที่น่าจะเป็นที่สุด ผลลัพธ์ยังแสดงช่วง QTF ของสองสถานีตลอดทั้ง Scatter trail (ค่าเบี่ยงเบน ≤ 1.5°): ออโรราอาจมาจากทุกจุดในช่วงนี้ และจุดที่น่าจะเป็นที่สุดให้ความสำคัญกับเส้นทางที่สั้นที่สุด
H2|8.1 BENCHMARK AURORA
P|แท็บ AURORA มีแท็บย่อยสองแท็บ: REAL-TIME คือการคำนวณที่อธิบายข้างต้น และ BENCHMARK AURORA ซึ่งเป็นแท่นทดสอบแบบจำลองบน QSO ออโรราจริงที่เผยแพร่แล้ว 298 รายการ (ล็อกของ EI5FK 2003-2005 และแผนที่ล็อกของ PA0O)
LI|เมนู ล็อก เลือกล็อกหนึ่งหรือทั้งหมดรวมกัน; ความสูงเริ่มต้นคือ 110 km พร้อมค่าเผื่อ 3°, การหักเห 4/3 และ IGRF-14
LI|ตารางแสดงสำหรับแต่ละ QSO: จุดกระเจิงที่คำนวณได้ ค่าเบี่ยงเบน QTF และมุมเงยของสถานี และ QTF ของสถานีคู่ติดต่อ เขียว: จุดกระเจิงอยู่ในช่วง Lange-Hesse ของทั้งสองสถานี; เหลือง: อธิบายได้แต่อยู่นอกช่วงนี้; ส้ม: QSO เกิน 2000 km; แดง: ไม่มีจุดกระเจิง QSO ที่แบบจำลองอธิบายไม่ได้
LI|ช่อง ความสูง km เปลี่ยนความสูงของการคำนวณ (80 ถึง 160 km) และคำนวณ QSO ทั้งหมดใหม่ คอลัมน์ของตารางคือ วัน, UTC, สัญญาณเรียกขาน, WWL, km, Scatter, dev°, QTF และ el° ของสถานีในล็อก, QTF ที่แก้ไข (QTF ของสถานีคู่ติดต่อ) และ ผลลัพธ์ กรอบ รายละเอียดของ QSO ที่เลือก แสดงระยะทาง ทิศการหันสายอากาศ ช่วง Lange-Hesse ของแต่ละสถานี และส่วนต่างจากเส้นทางตรง
LI|สรุปให้ค่าร้อยละ รวมถึงกับช่วงคงที่ 370-1100 km เพื่อเปรียบเทียบ และสำหรับแต่ละล็อก ช่วงและมัธยฐานของ QTF ที่คำนวณได้; การคลิกแถวจะวาดเส้นทางและทิศการหันสายอากาศทั้งสอง และแสดงช่วงของแต่ละสถานี ล็อกไม่ได้บันทึกทิศการหันสายอากาศ: การเปรียบเทียบอยู่บนเรขาคณิต ไม่ใช่บน QTF
H1|9. LOG ADIF
P|แท็บ LOG ADIF แสดงช่องกริดที่ติดต่อได้และยืนยันแล้ว ทีละย่านตั้งแต่ 28 MHz ขึ้นไป โดยไม่รวมย่าน เปิดไฟล์ ADIF... จะเพิ่มไฟล์ล็อก; ดาวน์โหลดจาก LoTW... จะดาวน์โหลดรายงานการยืนยัน (จำชื่อผู้ใช้ได้ แต่รหัสผ่านไม่ถูกบันทึกเลย); ล้างหน่วยความจำ จะนำไฟล์และรายงานออก ช่องกริดเป็นสีส้มหากติดต่อได้แล้ว และเป็นสีอื่นหากยืนยันด้วย QSL หรือผ่าน LoTW; การคลิกช่องกริดจะแสดงสัญญาณเรียกขานและโหมดการแพร่กระจาย
LI|เหนือแผนที่มีแท็บของย่านความถี่: 28, 50, 70, 144 และ 432 MHz แสดงเสมอ และย่านอื่นที่มีในล็อก แต่ละแท็บแสดงจำนวนช่องกริดที่ติดต่อได้และที่ยืนยันแล้ว เมนู การแพร่กระจาย จำกัดช่องกริดให้เหลือโหมดเดียว: ES, FAI, ออโรรา (AUR/AUE), MS, TR, EME, F2 หรือ QSO ที่ไม่มี PROP_MODE
LI|สี: ส้ม = ติดต่อได้แต่ยังไม่ยืนยัน, น้ำเงิน = ยืนยันด้วย QSL, เขียว = ยืนยันผ่าน LoTW ตาราง ช่องกริดของย่าน แสดง ช่องกริด, QSO, สถานะ, สัญญาณเรียกขาน และ Prop; การคลิกที่ช่องกริดบนแผนที่หรือในตารางจะแสดงรายละเอียดในกรอบ ช่องกริดที่เลือก
LI|ดาวน์โหลดจาก LoTW... ถามชื่อผู้ใช้ รหัสผ่าน และหากต้องการ สัญญาณเรียกขานเพียงหนึ่งสัญญาณ; จะดาวน์โหลด QSO ทั้งหมดที่อัปโหลดไว้ใน LoTW พร้อมรายละเอียดการยืนยัน หาก LoTW ปฏิเสธการเข้าถึง โปรแกรมจะแจ้ง; ช่องทำเครื่องหมาย จำชื่อผู้ใช้ เก็บชื่อผู้ใช้ไว้ แต่ไม่เก็บรหัสผ่านเลย
H1|10. เอกสาร
P|แท็บ แหล่งอ้างอิง แสดงรายการแหล่งอ้างอิงที่โปรแกรมอ้างถึง แยกตามแท็บ แท็บ สรุปทางเลือกในการคำนวณ แสดงสูตรและทางเลือกในการคำนวณพร้อมแหล่งอ้างอิงในแต่ละขั้นตอน; คู่มือผู้ใช้ ฉบับนี้อธิบายวิธีใช้โปรแกรม; รายงานทางเทคนิค อธิบายเหตุผลที่นำทางการสร้างโปรแกรม เอกสารทั้งสามสามารถส่งออกเป็น Word ได้
LI|เอกสารแต่ละฉบับมีปุ่มที่ด้านบน: ส่งออกเป็น Word (.docx)... ซึ่งบันทึกสำเนาไว้ในที่ที่ต้องการ และ เปิดใน Word ซึ่งเปิดเอกสารด้วยโปรแกรมเริ่มต้นสำหรับไฟล์ .docx เอกสารจะเป็นไปตามภาษาที่เลือกไว้ด้านบน
H1|11. คำแนะนำในการใช้งาน

LI|NTP:FAILED: ไม่มีเซิร์ฟเวอร์เวลาใดตอบกลับ โดยปกติไฟร์วอลล์บล็อกพอร์ต UDP 123; โปรแกรมทำงานต่อด้วยนาฬิกาของ PC และลองใหม่ทุก 5 นาที
LI|เซสชัน telnet เชื่อมต่อไม่ได้หรือปิดทันที: ตรวจสอบโฮสต์ พอร์ต และการเข้าสู่ระบบ (คลัสเตอร์จำนวนมากต้องการสัญญาณเรียกขาน) และตรวจว่าไม่มีเซสชันอื่นที่เปิดอยู่แล้วด้วยสัญญาณเรียกขานเดียวกัน เช่น จากโปรแกรมอื่น
LI|ไม่มีสปอตใน SPORADIC-E: ตรวจสอบย่านความถี่และช่วงเวลาที่เลือก ตรวจว่าตัวกรองในเครื่องไม่ได้ตัดย่านนั้นทิ้ง (ตัวกรองให้ผ่านตั้งแต่ 27990 kHz ถึง 145 MHz) และบน 144 MHz ตรวจว่าสปอตได้รับการยืนยัน (บทที่ 3.4) ทดสอบตัวกรอง บอกว่าบรรทัดของคลัสเตอร์ถูกจัดประเภทอย่างไร
LI|แผนที่ว่างเปล่าเมื่อเริ่มครั้งแรก: แนวชายฝั่งและเส้นพรมแดนจะดาวน์โหลดจาก GitHub ในครั้งแรก; ต้องใช้เครือข่าย จากนั้นจะเก็บไว้ใน data/mappa
LI|LoTW ปฏิเสธการเข้าถึง: ตรวจสอบชื่อผู้ใช้และรหัสผ่านบนเว็บไซต์ของ LoTW; กับล็อกขนาดใหญ่ การดาวน์โหลดอาจใช้เวลาหลายนาที
LI|การอัปเดตอัตโนมัติไม่เริ่มหรือไม่สำเร็จ: ตรวจสอบเครือข่ายและตรวจว่าโฟลเดอร์ของโปรแกรมเขียนได้ ไม่ว่ากรณีใด สามารถติดตั้งเวอร์ชันใหม่ทับเวอร์ชันเก่าด้วยตนเองจากหน้า release ได้ โดยไม่สูญเสียโฟลเดอร์ data
