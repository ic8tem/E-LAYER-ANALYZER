TITLE|Panduan penggunaan E-LAYER ANALYZER
SUB|Panduan penggunaan lengkap - disusun oleh Costantino IC8TEM - versi 0.4.9, November 2026. Angka dalam kurung siku merujuk ke tab SUMBER; rumus dan pilihan perhitungan ada di tab RINGKASAN PILIHAN PERHITUNGAN.
H1|1. Sebelum memulai
H2|1.1 Apa yang dilakukan program ini
P|E-LAYER ANALYZER menghimpun dalam satu program alat-alat untuk mempelajari mode propagasi VHF yang melewati lapisan E ionosfer: sporadic-E, termasuk multi-lompatan dan antarbenua, F.A.I. (ketidakteraturan yang searah dengan medan magnet), meteor scatter, dengan program YA-MS yang terintegrasi, dan aurora radio. Program bekerja dengan spot DX cluster secara langsung dan dengan log ADIF, dan menampilkan setiap hasil pada peta yang menempati dua pertiga jendela, dengan data dan perhitungan di sepertiga bagian kanan.
H2|1.2 Instalasi dan folder data
P|Program berjalan di Windows (64 dan 32 bit), Linux x86_64, Raspberry Pi (Raspberry Pi OS 64 dan 32 bit, Slackware ARM64), Linux armv7l dan Mac (Apple Silicon dan Intel). Program diunduh dari halaman Releases repositori GitHub: untuk Windows tersedia installer dan versi portabel dalam file .zip; untuk Linux dan Raspberry Pi paket .deb, paket Slackware .txz untuk ARM64 dan arsip .tar.gz dengan skrip instalasi; untuk Mac image .dmg. Tidak ada versi untuk Linux i686 (PC 32 bit), karena .NET tidak tersedia untuk sistem itu, juga tidak untuk FreeBSD, yang tidak memiliki pustaka grafis Avalonia.
LI|Windows: installer menempatkan program di C:\E-LAYER-ANALYZER, dengan folder data di sebelahnya; versi portabel diekstrak ke folder mana saja dan dijalankan dengan E-LAYER-ANALYZER.exe.
LI|Linux dan Raspberry Pi: dengan paket .deb (sudo apt install ./e-layer-analyzer_..._amd64.deb, atau _arm64.deb untuk Raspberry Pi OS 64 bit dan _armhf.deb untuk yang 32 bit) program dijalankan dari menu dan pada saat pertama dijalankan menyalin dirinya ke ~/E-LAYER-ANALYZER; arsip .tar.gz (linux-x64, linux-arm64, linux-arm atau linux-armv7l) diekstrak lalu dijalankan ./E-LAYER-ANALYZER, atau ./installa.sh memasangnya di ~/E-LAYER-ANALYZER dengan ikon di menu.
LI|Slackware ARM64: sebagai root, paket dipasang dengan installpkg e-layer-analyzer-...-aarch64-1_ic8tem.txz; program dijalankan dengan e-layer-analyzer dari menu atau terminal dan pada saat pertama dijalankan menyalin dirinya ke ~/E-LAYER-ANALYZER, seperti dengan .deb.
LI|Mac: buka file .dmg (arm64 untuk Apple Silicon M1-M4, x64 untuk Intel) lalu, dengan klik kanan pada "Installa E-LAYER-ANALYZER.command", pilih Buka (Open); sebagai alternatif, file -app.zip hanya berisi aplikasinya.
LI|Semua data program disimpan di folder data di samping program: pengaturan (config.ini), basis data CALL3, koefisien medan magnet, log, data NOAA yang diunduh, spot yang terkumpul. Tidak ada yang ditulis ke AppData atau ke folder sistem lainnya.
LI|Untuk memindahkan program ke komputer lain cukup salin foldernya; untuk kembali ke pengaturan awal cukup hapus data/config.ini.
LI|Di folder data program juga menyimpan: lingue (terjemahan), spot (spot terkumpul), spot_ms (spot meteor scatter dari YA-MS), swpc (data NOAA), mappa (garis pantai dan batas negara Natural Earth, diunduh dari GitHub saat pertama dijalankan: pertama kali diperlukan jaringan) dan aggiornamento (paket pembaruan otomatis, yang boleh dihapus).
LI|Kata sandi LoTW tidak pernah disimpan; hanya nama pengguna yang dapat diingat.
LI|Pembaruan: sejak versi 0.4.5 program memeriksa sendiri, saat mulai lalu setiap 6 jam, apakah ada versi baru di GitHub. Jika ada, program memberitahukannya dengan sebuah jendela dan tulisan oranye ▲ di bilah atas: "Perbarui sekarang" mengunduh paket yang sesuai untuk komputer (Windows 64 atau 32 bit, Linux, Raspberry Pi, Mac), menutup program, mengganti file lalu menjalankannya kembali; "Nanti" menunda, "Lewati versi ini" tidak lagi menawarkannya. Pengaturan, spot terkumpul dan call3.txt tetap tersimpan. Pemeriksaan dapat dimatikan dengan kotak centang di jendela yang sama.
LI|File hilang: saat mulai program memeriksa apakah semua file yang disertakan saat distribusi masih ada (terjemahan, dokumen, tabel). Jika ada yang hilang, sebuah jendela menampilkan daftarnya dan tombol "Unduh dari GitHub" mengambilnya kembali dari versi yang sama yang diterbitkan di GitHub.
LI|Selama pembaruan, jendela menampilkan kemajuan pengunduhan dan ekstraksi. Jika folder program tidak dapat ditulisi, misalnya di dalam folder sistem, program memberitahukannya dan menawarkan halaman Release, tempat paket instalasi dapat diunduh; jika ada yang gagal, alasannya ditampilkan dan tombolnya menjadi "Halaman Release".
H2|1.3 Bilah atas
P|Di kiri atas diisi callsign Anda, locator (4, 6 atau 8 karakter) dan ketinggian antena dalam meter; tombol Terapkan mengonfirmasinya dan semua tab diperbarui. Di kanan atas terdapat jam UTC, pilihan skema warna (semua skema YAEC: Terang, Malam, Hitam, delapan warna pastel dan Jejak meteor) dan pilihan bahasa (36 bahasa). Saat skema warna atau bahasa diganti, jendela langsung dibangun ulang tanpa kehilangan data yang sudah terkumpul.
P|Di samping jam UTC, tulisan NTP:OK (hijau) atau NTP:FAILED (merah) menunjukkan apakah jam sudah selaras: setiap 5 menit program menanyai dua server waktu dari sepuluh server yang tersebar di seluruh dunia dan beralih ke server lain jika tidak menjawab. Tooltip menampilkan server yang dipakai dan selisih jam PC.
P|Program selalu memakai waktu yang benar: selisih yang diukur diterapkan pada jamnya sendiri. Jika selisihnya lebih dari satu detik, di Windows dan dengan hak administrator program juga mengoreksi jam PC, dan tooltip menyebutkannya ("Jam PC telah dikoreksi."); di Linux dan Mac jam sistem tidak diubah.
P|Di samping tulisan NTP terdapat versi terpasang (misalnya v0.4.5, berwarna abu-abu): satu klik langsung memeriksa apakah ada versi yang lebih baru di GitHub. Saat versi baru keluar, tulisan berubah menjadi oranye, misalnya ▲ 0.4.6, dan satu klik membuka jendela pembaruan.
P|Di kanan bilah tab terdapat menu benua (Eropa, Amerika Utara, Amerika Selatan, Afrika, Asia, Oseania): menu ini menggeser peta Mercator serta peta F.A.I. dan aurora ke benua yang dipilih dan memilih data prakiraan benua itu (E-skip dari N0NBH hanya diterbitkan untuk Eropa dan Amerika Utara).
H2|1.4 Bilah status
P|Di bagian bawah, bilah status menunjukkan berapa callsign yang ada di basis data CALL3, berapa spot yang ada di memori dan model magnetik yang dipakai (IGRF-14 beserta epoknya). Spot di memori dihapus setiap kali program ditutup: setiap sesi dimulai tanpa spot lama.
H2|1.5 Peta
P|Semua peta digunakan dengan cara yang sama: roda mouse memperbesar atau memperkecil, menyeret dengan tombol kiri menggeser tampilan, klik kiri memilih titik, spot atau lintasan sesuai tab. Di kanan atas muncul koordinat dan locator 6 karakter di bawah kursor; pada peta azimutal juga jarak dan azimut dari pusat. Kisi field dan kotak Maidenhead makin rapat saat diperbesar.
LI|Setiap peta memiliki keterangan warna dan simbol yang dipakainya di kiri bawah. Pada penggambaran pertama, tulisan "Memuat peta (Natural Earth)..." dapat muncul selama beberapa detik.
H1|2. Pengumpulan data (DATA COLLECTION)
P|Tab ini memiliki dua subtab: Spot, dengan sesi telnet, spot terkumpul, basis data CALL3 dan kolom filter, serta Data propagasi (bab 2.5).
H2|2.1 Tiga sesi telnet
P|Tab DATA COLLECTION membuka hingga tiga koneksi telnet sekaligus: satu DX cluster pilihan (bawaan ON0DXK dengan filter VHF), Reverse Beacon Network (port 7001 untuk FT8, 7000 untuk CW dan RTTY) dan cluster DM4X dengan spot PSKReporter (dm4x.ddns.net, port 8500).
LI|Host dan Port: alamat cluster. Login: callsign untuk masuk (jika kosong dipakai callsign dari bilah atas). Perintah setelah login: perintah yang dikirim setelah login, dipisahkan dengan titik koma (misalnya filter band).
LI|Sambung dan Putuskan membuka dan menutup sesi; Sambung ulang membukanya kembali secara otomatis setelah terputus; Sambung saat mulai membukanya saat program dijalankan.
LI|Konsol menampilkan baris yang diterima; di kotak di bawahnya dapat ditulis perintah untuk dikirim ke cluster (misalnya sh/dx 20) dan dikonfirmasi dengan Kirim atau tombol Enter.
H2|2.2 Kolom filter
P|Kolom kanan tab, 40% dari jendela, menghimpun semua filter spot: pengumpulan data hanya satu untuk seluruh program, dan setiap spot yang diterima melewati kolom ini sebelum sampai ke tab tiap mode propagasi. Di bagian atas ada kotak centang filter lokal, aktif secara bawaan: baris "DX de" dengan frekuensi di bawah 27990,0 kHz atau di atas 145 MHz dibuang, tidak muncul di konsol dan tidak disimpan. Ini terutama berguna dengan RBN dan PSKReporter, yang mengirim sangat banyak spot HF. Jika kotak dimatikan, semua baris diteruskan. Di bawahnya ada lima subtab.
LI|Meteor scatter: filter YA-MS (jendela frekuensi khas MS, tag propagasi lain, mode digital MS dan <MS>, band, uji filter dan penghitung). Di dalam E-LAYER ANALYZER subtab Pengumpulan data YA-MS tidak muncul: filternya diatur di sini.
LI|Sporadic-E: tag di antara < > yang mengecualikan spot dari sporadic-E; aturan 28 dan 50 MHz (di 50 MHz dalam 450 km bukan sporadic-E; di 28 MHz jarak minimum diturunkan dari jarak 50 MHz mengikuti IK3XTV, sekitar 170 km; bandplan bukan kriteria eksklusif, sehingga spot di jendela meteor scatter tetap masuk sporadic-E kecuali mode digital MS atau <MS>); aturan 144 MHz (jarak minimum; konfirmasi dengan spot kedua pada awan yang sama dalam beberapa menit, atau dengan spot 50 MHz lompatan pendek di sekitarnya) dan aturan transekuatorial dengan pita inklinasi magnetiknya, yang berlaku untuk Afrika dan Amerika Selatan (aturan penulis) dan, di seluruh dunia, untuk hubungan 3000-8000 km yang melintasi ekuator magnetik dengan arah hampir utara-selatan (Kennewell dan Wilkinson [49]). Tombol Pulihkan aturan penulis mengembalikan nilai bawaan.
LI|Nilai awal aturan sporadic-E, semuanya dapat diubah: jarak minimum di 50 MHz 450 km; aturan 144 MHz aktif, dengan jarak minimum 900 km dan konfirmasi dalam 5 menit oleh spot kedua pada awan dalam radius 300 km, atau oleh spot 50 MHz dari 15 menit terakhir dengan lompatan pendek hingga 1200 km; aturan transekuatorial aktif, dengan pita inklinasi magnetik ±20°.
LI|F.A.I.: kata-kata yang menandai spot F.A.I. (bawaan FAI: berlaku <FAI> atau fai, dalam huruf besar, kecil, atau campuran; spot ini tidak masuk sporadic-E), band dan periode spot di peta (bawaan 24 jam).
LI|Aurora: kata-kata untuk spot aurora, dengan atau tanpa < > dan dalam huruf besar atau kecil (bawaan AU dan AUR), band dan periode spot di peta (bawaan 2 jam).
LI|Uji filter: ketik atau tempel satu baris kluster dan program menunjukkan bagaimana filter mengklasifikasikannya (meteor scatter, aurora, F.A.I., transekuatorial, sporadic-E), beserta band, locator dan jarak.
H2|2.3 Cara program membaca spot
P|Dari setiap baris "DX de" program mengambil spotter, frekuensi, DX, komentar, jam dan, bila ada, locator serta mode propagasi yang ditulis di komentar dalam bentuk JN70CN<ES>JO62QM (locator pertama milik spotter, yang kedua milik DX; bentuk dengan <>, > dan tanda kurung juga diterima).
LI|Locator yang tidak ada dicari di basis data CALL3; locator yang kurang presisi (kurang dari 6 karakter) diganti dengan locator 6 karakter dari CALL3, bila tersedia.
LI|Spot dengan <MS>, <AU>, <AUR>, <TR>, <AS> atau <ACS> dalam teks tidak dipakai untuk sporadic-E: spot tersebut untuk meteor scatter, aurora, tropo atau aircraft scatter.
LI|Seperti di YA-MS, spot meteor scatter adalah spot dalam jendela frekuensi khas MS (50190-50300, 70100-70400, 144290-144399 kHz) tanpa keterangan propagasi lain, serta spot dengan mode MSK144, FSK441, FSK41, PSK2K, JTMS, JT6M atau dengan <MS>.
LI|Spot dengan <AU> atau <AUR> masuk ke tab AURORA, spot dengan FAI ke tab F.A.I.
H2|2.4 Spot terkumpul dan basis data CALL3
P|Halaman Spot terkumpul menampilkan spot terakhir dengan filter per band dan per sumber; tombol Buka folder spot membuka data/spot. Halaman CALL3 menampilkan basis data callsign -> locator (format JTDX/WSJT): Anda dapat mencari callsign, memuat ulang basis data atau mengimpor file CALL3.TXT baru, yang menggantikan file yang sedang dipakai (file lama disimpan sebagai cadangan).
LI|Kolom spot terkumpul adalah: UTC, Sumber (cluster, RBN atau PSKReporter), MHz, Band, DX dengan locator-nya, Spotter dengan locator-nya, km, Prop (mode propagasi yang dinyatakan atau dikenali) dan Komentar. Menu Semua sumber membatasi tabel pada satu sesi saja.
LI|Halaman CALL3 menampilkan file yang dipakai, tanggalnya, header-nya dan jumlah callsign yang dimuat (lebih dari satu juta dengan basis data yang disertakan).
H2|2.5 Data propagasi
P|Subtab Data propagasi mengumpulkan data yang membantu memahami apakah sebuah band dapat terbuka. Data diperbarui sendiri paling banyak sekali per jam; tombol Perbarui sekarang langsung mengunduhnya.
LI|N0NBH (hamqsl.com): banner kondisi VHF dan data matahari (fluks matahari, indeks A dan K, sinar X, angin matahari, Bz, aurora dan lintang aurora) dengan E-skip Eropa dan Amerika Utara (data DXrobot).
LI|Kondisi VHF N0NBH ditampilkan sebagaimana diterbitkan hamqsl.com: Band Closed (band tertutup), 50MHz ES, 70MHz ES dan 144MHz ES (sporadic-E di band tersebut), High MUF; untuk aurora High LAT AUR dan Mid LAT AUR (aurora di lintang tinggi atau menengah).
LI|Bz untuk aurora: NOAA SWPC, angin matahari waktu nyata yang diukur satelit di titik L1 (DSCOVR/ACE), setiap menit. Bz negatif dan bertahan lama mendukung aurora.
LI|Aurora: indeks Dst Kyoto (badai geomagnetik) dan, untuk belahan bumi selatan, peringatan aurora dari Bureau of Meteorology Australia, yang memerlukan kunci gratis yang ditulis di kotak Kunci API BoM. Tombol Indeks AE (Kyoto) dan Konveksi SuperDARN membuka kedua halaman di peramban.
LI|Tingkat Dst dibaca sebagai berikut: tenang di atas -30 nT, gangguan lemah antara -30 dan -50 nT, badai sedang antara -50 dan -100 nT, badai kuat dari -100 nT ke bawah. Dengan kunci BoM juga muncul indeks K Australia dan peringatan pengawasan aurora yang sedang berlaku.
LI|Meteor scatter: grafik aktivitas meteor hari ini (data RMOB) dari Make More Miles on VHF; hujan meteor, efisiensi dan lalu lintas waktu nyata ada di tab METEOR SCATTER.
P|Ringkasan data ini tampil di kanan atas pada peta SPORADIC-E dan F.A.I. (E-skip benua yang dipilih) serta AURORA (aurora dari N0NBH dan Bz dari NOAA).
H1|3. Sporadic-E (SPORADIC-E)
P|Tab SPORADIC-E memiliki tiga subtab: REAL-TIME, spot langsung yang dijelaskan dalam bab ini; BENCHMARK Es (bab 4) dan BENCHMARK 50 MHz (bab 5).
H2|3.1 Peta
P|Menu Peta memilih proyeksi. Azimutal: peta azimutal ekuidistan yang berpusat pada stasiun Anda, dengan penggeser zoom (dari 300 hingga 20000 km dari pusat, juga dengan roda mouse). Mercator: peta dunia dengan tombol Eropa dan Dunia. Pada kedua proyeksi, lingkaran jarak dari tabel IK3XTV [3] digambar di sekitar stasiun: 500 km (minimum satu lompatan), 1500-2000 km (optimal), 2400 km (maksimum satu lompatan), 5000 km (maksimum dua lompatan) dan 6900 km (maksimum tiga lompatan).
P|Tabel panjang lompatan di 50 MHz adalah tabel Flavio Egano IK3XTV, «Propagazione sui 6 metri - Caratteristiche generali» [3]; awan Es berada pada ketinggian sekitar 100 km, dan hal ini membatasi satu lompatan sekitar 2000 km [29]. Cincin pada peta dan jumlah lompatan mengikuti jarak-jarak ini:
TAB|Lompatan;Jarak minimum;Jarak optimal;Jarak maksimum
TAB|Satu lompatan;500-650 km;1500-2000 km;2200-2400 km
TAB|Dua lompatan;2800-3000 km;3200-4000 km;4400-5000 km
TAB|Tiga lompatan;-;4800-6400 km;6900 km
P|Pada tampilan azimutal, lingkaran putus-putus menunjukkan km dari pusat; jarak antarlingkaran berubah sesuai perbesaran dan tepi luar menunjukkan jarak maksimum yang ditampilkan.
H2|3.2 Kontrol
LI|Band: 10, 6, 4 dan 2 m (432 MHz tidak dianalisis: sporadic-E tidak berlaku [22]-[24]); jendela waktu spot dari 15 menit hingga 12 jam.
LI|Ketinggian Es (bawaan 110 km) dan elevasi minimum antena (bawaan 1°); elevasi memperhitungkan refraksi troposfer (jari-jari Bumi 4/3), sehingga satu lompatan mencapai sekitar 2440 km.
LI|Lompatan pertama (lompatan sama): menampilkan lompatan pertama kedua stasiun; Lompatan pertama pendek dalam…: menampilkan hipotesis penulis tentang lompatan pertama pendek (bawaan 1200 km) [4].
LI|Awan Es pada kotak Maidenhead: mewarnai kotak titik pantul menurut frekuensi tertinggi spot (hijau hingga 29 MHz, kuning hingga 51, oranye hingga 71, merah hingga 145 MHz). Jika MUF kemungkinan awan pada lompatan terpanjang (2400 km) mencapai band yang lebih tinggi, kotak berkedip dengan warna band tersebut.
LI|144 MHz ke arah Kepulauan Canaria, Madeira, dan Azores (aturan penulis): di atas 2400 km spot hanya berlaku jika paling sedikit dua spot menunjuk awan Es yang sama; digambar lompatan Es, awan, dan lintasan tropo putus-putus hingga ke pulau. Pada 50 dan 70 MHz aturan ini tidak berlaku.
H2|3.3 Tabel dan rincian
P|Tabel Spot Es menampilkan spot yang valid dengan jarak, jumlah lompatan dan foEs minimum; tabel Awan Es (kotak) menampilkan kotak dengan perkiraan awan dan MUF yang akan dihasilkannya untuk stasiun Anda (merah 144 MHz, oranye 70 MHz, kuning 50 MHz). Bila perbesaran diatur, tabel hanya menampilkan apa yang terlihat di peta.
LI|Kolom tabel Spot Es: UTC, MHz, DX, Spotter, km, Lompatan, foEs≥ (foEs minimum perkiraan) dan Prop. Kolom tabel Awan Es: Kotak, foEs≥, jumlah spot, azimut dan jarak dari stasiun Anda, dan MUF saya.
LI|Warna dan simbol di peta: lintasan 10 m hijau, 6 m biru muda, 4 m ungu dan 2 m oranye; kotak kecil kuning = titik tengah lompatan tunggal; kotak kecil oranye = lompatan pertama spotter dan kotak kecil ungu = lompatan pertama DX (lompatan sama panjang); lingkaran kecil oranye = lompatan pertama pendek (hipotesis IC8TEM); lingkaran hijau = jangkauan lompatan tunggal dari stasiun Anda.
LI|Klik spot di tabel atau di peta: lintasan menyala dengan pendar kuning, peta menggesernya ke tampilan bila perlu dan panel Rincian menampilkan lompatan, titik pantul, foEs dan azimut. Spot tetap terpilih meskipun spot baru berdatangan.
LI|Klik titik kosong di peta: titik itu diperlakukan sebagai kemungkinan awan Es, dengan foEs yang diperlukan untuk 28, 50, 70 dan 144 MHz.
LI|Bila Kp di atas 3, peta menandainya di kanan atas, sebagai pemberitahuan saja: IK3XTV-IZ3ESV [51] mendapati lebih dari 90% bukaan terjadi dengan Kp ≤ 3, tetapi pada log 50 MHz penulis sporadic-E tidak berkurang dengan Kp > 3.
LI|QSO di 50 MHz lebih dari 11000 km muncul dalam detail sebagai PERINGATAN, hanya sebagai kabar statistik (EI7GL [56]: HZ1SK-K4MOG, 11460 km).
LI|Subtab Prekursor multi-lompatan: untuk wilayah yang jauh (tiga puluh di seluruh dunia) program memeriksa apakah pada titik-titik lompatan lintasan, dengan lompatan sama dan selalu juga dengan lompatan pertama pendek dalam 1200 km, terdapat awan Es aktif yang terlihat dari spot stasiun lain. PERINGATAN (merah): semua titik tertutup; PREKURSOR (kuning): hanya kurang satu titik, di wilayah tanpa pengamat. Klik pada sebuah baris menggambar lintasan putus-putus, titik-titik lompatan (hijau: awan aktif; abu-abu: tidak ada pengamat; merah: tidak ada awan) dan spot yang membuktikan awan tersebut; rincian mencantumkan foEs yang diperlukan untuk setiap lompatan.
LI|Ketiga puluh wilayah prekursor adalah: Jepang, Korea, Tiongkok timur, Filipina, Guam dan Mariana, Indonesia, Australia utara, Australia timur, Selandia Baru, India, Jazirah Arab, Asia Tengah, Siberia timur, Eropa Barat, Eropa Timur, Skandinavia, Afrika Barat, Afrika bagian selatan, Karibia, Amerika Tengah, Meksiko, Amerika Utara bagian timur, Amerika Utara bagian tengah, Amerika Utara bagian barat, Kanada utara, Alaska, Hawaii, Amerika Selatan bagian utara, Brasil dan Kerucut Selatan; yang diperiksa adalah wilayah yang jauh dari stasiun Anda. Kolom tabelnya adalah Tingkat, Wilayah, Band, Lompatan, Hipotesis (lompatan sama panjang atau lompatan pertama pendek), km dan Az°.
LI|Spot berwarna biru listrik dengan tulisan TEP adalah lintasan yang melintasi ekuator magnetik tetapi lebih panjang atau lebih asimetris daripada TEP murni (misalnya ZS6 - OH, SM, LA): sporadic-E dapat mengait TEP. Spot ini tetap termasuk spot Es; di kolom Prop muncul ES+TEP.
H2|3.4 Aturan penulis
LI|144 MHz: sporadic-E dimulai dari lebih dari 900 km; satu spot saja tidak digambar; spot digambar jika dalam 5 menit datang spot kedua pada awan yang sama atau jika di sekitarnya ada spot 50 MHz lompatan pendek. Baris hijau di atas menunjukkan berapa spot yang menunggu konfirmasi.
LI|Transekuatorial: ke arah Afrika daratan (termasuk Madagaskar) dan Amerika Selatan, jika titik tengah jatuh pada pita inklinasi magnetik antara -20° dan +20°, hubungan tersebut transekuatorial dan bukan sporadic-E, kecuali spot menyatakan <ES>. Kepulauan Canaria, Madeira, Tanjung Verde dan Jazirah Arab tidak termasuk dalam aturan ini.
H1|4. BENCHMARK Es (subtab SPORADIC-E)
H2|4.1 Memuat log
P|Subtab BENCHMARK Es adalah bangku uji sporadic-E pada satu log ADIF utuh, termasuk log stasiun lain. Muat ADIF membuka file (program mengingatnya dan memuatnya lagi saat dijalankan), Lepas ADIF melepaskannya. Stasiun di tengah mengusulkan callsign dan locator yang paling sering muncul di log; keduanya dapat diubah dan dikonfirmasi dengan Terapkan.
LI|Posisi pemancar adalah MY_GRIDSQUARE setiap QSO; posisi penerima adalah GRIDSQUARE (locator yang tidak ada atau 4 karakter diambil dari CALL3).
LI|QSO dengan PROP_MODE lain dan QSO di bawah 500 km (900 km di 144 MHz) dapat dikecualikan; QSO transekuatorial selalu dikecualikan, kecuali PROP_MODE=ES.
LI|Di peta, titik kuning buram menandai pusat setiap lompatan, tempat awan sporadic-E diperkirakan berada (juga pusat lompatan pertama pendek, bila hipotesis itu aktif).
H2|4.2 Hari, jam dan perhitungan
P|Tabel QSO per hari menampilkan hari-hari dengan jumlah QSO, band, jarak maksimum dan multi-lompatan; klik pada satu hari mengisi tabel Jam dalam sehari, dengan satu baris untuk setiap jam UTC dan baris Sepanjang hari. Peta azimutal, dengan penggeser jarak maksimum, menggambar skip per sektor 10° (busur oranye = QSO terdekat, sektor hijau = jarak yang tercapai), awan pada kotak dan, untuk satu hari penuh, pergeseran awan per jam (garis merah).
P|Halaman Perhitungan yang diusulkan menampilkan skip per sektor, perkiraan foEs dengan MUF yang diharapkan pada 1000, 1500, 2000 dan 2400 km, perkiraan awan, verifikasi multi-lompatan (lompatan sama dibandingkan lompatan pertama pendek, dicocokkan dengan awan yang terlihat dalam satu lompatan dalam ±30 menit) dan pergeseran awan jam demi jam.
LI|Kolom tabel: QSO per hari (Hari, QSO, Band, km maks, Multi-lompatan); Jam dalam sehari (Waktu UTC, QSO, km min - maks, Multi-lompatan, Band): klik pada sebuah jam menampilkan QSO pada jam itu, dengan UTC, Callsign, Locator, MHz, km, Lompatan dan foEs≥. Klik pada sebuah QSO menyorotnya di peta beserta lompatan pertama stasiun lawan. Ringkasan juga menyebutkan berapa QSO transekuatorial yang dikecualikan.
H1|5. BENCHMARK 50 MHz (subtab SPORADIC-E)
H2|5.1 Satu atau dua stasiun

Pada baris Stasiun 1 dimuat dan dilepas log stasiun Anda; pada baris Stasiun 2 log stasiun kedua, yang ditampilkan atau disembunyikan dengan kotak centang Stasiun 2. LI|Yang ditampilkan adalah QSO 50 MHz multi-lompatan, yaitu di atas 3100 km (aturan penulis); jumlah lompatan mengikuti tabel IK3XTV.
LI|Hari, dari… sampai… UTC: hari (saat dibuka, hari dengan QSO multi-lompatan terbanyak) dan rentang jam, dalam langkah 15 menit.
LI|foEs (opsional): mewarnai lintasan dengan foEs minimum dan mencantumkannya di tabel. Ketinggian Es dan Lompatan pertama pendek dalam 1200 km seperti di tab lainnya.

LI|Tabel mencantumkan QSO yang ditampilkan dengan St. (stasiun 1 atau 2), Hari, UTC, Callsign, WWL, km, Lompatan dan foEs≥. Dengan foEs aktif, titik lompatan menampilkan foEs minimum; locator 4 karakter yang tidak ada di CALL3 ditandai di samping WWL.

Dengan klik kiri pada lintasan itu, sebuah popup menanyakan apakah akan menampilkan semua QSO dalam file, dari semua hari, yang posisi ujungnya berada dalam 150 km: Ya mengosongkan peta dan menampilkan QSO tersebut di dalam lingkaran oranye, Tidak membiarkan peta apa adanya. Tombol Kembali ke hari dan jam mengembalikan ke pilihan sebelumnya.
H1|6. F.A.I.
H2|6.1 Dua tampilan
P|Tab F.A.I. mempelajari scatter dari ketidakteraturan yang searah dengan medan magnet (sumber utama [1], [2]). Tampilan Scatter trail (pasangan A-B) menghitung, untuk dua stasiun, tempat kedudukan scatter point yang mungkin, diwarnai menurut deviasi dari kondisi pantulan, mengusulkan scatter point yang paling mungkin dan menggambar di kanan atas panel QTF dan elevasi kedua stasiun (merah = A, hijau = B). Tampilan Iso-refleksi (titik) menggambar, untuk titik pantul yang dipilih, garis-garis iso-refleksi seperti AuroReflex dan SE-PROP karya K9SE: pita berwarna pada skema gelap, garis tebal pada skema terang.
H2|6.2 Kontrol
LI|Stasiun A dan Stasiun B: callsign (dicari di CALL3) dan/atau locator; A kosong = stasiun Anda. Menu Verifikasi… memuat pasangan uji (IC8FAX-F6DRO, IC8FAX-G4LOH, IC8FAX-FA1MXE, DL5MCG-SV1DH tahun 1987 via Budapest); menu Scatter point dikenal… memilih scatter point yang terdokumentasi (Jenewa, Brussel, Budapest, JN92, JN41/42).
LI|Ketinggian (bawaan 110 km), elevasi minimum dan Refraksi (jari-jari Bumi 4/3), aktif secara bawaan.
LI|Menu tampilan memilih antara Scatter trail (pasangan A-B) dan Iso-refleksi (titik). Pada tampilan Iso-refleksi, garis kontur berada pada deviasi 0, ±1, ±2, ±4, ±8 dan ±16 derajat; kontur 0 adalah tempat kedudukan stasiun yang menerima A melalui titik yang dipilih.
LI|Klik kiri pada peta: titik pantul yang akan diverifikasi (beralih ke tampilan Iso-refleksi); klik kanan: posisi stasiun B.
LI|Verifikasi titik yang disarankan: menghitung jejak, mengambil scatter point yang diusulkan dan menampilkan garis iso-refleksinya beserta penilaiannya: MEMUASKAN (dalam 1°), DAPAT DITERIMA (dalam 2,5°), TIDAK MEMUASKAN (lebih dari itu).
LI|Hasil tampilan Scatter trail menyebutkan scatter point paling mungkin (locator 6 karakter, koordinat dan deviasi), untuk setiap stasiun QTF, elevasi dan jarak, serta inklinasi magnetik di titik itu; jika jejak melewati dekat scatter point yang dikenal, hal itu juga disebutkan. Di peta, kotak di kanan atas menampilkan QTF: A merah, B hijau.
LI|Perlengkapan (DL5MCG [6]): F.A.I. di 144 MHz memerlukan setidaknya yagi panjang dan 100 W (SV1DH juga pernah dikontak dengan 8 elemen dan 50 W). Antena diarahkan ke scatter point yang ditunjukkan program, bukan ke stasiun lawan.
P|Jika menurut model perhitungan tidak dapat dilakukan, muncul pesan Perhitungan tidak mungkin dan tidak ada hasil lain yang ditampilkan. Di bagian bawah, tabel Spot F.A.I. menampilkan spot yang dinyatakan FAI; klik pada sebuah spot memuat pasangan stasiunnya.
LI|Spot F.A.I. di peta dan di tabel adalah spot dari periode yang dipilih di kolom filter DATA COLLECTION (awalnya 24 jam); tabel menampilkan UTC, MHz, DX, Spotter, km dan Komentar.
H1|7. METEOR SCATTER
P|Tab ini berisi program YA-MS lengkap, dengan tab-tabnya (Langsung dan data waktu nyata: lalu lintas meteor scatter langsung, fluks radar, radar GRAVES; Perhitungan prakiraan: kubah langit dan perhitungan, geometri dan redaman, perhitungan efisiensi, penerapan eksperimental prakiraan; Dokumen teknis: hujan meteor, sumber, peta sumber, penjelasan perhitungan efisiensi, panduan penggunaan, peta kotak) dan manual perhitungannya. Bahasa dan skema warna mengikuti pilihan di bagian atas. Di dalam E-LAYER ANALYZER Pengumpulan data YA-MS tidak muncul: pengumpulan data hanya satu, yaitu milik DATA COLLECTION, yang meneruskan baris ke YA-MS, dan filter spot meteor scatter diatur di kolom filter DATA COLLECTION.
P|YA-MS 1.8.1 memperlakukan lobus antena sebagai pola vertikal (kotak «pola antena», aktif secara bawaan): titik pantulan diberi bobot dengan penguatan vertikal kedua antena dan efisiensi tidak lagi hilang pada lintasan panjang. Ditambahkan peringatan «tidak ada zona bersama», kotak sudut β yang ditonjolkan (pilihan yang paling berpengaruh), satu tanggal perhitungan, «Panduan penggunaan» dan perbandingan dengan 181 767 spot nyata di 50 MHz dari HamSCI Meteor Scatter QSO Party Agustus 2025: jam dan sisi lintasan dapat diandalkan, persentasenya bersifat indikatif.
H1|8. AURORA
P|Tab AURORA memakai tampilan yang sama dengan F.A.I. (ketinggian bawaan 110 km, Lange-Hesse [12]) dengan data cuaca antariksa dari NOAA [15]: oval aurora OVATION (diarsir di peta), indeks Kp tiga hari terakhir dan angin surya, diunduh setiap 5 menit ke data/swpc atau segera dengan Unduh NOAA sekarang. Program menyarankan arah antena untuk kedua stasiun.
LI|Kontrol khusus tab ini: kotak centang Oval aurora (NOAA OVATION), aktif sejak awal, menampilkan oval secara samar di peta dan memakainya sebagai bobot dalam pemilihan scatter point; Unduh NOAA sekarang langsung memperbarui data. Panel Cuaca antariksa (NOAA SWPC) menampilkan grafik Kp planeter 3 hari terakhir, setiap 3 jam, serta waktu oval dan unduhan terakhir. Tampilan Scatter trail dan Iso-refleksi dipakai seperti pada F.A.I. (bab 6), dengan toleransi 3°.
LI|Spot aurora dari periode yang dipilih di filter DATA COLLECTION (bawaan 2 jam terakhir, paling banyak 30) digambar di peta dengan scatter point yang dihitung (lingkaran oranye) jika kotak centang Spot <AU>/<AUR> di peta dengan perhitungan aktif; hasilnya menampilkan QTF dan elevasi kedua stasiun.
LI|Dalam hasil tampilan Scatter trail muncul probabilitas aurora di scatter point (kecil kemungkinannya dengan Kp ≤ 2; selebihnya menurut oval NOAA), QTF khas antara N dan NE (S-SE di belahan bumi selatan) dengan selisih dari jalur langsung, serta saran tentang Doppler dan mode (CW/SSB atau Q65 dengan submode lebar: FT8 sering tidak terdekode). Scatter point dicari terutama di dalam jendela Lange-Hesse masing-masing stasiun, dengan ketegaklurusan dalam ±3°: 370-1100 km pada lintang geomagnetik 54°, lebih dekat untuk stasiun yang lebih ke selatan dan lebih jauh untuk yang lebih ke utara, sesuai inklinasi IGRF-14 (misalnya Capri sekitar 260-990 km, Oslo 470-1200 km). Hasil menampilkan jendela setiap stasiun; jika titik yang diusulkan berada di luar, program menandainya.
LI|Probabilitas aurora di scatter point ditentukan dengan urutan ini: kecil kemungkinannya dengan Kp ≤ 2, kecuali ada badai (Dst ≤ -50 nT); di belahan bumi selatan mungkin dengan peringatan aurora dari BoM; mungkin dengan Dst ≤ -100 nT dan bisa jadi dengan Dst ≤ -50 nT, jika oval di titik itu tidak nol; mungkin dengan oval mulai 10%; bisa jadi dengan oval mulai 3% atau dengan Kp ≥ 5; selain itu kecil kemungkinannya.
LI|Spot aurora di atas 2000 km ditandai meragukan: menurut Newton [48], aurora mencapai sekitar 1000 km utara-selatan dan 2000 km timur-barat. Spot aurora-E (AUE, AU-E, AURORAL E) digambar berwarna hijau pada jalur langsung: ini adalah sporadic-E asal aurora, tanpa Doppler.
LI|Hasil menampilkan waktu matahari di scatter point: sebagian besar pantulan aurora terjadi dalam 4 jam dari tengah malam setempat (Reeve [52]). Di belahan bumi selatan, aurora di 50 MHz mencapai sekitar 2000 km pada lintasan timur-barat (ANVDG [55]); aurora-E memberi sinyal lebih lemah dan stabil pada jalur langsung (SM2CEW-SM0FOB [54]).
LI|Selain scatter point paling mungkin, hasil menampilkan rentang QTF kedua stasiun di sepanjang seluruh jejak (deviasi ≤ 1,5°): aurora dapat datang dari titik mana pun dalam rentang, dan titik paling mungkin mengutamakan lintasan terpendek.
H2|8.1 BENCHMARK AURORA
P|Tab AURORA memiliki dua subtab: REAL-TIME, perhitungan yang dijelaskan di atas, dan BENCHMARK AURORA, bangku uji model pada 298 QSO aurora nyata yang telah dipublikasikan (log EI5FK 2003-2005 dan peta log PA0O).
LI|Menu Log memilih satu log atau semuanya sekaligus; ketinggian bawaan 110 km, dengan toleransi 3°, refraksi 4/3 dan IGRF-14.
LI|Untuk setiap QSO tabel mencantumkan scatter point terhitung, deviasi, QTF dan elevasi stasiun serta QTF stasiun lawan. Hijau: scatter point di dalam jendela Lange-Hesse kedua stasiun; kuning: terjelaskan tetapi di luar jendela ini; oranye: QSO lebih dari 2000 km; merah: tidak ada scatter point, QSO tidak terjelaskan oleh model.
LI|Kotak Ketinggian km mengubah ketinggian perhitungan (dari 80 hingga 160 km) dan menghitung ulang semua QSO. Kolom tabelnya adalah Hari, UTC, Callsign, WWL, km, Scatter, dev°, QTF dan el° stasiun log, QTF lawan (QTF stasiun lawan) dan Hasil. Panel Detail QSO yang dipilih menampilkan jarak, arah antena, jendela Lange-Hesse setiap stasiun dan selisih dari jalur langsung.
LI|Ringkasan memberikan persentase, juga dengan jendela tetap 370-1100 km sebagai pembanding, dan, untuk setiap log, rentang dan median QTF terhitung; klik pada sebuah baris menggambar lintasan dan kedua arah antena serta menampilkan jendela setiap stasiun. Log tidak mencantumkan arah antena: perbandingannya pada geometri, bukan pada QTF.
H1|9. LOG ADIF

H1|12. Masalah yang sering terjadi
LI|NTP:FAILED: tidak ada server waktu yang menjawab. Biasanya firewall memblokir port UDP 123; program tetap berjalan dengan jam PC dan mencoba lagi setiap 5 menit.
LI|Sesi telnet tidak tersambung atau langsung tertutup: periksa host, port dan login (banyak cluster meminta callsign), dan pastikan tidak ada sesi lain yang sudah terbuka dengan callsign yang sama, misalnya dari program lain.
LI|Tidak ada spot di SPORADIC-E: periksa band dan rentang waktu yang dipilih, pastikan filter lokal tidak membuang band tersebut (filter meloloskan 27990 kHz hingga 145 MHz) dan, di 144 MHz, bahwa spot memiliki konfirmasi (bab 3.4). Uji filter menunjukkan bagaimana sebuah baris cluster diklasifikasikan.
LI|Peta kosong saat pertama dijalankan: garis pantai dan batas negara diunduh dari GitHub pada kali pertama; diperlukan jaringan, setelah itu tersimpan di data/mappa.
LI|LoTW menolak akses: periksa nama pengguna dan kata sandi di situs LoTW; dengan log besar pengunduhan dapat memakan waktu beberapa menit.
LI|Pembaruan otomatis tidak berjalan atau gagal: periksa jaringan dan pastikan folder program dapat ditulisi. Bagaimanapun, versi baru dapat dipasang secara manual dari halaman Release di atas versi lama, tanpa kehilangan folder data.
