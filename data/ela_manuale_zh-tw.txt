TITLE|E-LAYER ANALYZER 使用手冊
SUB|詳細使用手冊 - 作者 Costantino IC8TEM - 版本 0.5.0，2026 年 11 月。方括號中的編號對應 資料來源 頁籤；公式與計算選擇見 計算選擇摘要 頁籤。
H1|1. 開始之前
H2|1.1 本程式的功能
P|E-LAYER ANALYZER 將研究經由電離層 E 層的 VHF 傳播模式所需的工具整合在一個程式中：散塊 E 層（包括多跳與跨洲）、F.A.I.（沿磁場排列的不規則體）、流星散射（內建 YA-MS 程式）以及無線電極光。它以 DX cluster 的即時 spot 與 ADIF 日誌為資料，並將每個結果顯示在占視窗三分之二的地圖上，資料與計算則顯示在右側三分之一。
H2|1.2 安裝與資料資料夾
P|本程式可在 Windows（64 位元、32 位元與 ARM64）、Linux（x86_64、ARM64、armv7l 與 Alpine）、Raspberry Pi（64 與 32 位元的 Raspberry Pi OS、Slackware ARM64）與 Mac（Apple Silicon 與 Intel）上執行；FreeBSD amd64 有一個實驗性套件。請從 GitHub 儲存庫的 Releases 頁面下載：Windows 有安裝程式及 .zip 檔的免安裝版；Linux 有 .deb、.rpm、Arch 與 Slackware 套件、AppImage，以及附安裝腳本的 .tar.gz 壓縮檔；Mac 為 .dmg 映像檔。沒有適用於 Linux i686（32 位元 PC）與 OpenBSD 的版本，因為這些系統沒有 .NET。
LI|Windows：安裝程式會將程式安裝在 C:\E-LAYER-ANALYZER，data 資料夾就在旁邊；可攜版可解壓縮到任一資料夾，以 E-LAYER-ANALYZER.exe 啟動。使用 ARM 處理器（Snapdragon）的電腦有 -win-arm64- 檔案。
LI|Linux 與 Raspberry Pi：使用 .deb 套件（sudo apt install ./e-layer-analyzer_..._amd64.deb，或 64 位元 Raspberry Pi OS 用的 _arm64.deb 與 32 位元用的 _armhf.deb）時，程式從選單啟動，首次啟動時會複製到 ~/E-LAYER-ANALYZER；使用 .tar.gz 壓縮檔（linux-x64、linux-arm64、linux-arm 或 linux-armv7l）時，解壓縮後執行 ./E-LAYER-ANALYZER，或以 ./installa.sh 將其安裝到 ~/E-LAYER-ANALYZER 並在選單中加入圖示。
LI|Slackware（x86_64 與 ARM64）：以 root 身分用 installpkg e-layer-analyzer-...-x86_64-1_ic8tem.txz（或 -aarch64-）安裝套件；程式從選單或終端機以 e-layer-analyzer 啟動，首次啟動時會複製到 ~/E-LAYER-ANALYZER，與 .deb 相同。
LI|Fedora 與 openSUSE：sudo dnf install ./e-layer-analyzer-....x86_64.rpm（或 zypper install；另有 .aarch64.rpm 與 .armv7hl.rpm）。Arch、Manjaro、EndeavourOS 與 Arch Linux ARM：sudo pacman -U e-layer-analyzer-...-x86_64.pkg.tar.zst（或 -aarch64）。使用這些套件時，程式同樣會在首次啟動時複製到 ~/E-LAYER-ANALYZER。
LI|AppImage（x86_64 與 aarch64）：一個檔案適用於幾乎所有 Linux 發行版；設為可執行後啟動。首次啟動時會將程式複製到 ~/E-LAYER-ANALYZER，並從那裡啟動。
LI|Alpine Linux 與其他使用 musl 的 Linux：-alpine-x64- 或 -alpine-arm64-portatile.tar.gz 壓縮檔；需要 icu-libs 與 fontconfig 套件（apk add icu-libs fontconfig）。
LI|FreeBSD amd64：實驗性、未經驗證的套件（-freebsd-amd64-sperimentale.tar.gz）。需要社群版 .NET 8（pkg install dotnet），以及為 FreeBSD 編譯的 SkiaSharp 與 HarfBuzzSharp 函式庫，而 Avalonia 不提供這些函式庫：沒有它們程式無法啟動。說明在 LEGGIMI-FREEBSD.txt 檔案中。
LI|Mac：開啟 .dmg 檔案（arm64 用於 Apple Silicon M1-M4，x64 用於 Intel），在 «Installa E-LAYER-ANALYZER.command» 上按右鍵並選擇 開啟；另外，-app.zip 檔案只包含應用程式本身。
LI|程式的所有資料都放在程式旁的 data 資料夾中：設定（config.ini）、CALL3 資料庫、磁場係數、日誌、下載的 NOAA 資料、收集到的 spot。不會在 AppData 或其他系統資料夾中寫入任何東西。
LI|要把程式搬到另一台電腦，只要複製它的資料夾；要恢復初始設定，只要刪除 data/config.ini。
LI|程式在 data 資料夾中還存放：lingue（翻譯）、spot（收集到的 spot）、spot_ms（YA-MS 的流星散射 spot）、swpc（NOAA 的資料）、mappa（Natural Earth 的海岸線與國界，首次啟動時從 GitHub 下載：第一次需要網路）以及 aggiornamento（自動更新的套件，可以刪除）。
LI|LoTW 密碼永遠不會儲存；只能記住使用者名稱。
LI|更新：從 0.4.5 版起，程式會在啟動時以及之後每 30 分鐘（0.4.17 版以前為每 6 小時）自動檢查 GitHub 上是否有新版本。若有，會以一個視窗及上方工具列中的橘色 ▲ 字樣提示：「立即更新」會下載適用於這部電腦的套件（Windows 64 或 32 位元、Linux、Raspberry Pi、Mac），關閉程式，替換檔案並重新啟動；「稍後」表示延後，「略過此版本」則不再提示該版本。設定、已收集的 spot 與 call3.txt 都會保留。可以用同一視窗中的核取方塊關閉此檢查。
LI|從 0.4.12 版起，更新為自動且靜默：GitHub 上有新版本時，程式會下載、安裝並自動重新啟動，不詢問任何問題。缺少的檔案也會在不詢問的情況下重新下載。只有點擊頂部的版本號，或在 設定（一般）中關閉自動更新時，才會出現更新視窗。
LI|自動更新適用於 Windows 的安裝程式與 zip、Mac 的 app、.tar.gz 壓縮檔與 AppImage。使用系統套件（.deb、.rpm、Arch 與 Slackware）時，程式不會自行更新：它會提示新版本，須從 Release 頁面下載新套件，並像第一次一樣安裝。
LI|磁場模型也會自動更新：啟動時及每 30 天，程式會在不詢問的情況下到 NOAA 網站尋找新一代 IGRF，若有，就下載到 data 資料夾並立即使用。
LI|缺少的檔案：啟動時，程式會檢查隨程式發布的所有檔案（翻譯、文件、表格）是否齊全。若有缺少，會以視窗列出這些檔案，「從 GitHub 下載」按鈕會從 GitHub 上發布的同一版本重新取得它們。
LI|更新期間，視窗會顯示下載與解壓縮的進度。若程式資料夾無法寫入，例如位於系統資料夾內，程式會提示並提供 release 頁面，可從那裡下載安裝套件；若某個步驟失敗，會顯示原因，按鈕會變成 Release 頁面。
H2|1.3 上方工具列
P|在左上方輸入自己的呼號、網格座標（4、6 或 8 碼）與天線高度（公尺）；按 套用 按鈕確認後，所有頁籤都會更新。右上方是 UTC 時間、配色選擇（YAEC 的所有方案：淺色、夜間、黑色、八種粉彩與流星餘跡；自 0.5.0 版起另有 IP-TRX-CTRL 的六種主題：IP-TRX-CTRL 的 淺色、夜間 與 黑色，以及 藍色、紫色 與 綠色，後三種 YAEC 中也有）與語言選擇（36 種語言）。變更配色或語言時，視窗會立即重建，不會遺失已收集的資料。
P|UTC 時間旁的 NTP:OK（綠色）或 NTP:FAILED（紅色）表示時間是否已對齊：程式每 5 分鐘向分布全球的十個時間伺服器中的兩個查詢，若沒有回應就改用其他伺服器。提示框會列出所用的伺服器與電腦時鐘的偏差。
P|程式一律使用正確的時間：量測到的偏差會套用到程式本身的時鐘。若偏差超過一秒，在 Windows 上且具有系統管理員權限時，程式也會校正電腦時鐘，並在提示框中說明（電腦時鐘已校正）；在 Linux 與 Mac 上不會更動系統時鐘。
P|NTP 字樣旁顯示目前使用的版本（例如 v0.4.5，灰色）：按一下即可立即檢查 GitHub 上是否有更新的版本。有新版本發布時，該字樣會變成橘色，例如 ▲ 0.4.6，按一下即可開啟更新視窗。
P|頁籤列右側有洲別選單（歐洲、北美洲、南美洲、非洲、亞洲、大洋洲）：它會將麥卡托地圖以及 F.A.I. 與極光的地圖移到所選的洲，並選擇該洲的預報資料（N0NBH 的 E-skip 只發布歐洲與北美洲）。
P|呼號、網格座標、高度、語言、配色、洲與更新也可在 設定 頁籤（第 10 章）中設定，那裡還可以設定整個程式的字型大小。
H2|1.4 狀態列
P|下方的狀態列顯示 CALL3 資料庫中的呼號數、記憶體中的 spot 數，以及使用中的磁場模型（IGRF-14 及其曆元）。記憶體中的 spot 在每次關閉程式時清除：每次連線階段都從沒有舊 spot 的狀態開始。
H2|1.5 地圖
P|所有地圖的操作方式都相同：滑鼠滾輪放大或縮小，按住左鍵拖曳可平移檢視，按左鍵則依頁籤選擇一個點、一筆 spot 或一條路徑。右上方顯示游標所在位置的座標與 6 碼網格座標；方位等距地圖還會顯示與中心的距離及方位角。梅登黑德的大區與網格線會隨縮放而加密。
LI|每張地圖的左下角都有其所用顏色與符號的圖例。首次繪製時，可能會有幾秒鐘顯示 正在載入地圖（Natural Earth）...。
H1|2. 資料收集（DATA COLLECTION）
P|此頁籤有兩個子頁籤：spot，包含 telnet 連線階段、PSKReporter MQTT、WSJT-X UDP、已收集的 spot 與 CALL3 資料庫；以及 傳播資料（第 2.5 章）。spot 篩選器位於 設定 頁籤（第 10 章）。
H2|2.1 三個 telnet 連線階段
P|DATA COLLECTION 頁籤最多可同時開啟三個 telnet 連線：一個自選的 DX cluster（預設為含 VHF 篩選的 ON0DXK）、Reverse Beacon Network（FT8 用連接埠 7001，CW 與 RTTY 用 7000），以及含 PSKReporter spot 的 DM4X Cluster（dm4x.ddns.net，連接埠 8500）。
LI|主機 與 連接埠：Cluster 的位址。登入：登入用的呼號（若空白則使用上方工具列中的呼號）。登入後的指令：登入後要送出的指令，以分號分隔（例如頻段篩選）。
LI|連線 與 中斷連線 開啟與關閉連線階段；重新連線 在斷線後自動重新開啟；啟動時連線 在程式啟動時開啟連線階段。
LI|主控台顯示收到的資料行；在下方的方框中可輸入要送給 Cluster 的指令（例如 sh/dx 20），並以 送出 或 Enter 鍵確認。
H2|2.2 篩選器在哪裡
P|在 DATA COLLECTION 收到的每一筆 spot 都會先經過篩選器，再送到各傳播模式的頁籤：整個程式共用同一套資料收集。自 0.4.18 版起，篩選器與本機篩選位於 設定 頁籤的 spot 分派 子頁籤（第 10.2 章）。
H2|2.3 程式如何讀取 spot
P|程式從每一行 "DX de" 取得 spotter、頻率、DX、備註、時間，以及（若有的話）備註中以 JN70CN<ES>JO62QM 格式寫出的網格座標與傳播模式（第一個網格座標屬於 spotter，第二個屬於 DX；也接受使用 <>、> 與括號的寫法）。
LI|缺少的網格座標從 CALL3 資料庫查找；不精確的網格座標（少於 6 碼）若 CALL3 中有 6 碼的網格座標，就以其取代。
LI|文字中含有 <MS>、<AU>、<AUR>、<TR>、<AS> 或 <ACS> 的 spot 不會用於散塊 E 層：它們屬於流星散射、極光、對流層或飛機散射。
LI|與 YA-MS 相同，落在 MS 典型頻率窗內（50190-50300、70100-70400、144290-144399 kHz）且沒有其他傳播方式標記的 spot，以及使用 MSK144、FSK441、FSK41、PSK2K、JTMS、JT6M 模式或帶有 <MS> 的 spot，都屬於流星散射。50 與 70 MHz 的 FT8 與 FT4 例外：模式已知時由模式決定，因此 70.154 MHz 的 FT8 即使落在流星散射頻率窗內也歸散塊 E 層。
LI|帶有 <AU> 或 <AUR> 的 spot 送到 AURORA 頁籤，帶有 FAI 的送到 F.A.I. 頁籤。
H2|2.4 已收集的 spot 與 CALL3 資料庫
P|已收集的 spot 頁面列出最近的 spot，可依頻段與來源篩選；開啟 spot 資料夾 按鈕會開啟 data/spot。CALL3 頁面顯示呼號 -> 網格座標資料庫（JTDX/WSJT 格式）：可以搜尋呼號、重新載入資料庫，或匯入新的 CALL3.TXT 檔案取代使用中的檔案（舊檔會保留為備份）。
LI|已收集 spot 的欄位為：UTC、來源（cluster、RBN 或 PSKReporter）、MHz、頻段、DX 及其網格座標、Spotter 及其網格座標、km、Prop（宣告的或辨識出的傳播模式）與 備註。所有來源 選單可將表格限定為單一連線階段。
LI|CALL3 頁面顯示使用中的檔案、其日期、檔頭以及已載入的呼號數量（使用隨程式發布的資料庫時超過一百萬個）。
LI|從 0.4.16 版起，整個程式只有一個 CALL3 資料庫，即 YA-MS 資料收集（METEOR SCATTER 分頁）中的資料庫，規則與 LIVETROPOVHF 相同：每 12 小時從 MMMonVHF 更新、手動條目、加入的檔案、叢集修正、學到的定位碼、每 30 分鐘一次的 G7VRD，以及作為最後來源的 JTDX 層（data/grid_data.bin，約 365,000 個呼號：只用於其他來源中沒有 6 碼定位碼的呼號，只在與收到的定位碼相同的網格內使用，並且從不寫入 data/call3.txt）；修正寫入 data/call3.txt，data/call3_nuovi.txt 中的定位碼匯入一次。WSJT-X、JTDX 和 MSHV 的報告也可透過 UDP 接收（來源 WSJT-X UDP，連接埠 2237，轉送到 2238）。
LI|這些來自 YA-MS 的過濾條件（CW、最小距離、頻率視窗、MS 模式、波段）只適用於 METEOR SCATTER 分頁：它們決定哪些報告進入該分頁的收集。其他分頁接收全部報告並使用各自的過濾條件。
H2|2.5 傳播資料
P|傳播資料 子頁籤收集有助於判斷某個頻段是否可能開通的資料。這些資料最多每小時自動更新一次；立即更新 按鈕會馬上下載。
LI|N0NBH（hamqsl.com）：VHF 狀況橫幅與太陽資料（太陽通量、A 與 K 指數、X 射線、太陽風、Bz、極光與極光緯度），以及歐洲與北美洲的 E-skip（DXrobot 資料）。
LI|N0NBH 的 VHF 狀況依 hamqsl.com 發布的原樣顯示：Band Closed（頻段關閉）、50MHz ES、70MHz ES 與 144MHz ES（該頻段出現散塊 E 層）、High MUF；極光方面為 High LAT AUR 與 Mid LAT AUR（高緯度或中緯度極光）。
LI|極光用的 Bz：NOAA SWPC，由位於 L1 點的衛星（DSCOVR/ACE）每分鐘量測的即時太陽風。持續的負值 Bz 有利於極光。
LI|極光：京都的 Dst 指數（地磁暴），以及南半球用的澳洲 Bureau of Meteorology 極光警報，後者需要一組免費金鑰，填入 BoM API 金鑰 欄位。AE 指數（京都） 與 SuperDARN 對流 按鈕會在瀏覽器中開啟這兩個網頁。
LI|Dst 的等級解讀如下：高於 -30 nT 為平靜，-30 至 -50 nT 為微弱擾動，-50 至 -100 nT 為中度磁暴，-100 nT 以下為強烈磁暴。有 BoM 金鑰時，也會顯示澳洲 K 指數與目前發布中的極光監測警報。
LI|流星散射：Make More Miles on VHF 的當日流星活動圖（RMOB 資料）；流星雨、效率與即時通訊在 METEOR SCATTER 頁籤中。
P|這些資料的摘要顯示在 SPORADIC-E 與 F.A.I. 地圖的右上方（所選洲的 E-skip），以及 AURORA 地圖的右上方（N0NBH 的極光與 NOAA 的 Bz）。
H1|3. 散塊 E 層（SPORADIC-E）
P|SPORADIC-E 頁籤有三個子頁籤：REAL-TIME，即本章所述的即時 spot；BENCHMARK Es（第 4 章）與 BENCHMARK 50 MHz（第 5 章）。
H2|3.1 地圖
P|地圖 選單用來選擇投影。方位等距：以自己電台為中心的方位等距地圖，附縮放滑桿（距中心 300 至 20000 km，也可用滑鼠滾輪）。麥卡托：世界地圖，附 歐洲 與 全球 按鈕。兩種投影都會在電台周圍繪出 IK3XTV 表 [3] 的距離圓：500 km（單跳最短距離）、1500-2000 km（最佳）、2400 km（單跳最長距離）、5000 km（雙跳最長距離）與 6900 km（三跳最長距離）。
P|50 MHz 的跳距表出自 Flavio Egano IK3XTV 的《Propagazione sui 6 metri - Caratteristiche generali》[3]；Es 雲位於約 100 km 高度，這將單跳限制在 2000 km 左右 [29]。地圖上的環帶與跳數依循以下距離：
TAB|跳數;最短距離;最佳距離;最長距離
TAB|單跳;500-650 km;1500-2000 km;2200-2400 km
TAB|雙跳;2800-3000 km;3200-4000 km;4400-5000 km
TAB|三跳;-;4800-6400 km;6900 km
P|在方位等距檢視中，虛線環標示距中心的公里數；環的間距隨縮放改變，外緣表示所顯示的最大距離。
H2|3.2 控制項
LI|頻段：10、8、6、4 與 2 m（不分析 432 MHz：散塊 E 層不適用 [22]-[24]）；8 m（40 MHz）預設為關閉。spot 的時間範圍從 15 分鐘到 12 小時。
LI|Es 高度（預設 110 km）與天線最小仰角（預設 1°）；仰角計入對流層折射（4/3 地球半徑），因此單跳可達約 2440 km。

H2|3.4 作者規則
LI|144 MHz：散塊 E 層從 900 km 以上開始；單獨一筆 spot 不繪出；若 5 分鐘內有同一片雲上的第二筆 spot，或附近有一筆 50 MHz 短跳 spot，才會繪出。上方的綠色列顯示有多少筆 spot 正在等待確認。
LI|跨赤道：朝向非洲大陸（含馬達加斯加）與南美洲時，若中點落在磁傾角 -15° 到 +15° 的帶狀區域內，該通聯即為跨赤道而非散塊 E 層，除非 spot 宣告為 <ES>。加那利群島、馬德拉、維德角與阿拉伯半島不適用此規則。15° 的數值取自 Cracknell [66]，他將 TEP 區域置於距零傾角線約 5-15° 處（作者的選擇）。
LI|50 MHz：450 km 以內不是散塊 E 層。FT8 與 FT4 spot 只有屬於一片雲時才是散塊 E 層，也就是 4 分鐘內有另一筆中點在 150 km 以內的 50 MHz spot；孤立的 FT8 或 FT4 spot 歸流星散射（作者規則）。
LI|70 MHz：450 km 以內不是散塊 E 層（作者規則；G0ISW [65] 觀測到的最短散塊 E 層在 50 與 70 MHz 超過 400 km）。FT8 與 FT4 即使落在頻段計畫的流星散射頻率窗內也歸散塊 E 層。
LI|40 MHz（8 m）：最短距離以正割定律由 50 MHz 的 450 km 求得（約 330 km），且只接受 E 層幾何第一跳以內的距離（約 2440 km）。
LI|144 MHz：Q65 與 JT65 spot 屬於 EME，不會進入散塊 E 層，除非文字中有 <ES>。G0ISW [65] 只在 1400 km 以上觀測到 144 MHz 的散塊 E 層：作者規則從 900 km 起，但要求確認。

H1|8. AURORA

LI|若勾選 在地圖上顯示 <AU>/<AUR> spot 及其計算，則在 設定 的篩選器中所選時間範圍內（預設最近 2 小時，最多 30 筆）的極光 spot 會連同計算出的散射點（橘色圓）繪於地圖上；結果中會顯示兩個電台的 QTF 與仰角。
LI|Scatter trail 檢視的結果會顯示散射點的極光機率（Kp ≤ 2 時為不太可能；其他情況依 NOAA 橢圓區）、介於 N 與 NE 之間的典型 QTF（南半球為 S-SE）及其與直接路徑的偏差，以及關於都卜勒頻移與模式的建議（CW/SSB 或使用寬子模式的 Q65：FT8 常常無法解碼）。散射點優先在各電台的 Lange-Hesse 範圍內、垂直條件 ±3° 以內尋找：地磁緯度 54° 處為 370-1100 km，依 IGRF-14 磁傾角，越南的電台範圍越近，越北的越遠（例如卡布里島約 260-990 km，奧斯陸 470-1200 km）。結果會列出各電台的範圍；若所提出的點在範圍外，程式會提示。
LI|散射點的極光機率依下列順序判定：Kp ≤ 2 時為不太可能，除非有磁暴（Dst ≤ -50 nT）；在南半球，有 BoM 極光警報時為很可能；若該點的橢圓區不為零，Dst ≤ -100 nT 時為很可能，Dst ≤ -50 nT 時為可能；橢圓區達 10% 時為很可能；橢圓區達 3% 或 Kp ≥ 5 時為可能；其他情況為不太可能。
LI|超過 2000 km 的極光 spot 會標示為存疑：依 Newton [48]，極光的距離南北向約 1000 km、東西向約 2000 km。極光 E 的 spot（AUE、AU-E、AURORAL E）以綠色繪於直接路徑上：這是極光成因的散塊 E 層，沒有都卜勒頻移。
LI|結果會列出散射點的太陽時：大部分極光反射出現在當地午夜前後 4 小時內（Reeve [52]）。在南半球，50 MHz 的極光在東西向路徑上可達約 2000 km（ANVDG [55]）；極光 E 在直接路徑上的訊號較弱且穩定（SM2CEW-SM0FOB [54]）。
LI|除了最可能的散射點外，結果還會列出兩個電台沿整條軌跡的 QTF 範圍（偏差 ≤ 1.5°）：極光可能來自範圍內的任一點，而最可能的點偏好最短路徑。
H2|8.1 BENCHMARK AURORA
P|AURORA 頁籤有兩個子頁籤：REAL-TIME，即上述的計算；以及 BENCHMARK AURORA，以 298 筆已發表的實際極光通聯（EI5FK 2003-2005 年的日誌與 PA0O 的日誌地圖）測試模型的平台。
LI|日誌 選單可選擇單一日誌或全部；預設高度為 110 km，容許 3°，折射 4/3，每筆通聯年份的 IGRF-14（1900-2030 年歷史曆元；日期未知時使用目前的磁場）。
LI|表格列出每筆通聯計算出的散射點、偏差、本台的 QTF 與仰角，以及對方電台的 QTF。綠色：散射點位於兩個電台的 Lange-Hesse 範圍內；黃色：可解釋但在此範圍外；橘色：超過 2000 km 的通聯；紅色：沒有散射點，模型無法解釋的通聯。
LI|高度 km 欄位可變更計算高度（80 至 160 km），並重新計算所有通聯。表格欄位為 日期、UTC、呼號、WWL、km、Scatter、dev°、日誌電台的 QTF 與 el°、對方 QTF（對方電台的 QTF）與 結果。所選通聯的詳細資訊 框列出距離、指向、每個電台的 Lange-Hesse 範圍，以及與直接路徑的偏差。
LI|摘要列出百分比（也列出以固定範圍 370-1100 km 計算的百分比，以供比較），以及每份日誌計算出的 QTF 範圍與中位數；點選某一列會繪出路徑與兩個指向，並列出各電台的範圍。日誌沒有記錄指向：比較的是幾何，而非 QTF。
H1|9. LOG ADIF
P|LOG ADIF 頁籤從 28 MHz 起逐頻段顯示已通聯與已確認的網格，不合併頻段。開啟 ADIF 檔案… 加入日誌檔案；從 LoTW 下載… 下載確認報告（可記住使用者名稱，密碼永遠不會儲存）；清除記憶 移除檔案與報告。已通聯的網格為橘色，以 QSL 或經由 LoTW 確認的則以不同顏色顯示；點選網格會顯示呼號與傳播模式。
LI|地圖上方是各頻段的頁籤：28、50、70、144 與 432 MHz 一律顯示，另加日誌中出現的其他頻段，每個頁籤都標示已通聯與已確認的網格數。傳播 選單可將網格限定為單一模式：ES、FAI、極光（AUR/AUE）、MS、TR、EME、F2，或沒有 PROP_MODE 的通聯。
LI|顏色：橘色 = 已通聯未確認，藍色 = 已以 QSL 確認，綠色 = 已透過 LoTW 確認。該頻段的網格 表格列出 網格、通聯、狀態、呼號 與 Prop；點選地圖或表格中的網格，會在 所選網格 框中顯示其詳細資訊。
LI|從 LoTW 下載... 會詢問使用者名稱、密碼，必要時也可只指定一個呼號；它會下載上傳到 LoTW 的所有通聯及其確認詳細資訊。若 LoTW 拒絕存取，程式會提示；記住使用者名稱 核取方塊只保存使用者名稱，永遠不保存密碼。
H1|10. 設定
P|設定 頁籤集中了程式的一般選項，以及 spot 在各頁籤之間的分派。它有兩個子頁籤：一般 與 spot 分派。
H2|10.1 一般
LI|電台：呼號、網格座標與高度，與上方那一列相同；套用 會將其確認到所有頁籤。
LI|外觀：語言、配色以及整個程式的字型大小，從 85 到 140 %，與 YA-MS 相同。變更語言與配色會重建視窗，不會遺失設定與 spot。
LI|地圖與預報資料：洲，與頁籤列中的選單相同。
LI|時間：NTP 檢查的狀態，以及伺服器時間與電腦時間的差。
LI|更新：啟動時及每 30 分鐘在 GitHub 上檢查、自動靜默更新（不適用於系統套件 .deb、.rpm、Arch 與 Slackware），以及 立即檢查 按鈕。
LI|資料：開啟 data 資料夾的按鈕。Bureau of Meteorology 的 API 金鑰仍在 DATA COLLECTION 的 傳播資料 中。
H2|10.2 spot 分派
P|左側的表格依套用順序列出程式決定每一筆 spot 去向的規則：第一條符合的規則決定頁籤。顯示的數值是在篩選器中設定的數值。右側是本機篩選與各模式的篩選器，分為五個子頁籤。
P|最上方是本機篩選的勾選框，預設為勾選：頻率低於 27990.0 kHz 或高於 145 MHz 的 "DX de" 行會被捨棄，不會出現在主控台，也不會儲存；在 430 至 440 MHz 之間只放行極光 spot。這主要在使用 RBN 與 PSKReporter 時有用，因為它們會送出大量 HF spot。取消勾選則全部通過。下方有五個子頁籤。
LI|流星散射：YA-MS 的篩選器（MS 典型頻率窗、其他傳播方式標記、MS 數位模式與 <MS>、頻段、篩選測試與計數器）。在 E-LAYER ANALYZER 內，YA-MS 的篩選器在 METEOR SCATTER 頁籤中設定，且只對該頁籤有效。
LI|散塊 E 層：將 spot 排除於散塊 E 層之外的 < > 標記；28、40、50 與 70 MHz 規則（50 與 70 MHz 在 450 km 以內不是散塊 E 層；40 MHz 從約 330 km 到第一跳，約 2440 km；50 MHz 的 FT8 與 FT4 只有屬於一片雲時才算；28 MHz 的最短距離依 IK3XTV 由 50 MHz 的值推得，約 170 km；頻段計畫並非排他性準則，因此落在流星散射頻率窗內的 spot 仍歸散塊 E 層，除非帶有 MS 數位模式或 <MS>）；144 MHz 規則（最短距離；以數分鐘內同一片雲上的第二筆 spot 確認，或以附近一筆 50 MHz 短跳 spot 確認），以及帶有磁傾角帶的跨赤道規則，適用於非洲與南美洲（作者規則），並在全球適用於大致沿南北方向穿越磁赤道、長 3000-8000 km 的通聯（Kennewell 與 Wilkinson [49]）。恢復作者規則 按鈕會恢復預設值。
LI|散塊 E 層規則的預設值，皆可修改：50 與 70 MHz 最小距離 450 km；50 MHz 的 FT8 與 FT4 須 4 分鐘內有另一筆 spot 且中點在 150 km 以內；144 MHz 規則開啟，最小距離 900 km，須在 5 分鐘內由 300 km 以內同一雲上的第二個 spot 確認，或由最近 15 分鐘內短跳不超過 1200 km 的 50 MHz spot 確認；跨赤道規則開啟，磁傾角帶為 ±15°。
LI|F.A.I.：表示 F.A.I. spot 的字詞（預設為 FAI：<FAI> 或 fai 皆可，大寫、小寫或混合；這些 spot 不會進入散塊 E 層）、頻段（6、4 與 2 m：F.A.I. 到不了 432 MHz），以及地圖上 spot 的時間範圍（預設 24 小時）。
LI|極光：極光 spot 的字詞，加不加 < > 皆可，大小寫皆可（預設為 AU 與 AUR）、頻段，以及地圖上 spot 的時間範圍（預設 2 小時）。
LI|篩選器測試：輸入或貼上一行 Cluster 內容，程式會顯示篩選器如何分類它（流星散射、極光、F.A.I.、跨赤道、散塊 E 層），並列出頻段、網格座標與距離。
H1|11. 文件
P|資料來源 頁籤依頁籤列出程式引用的資料來源。計算選擇摘要 頁籤列出公式與計算選擇，並附上每一步的資料來源；本 使用手冊 說明如何使用程式；技術報告 說明引導本程式開發的理由。三份文件都可以匯出為 Word。
LI|每份文件的上方都有 匯出為 Word (.docx)... 按鈕（將副本儲存到任意位置）與 以 Word 開啟 按鈕（以 .docx 檔案的預設程式開啟）。文件使用上方所選的語言。
H1|12. 實用建議
LI|首先在上方輸入呼號與網格座標並按 套用：所有距離、MUF 與仰角都由此計算。
LI|使用 RBN 與 PSKReporter 時請保持本機篩選開啟，以免記憶體塞滿 HF spot。
LI|要分析過去的某一季，請用自己的日誌執行兩個 BENCHMARK；在極光與 F.A.I. 方面，務必以等反射線檢視驗證所提出的點。
LI|這些計算僅供參考：一筆 spot 或通聯只說明路徑當時是開通的，並不能精確指出雲的位置。
H1|13. 常見問題
LI|NTP:FAILED：沒有任何時間伺服器回應。通常是防火牆封鎖了 UDP 123 連接埠；程式會繼續使用電腦時鐘，並每 5 分鐘重試一次。
LI|telnet 連線階段無法連線或立即關閉：檢查主機、連接埠與登入資訊（許多 cluster 要求輸入呼號），並確認沒有以同一呼號開啟的另一個連線階段，例如來自另一個程式。
LI|SPORADIC-E 中沒有 spot：檢查所選的頻段與時間範圍，確認本機篩選沒有丟棄該頻段（它放行 27990 kHz 至 145 MHz，在 430 至 440 MHz 之間只放行極光），在 144 MHz 還要確認 spot 已獲得確認（第 3.4 章）。篩選器測試（設定，spot 分派）可顯示 cluster 的一行是如何分類的。
LI|首次啟動時地圖空白：海岸線與國界在第一次時從 GitHub 下載；需要網路，之後會保存在 data/mappa 中。
LI|LoTW 拒絕存取：在 LoTW 網站上檢查使用者名稱與密碼；日誌較大時，下載可能需要幾分鐘。
LI|自動更新無法啟動或失敗：檢查網路，並確認程式資料夾可寫入；使用 .deb、.rpm、Arch 與 Slackware 套件時，自動更新是刻意不啟動的。無論如何，都可以從 release 頁面手動將新版本安裝在舊版本之上，不會遺失 data 資料夾。
