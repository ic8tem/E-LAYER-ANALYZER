TITLE|Brukerhåndbok for E-LAYER ANALYZER
SUB|Utførlig brukerhåndbok - ved Costantino IC8TEM - versjon 0.4.18, november 2026. Tallene i hakeparentes viser til fanen KILDER; formlene og beregningsvalgene finnes i fanen SAMMENDRAG AV BEREGNINGSVALGENE.
H1|1. Før du begynner
H2|1.1 Hva programmet gjør
P|E-LAYER ANALYZER samler i ett program verktøyene for å studere de VHF-utbredelsesmåtene som går via ionosfærens E-lag: sporadisk E, også multihopp og interkontinental, F.A.I. (feltlinjeorienterte irregulariteter), meteor scatter, med det integrerte programmet YA-MS, og radionordlys. Programmet arbeider med spot fra DX-klynger i sanntid og med ADIF-logger, og viser hvert resultat på et kart som opptar to tredjedeler av vinduet, med data og beregninger i den høyre tredjedelen.
H2|1.2 Installasjon og datamappe
P|Programmet fungerer på Windows (64 bit, 32 bit og ARM64), Linux (x86_64, ARM64, armv7l og Alpine), Raspberry Pi (64- og 32-bits Raspberry Pi OS, Slackware ARM64) og Mac (Apple Silicon og Intel); for FreeBSD amd64 finnes en eksperimentell pakke. Det lastes ned fra siden Releases i GitHub-depotet: for Windows finnes et installasjonsprogram og en bærbar versjon i en .zip-fil; for Linux pakkene .deb, .rpm, Arch og Slackware, AppImage og .tar.gz-arkivene med installasjonsskript; for Mac et .dmg-bilde. Det finnes ingen versjoner for Linux i686 (32-bits PC-er) og OpenBSD, fordi .NET ikke finnes for disse systemene.
LI|Windows: installasjonsprogrammet legger programmet i C:\E-LAYER-ANALYZER med mappen data ved siden av; den bærbare versjonen pakkes ut i en hvilken som helst mappe og startes med E-LAYER-ANALYZER.exe. For PC-er med ARM-prosessor (Snapdragon) finnes filene -win-arm64-.
LI|Linux og Raspberry Pi: med .deb-pakken (sudo apt install ./e-layer-analyzer_..._amd64.deb, eller _arm64.deb for 64-bits Raspberry Pi OS og _armhf.deb for 32-bits) startes programmet fra menyen og kopierer seg ved første oppstart til ~/E-LAYER-ANALYZER; med .tar.gz-arkivet (linux-x64, linux-arm64, linux-arm eller linux-armv7l) pakker du det ut og starter ./E-LAYER-ANALYZER, eller så installerer ./installa.sh det i ~/E-LAYER-ANALYZER med ikon i menyen.
LI|Slackware (x86_64 og ARM64): som root installeres pakken med installpkg e-layer-analyzer-...-x86_64-1_ic8tem.txz (eller -aarch64-); programmet startes med e-layer-analyzer fra menyen eller terminalen og kopierer seg ved første oppstart til ~/E-LAYER-ANALYZER, som med .deb-pakken.
LI|Fedora og openSUSE: sudo dnf install ./e-layer-analyzer-....x86_64.rpm (eller zypper install; det finnes også .aarch64.rpm og .armv7hl.rpm). Arch, Manjaro, EndeavourOS og Arch Linux ARM: sudo pacman -U e-layer-analyzer-...-x86_64.pkg.tar.zst (eller -aarch64). Også med disse pakkene kopierer programmet seg ved første oppstart til ~/E-LAYER-ANALYZER.
LI|AppImage (x86_64 og aarch64): én fil for nesten alle Linux-distribusjoner; gjør den kjørbar og start den. Ved første oppstart kopierer den programmet til ~/E-LAYER-ANALYZER og starter det derfra.
LI|Alpine Linux og andre Linux med musl: arkivet -alpine-x64- eller -alpine-arm64-portatile.tar.gz; pakkene icu-libs og fontconfig trengs (apk add icu-libs fontconfig).
LI|FreeBSD amd64: eksperimentell og ikke verifisert pakke (-freebsd-amd64-sperimentale.tar.gz). Den krever .NET 8 fra fellesskapet (pkg install dotnet) og bibliotekene SkiaSharp og HarfBuzzSharp kompilert for FreeBSD, som Avalonia ikke leverer: uten dem starter ikke programmet. Instruksjonene står i filen LEGGIMI-FREEBSD.txt.
LI|Mac: åpne .dmg-filen (arm64 for Apple Silicon M1-M4, x64 for Intel), høyreklikk på «Installa E-LAYER-ANALYZER.command», og velg Åpne; alternativt inneholder filen -app.zip bare selve programmet.
LI|Alle programmets data ligger i mappen data ved siden av programmet: innstillinger (config.ini), CALL3-databasen, magnetfeltkoeffisienter, logger, nedlastede NOAA-data og innsamlede spot. Ingenting skrives til AppData eller til andre systemmapper.
LI|For å flytte programmet til en annen datamaskin holder det å kopiere mappen; for å gå tilbake til standardinnstillingene holder det å slette data/config.ini.
LI|I mappen data lagrer programmet også: lingue (oversettelsene), spot (de innsamlede spotene), spot_ms (meteor scatter-spotene fra YA-MS), swpc (dataene fra NOAA), mappa (kystlinjer og grenser fra Natural Earth, lastet ned fra GitHub ved første oppstart: første gang trengs nettforbindelse) og aggiornamento (pakkene fra den automatiske oppdateringen, som kan slettes).
LI|Passordet til LoTW lagres aldri; bare brukernavnet kan huskes.
LI|Oppdateringer: fra versjon 0.4.5 sjekker programmet selv, ved oppstart og deretter hver 6. time, om det er kommet en ny versjon på GitHub. Er det det, melder det dette med et vindu og med den oransje teksten ▲ i linjen øverst: «Oppdater nå» laster ned pakken som passer til datamaskinen (Windows 64 eller 32 bit, Linux, Raspberry Pi, Mac), lukker programmet, erstatter filene og starter det på nytt; «Senere» utsetter, «Hopp over versjonen» foreslår den ikke lenger. Innstillinger, innsamlede spot og call3.txt beholdes. Sjekken kan slås av med avkrysningsboksen i samme vindu.
LI|Fra versjon 0.4.12 er oppdateringene automatiske og stille: når det finnes en ny versjon på GitHub, laster programmet den ned, installerer den og starter på nytt av seg selv uten å spørre om noe. Manglende filer lastes også ned på nytt uten å spørre. Oppdateringsvinduet vises bare med et klikk på versjonen øverst, eller hvis du slår av den automatiske oppdateringen i INNSTILLINGER (Generelt).
LI|Den automatiske oppdateringen gjelder for installasjonsprogrammet og zip-filen for Windows, Mac-appen, .tar.gz-arkivene og AppImage. Med systempakkene (.deb, .rpm, Arch og Slackware) oppdaterer ikke programmet seg selv: det varsler om den nye versjonen, som installeres ved å laste ned den nye pakken fra siden Releases og installere den som den første.
LI|Også magnetfeltmodellen oppdaterer seg selv: ved oppstart og hver 30. dag ser programmet, uten å spørre, etter den nye IGRF-generasjonen på nettstedet til NOAA, og hvis den finnes, laster det den ned til mappen data og bruker den med en gang.
LI|Manglende filer: ved oppstart sjekker programmet at det har alle filene det ble distribuert med (oversettelser, dokumenter, tabeller). Mangler noen, lister et vindu dem opp, og knappen «Last ned fra GitHub» henter dem på nytt fra den samme versjonen publisert på GitHub.
LI|Under oppdateringen viser vinduet hvordan nedlastingen og utpakkingen går. Hvis det ikke kan skrives til programmappen, for eksempel inne i en systemmappe, sier programmet fra og foreslår release-siden, der installasjonspakken kan lastes ned; hvis noe mislykkes, vises årsaken, og knappen endres til «Release-side».
H2|1.3 Linjen øverst
P|Øverst til venstre skriver du inn ditt kallesignal, din lokator (4, 6 eller 8 tegn) og antennehøyden i meter; knappen Bruk bekrefter dem, og alle faner oppdateres. Øverst til høyre finner du UTC-tiden, valg av fargetema (alle temaene fra YAEC: Lys, Natt, Svart, åtte pasteller og Meteorspor) og valg av språk (36 språk). Når fargetema eller språk endres, bygges vinduet opp på nytt med en gang, uten at innsamlede data går tapt.
P|Ved siden av UTC-tiden viser teksten NTP:OK (grønn) eller NTP:FAILED (rød) om tiden er synkronisert: hvert 5. minutt spør programmet to tidsservere blant ti spredt over hele verden og bytter til andre hvis de ikke svarer. Verktøytipset viser serverne som brukes og avviket i PC-ens klokke.
P|Programmet bruker alltid riktig tid: det målte avviket brukes på programmets egen klokke. Hvis avviket er over ett sekund, retter programmet på Windows og med administratorrettigheter også PC-ens klokke, og verktøytipset sier fra om det («PC-ens klokke er korrigert»); på Linux og Mac blir systemklokken ikke endret.
P|Ved siden av NTP-teksten står versjonen i bruk (for eksempel v0.4.5, i grått): et klikk sjekker straks om det finnes en nyere på GitHub. Når en ny versjon kommer ut, blir teksten oransje, for eksempel ▲ 0.4.6, og et klikk åpner oppdateringsvinduet.
P|Til høyre i fanelinjen er kontinentmenyen (Europa, Nord-Amerika, Sør-Amerika, Afrika, Asia, Oseania): den flytter Mercator-kartene og F.A.I.- og nordlyskartene til valgt kontinent og velger prognosedataene for det kontinentet (E-skip fra N0NBH publiseres bare for Europa og Nord-Amerika).
P|Kallesignal, lokator, høyde, språk, fargetema, kontinent og oppdateringer stilles også inn i fanen INNSTILLINGER (kapittel 10), der også skriftstørrelsen for hele programmet finnes.
H2|1.4 Statuslinjen
P|Nederst viser statuslinjen hvor mange kallesignaler CALL3-databasen inneholder, hvor mange spot som ligger i minnet, og hvilken magnetisk modell som er i bruk (IGRF-14 med sin epoke). Spot i minnet slettes hver gang programmet lukkes: hver økt starter på nytt uten gamle spot.
H2|1.5 Kartene
P|Alle kartene brukes på samme måte: musehjulet zoomer inn eller ut, å dra med venstre knapp flytter visningen, og venstreklikk velger et punkt, et spot eller en strekning avhengig av fanen. Øverst til høyre vises koordinatene og 6-tegns lokatoren under markøren; i de asimutale kartene også avstand og asimut fra sentrum. Rutenettet med Maidenhead-felt og -ruter blir tettere når du zoomer inn.
LI|Hvert kart har nederst til venstre en forklaring på fargene og symbolene det bruker. Første gang kartet tegnes, kan teksten «Laster inn kartet (Natural Earth)...» vises i noen sekunder.
H1|2. Datainnsamling (DATA COLLECTION)
P|Fanen har to underfaner: Spot, med telnet-øktene, PSKReporter MQTT, WSJT-X UDP, de innsamlede spotene og CALL3-databasen, og Utbredelsesdata (kapittel 2.5). Spotfiltrene ligger i fanen INNSTILLINGER (kapittel 10).
H2|2.1 De tre telnet-øktene
P|Fanen DATA COLLECTION åpner inntil tre samtidige telnet-forbindelser: en valgfri DX-klynge (som standard ON0DXK med VHF-filtre), Reverse Beacon Network (port 7001 for FT8, 7000 for CW og RTTY) og klyngen til DM4X med spot fra PSKReporter (dm4x.ddns.net, port 8500).
LI|Vert og Port: klyngens adresse. Login: kallesignal for pålogging (hvis feltet er tomt, brukes det i linjen øverst). Kommandoer etter innlogging: kommandoer som sendes etter innlogging, atskilt med semikolon (for eksempel båndfiltre).
LI|Koble til og Koble fra åpner og lukker økten; Koble til på nytt åpner den automatisk igjen etter et brudd; Koble til ved oppstart åpner den når programmet starter.
LI|Konsollen viser de mottatte linjene; i feltet under kan du skrive kommandoer som skal sendes til klyngen (for eksempel sh/dx 20), og bekrefte dem med Send eller med Enter-tasten.
H2|2.2 Hvor filtrene er
P|Hvert spot som mottas i DATA COLLECTION, går gjennom filtrene før det når fanene for hver utbredelsesmåte: datainnsamlingen er én for hele programmet. Fra versjon 0.4.18 ligger filtrene og det lokale filteret i fanen INNSTILLINGER, underfanen Fordeling av spot (kapittel 10.2).
H2|2.3 Hvordan programmet leser spot
P|Fra hver «DX de»-linje henter programmet spotter, frekvens, DX, kommentar, tid og, når de finnes, lokatorene og utbredelsesmåten som er skrevet i kommentaren på formen JN70CN<ES>JO62QM (den første lokatoren tilhører spotteren, den andre DX-stasjonen; også formene med <>, > og parenteser godtas).
LI|Manglende lokatorer søkes i CALL3-databasen; upresise lokatorer (færre enn 6 tegn) erstattes med 6-tegns lokatoren fra CALL3 når den finnes.
LI|Spot med <MS>, <AU>, <AUR>, <TR>, <AS> eller <ACS> i teksten brukes ikke for sporadisk E: de hører til meteor scatter, nordlys, tropo eller aircraft scatter.
LI|Som i YA-MS regnes som meteor scatter-spot de som ligger i de typiske MS-frekvensvinduene (50190-50300, 70100-70400, 144290-144399 kHz) uten angivelse av annen utbredelse, og de med modusene MSK144, FSK441, FSK41, PSK2K, JTMS, JT6M eller med <MS>. Unntak er FT8 og FT4 på 50 og 70 MHz: hvis modusen er kjent, avgjør modusen, så FT8 på 70,154 MHz går til sporadisk E selv om den faller i meteor scatter-vinduet.
LI|Spot med <AU> eller <AUR> går til fanen AURORA, de med FAI til fanen F.A.I.
H2|2.4 Innsamlede spot og CALL3-databasen
P|Siden Innsamlede spot lister de siste spotene med filter for bånd og kilde; knappen Åpne spot-mappen åpner data/spot. Siden CALL3 viser databasen kallesignal -> lokator (JTDX/WSJT-format): du kan søke etter et kallesignal, laste inn databasen på nytt eller importere en ny CALL3.TXT-fil, som erstatter den som er i bruk (den gamle beholdes som sikkerhetskopi).
LI|Kolonnene for de innsamlede spotene er: UTC, Kilde (cluster, RBN eller PSKReporter), MHz, Bånd, DX med sin lokator, Spotter med sin lokator, km, Prop (den oppgitte eller gjenkjente utbredelsesmåten) og Kommentar. Menyen Alle kilder begrenser tabellen til én økt.
LI|Siden CALL3 viser filen som er i bruk, datoen dens, overskriften og antallet innlastede kallesignaler (over én million med den medfølgende databasen).
LI|Fra versjon 0.4.16 finnes én CALL3-database for hele programmet, den i YA-MS Datainnsamling (fanen METEOR SCATTER), med samme regler som LIVETROPOVHF: oppdatering fra MMMonVHF, håndoppføringer, tillagte filer, klyngekorreksjoner, lærte lokatorer og G7VRD hver 6. time; korreksjonene skrives inn i data/call3.txt og lokatorene i data/call3_nuovi.txt importeres én gang. Spotter fra WSJT-X, JTDX og MSHV kommer også via UDP (kilde WSJT-X UDP, port 2237 videresendt til 2238).
LI|Disse filtrene fra YA-MS (CW, minsteavstand, frekvensvinduer, MS-moduser, bånd) gjelder bare fanen METEOR SCATTER: de avgjør hvilke spotter som kommer inn i innsamlingen. De andre fanene får alle spotter og bruker sine egne filtre.
H2|2.5 Utbredelsesdata
P|Underfanen Utbredelsesdata samler dataene som hjelper med å forstå om et bånd kan åpne. De oppdateres av seg selv høyst én gang i timen; knappen Oppdater nå laster dem ned med en gang.
LI|N0NBH (hamqsl.com): banneret med VHF-forholdene og soldataene (solfluks, A- og K-indeks, røntgenstråling, solvind, Bz, nordlys og nordlysbredde) med E-skip for Europa og Nord-Amerika (data fra DXrobot).
LI|VHF-forholdene fra N0NBH vises slik hamqsl.com publiserer dem: Band Closed (båndet stengt), 50MHz ES, 70MHz ES og 144MHz ES (sporadisk E på det båndet), High MUF; for nordlys High LAT AUR og Mid LAT AUR (nordlys på høye eller midlere breddegrader).
LI|Bz for nordlys: NOAA SWPC, solvind i sanntid målt av satellitten i punktet L1 (DSCOVR/ACE), hvert minutt. En negativ og vedvarende Bz begunstiger nordlys.
LI|Nordlys: Dst-indeksen fra Kyoto (geomagnetiske stormer) og, for den sørlige halvkule, nordlysvarslene fra australske Bureau of Meteorology, som krever en gratis nøkkel som skrives i feltet BoM API-nøkkel. Knappene AE-indeks (Kyoto) og SuperDARN-konveksjon åpner de to sidene i nettleseren.
LI|Dst-nivået leses slik: rolig over -30 nT, svak forstyrrelse mellom -30 og -50 nT, moderat storm mellom -50 og -100 nT, kraftig storm fra -100 nT og nedover. Med nøkkelen fra BoM vises også den australske K-indeksen og de pågående nordlysvarslene.
LI|Meteor scatter: grafen over dagens meteoraktivitet (RMOB-data) fra Make More Miles on VHF; svermer, effektivitet og direkte trafikk finnes i fanen METEOR SCATTER.
P|Sammendraget av disse dataene vises øverst til høyre på kartene SPORADIC-E og F.A.I. (E-skip for valgt kontinent) og AURORA (nordlys fra N0NBH og Bz fra NOAA).
H1|3. Sporadisk E (SPORADIC-E)
P|Fanen SPORADIC-E har tre underfaner: REAL-TIME, spot i sanntid som beskrives i dette kapitlet; BENCHMARK Es (kapittel 4) og BENCHMARK 50 MHz (kapittel 5).
H2|3.1 Kartet
P|Menyen Kart velger projeksjonen. Asimutal: asimutalt ekvidistant kart sentrert på egen stasjon, med zoomglidebryteren (fra 300 til 20000 km fra sentrum, også med musehjulet). Mercator: verdenskartet med knappene Europa og Verden. I begge projeksjonene tegnes avstandssirklene fra tabellen til IK3XTV [3] rundt stasjonen: 500 km (minst for enkelthopp), 1500-2000 km (optimalt), 2400 km (høyst for enkelthopp), 5000 km (høyst for dobbelthopp) og 6900 km (høyst for trippelhopp).
P|Tabellen over hopplengder på 50 MHz er den til Flavio Egano IK3XTV, «Propagazione sui 6 metri - Caratteristiche generali» (Utbredelse på 6 meter - Generelle egenskaper) [3]; Es-skyene ligger i omkring 100 km høyde, og dette begrenser enkelthoppet til rundt 2000 km [29]. Ringene på kartene og antallet hopp følger disse avstandene:
TAB|Hopp;Minste avstand;Optimal avstand;Største avstand
TAB|Enkelthopp;500-650 km;1500-2000 km;2200-2400 km
TAB|Dobbelthopp;2800-3000 km;3200-4000 km;4400-5000 km
TAB|Trippelhopp;-;4800-6400 km;6900 km
P|I de asimutale visningene angir de stiplede ringene km fra sentrum; avstanden mellom ringene endres med zoomen, og ytterkanten viser den største avstanden som vises.
H2|3.2 Kontrollene
LI|Bånd: 10, 8, 6, 4 og 2 m (432 MHz analyseres ikke: sporadisk E gjelder ikke der [22]-[24]); 8 m (40 MHz) er slått av fra start. Tidsvindu for spot fra 15 minutter til 12 timer.
LI|Es-høyde (som standard 110 km) og antennenes minste elevasjon (som standard 1°); elevasjonen tar hensyn til troposfærisk refraksjon (jordradius 4/3), så enkelthoppet når rundt 2440 km.
LI|Første hopp (like hopp): viser begge stasjonenes første hopp; Kort første hopp innenfor…: viser forfatterens hypotese om et kort første hopp (som standard 1200 km) [4].
LI|Es-skyer på Maidenhead-ruter: farger rutene for refleksjonspunktene etter spotenes høyeste frekvens (grønn opp til 29 MHz, gul opp til 51, oransje opp til 71, rød opp til 145 MHz). Hvis skyens sannsynlige MUF på det lengste hoppet (2400 km) når et høyere bånd, blinker ruten med fargen til det båndet. For 144 MHz gjelder forfatterens regel: ruten blinker rødt bare hvis skyen gir et hopp på 50 MHz mellom 450 og 500 km (450 km med en toleranse på 50 km).
LI|144 MHz mot Kanariøyene, Madeira og Asorene (forfatterens regel): over 2400 km gjelder spoten bare hvis minst to spot peker på den samme Es-skyen; Es-hoppet, skyen og den stiplede tropo-strekningen fram til øya tegnes. På 50 og 70 MHz gjelder ikke regelen.
H2|3.3 Tabeller og detaljer
P|Tabellen Es-spot lister gyldige spot med avstand, antall hopp og minste foEs; tabellen Es-skyer (ruter) lister rutene med estimerte skyer og den MUF de ville gi for egen stasjon (rød 144 MHz, oransje 70 MHz, gul 50 MHz). Når en zoom er innstilt, viser tabellene bare det som er synlig på kartet.
LI|Kolonner i tabellen Es-spot: UTC, MHz, DX, Spotter, km, Hopp, foEs≥ (estimert minste foEs) og Prop. Kolonner i tabellen Es-skyer: Rute, foEs≥, antall spot, asimut og avstand fra egen stasjon og Min MUF.
LI|Farger og symboler på kartet: strekninger på 10 m grønne, på 8 m gule, på 6 m lyseblå, på 4 m fiolette og på 2 m oransje; liten gul firkant = midtpunkt for enkelthopp; liten oransje firkant = spotterens første hopp og liten fiolett firkant = DX-stasjonens første hopp (like hopp); liten oransje sirkel = kort første hopp (IC8TEMs antagelse); grønn sirkel = rekkevidde for enkelthopp fra egen stasjon.
LI|Klikk på et spot i tabellen eller på kartet: strekningen lyses opp med en gul glorie, kartet flytter den inn i synsfeltet om nødvendig, og boksen Detaljer viser hopp, refleksjonspunkter, foEs og asimut. Spotet forblir valgt også når nye spot kommer inn.
LI|Klikk på et ledig punkt på kartet: punktet behandles som en mulig Es-sky, med den foEs som kreves for 28, 50, 70 og 144 MHz.
LI|Når Kp er over 3, viser kartet dette øverst til høyre som et rent varsel: IK3XTV-IZ3ESV [51] finner over 90 % av åpningene ved Kp ≤ 3, men i forfatterens 50 MHz-logg går sporadisk E ikke ned ved Kp > 3.
LI|En QSO på 50 MHz over 11000 km vises i detaljene som ALARM, bare som statistisk notis (EI7GL [56]: HZ1SK-K4MOG, 11460 km).
LI|Underfanen Multihopp-forløpere: for fjerne regioner (tretti i hele verden) kontrollerer programmet om det på strekningens hoppunkter, med like hopp og alltid også med et kort første hopp innenfor 1200 km, finnes aktive Es-skyer sett i spotene fra andre stasjoner. ALARM (rød): alle punkter dekket; FORLØPER (gul): bare ett punkt mangler, i et område uten observatører. Et klikk på en rad tegner den stiplede strekningen, hoppunktene (grønn: aktiv sky; grå: ingen observatør; rød: ingen sky) og spotene som beviser skyene; detaljene oppgir den foEs som kreves for hvert hopp.
LI|De tretti forløperregionene er: Japan, Korea, Øst-Kina, Filippinene, Guam og Marianene, Indonesia, Nord-Australia, Øst-Australia, New Zealand, India, Den arabiske halvøy, Sentral-Asia, Øst-Sibir, Vest-Europa, Øst-Europa, Skandinavia, Vest-Afrika, Det sørlige Afrika, Karibia, Mellom-Amerika, Mexico, Østlige Nord-Amerika, Sentrale Nord-Amerika, Vestlige Nord-Amerika, Nord-Canada, Alaska, Hawaii, Nordlige Sør-Amerika, Brasil og Sørlige Sør-Amerika; programmet kontrollerer dem som ligger langt fra egen stasjon. Kolonnene i tabellen er Nivå, Region, Bånd, Hopp, Antagelse (like hopp eller kort første hopp), km og Az°.
LI|Spot i elektrisk blått med teksten TEP er strekninger som krysser den magnetiske ekvator, men er lengre eller mer asymmetriske enn ren TEP (for eksempel ZS6 - OH, SM, LA): sporadisk E kan koble seg på TEP. De forblir blant Es-spotene; i kolonnen Prop vises ES+TEP.
H2|3.4 Forfatterens regler
LI|144 MHz: sporadisk E begynner over 900 km; et enkeltstående spot tegnes ikke; det tegnes hvis et nytt spot på samme sky kommer innen 5 minutter, eller hvis det i nærheten finnes et 50 MHz-spot med kort hopp. Den grønne linjen øverst viser hvor mange spot som venter på bekreftelse.
LI|Transekvatorial: mot det afrikanske fastlandet (med Madagaskar) og Sør-Amerika er forbindelsen transekvatorial og ikke sporadisk E dersom midtpunktet faller i beltet med magnetisk inklinasjon mellom -15° og +15°, med mindre spotet oppgir <ES>. Kanariøyene, Madeira, Kapp Verde og Den arabiske halvøy faller utenfor regelen. Verdien 15° er hentet fra Cracknell [66], som plasserer TEP-sonene ca. 5-15° fra linjen med inklinasjon null (forfatterens valg).
LI|50 MHz: innenfor 450 km er det ikke sporadisk E. FT8- og FT4-spot er bare sporadisk E hvis de hører til en sky, det vil si hvis det innen 4 minutter finnes et annet spot på 50 MHz med midtpunktet innenfor 150 km; et isolert FT8- eller FT4-spot går til meteor scatter (forfatterens regel).
LI|70 MHz: innenfor 450 km er det ikke sporadisk E (forfatterens regel; G0ISW [65] ser den korteste sporadiske E over 400 km på 50 og 70 MHz). FT8 og FT4 går til sporadisk E, også innenfor båndplanens meteor scatter-vindu.
LI|40 MHz (8 m): minsteavstanden utledes av 450 km på 50 MHz med sekantloven (ca. 330 km), og bare avstander innenfor det første hoppet i E-lagets geometri gjelder (ca. 2440 km).
LI|144 MHz: Q65- og JT65-spot er EME og går ikke inn i sporadisk E, med mindre <ES> står i teksten. G0ISW [65] ser sporadisk E på 144 MHz først over 1400 km: forfatterens regel starter ved 900 km, men krever en bekreftelse.

H1|6. F.A.I.
H2|6.1 De to visningene
P|Fanen F.A.I. studerer scatter fra feltlinjeorienterte irregulariteter (hovedkilder [1], [2]). Visningen Scatter trail (par A-B) beregner, for to stasjoner, det geometriske stedet for mulige scatter-punkter, farget etter avviket fra refleksjonsbetingelsen, foreslår det mest sannsynlige scatter-punktet og tegner øverst til høyre boksen med QTF og elevasjon for begge stasjonene (rød = A, grønn = B). Visningen Isorefleksjon (punkt) tegner, for et valgt refleksjonspunkt, isorefleksjonslinjene på samme måte som AuroReflex og SE-PROP fra K9SE: fargede belter i de mørke temaene, tykke linjer i de lyse.
H2|6.2 Kontrollene
LI|Stasjon A og Stasjon B: kallesignal (søkes i CALL3) og/eller lokator; tom A = egen stasjon. Menyen Kontroller... laster inn testparene (IC8FAX-F6DRO, IC8FAX-G4LOH, IC8FAX-FA1MXE, DL5MCG-SV1DH fra 1987 via Budapest); de to tilfellene med en dato (1990 og 1987) beregnes med IGRF-14-feltet fra det året, som står i bildeteksten på kartet, så lenge stasjonene er de i tilfellet; menyen Kjente scatter-punkter... velger et dokumentert scatter-punkt (Genève, Brussel, Budapest, JN92, JN41/42).
LI|Høyde (som standard 110 km), minste elevasjon og Refraksjon (4/3 jordradius), avkrysset fra start.
LI|Menyen Visning velger mellom Scatter trail (par A-B) og Isorefleksjon (punkt). I visningen Isorefleksjon ligger nivåkurvene ved 0, ±1, ±2, ±4, ±8 og ±16 graders avvik; kurven 0 er det geometriske stedet for stasjonene som tar imot A via det valgte punktet.
LI|Venstreklikk på kartet: refleksjonspunkt som skal kontrolleres (bytter til visningen Isorefleksjon); høyreklikk: posisjonen til stasjon B.
LI|Kontroller det anbefalte punktet: beregner sporet, tar det foreslåtte scatter-punktet og viser isorefleksjonslinjene med vurderingen: TILFREDSSTILLENDE (innenfor 1°), AKSEPTABEL (innenfor 2,5°), IKKE TILFREDSSTILLENDE (utover dette).
LI|Resultatene for visningen Scatter trail angir det mest sannsynlige scatter-punktet (6-tegns lokator, koordinater og avvik), for hver stasjon QTF, elevasjon og avstand, og den magnetiske inklinasjonen i punktet; hvis sporet går nær et kjent scatter-punkt, sier de fra om det. På kartet viser feltet øverst til høyre QTF-ene: A i rødt, B i grønt.
LI|Utstyr (DL5MCG [6]): for F.A.I. på 144 MHz trengs minst en lang yagi og 100 W (SV1DH er også blitt kjørt med en 8-elementers og 50 W). Antennen rettes mot scatter-punktet som programmet angir, ikke mot motstasjonen.
P|Hvis beregningen ikke er mulig ifølge modellen, vises meldingen Beregning ikke mulig, og ingen andre resultater vises. Nederst lister tabellen F.A.I.-spot de spotene som er oppgitt som FAI; et klikk på et spot laster inn stasjonsparet.
