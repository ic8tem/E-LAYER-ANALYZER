TITLE|Manuel d'utilisation de E-LAYER ANALYZER
SUB|Manuel d'utilisation détaillé - par Costantino IC8TEM - version 0.4.10, novembre 2026. Les numéros entre crochets renvoient à l'onglet SOURCES ; les formules et les choix de calcul se trouvent dans l'onglet SYNTHÈSE DES CHOIX DE CALCUL.
H1|1. Avant de commencer
H2|1.1 Ce que fait le programme
P|E-LAYER ANALYZER réunit en un seul programme les outils pour étudier les modes de propagation VHF qui passent par la couche E de l'ionosphère : l'E sporadique, y compris multi-bond et extracontinental, le F.A.I. (irrégularités alignées sur le champ magnétique), le meteor scatter, avec le programme YA-MS intégré, et l'aurore radio. Il travaille sur les spots des DX clusters en temps réel et sur les logs ADIF, et affiche chaque résultat sur une carte qui occupe les deux tiers de la fenêtre, les données et les calculs se trouvant dans le tiers droit.
H2|1.2 Installation et dossier des données
P|Le programme fonctionne sous Windows (64 et 32 bits), Linux x86_64, Raspberry Pi (Raspberry Pi OS 64 et 32 bits, Slackware ARM64), Linux armv7l et Mac (Apple Silicon et Intel). Il se télécharge depuis la page Releases du dépôt GitHub : pour Windows, il existe un programme d'installation et une version portable dans un fichier .zip ; pour Linux et Raspberry Pi, un paquet .deb, un paquet Slackware .txz pour ARM64 et une archive .tar.gz avec le script d'installation ; pour Mac, une image .dmg. Il n'existe pas de version pour Linux i686 (PC 32 bits), car .NET n'existe pas pour ce système, ni pour FreeBSD, où manquent les bibliothèques graphiques d'Avalonia.
LI|Windows : l'installateur place le programme dans C:\E-LAYER-ANALYZER, avec le dossier data à côté ; la version portable s'extrait dans un dossier quelconque et se lance avec E-LAYER-ANALYZER.exe.
LI|Linux et Raspberry Pi : avec le paquet .deb (sudo apt install ./e-layer-analyzer_..._amd64.deb, ou _arm64.deb pour Raspberry Pi OS 64 bits et _armhf.deb pour celui en 32 bits), le programme se lance depuis le menu et, au premier démarrage, se copie dans ~/E-LAYER-ANALYZER ; avec l'archive .tar.gz (linux-x64, linux-arm64, linux-arm ou linux-armv7l), on l'extrait et on lance ./E-LAYER-ANALYZER, ou bien ./installa.sh l'installe dans ~/E-LAYER-ANALYZER avec l'icône dans le menu.
LI|Slackware ARM64 : en root, on installe le paquet avec installpkg e-layer-analyzer-...-aarch64-1_ic8tem.txz ; le programme se lance avec e-layer-analyzer depuis le menu ou le terminal et, au premier démarrage, se copie dans ~/E-LAYER-ANALYZER, comme avec le .deb.
LI|Mac : ouvrir le fichier .dmg (arm64 pour Apple Silicon M1-M4, x64 pour Intel) et, avec un clic droit sur « Installa E-LAYER-ANALYZER.command », choisir Ouvrir ; sinon, le fichier -app.zip contient seulement l'application.
LI|Toutes les données du programme se trouvent dans le dossier data à côté du programme : réglages (config.ini), base CALL3, coefficients du champ magnétique, logs, données NOAA téléchargées, spots collectés. Rien n'est écrit dans AppData ni dans d'autres dossiers système.
LI|Pour transférer le programme sur un autre ordinateur, il suffit de copier son dossier ; pour revenir aux réglages initiaux, il suffit d'effacer data/config.ini.
LI|Dans le dossier data, le programme conserve aussi : lingue (les traductions), spot (les spots collectés), spot_ms (les spots de meteor scatter de YA-MS), swpc (les données de la NOAA), mappa (côtes et frontières de Natural Earth, téléchargées depuis GitHub au premier démarrage : la première fois, il faut le réseau) et aggiornamento (les paquets de la mise à jour automatique, que l'on peut effacer).
LI|Le mot de passe LoTW n'est jamais enregistré ; seul le nom d'utilisateur peut être mémorisé.
LI|Mises à jour : à partir de la version 0.4.5, le programme vérifie tout seul, au démarrage puis toutes les 6 heures, si une nouvelle version est sortie sur GitHub. Si c'est le cas, il le signale par une fenêtre et par l'indication orange ▲ dans la barre du haut : « Mettre à jour » télécharge le paquet adapté à l'ordinateur (Windows 64 ou 32 bits, Linux, Raspberry Pi, Mac), ferme le programme, remplace les fichiers et le redémarre ; « Plus tard » reporte, « Ignorer cette version » ne la propose plus. Les réglages, les spots collectés et call3.txt sont conservés. La vérification peut être désactivée avec la case de la même fenêtre.
LI|Fichiers manquants : au démarrage, le programme vérifie qu'il dispose de tous les fichiers avec lesquels il a été distribué (traductions, documents, tables). S'il en manque, une fenêtre les énumère et le bouton « Télécharger depuis GitHub » les récupère dans la même version publiée sur GitHub.
LI|Pendant la mise à jour, la fenêtre affiche l'avancement du téléchargement et de l'extraction. Si le dossier du programme n'est pas accessible en écriture, par exemple dans un dossier système, le programme le signale et propose la page de la release, d'où l'on télécharge le paquet d'installation ; si quelque chose échoue, la raison s'affiche et le bouton devient « Page de la release ».
H2|1.3 La barre du haut
P|En haut à gauche, on saisit son indicatif, son locator (4, 6 ou 8 caractères) et la hauteur de l'antenne en mètres ; le bouton Appliquer les valide et tous les onglets se mettent à jour. En haut à droite se trouvent l'heure UTC, le choix du jeu de couleurs (tous les jeux de YAEC : Clair, Nuit, Noir, huit pastels et Traînée météorique) et le choix de la langue (36 langues). Lorsqu'on change de jeu de couleurs ou de langue, la fenêtre est reconstruite immédiatement, sans perdre les données collectées.
P|À côté de l'heure UTC, l'indication NTP:OK (vert) ou NTP:FAILED (rouge) dit si l'heure est alignée : toutes les 5 minutes, le programme interroge deux serveurs de temps parmi dix répartis dans le monde et passe à d'autres s'ils ne répondent pas. L'infobulle indique les serveurs utilisés et l'écart de l'horloge du PC.
P|Le programme utilise toujours l'heure correcte : l'écart mesuré est appliqué à sa propre horloge. Si l'écart dépasse une seconde, sous Windows et avec les droits d'administrateur, le programme corrige aussi l'horloge du PC, et l'infobulle l'indique (« L'horloge du PC a été corrigée ») ; sous Linux et Mac, l'horloge du système n'est pas modifiée.
P|À côté de l'indication NTP se trouve la version installée (par exemple v0.4.5, en gris) : un clic vérifie aussitôt s'il en existe une plus récente sur GitHub. Quand une nouvelle version sort, l'indication devient orange, par exemple ▲ 0.4.6, et un clic ouvre la fenêtre de mise à jour.
P|À droite dans la barre des onglets se trouve le menu du continent (Europe, Amérique du Nord, Amérique du Sud, Afrique, Asie, Océanie) : il déplace les cartes de Mercator et celles du F.A.I. et de l'aurore sur le continent choisi et choisit les données de prévision de ce continent (l'E-skip de N0NBH n'est publié que pour l'Europe et l'Amérique du Nord).
H2|1.4 La barre d'état
P|En bas, la barre d'état indique combien d'indicatifs contient la base CALL3, combien de spots sont en mémoire et le modèle magnétique utilisé (IGRF-14 avec son époque). Les spots en mémoire sont effacés à chaque fermeture du programme : chaque session repart sans anciens spots.
H2|1.5 Les cartes
P|Toutes les cartes s'utilisent de la même façon : la molette de la souris agrandit ou réduit, le glisser avec le bouton gauche déplace la vue, le clic gauche choisit un point, un spot ou un trajet selon l'onglet. En haut à droite apparaissent les coordonnées et le locator à 6 caractères sous le curseur ; sur les cartes azimutales, également la distance et l'azimut depuis le centre. La grille des champs et des carrés Maidenhead se densifie avec le zoom.
LI|Chaque carte porte en bas à gauche la légende des couleurs et des symboles qu'elle utilise. Au premier affichage, le texte « Chargement de la carte (Natural Earth)... » peut apparaître pendant quelques secondes.
H1|2. Collecte des données (DATA COLLECTION)
P|L'onglet a deux sous-onglets : Spots, avec les sessions telnet, les spots collectés, la base CALL3 et la colonne des filtres, et Données de propagation (chapitre 2.5).
H2|2.1 Les trois sessions telnet
P|L'onglet DATA COLLECTION ouvre jusqu'à trois connexions telnet simultanées : un DX cluster au choix (par défaut ON0DXK avec les filtres VHF), le Reverse Beacon Network (port 7001 pour le FT8, 7000 pour la CW et le RTTY) et le cluster de DM4X avec les spots de PSKReporter (dm4x.ddns.net, port 8500).
LI|Hôte et Port : adresse du cluster. Login : indicatif utilisé pour la connexion (s'il est vide, on utilise celui de la barre du haut). Commandes après le login : commandes à envoyer après le login, séparées par des points-virgules (par exemple les filtres de bande).
LI|Connecter et Déconnecter ouvrent et ferment la session ; Reconnecter la rouvre automatiquement après une coupure ; Connecter au démarrage l'ouvre au lancement du programme.
LI|La console affiche les lignes reçues ; dans la case au-dessous, on peut saisir des commandes à envoyer au cluster (par exemple sh/dx 20) et les valider avec Envoyer ou avec la touche Entrée.
H2|2.2 La colonne des filtres
P|La colonne de droite de l'onglet, 40 % de la fenêtre, regroupe tous les filtres des spots : la collecte des données est unique pour tout le programme, et chaque spot reçu passe par ici avant d'arriver aux onglets de chaque mode de propagation. En haut se trouve la case du filtre local, cochée par défaut : les lignes « DX de » dont la fréquence est inférieure à 27990,0 kHz ou supérieure à 145 MHz sont écartées, n'apparaissent pas dans la console et ne sont pas enregistrées. C'est utile surtout avec RBN et PSKReporter, qui envoient énormément de spots HF. Si la case est décochée, tout passe. En dessous se trouvent cinq sous-onglets.
LI|Meteor scatter : le filtre de YA-MS (fenêtres de fréquence typiques du MS, mentions d'autre propagation, modes numériques MS et <MS>, bandes, test du filtre et compteurs). Dans E-LAYER ANALYZER, le sous-onglet Collecte de données de YA-MS n'apparaît pas : son filtre se règle ici.
LI|E sporadique : les mentions entre < > qui excluent un spot de l'E sporadique ; les règles du 28 et du 50 MHz (en 50 MHz, en deçà de 450 km, ce n'est pas de l'E sporadique ; en 28 MHz, la distance minimale se déduit de celle du 50 MHz selon IK3XTV, environ 170 km ; le plan de bande n'est pas un critère exclusif, donc un spot dans la fenêtre du meteor scatter reste dans l'E sporadique sauf mode numérique MS ou <MS>) ; la règle du 144 MHz (distance minimale ; confirmation par un second spot sur le même nuage en quelques minutes, ou par un spot en 50 MHz à saut court dans les environs) et la règle transéquatoriale avec sa bande d'inclinaison magnétique, qui s'applique à l'Afrique et à l'Amérique du Sud (règle de l'auteur) et, dans le monde entier, aux liaisons de 3000-8000 km qui traversent l'équateur magnétique dans une direction proche du nord-sud (Kennewell et Wilkinson [49]). Le bouton Rétablir les règles de l'auteur remet les valeurs par défaut.
LI|Valeurs par défaut des règles de l'E sporadique, toutes modifiables : distance minimale en 50 MHz 450 km ; règle du 144 MHz activée, avec distance minimale 900 km et confirmation dans les 5 minutes par un second spot sur un nuage à moins de 300 km, ou par un spot en 50 MHz des 15 dernières minutes avec un bond court jusqu'à 1200 km ; règle transéquatoriale activée, avec la bande d'inclinaison magnétique de ±20°.
LI|F.A.I. : les mots qui signalent un spot de F.A.I. (par défaut FAI : <FAI> ou fai sont acceptés, en majuscules, minuscules ou mélangés ; ces spots n'entrent pas dans l'E sporadique), les bandes et la période des spots sur la carte (par défaut 24 heures).
LI|Aurore : les mots des spots d'aurore, avec ou sans < > et en majuscules ou en minuscules (par défaut AU et AUR), les bandes et la période des spots sur la carte (par défaut 2 heures).
LI|Test des filtres : on écrit ou on colle une ligne du cluster et le programme montre comment les filtres la classent (meteor scatter, aurore, F.A.I., transéquatorial, E sporadique), avec bande, locator et distance.
H2|2.3 Comment le programme lit les spots
P|De chaque ligne « DX de », le programme tire le spotter, la fréquence, le DX, le commentaire, l'heure et, lorsqu'ils sont présents, les locators et le mode de propagation écrits dans le commentaire sous la forme JN70CN<ES>JO62QM (le premier locator est celui du spotter, le second celui du DX ; les formes avec <>, > et parenthèses sont également acceptées).
LI|Les locators manquants sont recherchés dans la base CALL3 ; les locators imprécis (moins de 6 caractères) sont remplacés par le locator à 6 caractères de CALL3, s'il existe.
LI|Les spots portant <MS>, <AU>, <AUR>, <TR>, <AS> ou <ACS> dans le texte ne sont pas utilisés pour l'E sporadique : ils servent au meteor scatter, à l'aurore, au tropo ou à l'aircraft scatter.
LI|Comme dans YA-MS, sont des spots de meteor scatter ceux situés dans les fenêtres de fréquence typiques du MS (50190-50300, 70100-70400, 144290-144399 kHz) sans mention d'une autre propagation, et ceux avec les modes MSK144, FSK441, FSK41, PSK2K, JTMS, JT6M ou avec <MS>.
LI|Les spots avec <AU> ou <AUR> vont dans l'onglet AURORA, ceux avec FAI dans l'onglet F.A.I.
H2|2.4 Spots collectés et base CALL3
P|La page Spots collectés liste les derniers spots avec un filtre par bande et par source ; le bouton Ouvrir le dossier des spots ouvre data/spot. La page CALL3 affiche la base indicatif -> locator (format JTDX/WSJT) : on peut rechercher un indicatif, recharger la base ou importer un nouveau fichier CALL3.TXT, qui remplace celui en service (l'ancien est conservé comme copie de sauvegarde).
LI|Les colonnes des spots collectés sont : UTC, Source (cluster, RBN ou PSKReporter), MHz, Bande, DX avec son locator, Spotter avec son locator, km, Prop (le mode de propagation déclaré ou reconnu) et Commentaire. Le menu Toutes les sources limite le tableau à une seule session.
LI|La page CALL3 indique le fichier utilisé, sa date, l'en-tête et le nombre d'indicatifs chargés (plus d'un million avec la base distribuée).
H2|2.5 Données de propagation
P|Le sous-onglet Données de propagation rassemble les données qui aident à comprendre si une bande peut s'ouvrir. Elles se mettent à jour d'elles-mêmes au plus une fois par heure ; le bouton Mettre à jour maintenant les télécharge tout de suite.
LI|N0NBH (hamqsl.com) : la bannière des conditions VHF et les données solaires (flux solaire, indices A et K, rayons X, vent solaire, Bz, aurore et latitude aurorale) avec l'E-skip de l'Europe et de l'Amérique du Nord (données DXrobot).
LI|Les conditions VHF de N0NBH apparaissent telles que hamqsl.com les publie : Band Closed (bande fermée), 50MHz ES, 70MHz ES et 144MHz ES (E sporadique sur cette bande), High MUF ; pour l'aurore, High LAT AUR et Mid LAT AUR (aurore aux latitudes hautes ou moyennes).
LI|Bz pour l'aurore : NOAA SWPC, vent solaire en temps réel mesuré par le satellite au point L1 (DSCOVR/ACE), chaque minute. Un Bz négatif et persistant favorise l'aurore.
LI|Aurore : l'indice Dst de Kyoto (tempêtes géomagnétiques) et, pour l'hémisphère sud, les alertes d'aurore du Bureau of Meteorology australien, qui demandent une clé gratuite à saisir dans la case Clé API BoM. Les boutons Indice AE (Kyoto) et Convection SuperDARN ouvrent les deux pages dans le navigateur.
LI|Le niveau du Dst se lit ainsi : calme au-dessus de -30 nT, faible perturbation entre -30 et -50 nT, tempête modérée entre -50 et -100 nT, tempête intense à partir de -100 nT et en dessous. Avec la clé du BoM apparaissent aussi l'indice K australien et les alertes de surveillance d'aurore en cours.
LI|Meteor scatter : le graphique de l'activité météorique du jour (données RMOB) de Make More Miles on VHF ; essaims, efficacité et trafic en direct se trouvent dans l'onglet METEOR SCATTER.
P|La synthèse de ces données apparaît en haut à droite sur les cartes SPORADIC-E et F.A.I. (E-skip du continent choisi) et AURORA (aurore de N0NBH et Bz de la NOAA).
H1|3. E sporadique (SPORADIC-E)
P|L'onglet SPORADIC-E comporte trois sous-onglets : REAL-TIME, les spots en direct décrits dans ce chapitre ; BENCHMARK Es (chapitre 4) et BENCHMARK 50 MHz (chapitre 5).
H2|3.1 La carte
P|Le menu Carte choisit la projection. Azimutale : carte azimutale équidistante centrée sur sa propre station, avec le curseur du zoom (de 300 à 20000 km du centre, aussi avec la molette de la souris). Mercator : la carte du monde, avec les boutons Europe et Monde. Dans les deux projections, les cercles de distance du tableau de IK3XTV [3] sont tracés autour de la station : 500 km (minimale du bond unique), 1500-2000 km (optimale), 2400 km (maximale du bond unique), 5000 km (maximale du double bond) et 6900 km (maximale du triple bond).
P|Le tableau des longueurs des bonds en 50 MHz est celui de Flavio Egano IK3XTV, «Propagazione sui 6 metri - Caratteristiche generali» (Propagation sur 6 mètres - Caractéristiques générales) [3] ; les nuages Es se trouvent à environ 100 km d'altitude, ce qui limite le bond unique à environ 2000 km [29]. Les couronnes des cartes et le nombre de bonds suivent ces distances :
TAB|Bond;Distance minimale;Distance optimale;Distance maximale
TAB|Bond unique;500-650 km;1500-2000 km;2200-2400 km
TAB|Double bond;2800-3000 km;3200-4000 km;4400-5000 km
TAB|Triple bond;-;4800-6400 km;6900 km
P|Dans les vues azimutales, les anneaux en pointillé indiquent les km depuis le centre ; l'espacement des anneaux change avec le zoom et le bord extérieur indique la distance maximale affichée.
H2|3.2 Les commandes
LI|Bandes : 10, 6, 4 et 2 m (le 432 MHz n'est pas analysé : l'E sporadique ne s'y applique pas [22]-[24]) ; fenêtre de temps des spots de 15 minutes à 12 heures.
LI|Altitude Es (110 km par défaut) et élévation minimale des antennes (1° par défaut) ; l'élévation tient compte de la réfraction troposphérique (rayon terrestre 4/3), si bien que le bond unique atteint environ 2440 km.
LI|Premiers bonds (bonds égaux) : affiche le premier bond des deux stations ; Premier bond court jusqu'à… : affiche l'hypothèse de l'auteur du premier bond court (1200 km par défaut) [4].
LI|Nuages Es sur les carrés Maidenhead : colore les carrés des points de réflexion selon la fréquence la plus haute des spots (vert jusqu'à 29 MHz, jaune jusqu'à 51, orange jusqu'à 71, rouge jusqu'à 145 MHz). Si la MUF probable du nuage sur le bond le plus long (2400 km) atteint une bande plus haute, le carré clignote dans la couleur de cette bande.
LI|144 MHz vers les îles Canaries, Madère et les Açores (règle de l'auteur) : au-delà de 2400 km, le spot n'est valable que si au moins deux spots désignent le même nuage Es ; on dessine le bond Es, le nuage et le tronçon tropo en pointillés jusqu'à l'île. Sur 50 et 70 MHz, la règle ne s'applique pas.
H2|3.3 Tableaux et détails
P|Le tableau Spots Es liste les spots valides avec la distance, le nombre de bonds et la foEs minimale ; le tableau Nuages Es (carrés) liste les carrés avec les nuages estimés et la MUF qu'ils donneraient pour sa propre station (rouge 144 MHz, orange 70 MHz, jaune 50 MHz). Lorsqu'un zoom est réglé, les tableaux ne montrent que ce qui est visible sur la carte.
LI|Colonnes du tableau Spots Es : UTC, MHz, DX, Spotter, km, Bonds, foEs≥ (foEs minimale estimée) et Prop. Colonnes du tableau Nuages Es (carrés) : Carré, foEs≥, nombre de spots, azimut et distance depuis sa propre station et Ma MUF.
LI|Couleurs et symboles sur la carte : trajets en 10 m verts, en 6 m bleu clair, en 4 m violets et en 2 m orange ; petit carré jaune = point milieu du bond simple ; petit carré orange = premier bond du spotter et petit carré violet = premier bond du DX (bonds égaux) ; petit cercle orange = premier bond court (hypothèse IC8TEM) ; cercle vert = portée du bond simple depuis sa propre station.
LI|Clic sur un spot dans le tableau ou sur la carte : le trajet s'illumine d'un halo jaune, la carte l'amène dans le champ si nécessaire et le cadre Détails indique bonds, points de réflexion, foEs et azimut. Le spot reste sélectionné même lorsque de nouveaux spots arrivent.
LI|Clic sur un point libre de la carte : le point est traité comme un nuage Es possible, avec la foEs nécessaire pour 28, 50, 70 et 144 MHz.
LI|Avec un Kp supérieur à 3, la carte le signale en haut à droite, comme simple avertissement : IK3XTV-IZ3ESV [51] trouvent plus de 90 % des ouvertures avec Kp ≤ 3, mais sur le log 50 MHz de l'auteur l'E sporadique ne diminue pas avec Kp > 3.
LI|Un QSO en 50 MHz au-delà de 11000 km apparaît dans les détails comme ALERTE, uniquement comme information statistique (EI7GL [56] : HZ1SK-K4MOG, 11460 km).
LI|Sous-onglet Précurseurs multi-bond : pour les régions lointaines (trente dans le monde entier), le programme vérifie si, sur les points de bond du trajet, avec des bonds égaux et toujours aussi avec le premier bond court jusqu'à 1200 km, il y a des nuages Es actifs vus à partir des spots d'autres stations. ALERTE (rouge) : tous les points couverts ; PRÉCURSEUR (jaune) : il ne manque qu'un seul point, dans une zone sans observateurs. Un clic sur une ligne dessine le trajet en pointillé, les points de bond (vert : nuage actif ; gris : aucun observateur ; rouge : aucun nuage) et les spots qui prouvent les nuages ; les détails indiquent la foEs nécessaire pour chaque bond.
LI|Les trente régions des précurseurs sont : Japon, Corée, Chine orientale, Philippines, Guam et Mariannes, Indonésie, Australie septentrionale, Australie orientale, Nouvelle-Zélande, Inde, Péninsule Arabique, Asie centrale, Sibérie orientale, Europe occidentale, Europe orientale, Scandinavie, Afrique de l'Ouest, Afrique australe, Caraïbes, Amérique centrale, Mexique, Amérique du Nord orientale, Amérique du Nord centrale, Amérique du Nord occidentale, Nord du Canada, Alaska, Hawaï, Amérique du Sud septentrionale, Brésil et Cône Sud ; on contrôle celles qui sont éloignées de sa propre station. Les colonnes du tableau sont Niveau, Région, Bande, Bonds, Hypothèse (bonds égaux ou premier bond court), km et Az°.
LI|Les spots en bleu électrique avec l'inscription TEP sont des trajets qui traversent l'équateur magnétique mais sont plus longs ou plus asymétriques qu'une TEP pure (par exemple ZS6 - OH, SM, LA) : l'E sporadique peut s'accrocher à la TEP. Ils restent parmi les spots Es ; dans la colonne Prop apparaît ES+TEP.
H2|3.4 Les règles de l'auteur
LI|144 MHz : l'E sporadique commence au-delà de 900 km ; un spot isolé n'est pas dessiné ; il l'est si, dans les 5 minutes, arrive un second spot sur le même nuage ou s'il y a dans les environs un spot 50 MHz de bond court. La ligne verte en haut indique combien de spots attendent une confirmation.
LI|Transéquatoriale : vers l'Afrique continentale (Madagascar compris) et l'Amérique du Sud, si le point milieu tombe dans la bande d'inclinaison magnétique comprise entre -20° et +20°, la liaison est transéquatoriale et non en E sporadique, sauf si le spot déclare <ES>. Les Canaries, Madère, le Cap-Vert et la péninsule Arabique restent en dehors de la règle.
H1|4. BENCHMARK Es (sous-onglet de SPORADIC-E)
H2|4.1 Charger un log
P|Le sous-onglet BENCHMARK Es est un banc d'essai de l'E sporadique sur un log ADIF entier, même celui d'une autre station. Charger l'ADIF ouvre le fichier (le programme s'en souvient et le recharge au démarrage), Retirer l'ADIF l'enlève. Station au centre propose l'indicatif et le locator les plus fréquents du log ; on peut les modifier et les valider avec Appliquer.
LI|La position d'émission est le MY_GRIDSQUARE de chaque QSO ; les positions de réception sont les GRIDSQUARE (les locators manquants ou à 4 caractères sont pris dans CALL3).
LI|On peut exclure les QSO avec un autre PROP_MODE et ceux de moins de 500 km (900 km en 144 MHz) ; les transéquatoriaux sont toujours exclus, sauf PROP_MODE=ES.
LI|Sur la carte, un point jaune flou marque le centre de chaque bond, où l'on présume que se trouve le nuage d'E sporadique (aussi le centre du premier bond court, si l'hypothèse est active).
H2|4.2 Journées, horaires et calculs
P|Le tableau QSO par journée liste les journées avec le nombre de QSO, les bandes, la distance maximale et les multi-bonds ; un clic sur une journée remplit le tableau Heures de la journée, avec une ligne pour chaque heure UTC et la ligne Toute la journée. La carte azimutale, avec le curseur de la distance maximale, dessine le skip par secteurs de 10° (arc orange = QSO le plus proche, secteur vert = distances atteintes), les nuages sur les carrés et, pour la journée entière, le déplacement horaire des nuages (ligne rouge).
P|La page Calculs proposés indique le skip par secteurs, la foEs estimée avec la MUF attendue à 1000, 1500, 2000 et 2400 km, les nuages estimés, la vérification du multi-bond (bonds égaux contre premier bond court, comparés aux nuages vus en bond unique à ±30 minutes près) et le déplacement des nuages heure par heure.
LI|Colonnes des tableaux : QSO par journée (Journée, QSO, Bandes, km max, Multi-bond) ; Heures de la journée (Heure UTC, QSO, km min - max, Multi-bond, Bandes) : un clic sur une heure affiche les QSO de cette heure, avec UTC, Indicatif, Locator, MHz, km, Bonds et foEs≥. Un clic sur un QSO le met en évidence sur la carte avec le premier bond du correspondant. Le récapitulatif indique aussi combien de QSO transéquatoriaux ont été exclus.
H1|5. BENCHMARK 50 MHz (sous-onglet de SPORADIC-E)
H2|5.1 Une ou deux stations
P|Le sous-onglet BENCHMARK 50 MHz est consacré à l'E sporadique multi-bond en 50 MHz. Dans la ligne Station 1, on charge et on retire le log de sa propre station ; dans la ligne Station 2, le log d'une seconde station, que l'on affiche ou masque avec la case Station 2. Les trajets de la station 1 sont bleu clair, ceux de la station 2 violets.
LI|Sont affichés les QSO 50 MHz multi-bond, c'est-à-dire au-delà de 3100 km (règle de l'auteur) ; le nombre de bonds suit le tableau de IK3XTV.
LI|Jour, de… à… UTC : la journée (à l'ouverture, celle qui compte le plus de QSO multi-bond) et l'horaire, par pas de 15 minutes.
LI|foEs (facultative) : colore les trajets selon la foEs minimale et l'indique dans le tableau. Altitude Es et Premier bond court jusqu'à 1200 km comme dans les autres onglets.
LI|Le point jaune flou marque le centre de chaque bond, où l'on présume que se trouve le nuage d'E sporadique ; sur le trajet sous la souris, il devient plus grand.
LI|Le tableau énumère les QSO affichés avec St. (station 1 ou 2), Journée, UTC, Indicatif, WWL, km, Bonds et foEs≥. Avec foEs activé, les points de bond indiquent la foEs minimale ; un locator de 4 caractères absent de CALL3 est signalé à côté du WWL.
H2|5.2 La carte de Mercator
P|La carte est une projection de Mercator à centre libre. Lorsque la souris s'approche d'un trajet, la ligne et les icônes s'agrandissent et le carré WWL à 6 caractères du correspondant apparaît. D'un clic gauche sur ce trajet, une fenêtre contextuelle demande s'il faut afficher tous les QSO du fichier, de toutes les journées, dont la position d'arrivée se trouve à moins de 150 km : Oui vide la carte et affiche ces QSO dans le cercle orange, Non laisse la carte telle quelle. Le bouton Retour au jour et à l'horaire ramène à la sélection précédente.
H1|6. F.A.I.
H2|6.1 Les deux vues
P|L'onglet F.A.I. étudie le scatter sur les irrégularités alignées sur le champ magnétique (source principale [1], [2]). La vue Scatter trail (paire A-B) calcule, pour deux stations, le lieu des scatter points possibles, coloré selon l'écart par rapport à la condition de réflexion, propose le scatter point le plus probable et dessine en haut à droite le cadre des QTF et des élévations des deux stations (rouge = A, vert = B). La vue Iso-réflexion (point) dessine, pour un point de réflexion choisi, les lignes d'iso-réflexion comme AuroReflex et SE-PROP de K9SE : bandes colorées dans les jeux sombres, lignes épaisses dans les jeux clairs.
H2|6.2 Les commandes
LI|Station A et Station B : indicatif (recherché dans CALL3) et/ou locator ; A vide = sa propre station. Le menu Vérifications… charge les paires d'essai (IC8FAX-F6DRO, IC8FAX-G4LOH, IC8FAX-FA1MXE, DL5MCG-SV1DH de 1987 via Budapest) ; le menu Scatter points connus… choisit un scatter point documenté (Genève, Bruxelles, Budapest, JN92, JN41/42).
LI|Altitude (110 km par défaut), élévation minimale et Réfraction (rayon terrestre 4/3), cochée par défaut.
LI|Le menu de la vue choisit entre Scatter trail (paire A-B) et Iso-réflexion (point). Dans la vue Iso-réflexion, les courbes de niveau sont à 0, ±1, ±2, ±4, ±8 et ±16 degrés d'écart ; la courbe 0 est le lieu des stations qui reçoivent A par le point choisi.
LI|Clic gauche sur la carte : point de réflexion à vérifier (passe à la vue Iso-réflexion) ; clic droit : position de la station B.
LI|Vérifier le point conseillé : calcule la trace, prend le scatter point proposé et en affiche les lignes d'iso-réflexion avec le verdict : SATISFAISANT (à moins de 1°), ACCEPTABLE (à moins de 2,5°), NON SATISFAISANT (au-delà).
LI|Les résultats de la vue Scatter trail indiquent le scatter point le plus probable (locator à 6 caractères, coordonnées et écart), pour chaque station le QTF, l'élévation et la distance, ainsi que l'inclinaison magnétique au point ; si la traînée passe près d'un scatter point connu, ils le signalent. Sur la carte, le cadre en haut à droite indique les QTF : A en rouge, B en vert.
LI|Équipement (DL5MCG [6]) : pour le F.A.I. en 144 MHz, il faut au moins une yagi longue et 100 W (SV1DH a aussi été contacté avec une 8 éléments et 50 W). L'antenne se pointe vers le scatter point indiqué par le programme, non vers le correspondant.
P|Si le calcul n'est pas possible pour le modèle, le message Calcul impossible apparaît et aucun autre résultat n'est affiché. En bas, le tableau Spots F.A.I. liste les spots déclarés FAI ; un clic sur un spot charge la paire de stations correspondante.
LI|Les spots F.A.I. sur la carte et dans le tableau sont ceux de la période choisie dans la colonne des filtres de DATA COLLECTION (24 heures par défaut) ; le tableau indique UTC, MHz, DX, Spotter, km et Commentaire.
H1|7. METEOR SCATTER
P|L'onglet contient le programme YA-MS complet, avec ses onglets (Direct et données en temps réel : trafic meteor scatter en direct, flux radar, radar GRAVES ; Calcul prévisionnel : voûte céleste et calcul, géométrie et atténuation, calcul de l'efficacité, mise en œuvre expérimentale des prévisions ; Documents techniques : essaims, sources, carte des sources, explication du calcul de l'efficacité, manuel d'utilisation, carte des carrés) et son manuel des calculs. La langue et le jeu de couleurs sont ceux choisis en haut. Dans E-LAYER ANALYZER, la Collecte de données de YA-MS n'apparaît pas : la collecte est unique, celle de DATA COLLECTION, qui transmet les lignes à YA-MS, et le filtre des spots de meteor scatter se règle dans la colonne des filtres de DATA COLLECTION.
P|YA-MS 1.8.1 traite le lobe d'antenne comme un diagramme vertical (case «diagramme d'antenne», activée par défaut) : les points de réflexion sont pondérés par le gain vertical des deux antennes et les efficacités ne disparaissent plus sur les longs trajets. Il ajoute l'avertissement «aucune zone commune», met en évidence la case de l'angle β (le choix qui pèse le plus), utilise une seule date de calcul, apporte le «Manuel d'utilisation» et la comparaison avec 181 767 spots réels sur 50 MHz du Meteor Scatter QSO Party HamSCI d'août 2025 : les heures et les côtés du trajet sont fiables, les pourcentages sont indicatifs.
H1|8. AURORA
P|L'onglet AURORA utilise les mêmes vues que le F.A.I. (altitude par défaut 110 km, Lange-Hesse [12]) avec les données de météorologie de l'espace de la NOAA [15] : ovale auroral OVATION (estompé sur la carte), indice Kp des trois derniers jours et vent solaire, téléchargés toutes les 5 minutes dans data/swpc ou immédiatement avec Télécharger NOAA maintenant. Le programme conseille l'orientation des antennes pour les deux stations.
LI|Commandes propres à l'onglet : la case Ovale auroral (NOAA OVATION), activée par défaut, estompe l'ovale sur la carte et l'utilise comme poids dans le choix du scatter point ; Télécharger NOAA maintenant met aussitôt les données à jour. Le cadre Météo spatiale (NOAA SWPC) affiche le graphique du Kp planétaire des 3 derniers jours, toutes les 3 heures, ainsi que l'heure de l'ovale et du dernier téléchargement. Les vues Scatter trail et Iso-réflexion s'utilisent comme pour le F.A.I. (chapitre 6), avec une tolérance de 3°.
LI|Les spots d'aurore de la période choisie dans les filtres de DATA COLLECTION (par défaut les 2 dernières heures, 30 au maximum) sont dessinés sur la carte avec le scatter point calculé (cercle orange) si la case Spots <AU>/<AUR> sur la carte avec le calcul est cochée ; les résultats indiquent le QTF et l'élévation des deux stations.
LI|Les résultats de la vue Scatter trail indiquent la probabilité d'aurore au scatter point (improbable avec Kp ≤ 2 ; pour le reste selon l'ovale NOAA), le QTF typique entre N et NE (S-SE dans l'hémisphère sud) avec l'écart par rapport au trajet direct, et des conseils sur le Doppler et les modes (CW/SSB ou Q65 avec des sous-modes larges : le FT8 ne décode souvent pas). Le scatter point est recherché de préférence dans la fenêtre de Lange-Hesse de chaque station, avec une perpendicularité à ±3° près : 370-1100 km à 54° de latitude géomagnétique, plus proche pour les stations plus au sud et plus lointaine pour celles plus au nord, selon l'inclinaison IGRF-14 (par exemple Capri environ 260-990 km, Oslo 470-1200 km). Les résultats indiquent la fenêtre de chaque station ; si le point proposé est en dehors, le programme le signale.
LI|La probabilité d'aurore au scatter point se décide dans cet ordre : improbable avec Kp ≤ 2, sauf en cas de tempête (Dst ≤ -50 nT) ; dans l'hémisphère sud, probable avec une alerte aurore du BoM ; probable avec Dst ≤ -100 nT et possible avec Dst ≤ -50 nT, si l'ovale au point n'est pas nul ; probable avec l'ovale à partir de 10 % ; possible avec l'ovale à partir de 3 % ou avec Kp ≥ 5 ; sinon improbable.
LI|Les spots d'aurore au-delà de 2000 km sont signalés comme douteux : selon Newton [48], l'aurore porte à environ 1000 km nord-sud et 2000 km est-ouest. Les spots d'aurore-E (AUE, AU-E, AURORAL E) sont dessinés en vert sur le trajet direct : il s'agit d'un E sporadique d'origine aurorale, sans Doppler.
LI|Les résultats indiquent l'heure solaire au scatter point : c'est à moins de 4 heures du minuit local que se produisent la plupart des réflexions aurorales (Reeve [52]). Dans l'hémisphère sud, l'aurore en 50 MHz porte jusqu'à environ 2000 km sur les trajets est-ouest (ANVDG [55]) ; l'aurore-E donne des signaux plus faibles et plus stables sur le trajet direct (SM2CEW-SM0FOB [54]).
LI|En plus du scatter point le plus probable, les résultats indiquent la plage de QTF des deux stations le long de toute la traînée (écart ≤ 1,5°) : l'aurore peut venir de n'importe quel point de la plage, et le point le plus probable privilégie le trajet le plus court.
H2|8.1 BENCHMARK AURORA
P|L'onglet AURORA a deux sous-onglets : REAL-TIME, le calcul décrit ci-dessus, et BENCHMARK AURORA, un banc d'essai du modèle sur 298 QSO d'aurore réels publiés (logs d'EI5FK 2003-2005 et carte du log de PA0O).
LI|Le menu Log choisit un log ou tous ensemble ; l'altitude de départ est de 110 km, avec une tolérance de 3°, la réfraction 4/3 et IGRF-14.
LI|Le tableau indique pour chaque QSO le scatter point calculé, l'écart, le QTF et l'élévation de la station et le QTF du correspondant. Vert : scatter point dans la fenêtre de Lange-Hesse des deux stations ; jaune : expliqué mais hors de cette fenêtre ; orange : QSO au-delà de 2000 km ; rouge : aucun scatter point, QSO non expliqué par le modèle.
LI|La case Altitude km change l'altitude du calcul (de 80 à 160 km) et recalcule tous les QSO. Les colonnes du tableau sont Journée, UTC, Indicatif, WWL, km, Scatter, dev°, QTF et el° de la station du log, QTF corr. (le QTF du correspondant) et Résultat. Le cadre Détails du QSO choisi indique les distances, les pointages, la fenêtre de Lange-Hesse de chaque station et l'écart par rapport au trajet direct.
LI|Le récapitulatif donne les pourcentages, aussi avec la fenêtre fixe 370-1100 km pour comparaison, et, pour chaque log, la plage et la médiane du QTF calculé ; un clic sur une ligne dessine le trajet et les deux pointages et indique la fenêtre de chaque station. Les logs n'indiquent pas le pointage : la comparaison porte sur la géométrie, non sur le QTF.

H1|11. Conseils pratiques
LI|Avant tout, saisir l'indicatif et le locator en haut et appuyer sur Appliquer : toutes les distances, les MUF et les élévations partent de là.
LI|Avec RBN et PSKReporter, garder le filtre local activé pour ne pas remplir la mémoire de spots HF.
LI|Pour analyser une saison passée, utiliser les deux BENCHMARK avec son propre log ; pour l'aurore et le F.A.I., toujours vérifier le point proposé avec la vue Iso-réflexion.
LI|Les calculs sont indicatifs : un spot ou un QSO indique que le trajet était ouvert, pas l'emplacement exact du nuage.
H1|12. Problèmes fréquents
LI|NTP:FAILED : aucun serveur de temps n'a répondu. En général, un pare-feu bloque le port UDP 123 ; le programme continue avec l'horloge du PC et réessaie toutes les 5 minutes.
LI|La session telnet ne se connecte pas ou se ferme aussitôt : vérifier l'hôte, le port et le login (beaucoup de clusters demandent l'indicatif) et qu'aucune autre session ne soit déjà ouverte avec le même indicatif, par exemple depuis un autre programme.
LI|Aucun spot dans SPORADIC-E : vérifier les bandes et la fenêtre de temps choisies, que le filtre local n'écarte pas la bande (il laisse passer de 27990 kHz à 145 MHz) et, en 144 MHz, que le spot ait une confirmation (section 3.4). Le Test des filtres indique comment une ligne du cluster est classée.
LI|Cartes vides au premier démarrage : les côtes et les frontières se téléchargent depuis GitHub la première fois ; il faut le réseau, puis elles restent dans data/mappa.
LI|LoTW refuse l'accès : vérifier le nom d'utilisateur et le mot de passe sur le site de LoTW ; avec de gros logs, le téléchargement peut durer quelques minutes.
LI|La mise à jour automatique ne démarre pas ou échoue : vérifier le réseau et que le dossier du programme soit accessible en écriture. Dans tous les cas, depuis la page de la release, on installe à la main la nouvelle version par-dessus l'ancienne, sans perdre le dossier data.
